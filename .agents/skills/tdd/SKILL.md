name: tdd
description: Test-driven development for the Spacetime Java/Spring, React, and Taro codebase.
---

Read the relevant domain code and `TEAM_STANDARDS.md`, then route test execution through the existing `.agents/skills/code-test` and `.agents/skills/test-suite` instructions. Agree on the public behavior seam, write a failing test, implement the minimum behavior, and repeat by vertical slice. Backend verification should use the repository's Java 21/JDK guidance; frontend verification should use the documented build commands. Do not invent production URLs, tokens, or test accounts.
