name: to-tickets
description: Break a Spacetime design into context-sized implementation slices without bypassing OpenSpec or test workflows.
disable-model-invocation: true
---

Use the settled PRD, technical design, or OpenSpec change. Split by independently verifiable vertical slices across the affected backend, frontend, and miniapp layers. Record dependencies in the existing OpenSpec or project plan instead of assuming GitHub Issues. Each slice must name its test workflow and fit a fresh context window. Preserve separate admin and miniapp ownership.
