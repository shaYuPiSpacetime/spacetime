# 设置安全中心 - 测试用例

创建日期：2026-10-13。依据：已确认的设置安全中心 spec/plan；目标 miniapp，轻量模式。

## 1. 策略

无后端接口变更，L1/L2/L3 不适用。多页面联动：组件行为测试 + 小程序构建注册门禁 + 手动真机路径；浏览器不能代替原生微信预览，不伪造登录数据或设备验收。

## 2. 数据

用户提供 JPG：800×1499、214819 字节，存档后记录 SHA256；上传及公网 GET 字节均需相同。组件测试以真实 TSX 组件执行，Taro 平台 API 作为测试边界。
