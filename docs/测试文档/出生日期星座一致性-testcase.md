# 出生日期星座一致性 - 增量测试用例

## 1. 范围与依据

- 问题：出生日期为 `2003-05-28` 时，页面错误展示数据库历史值“水瓶座”，正确值应为“双子座”。
- 规则：有出生日期时，所有接口统一按公历月日计算星座；仅生日缺失的旧数据允许回退历史 `zodiac` 字段。
- 范围：基础资料、公开主页、推荐资料、关系标签、社区作者资料、管理端列表/详情/导出/导入，以及历史数据迁移。
- 测试级别：L3 单元与静态迁移契约测试；本次不直接执行测试环境或生产数据库迁移。

## 2. L3 测试用例

| ID | 优先级 | 条件与操作 | 预期 |
|---|---|---|---|
| ZODIAC-01 | P1 | 生日 `2003-05-28`，历史星座为“水瓶座”，查询基础资料 | 返回“双子座” |
| ZODIAC-02 | P1 | 同一脏数据查询公开主页 | 返回“双子座” |
| ZODIAC-03 | P1 | 校验十二星座全部起止边界 | 每个日期映射到正确星座 |
| ZODIAC-04 | P1 | 有生日且历史星座冲突 | 忽略历史值，按生日派生 |
| ZODIAC-05 | P2 | 无生日但存在历史星座 | 兼容返回历史值 |
| ZODIAC-06 | P1 | 执行受影响服务既有测试 | 推荐、关系、社区、管理端无回归 |
| ZODIAC-07 | P1 | 检查 107 迁移及生产工作流 | 迁移仅更新有生日且未删除用户；工作流上传并执行迁移 |

| ID | 层级 | 操作与预期 |

| ENV-02 | 数据库 | 发布流程执行 107 迁移后，所有未删除且生日非空用户的 `zodiac` 与生日计算结果一致 |
