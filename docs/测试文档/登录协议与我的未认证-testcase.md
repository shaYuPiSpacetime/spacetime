## 1. 测试策略决策

本次没有新增或修改后端接口，L1/L2/L3 不适用。前端评估如下：

| 条件 | 命中 | 说明 |
| --- | --- | --- |
| G 多角色权限差异 | ❌ | 同一用户仅按准入状态分流 |
| H 复杂交互/状态联动 | ✅ | 协议弹窗涉及原生 Video/CoverView 与普通视图层级切换 |
| I 多页面联动 | ✅ | 登录页、首页未认证节点、我的 Tab 与个人中心共同联动 |
| J 核心业务页面 | ✅ | 登录与“我的”均为高频核心入口 |

**最终策略：静态回归 + 微信小程序 L4 等价运行态自动化 + 生产构建门禁。**
