# 飞书波波 12 项问题测试用例（2026-10-19）

关联计划：`docs/superpowers/plans/2026-10-19-feishu-bobo-12-bugs.md`。

## 策略和数据

- 后端修改报价、锁内确认及扣币规则：使用 JUnit 服务测试和现有 Controller 回归；隔离合成用户/候选，不写生产资产。
- 前端覆盖真实组件/回调及页面显示隐藏生命周期，布局覆盖 320、375、393、414 像素窗口和胶囊零值/异常；微信真机无法自动执行的项目单独记录。
- 上线以既有生产域名只读健康检查、部署来源及包哈希证明交付，不能代替业务真机验收。

## 用例

| 编号 | 对应行 | 场景 | 期望 |
| --- | --- | --- | --- |
| F-01 | 190 | 已登录且缓存首页/其他动态，重新点击直接详情分享卡片 | 打开本次分享动态，旧异步任务不覆盖新目标 |
| F-02 | 190 | 普通前后台切换、未登录分享及旧首页 postId 卡片 | 普通切换不重置页面，登录后恢复目标，兼容旧卡片 |
| F-03 | 192 | 关注/粉丝 → 用户主页拉黑 → 返回；慢旧响应后到 | 对象不再显示，重新读取当前列表，旧响应不恢复对象 |
| F-04 | 219 | 分享单页中确认拉黑，服务端成功但无上页 | 提示已拉黑，正确落地；不误报操作失败 |
| F-05 | 219 | 拉黑接口失败或取消 | 不显示成功，不丢失当前页面，展示实际错误 |
| F-06 | 216 | 自我介绍含超长数字/字母和换行 | 卡片内换行，无水平溢出，原换行保留 |
| F-07 | 217、218 | 有效、零值、抛错胶囊及旧窗口 API | 历史按钮不遮标题，头像不覆盖胶囊，使用对应窗口比例 |
| F-08 | 227 | 我的动态快速多次点击获赞，关闭后切栏目 | 本页仅一个弹窗，不重复入栈；关闭不再打开 |
| F-09 | 229 | 我的认证 → 更新学历 → 返回；无页面栈 | 回真实来源，无栈回资料；不误进认证完成自动跳首页 |
| F-10 | 220、233 | 历史解锁加载两页，滚动后进主页返回 | 已加载列表、游标和偏移保留，不显示全屏加载 |
| F-11 | 220、233 | 历史解锁中拉黑、主动刷新及重复触底 | 拉黑对象移除，主动刷新有效，同一游标不并发重复追加 |
| B-01 | 232、234 | 手动选择 20 / 40 人报价、确认 | 与配置优惠一致，确认扣币、逐人分摊合计一致 |
| B-02 | 232、234 | 单人、重复候选和已解锁候选 | 单人原价；先去重/排除已解锁，按实际人数优惠，不重复收费 |
| B-03 | 232、234 | 报价后配置改变或重复确认 | 旧配置拒绝扣费，重复确认返回原回执且只扣一次 |
| F-12 | 232、234 | 选中批量入口和本页批量入口 | 展示相同后台优惠；单人勾选按实际报价无虚假优惠 |
