## 原因与修改

- 家人动态原来仅记录详情跳转，头像跳转返回进入整页刷新分支。现为详情、头像返回同步目标动态及作者关注状态，保留已加载顺序、分页进度和栏目偏移。
- 知音、话题、理想型、私信列表修复返回重置问题；话题仍同步目标动态的隐藏、关注、点赞状态，理想型保留充值回执处理及主动换批次入口。
- 喜欢我的、访客后台使用原快照同步已加载页，保留游标；权限展示模式变化时使用新响应替换，避免沿用旧身份展示。未显示的新喜欢不自动确认已读。
- 我喜欢的定向核对刚打开的主页，取消喜欢后移除目标；悄悄话定向更新刚处理的申请并迁移分组，保留其他记录和游标。
- 我的动态、互动、浏览记录增加页面内滚动保留；浏览记录保留本次列表的日期分组，防止再次查看后跨组移动。审核重提替换事件及统计更新继续生效。
- 他人主页返回后台刷新动态时不再先替换成加载骨架。推荐、精选、话题目录、搜索和私聊已检查已有加载生命周期，没有套用统一禁止刷新的逻辑。
- 缓存仅属于当前 React 页面实例，不写本地持久化；重新进入新页面重新加载。
