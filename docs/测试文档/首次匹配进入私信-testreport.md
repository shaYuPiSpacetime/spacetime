`npm run build:weapp` 在 prebuild 阶段被 3 条与本次变更无关的既有用例阻塞：

1. 本人动态菜单预期与当前删除能力不一致；
2. 悄悄话会员权益提示文案预期与当前动态配额文案不一致；
3. 热门动态滚动位置测试预期与当前页面实现不一致。

这些失败涉及 `CommunityPostActionSheet`、`CommunityWhisperSheet` 和千寻动态页面，本次未修改这些文件。
