## 4. 原始文件只读诊断

附件 `app-users-200-male-v18.xlsx`，工作表 `App用户导入`，`A1:BT201`，72 列、200 行。

- 真实 XLSX 解码器能读取 201 行，字典、必填和地区层级原有校验未发现格式错误。
- 200 行头像和相册的独立 URL 均超过 500 字符，最长 658；不能靠删除 URL 参数或截断来修复图片。
- 修复后，使用原文件和内存空手机号查找重放真实预校验：200 行均准确返回超长头像地址，不再作为可入库行。无数据库连接、无外部媒体请求。
- 当前 `DEV_DB_*` 所指数据库只读查询：输入的 200 个手机号对应 200 个不同有效用户。模拟该已存在事实时，原逻辑正常返回 200 条“手机号已存在”，不能据此解释截图中的系统异常。
- 47 行年龄与生日不符、188 行星座与生日不符、15 行未成年，另有演示 URL/占位值；仅报告，不修改生日、性别等真实身份资料。
- 新应用模板经相同配置快照和真实预校验代码离线检查：1 行有效、0 行错误。未发送导入接口。
