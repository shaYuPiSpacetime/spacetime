# 推荐实际数量角标 - 测试用例

日期：2026-10-09。范围：小程序推荐候选查询、角标计算与共享状态；后端接口不变。
策略：轻量增量验证，使用 Node 业务单元测试及小程序生产构建；真机联动列为待验。

| 编号 | 场景 | 期望 |
|---|---|---|
| U-01 | 额度10、实际1人；无候选；额度为0；不限制额度 | 分别显示1、0、0、实际人数 |
| U-02 | 多页、空扫描页、重复候选 | 沿游标继续并去重，统计到额度或候选耗尽 |
| U-03 | 额度小于候选数 | 只获取并计数额度内候选 |
| U-04 | 浏览成功、重复浏览、无效候选 | 人数减1；重复和无效动作不重复扣减；空额度仍记录已浏览 |
| U-05 | 多个底栏并发刷新；网络失败 | 合并刷新，失败保留确认过的数字 |
| U-06 | 旧响应、注销、换账号 | 旧响应不覆盖新数字，换账号清零 |
| U-07 | 重复游标、分页偏好/周期变化、分页失败 | 拒绝发布不完整数字 |
| M-01 | 实际候选少于额度，进入推荐并切回千寻 | 角标与实际未浏览人数一致，无候选时隐藏 |
