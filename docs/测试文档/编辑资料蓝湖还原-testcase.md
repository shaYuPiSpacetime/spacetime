# 编辑资料整体蓝湖还原测试用例

更新日期：2026-08-05

## 测试范围

- 编辑资料主页面：导航、评分、真实性提示、主照片、六宫格、基础资料、认证、脱单目标、感情状态、自我介绍、标签、语音、关于我、歌曲、微信。
- 二级页面：基本资料、我的标签、关于我、单题编辑、自我介绍、爱听的歌曲。
- 数据闭环：空态、本人最新填写内容回显、主页预览真实内容显隐、子页面局部更新、语音录制状态、标签连续点击、可选微信号空值失焦。
- 产品约束：编辑页与主页预览继续隐藏 MBTI；关于我主卡固定展示三个指定问题。
