# 安卓小程序底栏白闪回归记录

2026 年 11 月 19 日，基于安卓真机录屏定位问题，使用微信开发者工具的 Nexus 5X 预设复测。构建提交为 `1c4715ec`，上传版本为 `2026.11.19.1218`。

## 录屏定位

上一个预览包的占位布局出现在全白画面之后。首次点击心动、推荐、消息、我的时，录屏中的正文和整个底栏同时消失，白色画面分别持续约 204、134、205、219 毫秒。根据录屏帧时间与旧包的原生页面加载记录，空白发生在微信更换页面到首次绘制之间。旧包遍历五个原生底栏地址时产生五次页面加载。

六个底栏入口现共用一个微信页面，首次展示某个栏目时挂载内容，再次展示时复用已挂载的节点。五个外部可访问的原始地址均保留，详情页使用微信原生导航。

## 操作验证

| 操作 | 观察结果 |
| --- | --- |
| 依次打开心动、推荐、消息、我的，再切回千寻、时空邂逅，并重复切换 | 11 次点击均显示目标面板。操作期间只加载了最初的一个微信底栏页面，运行时异常 0 条。 |
| 首次从千寻进入心动，暂缓目标栏目的绘制 | 微信模拟器内确实有 2 次数据更新待绘制。经过 461 毫秒，原正文仍为 411 × 731，底栏消息按钮仍为 68 × 82 像素。放行后心动正常显示。 |
| 在消息栏打开系统消息，再点返回 | 回到之前选中的消息栏。 |
| 直接打开原有的“我的”地址，再切心动 | “我的”正常显示，点击后在同一微信页面显示心动。 |
| 从“我的”点击“最近来访” | 进入心动的最近访客面板。本地使用空列表数据，页面显示“暂时还没有访客”。 |

模拟器副本使用本机测试数据。发布构建使用项目正常接口配置。用户提供的原始录屏仅用于定位，安卓真机上新版的视觉效果待扫码复验。
