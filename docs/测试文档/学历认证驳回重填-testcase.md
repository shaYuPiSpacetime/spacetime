# 学历认证驳回重填测试用例

日期：2026-10-12；模式：完整；来源：`docs/技术方案/2026-10-12-学历认证驳回重填闭环-tcdesign.md`。

策略：小程序核心表单、状态刷新和材料异步联动命中 L4；纯函数/Hook 行为测试先行。后端不改业务接口，执行既有 L2/L3 契约与新增重提回归。L1/真机需要有效环境、授权 fixture，缺失则记未执行，不伪造用户凭证。

| ID | 优先级 | 输入/操作 | 期望 |
|----|--------|-----------|------|
| E01 | P0 | 驳回快照有学校名但 schoolCode 为空，点击提交 | 学校字段错误；无 POST；可重选真实候选 |
| E02 | P1 | 点选后编辑/清空名称；旧搜索晚返回 | 清编码，旧候选不覆盖新值 |
| E03 | P1 | 搜索失败/无结果 | 保留输入，显示反馈和重试/客服路径 |
| E04 | P1 | CHSI 5/11/19 位、非字母数字、12/18 位字母数字 | 非法值有字段错误；合法格式通过本地校验 |
| E05 | P0 | CHSI 历史记录无学历 | 有学历选择器，补齐后可提审 |
| E06 | P1 | 证书编号/姓名为空或超过 64/50 | 分别定位字段，不 POST |
| E07 | P0 | 上传 0 张；已有4张替换失败/成功；上限降为2 | 缺材料提示；失败保留旧引用；成功只替换一条；上限主动处理 |
| E08 | P1 | 单张预览失败；删除后预览返回 | 表单可用，错误可重试/替换；删除条目不复活 |
| E09 | P0 | 协议不勾选、上传中、快速双击合法提交 | 不合法不提交；合法单页面只提交一次 |
| E10 | P1 | 后台驳回，返回保留认证中心 | 更新状态和原因，显示重填入口 |
| E11 | P1 | 新输入后查看协议/选择图片再返回，旧请求晚返回 | 不覆盖新草稿 |
| E12 | P1 | 服务端已待审核、POST超时但已收单 | 更新资格，不再次提交 |
| E13 | P0 | 授权 fixture 合法驳回重提 | 新建 PENDING 记录；旧历史不变 |
| E14 | P1 | 资格未知/阻断、停用字典、材料401/403 | 不静默放行、不绕过鉴权 |
| E15 | P1 | 长原因、小屏、键盘、成功页 | 无遮挡；定位可见；文案为学历审核 |
| E16 | P1 | 无记录、已通过主动更新、方法切换、推广 | 原行为无回归；专属字段不串用；重审不重复奖励 |

派生脚本：`miniapp/scripts/test-education-verification-retry.cjs`、学历 Hook 行为脚本、现有认证与学校脚本；后端 `VerificationServiceImplTest/VerificationControllerTest/SchoolDictionaryServiceImplTest`。运行命令和实际结果单独写入 testreport，不预填通过。
