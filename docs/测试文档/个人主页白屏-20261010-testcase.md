# 个人主页白屏-20261010 测试用例

依据：点击个人主页均为空白页。排查完整主页及公共组件真实渲染、微信页面加载与分包依赖，不能只检查分享回调或局部照片区。

| ID | 场景 | 预期 |
| --- | --- | --- |
| P-01 | 本人主页预览完整渲染 | 导航、封面、昵称、分享按钮可见，无渲染异常 |
| P-02 | 他人主页完整渲染 | 基础资料及返回操作可见 |
| P-03 | 缺资料、空数组、接口失败 | 显示空态或重试，页面不白屏 |
| P-04 | 微信正式产物打开主页 | 页面注册及依赖加载正常，捕获运行异常 |
| P-05 | 分享与构建回归 | 原有分享、资料相关测试与发布门禁通过 |

补充复现：预览模式下令录音 API 初始化抛错，原实现出现未捕获错误且整页无法挂载（`profile-preview-red.log`）。新增 PREVIEW-01 验证预览不调用录音 API；PREVIEW-02 验证完整资料加载；PREVIEW-03 验证接口失败时保留导航与占位。边界测试验证渲染错误可重试和返回。
