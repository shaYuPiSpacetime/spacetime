# 基础资料地区修复 - 测试用例

创建日期：2026-10-13。模式：轻量增量；目标：miniapp、backend。关联方案：`docs/superpowers/plans/2026-10-13-基础资料地区重选与导入校验.md`。

## 1. 策略

无正式 tcdesign，使用轻量模式；补充 L3 导入及字典单元测试、真实 TSX 组件回调回归、现有认证保存回归、构建门禁。交互涉及省市联动，设计真机验收；没有本账号授权会话时不伪造 token、不自动提交账号资料。

## 2. 数据

单元测试使用明确启用、省市父子关联的上海、天津、浙江树，无外部写入。数据库仅指定 U1010，预期旧省/市为310100/310100；修复须锁行核验身份与字典，重复执行不得再修改。
