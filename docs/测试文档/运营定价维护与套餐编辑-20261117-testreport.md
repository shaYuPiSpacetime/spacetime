## 已确认的问题及修复

1. **未复现后台禁止编辑或保存失败。** 通过生产现有登录会话调用正常配置接口成功保存新套餐；在 Chrome 的生产页面实际执行会员编辑、填写变更原因、确认保存，返回成功并生成配置版本 `COMM-20261117175821`。不能将这次观察写成“修复了服务端保存报错”。
2. **编辑入口容易混淆。** 原页面把只读的当前可支付价也画成输入框，编辑之后还需填写变更原因再确认保存。本次将现价改为明确展示文本，补充新价输入说明、必填原因提示，将编辑按钮改为“下一步：填写变更原因”。
3. **千寻币列表使用可重复币数作为行标识。** 生产两个 500 币套餐产生相同 `COIN-500` React key。运行态已复现重复 key 警告；修复后使用数据库套餐 ID，未保存草稿使用独立前缀，修改币数不再改变行身份。
4. **学期卡周期和月均价显示错误。** 旧小程序将 90～364 天统一显示为 3 个月。实测 150 天、148 元显示为“3个月、¥49.33/月”。现改为按实际周期展示“5个月、¥29.60/月”；年卡仍为“12个月、¥24.83/月”。实际收费和权益发放逻辑未变。

1. 微信商品完成上传、发布及保护期，核对后台申请价已转为当前支付价，任务为已生效。

4. 如需回退套餐目录，通过后台 API 将本次新套餐下架，并按维护前快照恢复原套餐状态；不回滚历史订单、已获会员权益或已到账千寻币。
