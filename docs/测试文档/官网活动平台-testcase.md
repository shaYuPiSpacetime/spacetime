# 官网活动平台 - 测试用例

> 创建日期：2026-09-28
> 依据：官网线下活动平台首期免费报名实施方案
> 策略：L1 接口、L2 路由、L3 业务规则、L4 浏览器流程

## 测试数据

使用两名不同手机号的测试用户和一名具有 `website:*` 权限的管理员。短信验证码从受控测试环境获取；生产环境只使用真实短信，不写入测试账号、验证码或密钥。测试活动需上传图片、填写未来时间、地点和线下预计费用。

## L1 接口

| 用例 | 优先级 | 流程 | 预期 |
| --- | --- | --- | --- |
| F1-P0-01 | P0 | 用户 A 勾选两份协议并用短信注册、登录 | 登录成功，协议版本留痕，未同意被拒绝 |
| F1-P0-02 | P0 | A 上传图片并发布活动，管理员审核 | 审核前公众不可见，审核通过后可浏览 |
| F1-P0-03 | P0 | B 浏览活动并免费报名 | 生成报名记录，不创建支付订单；重复请求只有一条有效报名 |
| F1-P0-04 | P0 | B 向 A 发文字与图片消息 | 文字即时可见；图片审核通过前仅发送者可见，通过后双方可见 |
| F1-P1-05 | P1 | 发帖或发消息含敏感词 | 服务端拒绝写入或送达 |
| F1-P1-06 | P1 | 审核员下架活动、删除聊天消息、处理举报 | 前台隐藏违规内容，审核原因和日志可查询 |
| F1-P3-07 | P3 | 未登录、非会话成员、非所有者访问受保护资源 | 返回 401/403 或业务拒绝，不泄露内容 |
| F1-P1-08 | P1 | 查询登录、发帖、聊天、审核操作日志 | 含操作者、动作、时间及目标，留存期限不早于六个月 |
| F1-P1-09 | P1 | 未登录访客举报公开活动或提交隐私请求并填写回复渠道 | 生成后台可处理的反馈；同 IP 短时重复提交限流；不得查询私聊对象 |

## L2 路由

| 用例 | 验证点 |
| --- | --- |
| L2-01 | 网站公开活动、协议和访客反馈接口无需登录；发布、报名、聊天接口必须登录，访客反馈同源校验 |
| L2-02 | 管理审核、敏感聊天查看和日志导出均声明独立权限 |

## L3 业务规则

| 用例 | 验证点 |
| --- | --- |
| L3-01 | 过去时间、空地点、无图片及负数预计费用拒绝发布 |
| L3-02 | 敏感词拒绝；词库不可用时默认拒绝发帖和文字消息 |
| L3-03 | 非活动相关用户、自己与自己不能创建会话 |
| L3-04 | 审核前图片不能面向其他用户公开；已下架活动不能报名 |

## L4 浏览器

| 用例 | 优先级 | 验证点 |
| --- | --- | --- |
| L4-01 | P0 | 官网首页、关于我们、业务介绍文字一致且无旧婚恋宣传和支付入口 |
| L4-02 | P0 | 两账号完成登录、发帖、审核、报名、私聊、举报闭环 |
| L4-03 | P1 | 手机和桌面宽度下表单、协议、活动卡片、对话框可操作 |
