## 4. 根因与修复

### 4.1 原始文件问题

| 检查项 | 问题 | 修复 |
|--------|------|------|
| 文件前缀 | 文件级 BOM 之外，首列表头内部另有 2 个 BOM 和额外引号 | 规范为单个 UTF-8 BOM，首列为 `登录方式` |
| 资料问答 | 99/99 行 JSON 过度转义 | 统一为可解析 JSON |
| 业务字典 | 行业 82 行、脱单目标 74 行、感情状态 63 行不兼容 | 映射到当前启用字典值 |
| 运行时必填 | 当前配置要求 `residence`，官方 71 列模板没有该字段 | 最终文件增加 `residence`，取已有现居城市 |
| 地区字典 | 2 行“平城区”不在当前大同市旧版地区字典 | 区县为可选字段，保留省市并将区县留空 |
| 当前库重复 | 99 个手机号中已有 13 个 | 生成 86 行当前库可导入版，避免部分成功 |

### 4.2 XLSX 解析缺陷

Artifact Tool 导出的标准 XLSX 使用命名空间前缀（如 `<x:row>`、`<x:c>`），原控制器只按无前缀标签查找，导致读取内容为空。控制器改为启用 namespace-aware XML 解析，并按 local name 查找 `si/row/c/is/v`。
