# 系统管理全功能体验 - 测试用例

> **测试日期**：2026-07-22
> **测试级别**：L4 真实浏览器全功能体验 + L1/L2/L3 回归
> **被测范围**：登录/退出、用户管理、角色管理、菜单管理、字典类型、字典数据、跨页面 RBAC 权限闭环
> **数据约束**：只新增、修改和删除本轮 `codex_e2e_` 前缀临时数据；不修改 peter 或既有业务数据
> **环境约束**：本地最新前端通过 Vite 代理连接真实后台 API；账号密码只从运行时环境变量读取

---

## 1. 验收口径

1. 所有页面操作必须由真实浏览器触发，接口脚本不能替代页面操作。
2. “新增/编辑/分配/启停/重置密码/删除”必须提交并重新查询验证，打开后取消不算通过。
3. 分页必须同时核对选择器状态、请求参数、页码重置和表格结果。
4. 权限必须通过“建角色 → 分菜单 → 建用户 → 分角色 → 临时用户登录 → 回收权限 → 再登录”验证。
5. 必填校验、重复数据、错误密码、无权限访问等失败场景必须给出明确反馈，不能静默无响应。
6. 测试结束必须删除临时用户、角色、菜单和字典数据；自动化中途失败也必须兜底清理。

## 2. 测试数据

| 数据 | 规则 | 用途 |
|---|---|---|
| 管理员 | 运行时环境变量 `ADMIN_USERNAME` / `ADMIN_PASSWORD` | 完整操作权限 |
| 临时用户 | `codex_e2e_user_{时间戳}` | 用户 CRUD、登录、权限验证 |
| 临时角色 | `codex_e2e_role_{时间戳}` | 角色 CRUD、菜单绑定 |
| 临时菜单 | `codex_e2e_menu_{时间戳}` 目录/页面/按钮三级树 | 菜单 CRUD、级联删除 |
| 临时字典 | `codex_e2e_dict_{时间戳}` | 类型 CRUD、编码迁移、级联删除 |
| 临时字典数据 | `codex_e2e_data_{时间戳}` 根/子/孙三级树 | 数据 CRUD、树交互、级联删除 |

## 5. 通过标准

- P0 用例必须 100% 通过，不允许跳过。
- P1 用例不允许出现影响正常操作、数据一致性或安全性的缺陷。
- 每个失败必须有复现证据、根因、修复提交和修复后重跑证据。
- 浏览器真实操作、自动化结果、接口残留核对与构建/单测结果全部写入独立测试报告。
