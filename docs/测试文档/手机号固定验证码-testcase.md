# 手机号固定验证码 - 测试用例

- 日期：2026-10-09
- 依据：用户确认所有环境的小程序手机号登录验证码暂时固定为 `0000`。
- 模式：轻量；L3 登录服务回归与静态闭环校验。线上 L1 仅使用已确认的环境及测试账号。
- 保留获取验证码、后台频控、有效期、协议同意、账号校验和成功后消费验证码。

| ID | 优先级 | 场景 | 期望 |
|----|--------|------|------|
| L3-01 | P0 | 获取验证码 | Redis 写入 `0000`，返回 `FIXED`，不调用短信网关 |
| L3-02 | P0 | 获取后提交 `0000` | 登录成功并删除验证码 |
| L3-03 | P1 | 提交其他验证码 | 拒绝登录，不查询账号 |
| L3-04 | P1 | 未获取、过期或已消费后提交 `0000` | 拒绝登录 |
| L3-05 | P1 | Redis 残留旧随机码且提交该旧码 | 拒绝登录，要求重新获取 |
| L3-06 | P1 | 后台配置倒计时、有效期及每日次数 | 固定码仍遵循配置 |
| L3-07 | P1 | 登录账号处理失败 | 不提前删除验证码 |
| L3-08 | P1 | 获取验证码后连续两次登录 | 首次成功，第二次拒绝 |
| STATIC-01 | P1 | 阿里云短信静态闭环 | 固定验证码模式校验通过 |
| L1-01 | P0 | 部署后获取验证码 | 生产 API 返回 `providerCode=FIXED` |

派生测试：`backend/src/test/java/com/spacetime/miniapp/service/AuthMiniappServiceImplTest.java`。
