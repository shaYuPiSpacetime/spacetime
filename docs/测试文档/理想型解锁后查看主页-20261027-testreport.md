# 理想型解锁后查看主页修复记录

## 原因

后端结果接口先过滤已拥有有效解锁权益的候选，剩余结果又统一构造成未解锁卡片。因此解锁后重新加载时，原卡片被移出，前端已有的“查看主页”分支无法显示。前端还只依赖刷新结果，没有立即应用成功回执；刷新失败会保留原付费入口。

## 修改

- 当前快照保留已解锁候选及原排序，结果总人数不因解锁减少；待解锁人数仍排除有效解锁对象。
- 已解锁卡片通过统一公开资料服务读取审核通过的头像及资料，继续执行权益、账号和双向拉黑校验。
- 成功回执立即将原卡片改为已解锁，当前页刷新补齐批量解锁的公开资料；列表不重置滚动位置、不自动跳转。
- 按钮显示“查看主页”，点击后进入对应用户的统一主页，携带 `sourceScene=ideal`；资料暂缺时也不会重新触发解锁报价。
- 新增“重新加载”入口；刷新失败保留已确认权益。已解锁对象退出勾选和报价集合。
- 页面规格同步本次交互口径。新增定向回归加入开发和发布构建门禁。
