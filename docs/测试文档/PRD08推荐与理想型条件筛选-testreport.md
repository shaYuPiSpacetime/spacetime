## 4. 缺陷回归

| 缺陷 | 根因 | 结果 |
|---|---|---|
| 地址类型混入滚轮第一列 | 将“中国/海外”误作 PickerView 数据列 | 改为独立 Tab，滚轮只保留省/市两列 |
| 地址选中行没有文字 | 原生 `indicatorStyle` 不透明背景盖住文字 | 使用下层选中背景 + 上层透明原生滚轮，微信截图已显示“江苏省/南京市” |
| 理想型首卡被裁剪 | 负边距越过原生 ScrollView 顶边 | 改为固定滚动视口起点，首卡头像和标题完整 |
| 结果标签只能显示一行 | 卡片高度不足 | 卡片最小高度调整为 468rpx，支持两行命中条件 |
| 推荐聚合入口缺少图标 | 入口与会员横幅只保留文字/装饰 | 补齐悄悄话、同城和会员徽章真实图标 |
| 帮助页价格写死 | 客户端使用设计样例价格 | 改为后端动态单价、折扣和保留期 |
| 历史只回当前资料 | 未读取快照候选的不可变命中条件 | 历史记录改为读取快照候选摘要 |
