# 注销成功后关系失效测试用例

用户确认规则：提交注销只是记录申请；只有正式注销成功才执行关系失效。冷静期账号保持原状态，撤销只结束申请。旧版 CANCELLING 撤销兼容恢复 NORMAL，不覆盖冻结状态。

## L3 业务回归

1. 提交保存原因、快照、冷静期和审计，不更新账号、不使关系失效、不发布账号状态改变通知。
2. 重复申请返回现有申请，不改账号或关系。
3. 撤销 NORMAL 账号只更新申请；旧版 CANCELLING 可恢复；FROZEN 不解除冻结。
4. 到期且无阻断：账号 CANCELLED、关系失效、申请终态、审计在同一事务中提交。
5. 到期有阻断：安排重试，不改账号和关系。
6. 到期执行重新加锁读取申请；若已撤销、已完成或尚未到期，不注销。
7. 正式注销写入失败时事务回滚，另起事务只记录重试，不留下半完成关系状态。
8. 后台切换 CANCELLING 不失效关系；CANCELLED 仍失效。
9. 消息补偿仅处理冻结/最终注销，旧版冷静期不会被补偿任务失效。

## 执行边界

执行目标 JUnit/Mockito、Mapper 合约测试。L1/L4 缺少可用的独立测试账号会话，跳过生产注销测试，不再次对真实账号发起注销。发布前按 master 同步、当前源码构建和体验版上传流程；核对后端自动部署及健康检查。
