# 学历拍照选择闪烁 - 测试用例

> **关联报告**：`docs/测试文档/学历拍照选择闪烁-20261019-testreport.md`
> **创建日期**：2026-10-19
> **测试模式**：轻量模式
> **目标项目**：小程序 `miniapp/`

## 1. 测试策略

本次仅调整学历证明材料的媒体选择与上传状态切换时机，不改变上传接口、材料数量和提交流程。使用 Hook 单元测试覆盖原生选择层等待、取消、重复点击和真实上传状态，并执行认证流程回归门禁。

## 2. 自动化用例

| 用例 ID | 优先级 | 场景 | 期望结果 |
| --- | --- | --- | --- |
| EDU-CAMERA-P0-01 | P0 | 打开“拍照/从手机相册选择”原生选择层 | 页面底层保持原样，不提前切换“上传中”状态，不产生明暗闪烁 |
| EDU-CAMERA-P1-02 | P1 | 原生选择层未结束时连续触发 | 只发起一次选择任务，不重复弹出选择层 |
| EDU-CAMERA-P1-03 | P1 | 用户选好图片并开始网络上传 | 原生选择层关闭后才展示“上传中”，上传完成后恢复 |
| EDU-CAMERA-P1-04 | P1 | 用户取消拍照或相册选择 | 页面状态和已有材料保持不变，不展示上传错误 |

## 3. 执行方式

```powershell
cd miniapp
node --test scripts/test-education-verification-hook.cjs
node --test scripts/test-verification-onboarding-flow.cjs
```

## 4. 真机复核

在学历认证的在校学生与上传证书页面分别点击上传材料，观察原生“拍照/从手机相册选择”弹层出现及取消过程；底层页面不得提前变暗、显示“上传中”或重复弹层。选中照片返回后才允许展示真实上传状态。
