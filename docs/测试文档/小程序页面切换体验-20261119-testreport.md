# 小程序页面切换体验验收记录

2026 年 11 月 19 日，微信开发者工具已上传版本 `2026.11.19.1108`。构建对应 `master` 提交 `9cda55ee`。本次发布范围为体验构建。

## 切换场景

| 场景 | 原因 | 已验证的行为 |
| --- | --- | --- |
| 切回对我心动、最近访客 | 原逻辑用记录条数判断是否加载过，已查到的空结果会再次进入加载状态 | 后台刷新时保留空列表，新记录到达后正常显示。已翻页的记录与访问权限仍按最新回复更新 |
| 千寻与时空邂逅往返 | 两个底栏入口共用一个原生页面，切换时销毁了时空邂逅的栏目状态 | 返回时空站台保留选中栏目、已加载数据和阅读位置。千寻翻到第二页后离开超过一分钟，返回仍能看到原动态 |
| 推荐、认证引导、消息的首次与再次显示 | 返回时可能显示上次的理想型面板、整页骨架或尚未确认的空提示 | 点击底部推荐先显示推荐面板，从理想型详情返回保留原面板。认证引导后台刷新时保留内容，消息首次请求期间显示加载状态 |
| 连点动态、进入下一页后继续点击 | 连点可发出两次入栈，上一页迟到的回调可能干扰下一页 | 同一次连点只打开第一条动态，返回后可以打开下一条。新页面上的操作可以先于上一页的微信回调执行 |
| 认证、搜索与系统消息 | 6 处返回兜底把首页当作普通页面打开，系统消息也用同一种方式打开所有目标 | 有上一页时返回原页，单页入口或返回失败时切到首页。系统消息能分别打开「我的」「心动」「消息」和普通二级页，访客入口保留目标栏目 |
| 搜索分类 | 旧请求在途时会拦下新分类请求，重复点当前分类又会清空结果 | 接口逆序返回只展示当前分类结果，重复点当前分类保留现有列表 |
