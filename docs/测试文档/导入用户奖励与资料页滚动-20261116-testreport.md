# 导入用户奖励与资料页滚动修复验证

日期：2026-11-16。范围：后台用户导入与奖励、小程序基本资料及头像认证页。

## 问题与修复

1. 后台导入只写入用户资料，没有建立资产账户；奖励接口遇到历史导入用户即拒绝。新导入在同一事务内初始化零余额、未开通会员的资产账户；历史用户在发奖前按既有 `user_id` 唯一键幂等补建，再锁行处理奖励。已有余额、会员期限和充值总额不会被初始化覆盖，原奖励回执与重复请求校验继续生效。
2. 认证基本资料卡使用绝对定位，字段增加时不能撑开滚动内容。职场人有 12 行，婚姻状况在底部被固定按钮遮挡。改为正常文档流，保持原始卡片起点，并保留底部操作区留白。
3. 资料编辑页滚动区固定减去 `164rpx`，导航栏实际高度随机型变化；模拟 44px 状态栏时整页比视口多 12px，形成额外外层滚动。改为导航栏下方自适应的单一滚动区。
4. 同类检查发现两处弹层导致位置不稳定：资料弹层隐藏保存按钮时删除了占位；头像弹层打开时把 `ScrollView` 替换成普通容器。分别改为隐藏但保留按钮占位，以及始终保留头像页滚动容器。认证基本资料弹层也保持原有底部留白。

本轮无数据库结构变更、批量补数或生产数据操作。
