## 覆盖接口与场景

- 登录：微信登录、手机号兜底登录、协议勾选、Token、首登状态、准入状态。
- 首登资料：初始化状态、分步保存、完成首登、资料缺失与地区限制。
- 资料维护：基础资料、扩展资料、家乡/现居地、身高体重、职业收入、脱单目标、感情状态、标签、歌曲、微信号。
- 内容提交：头像、相册、背景图、自我介绍、关于我、语音介绍独立接口，覆盖审核中、通过、驳回、失败。
- 三重认证：头像、实名、学历，覆盖材料、错误码、核心准入联动。
- 准入与配置：核心能力开关、阻断原因、字段配置、上传限制、地区范围、审核策略、文案配置。

## 禁用旧口径

- 新小程序不接入 `PATCH /miniapp/profile`、`/miniapp/profile/media`、`/miniapp/profile/open-text`，全部使用 handoff 文档列出的独立接口。
- 移动端不实现前端页面，本矩阵只证明后端接口、出入参、状态码和对接文档对齐。
