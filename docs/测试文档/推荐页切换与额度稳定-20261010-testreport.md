# 推荐页切换与额度稳定 - 测试报告

日期：2026-10-10。用例来源：同目录 `推荐页切换与额度稳定-20261010-testcase.md`。

## 修复及根因

- 原推荐耗尽后调用导航打开独立等待页，切理想型再 switchTab 返回，造成整页切换。现在主路由常驻，等待内容、推荐卡片和理想型仅切内容显隐。
- 旧角标可被后台刷新加回：在原 master 代码上复现 17 → 20；分页过程中实际额度从 2 降到 1 时旧收集器仍返回 2。现在同周期同偏好不反弹，分页额度变化拒绝发布混合数据。
- 曝光 nextTick 前切到理想型或隐藏页面时，原代码仍提交 view。现在取消未形成有效曝光的动作，重新显示后可以正常曝光。
- 额度按不同候选去重，每日北京时间中午 12 点重置。新增数据库用户行锁，在事务第一次普通读取之前串行化同账号浏览；保护多设备和多实例并发的最后一个额度。
- 底部普通/选中图标改为常驻、互斥显示，避免切换 src 的加载闪烁。同步了相互矛盾的图标门禁，并使既有社区门禁识别分页参数、举报条件绑定和带序列保护的导航回调；没有放宽业务权限。
