# 电脑端录音上传格式修复记录

日期：2026-11-17

## 问题与修复

用户反馈电脑端语音介绍录制完成后提示“文件格式不支持，请按页面上传要求重新选择”。原实现直接取临时路径末段作为票据文件名，服务端按扩展名校验；无后缀或 `.tmp` 路径会导致实际 MP3 也被拒绝。通过实际 `prd01Api.uploadVoice` 调用链及模拟票据接口复现了相同错误。

本次仅修改小程序语音上传：读取文件前 64 字节，识别实际 MP3、AAC、WAV、M4A 格式，使用对应扩展名申请票据，仍上传原始文件。未知格式、空文件和读取失败不申请票据。后台格式配置和原有内容审核不变，未修改数据库。

线上配置只读核对：语音允许 MP3、单文件 20 MB、10–60 秒。识别出的其他格式仍须通过后台校验，不能伪装 MP3 绕过规则。

## 验证

- 修改前：无后缀 MP3 调用链复现同款格式错误。
- 修改后：语音上传、资料编辑、语音审核恢复和删除弹窗，共 70 项通过。
- 覆盖无扩展名、`.tmp`、Windows 路径、手机 MP3、无 ID3 的 MPEG 帧、AAC/M4A 区分、WAV 配置限制、损坏文件、空文件和读取失败。
- 本机 FFmpeg 生成的真实 MP3 样本识别通过，未使用用户音频。
- 新增回归用例纳入现有资料编辑构建检查。

## 验证边界

尚未取得截图设备的原始录音文件及具体运行端确认，因此当前证据能确认临时文件名误判这一缺陷，不能将其当作用户现场唯一原因。尝试使用独立微信开发者工具项目核对原生录音，自动化连接返回 `Cannot read properties of undefined (reading 'split')`，未能执行录音；未计为电脑微信或手机实机验证通过。
