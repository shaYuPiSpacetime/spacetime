# 腾讯地图逆地址解析接入说明

小程序以 GCJ-02 坐标获取用户位置，调用已登录接口 `POST /miniapp/location/reverse-geocode`，JSON 请求体为 `{ "latitude": 纬度, "longitude": 经度 }`。经纬度不放在 URL 查询参数中，避免被常见网关访问日志记录。后端代为请求腾讯地图 WebService，成功时仅返回 `data.province` 和 `data.city` 两个中文名称；小程序再从已有省市字典选中对应地区。接口不向客户端传递地图密钥。

## 部署配置

1. 在腾讯地图控制台为所用 Key 开通 **WebService 服务端调用权限**。腾讯官方说明：WebService 的「域名白名单」用于浏览器端 JSONP 调用，留空才不限制域名；后端请求没有网页来源，只填写小程序 AppID 或网页域名仍可能返回 `status=110`。建议另建服务端 Key，域名白名单留空，并用「授权 IP」限制生产服务器出口 IP；本机验收也需允许本机出口 IP。参见[腾讯位置服务 WebService Key 配置说明](https://lbs.qq.com/faq/serverFaq/webServiceKey)。
2. 在后端运行环境配置 `TENCENT_MAP_KEY`，不要把 Key 写入 Git、前端代码、构建产物或日志。可选超时变量为 `TENCENT_MAP_CONNECT_TIMEOUT_MILLIS`（默认 3000）和 `TENCENT_MAP_REQUEST_TIMEOUT_MILLIS`（默认 5000）。修改环境变量后重启后端进程。
3. 使用已登录的小程序请求接口确认返回 `code=200` 且 `data` 包含实际省市，例如上海坐标应对应 `province=上海市`、`city=上海市`。若未配置或第三方失败，接口返回可读中文提示，小程序允许手动选城市。

新接口位于 `/miniapp/**` 登录鉴权范围，不在 `WebConfig` 的公开接口放行列表中。不要通过伪造 `Referer` 等方式绕过腾讯地图来源校验；应在控制台修正授权范围。
