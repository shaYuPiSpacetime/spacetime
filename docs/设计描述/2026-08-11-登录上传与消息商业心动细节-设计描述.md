# 登录、动态上传与三处 UI 细节设计描述

## 1. 范围

本次只处理以下五项，不改变业务入口、底部导航或接口字段：

1. 手机号/微信手机号登录点击后存在明显等待。
2. 发布动态照片上传被统一提示为“网络不稳定”。
3. 消息首页“私信”复合插画位置不符合蓝湖切图基线。
4. 千寻币“充值须知”弹窗位置偏下。
5. 心动页右上“相互喜欢”图标与微信原生胶囊重叠。

## 3. 运行时映射

### 3.1 登录

- 点击后立即进入单一 in-flight 状态，重复点击不得重复发起请求。
- 推广归因最多占用 150ms 登录关键路径；超时后归因继续后台完成。
- 登录接口已返回 `firstLoginCompleted` 和 `nextStep`，优先直接导航。
- 只有返回缺失或非法 `nextStep` 时，才回退查询 `/miniapp/profile/init-status`。

### 3.2 发布动态照片

- 选择结果立即进入队列并展示上传态。
- 全局单批串行上传，选择流程等待当前批次结束，避免多个并发池叠加。
- 单次 OSS 直传超时 20 秒；临时网络错误按 300ms、1000ms 自动重试两次。
- 每次重试重新申请短时票据，不复用可能过期的签名。
- 域名未配置、格式、大小、签名或权限错误不盲目重试，并展示准确原因。
- 页面仍不展示“重新上传”按钮。

### 3.3 消息首页私信插画

- 继续使用现有无损 OSS 资源 `messageHomePrivateBubbleArt`。
- 卡片保持 340×158rpx，插画保持 111×140rpx、right=0。
- 恢复相对卡片顶部 `top=18rpx`，使裁切底边与卡片底边对齐。

### 3.4 充值须知弹窗

- 遮罩固定铺满窗口。
- 卡片使用明确绝对定位，不参与 Flex 剩余空间二次居中。
- 恢复蓝湖原始 620×538rpx、正文 24/40rpx 和 282rpx 高度。

### 3.5 心动右上图标

- 从 `getMenuButtonBoundingClientRect` 的换算结果读取 `menuLeft`。
- 图标横坐标为 `menuLeft - width - 12rpx`，并设置最小左边界避免侵入标题。
- 不再使用仅适用于单一机型的固定 `left:506rpx`。

## 4. 验收标准

- 登录响应有效时，导航前不再请求 `init-status`。
- 推广接口长期 pending 时，150ms 后登录请求可继续。
- 临时网络错误第三次上传成功；域名/签名错误只尝试一次。
- 充值须知运行态卡片坐标与蓝湖基线一致。
- 心动图标代码与运行态均依赖真实胶囊边界。
- 消息私信插画保留 18rpx 源裁切偏移。
