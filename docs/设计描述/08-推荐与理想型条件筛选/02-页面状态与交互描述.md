# PRD-08 页面状态与交互描述

## 1. 总体状态流

```text
推荐入口
  ├─ 资料/认证不满足 -> 完善资料或三重认证提示
  ├─ 有候选 -> 推荐候选首屏 -> 共用用户主页
  │                         ├─ 未解锁：悄悄话
  │                         └─ 已解锁：私信
  ├─ 无候选 -> 暂时还没有推荐
  └─ 达到每日上限 -> 等待聚合页 -> 三天回看/理想型/会员/社区

理想型入口
  -> 选择理想型
  -> 17 条件筛选
  -> 生成不可变快照
  -> 结果列表
       ├─ 单个解锁
       ├─ 解锁全部（服务端优惠报价）
       ├─ 余额不足 -> 千寻币充值 -> 回到原报价
       └─ 历史解锁 -> 共用用户主页
```

## 2. 批次 A：推荐候选与共用主页

### 001/003 公开主页完整长页

- 顶部保持推荐/理想型双 Tab、历史回看与偏好图标；主体从人物大图开始。
- 人物大图右上为分享按钮；头像、昵称、三重认证和交友状态压在图片底部。
- 白色基础资料卡展示性别、年龄、身高、星座、现居地和家乡。
- 后续模块依次为标签、自我介绍、认证、个人问答/歌曲/理想型/恋爱观/空闲活动、生活照、个人动态、IP 所属地、举报/屏蔽。
- 001 对未填内容显示可点击的完善/占位说明；003 对已填内容回显真实文案。生产共用组件遵循用户最新口径：没有填写的整个模块不显示，不能在公开主页保留空白占位卡；本人编辑预览可按编辑态提示完善。
- 固定操作区：左侧跳过/关闭，中间为沟通主按钮，右侧为心动。`communicationMode=WHISPER` 时文案“悄悄话”，`PRIVATE` 时文案“私信”。

### 002 推荐候选首屏

- 375×812 首屏从顶部 Tab 到标签卡；底部半透明渐隐上方浮动操作区，下面是自定义 Tab。
- 点击人物主体进入共用主页；点击认证徽章打开 006；点击 IP 说明打开 004。
- 点击跳过写浏览/跳过日志并切下一人；心动使用真实关系接口并防重复提交。

### 004 IP 所属地说明

- 全屏 `rgba(0,0,0,.6)` 遮罩，居中 520rpx 左右白卡、32rpx 圆角。
- 标题、两行说明和单个蓝色“知道了”按钮均为真实文本/按钮；点击遮罩不默认关闭，点击按钮关闭。

### 005 推荐空态

- 保留顶部双 Tab、历史和偏好图标及底部 Tab。
- 空状态插画垂直位于内容区中上部，文案“暂时还没有推荐”。
- 不显示“重新加载”按钮；下拉刷新或重新进入页面才触发重新请求。

### 006 三重认证底部面板

- 背景为推荐首屏的暗化态，白色面板从头像卡下沿起覆盖至底部。
- 面板顶部显示头像、昵称、已通过数量和总可信度；头像、实名、学历三行分别显示图标、认证方式、可信度。
- 底部声明和“我知道了”真实按钮；学历/学校文案来自审核通过数据。

## 3. 批次 B：每日上限与会员

### 007 每日推荐达到上限

- 顶部与推荐页一致；首卡强调“每日12点准时推荐”和“查看往日推荐”。
- 下方依次为理想型搜索入口、悄悄话、同城推荐、会员权益横幅、千寻动态卡片。
- 所有入口必须可点击并路由到真实页面，不能是纯视觉占位。
- “每日12点”是设计文案，实际下一次可用时间由服务端返回，避免客户端时区计算漂移。

### 008 会员中心

- 黑金主题，顶部返回、标题、原生胶囊；用户权益横幅、横向套餐卡、权益列表自然滚动。
- 底部白色支付区固定：当前价、周期、立即开通、协议勾选；必须预留安全区。
- 套餐、折扣、权益数字和支付金额均来自商业化接口，设计数值仅用于基线。

## 4. 批次 C：三天回看

### 009 普通用户门禁

- 标准白底导航；黑金权益卡包含返回图形、主标题、说明和“立即开通”。
- 立即开通进入会员中心并携带来源场景 `recommend_replay`。

### 010 会员回看列表

- 按自然日降序分组，日期左侧蓝色竖条，右侧显示推荐数和跳过数。
- 候选行显示真实头像、昵称、年龄/城市/职业及“查看”按钮。
- 无数据日期显示“这一天你没来，无推荐嘉宾”；底部说明仅展示最近三天。
- 日期和数量由接口返回，禁止写死 2026-08-02 等设计数据。

## 5. 批次 D：推荐偏好

### 011/012 普通与会员状态

- 统一表单组件：居住地偏好最多 3 城市、允许周边城市开关、年龄双端滑杆、仅认证用户开关、高级筛选区和保存按钮。
- 普通用户可编辑基础项，高级项展示会员标识并锁定；会员状态可选择第三城市、身高、体重、学历和家乡。
- 选择城市/家乡使用真实选择器；年龄、身高、体重使用可滑动的双端范围组件。
- 保存期间按钮禁用，失败时保留输入并显示服务端中文错误；成功后返回上页并刷新候选池。
- 蓝湖文案“默认有限推荐现居地城市用户”存在错字，生产文案采用“默认优先推荐现居地城市用户”。

## 6. 批次 E：理想型入口与筛选

### 013 理想型默认态

- 星空人物背景全屏铺设，顶部推荐/理想型双 Tab 和历史图标为白色。
- 大标题“精准筛选理想型”、副标题“一只邂逅你想要的人”、白色大按钮“选择理想型”。
- 底部自定义 Tab 仍为白底，推荐中心浮动按钮为蓝色。

### 014/015 筛选页

- 星空横幅保留返回和标题“选择你的理想型”；下方白底自然滚动。
- 基础筛选为地址和年龄两个描边胶囊；17 个固定条件按分组显示，选中为主蓝底白字，未选为 `#F8F9FB` 深蓝字。
- 17 条件分组：外在颜值 2、教育背景 4、经济实力 3、家庭背景 3、兴趣爱好 5；最后另有感情观相合、想2年内结婚，总数按正式 PRD 稳定 code 复核。
- “选好了”按钮必须至少选择一个条件后可提交；提交生成服务端快照，不能仅在本地筛列表。

### 016 地址面板

- 页面背景暗化，底部白色 32rpx 顶圆角面板。
- 标题“地址”，三列滚轮分别表示中国/海外、省/地区、市；中间选中行使用浅蓝背景。
- “确定”保存临时选择并关闭，不直接生成快照。

### 017 年龄面板

- 页面背景暗化，底部白色面板；标题“选择年龄”。
- 一行显示“年龄”和当前范围，双端滑杆支持连续拖动；确定后同步基础筛选胶囊。

## 7. 批次 F：理想型结果、充值和历史

### 018/019 结果列表

- 星空头部保留双 Tab 和历史图标，候选卡覆盖在背景下缘并自然向下滚动。
- 卡片显示服务端允许公开的城市、年龄、学历、学校状态和命中标签。未解锁头像必须由服务端提供脱敏图，客户端不能拿原图后模糊。
- 已解锁卡显示清晰头像和“查看主页”；未解锁卡显示“解锁ta”。
- 长页底部提供“换一批”“活动说明”、筛选浮动按钮和“解锁全部”主按钮。
- 解锁全部旁展示后端报价中的 `优惠X%`；客户端只展示 `originalPrice/payablePrice/discountPercent`，不自行计算。

### 020 理想型充值

- 顶部“千寻币”，中部脱敏头像组合和“立即解锁理想型”；显示本次消耗和余额。
- 套餐横向滚动，选中卡蓝色描边/浅蓝底，折扣和推荐角标来自接口。
- 底部固定“立即充值”和协议勾选。支付成功后携带原 quoteNo 回到确认流程，取消支付不生成解锁记录。

### 021/022 历史解锁

- 正常卡使用浅蓝渐变，展示清晰头像、基础资料、命中标签、解锁时间和“查看主页”。
- 用户不可用时卡片改浅灰并显示“用户已注销”，不可点击主页。
- 空态使用独立饼图插画和“暂无数据”，不显示重新加载按钮。

### 023 帮助中心

- 标准白底导航，标题“帮助中心”；正文标题“什么是理想型？”。
- 正文说明至少选一个条件、结果字段、单价/批量优惠、历史保留时间。
- 单价、优惠和保留天数属于动态商业化配置，页面加载后由接口插值，不能硬编码“200千寻币/位、9折、90天”。

## 8. 跨页面异常态

| 异常 | 页面表现 | 恢复方式 |
|---|---|---|
| 资料未完善 | 服务端返回门禁码，跳转/弹出完善资料入口 | 完成资料后重新请求推荐 home |
| 三重认证未完成 | 三重认证提示或认证流程入口 | 审核通过后刷新 |
| 候选为空 | 005 空态 | 下拉刷新/重新进入，不显示额外重试按钮 |
| 每日上限 | 007 聚合等待页 | 服务端 nextAvailableAt 到达后刷新 |
| 非会员访问高级能力 | 008/009/011 会员门禁 | 支付成功后回跳来源页 |
| 报价过期 | 固定操作区提示重新报价 | 原选择和快照保留 |
| 余额不足 | 020 理想型充值 | 成功后回到原 quoteNo |
| 候选失效/注销 | 结果剔除或 021 注销态 | 不扣费、不允许进入主页 |
| 网络失败 | 页面内轻量错误态/Toast | 用户下拉刷新；不替换为空数据 |
