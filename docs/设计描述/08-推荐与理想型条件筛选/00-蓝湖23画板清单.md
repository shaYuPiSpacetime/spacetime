## 4. 已确认的设计缺口

1. 23 稿没有独立的“理想型筛选记录列表”视觉稿，只有“什么是理想型？”帮助说明页；实现 `/pages/ideal/records/index` 时先复用历史列表信息结构，但不得将其纳入 23 稿 1:1 评分。
2. 001、003 是完整公开主页长图，002 是同一主页的首屏裁切/推荐入口状态；生产代码必须共享主体组件，不能做三套重复页面。
3. 008 在蓝湖项目中存在另一个同名同图画板，正式清单选用推荐分组子画板 `009c7591...`，避免重复计数。
4. 蓝湖生成稿绘制了状态栏和微信胶囊；运行时必须使用微信原生胶囊和系统状态栏，不得自绘。视觉验收以原生位置和安全区对齐为准。
5. 016 的地址面板展示“中国/海外—省—市”三列；这是理想型筛选，不等于此前“家乡两级”口径。后端需要分别维护筛选地址三列数据与用户家乡两级数据。
