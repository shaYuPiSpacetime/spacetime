## 2. 素材进入生产代码的规则

1. 原始切图只存档在验收证据目录，不直接复制进小程序包。
2. 非底部 Tab 静态图标必须无损上传 OSS，再由 `miniapp/src/constants/ossIcons.ts` 引用。
3. 上传前不得压缩、转换、缩放、裁切或添加 CDN 图片处理参数；若 OSS 返回 `AccessDenied`，立即停止替换并修复最小权限。
4. 底部 Tab 图标继续复用项目包内资源，不和 OSS 版本混用。
5. 人物照片是设计样例，不作为生产固定素材；候选头像、主页照片必须来自审核通过的真实用户数据。
6. 星空人物背景和会员横幅属于非交互背景，可以使用独立图片；按钮、标题、价格、协议、标签和导航必须由真实组件绘制。

## 3. 当前缺口与处理口径

| 编号 | 缺口/冲突 | 影响 | 当前处理 |
|---|---|---|---|
| GAP-01 | 没有独立“理想型筛选记录列表”视觉稿 | `/pages/ideal/records/index` 无法做严格 1:1 | 不计入 23 稿评分；先复用历史列表 Token，等待补稿后单页闭环 |
| GAP-02 | 帮助中心写死 200币/位、9折、90天 | 与新增后台折扣比例和动态价格冲突 | 结构按稿，数值由商业化接口动态插值 |
| GAP-03 | 结果稿展示“优惠10%”，帮助文案写“9折” | 语义相同但表达不同 | 统一后端字段为优惠百分比；结果显示“优惠10%”，帮助正文可显示“9折（优惠10%）” |
| GAP-04 | 011/012 文案“默认有限推荐”明显错字 | 影响上线文案质量 | 生产改为“默认优先推荐”，验收报告登记 2 字差异为设计纠错 |
| GAP-05 | 018 首张候选清晰且仍显示“解锁ta” | 解锁状态不一致 | 以按钮和服务端状态为准；未解锁统一使用服务端脱敏头像，已解锁显示“查看主页” |
| GAP-06 | 001/003 长图包含推荐底部操作区和完整主页 | 与“主页/预览共用”要求存在重复实现风险 | 提取共享 `ProfileDisplayPage`，推荐详情只注入操作区 |
| GAP-07 | 蓝湖把系统状态栏和微信胶囊画进稿内 | 自绘会出现双胶囊 | 运行态使用原生组件，仅对齐其测量位置 |
| GAP-08 | 地址面板为国内/海外、省、市三列，用户家乡为两级 | 数据口径容易混用 | 理想型筛选地址使用三列；用户家乡继续两级，接口字段分离 |
| GAP-09 | 部分普通稿同时包含底部 Tab，部分独立页没有 | 页面栈/TabBar 语义不同 | 主 Tab 页保留 TabBar；回看、偏好、充值、历史、帮助作为子页不显示 TabBar |
| GAP-10 | 自动生成 HTML 的超长 set 画板存在负 margin/超大容器 | 不能直接复制为生产 CSS | 只读取尺寸和 Token；长页用正常文档流重建 |
