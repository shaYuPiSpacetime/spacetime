# PRD-08 接口字段与页面绑定

> 本文件把蓝湖页面状态绑定到服务端字段。接口未返回的业务状态不得由客户端猜测；未解锁隐私字段不得先返回再由 CSS 隐藏。

## 1. 公共响应约定

- 所有接口使用项目统一 `R<T>`。
- 列表使用不透明 `cursor`，客户端不得解析游标。
- 时间由服务端返回 ISO-8601，北京时间分组由客户端按统一工具处理。
- 真实候选接口均校验登录、核心准入、账号状态和双向关系阻断。
- 公开图片只使用审核通过且可公网访问的 URL；未解锁模糊图不得包含原图 URL 或可逆处理参数。

## 3. 推荐接口

### 3.1 查询偏好

`GET /miniapp/recommend/preferences`

```ts
interface RecommendPreferenceVO {
  version: number
  targetCities: Array<{ code: string; name: string }>
  allowNeighborCity: boolean
  minAge: number
  maxAge: number
  advanced: {
    minHeight?: number
    maxHeight?: number
    minWeight?: number
    maxWeight?: number
    educationCodes: string[]
    hometowns: Array<{ provinceCode: string; cityCode?: string; name: string }>
    schoolCodes: string[]
    majorNames: string[]
  }
  vipEffective: boolean
  advancedEffectiveCount: number
  defaulted: boolean
}
```

`defaulted=true` 表示服务端根据本人现居城市和年龄 ±5 岁生成临时默认，用户保存前不落库。

### 3.2 保存偏好

`PUT /miniapp/recommend/preferences`

请求包含查询响应中的可编辑字段和 `version`。成功返回新 `RecommendPreferenceVO`；版本冲突返回 `RECOMMEND_FILTER_VERSION_CONFLICT`。

### 3.3 推荐候选

`GET /miniapp/recommend/candidates?cursor={cursor}`

```ts
interface RecommendCandidatePageVO {
  items: RecommendCandidateVO[]
  nextCursor?: string
  remainingBrowseCount?: number
  waitingReason?: 'no_candidate' | 'browse_limit'
  preferenceVersion: number
}

interface RecommendCandidateVO {
  candidateNo: string
  userId: number
  profile: ProfileDisplayModel
  liked: boolean
  communicationMode: 'WHISPER' | 'PRIVATE_MESSAGE'
  actualCity: string
}
```

- `remainingBrowseCount=null/undefined` 表示当前不限制，不得显示“已看完”。
- 候选卡进入有效可见区后由客户端显式确认曝光，避免预加载即扣额度。

### 3.4 浏览动作与回看

| 方法 | 路径 | 请求/响应 |
|---|---|---|
| POST | `/miniapp/recommend/candidates/{candidateNo}/view` | `filterVersion, position, requestId`；幂等记曝光并扣额度 |
| POST | `/miniapp/recommend/candidates/{candidateNo}/skip` | `requestId`；幂等记录 `skip` |
| POST | `/miniapp/recommend/candidates/{candidateNo}/never` | 创建场景屏蔽关系 |
| GET | `/miniapp/recommend/replay?cursor={cursor}` | 权益有效时返回按今天/昨天/前天分组的数据 |

回看项字段：`candidateNo/profile/viewedAt/lastAction/liked/dateGroup`；同一候选只返回最近一次。

### 3.5 见面偏好

| 方法 | 路径 | 字段 |
|---|---|---|
| GET | `/miniapp/recommend/meeting-preference` | `meetingPreference, preferredActivities, updatedAt, options` |
| PUT | `/miniapp/recommend/meeting-preference` | `meetingPreference, preferredActivities` |

保存只更新 PRD-01 资料，不更新推荐偏好版本。

## 4. 理想型接口

### 4.1 元数据与筛选

`GET /miniapp/ideal/meta`

返回：共享城市年龄、17 条固定条件、中文分类、本人依赖可用性、最近一次草稿、历史入口计数和动态帮助配置。

`POST /miniapp/ideal/search`

```ts
interface IdealSearchReq {
  requestId: string
  preferenceVersion: number
  targetCityCodes: string[]
  minAge: number
  maxAge: number
  conditionCodes: string[]
}

interface IdealSearchVO {
  snapshotNo: string
  resultCount: number
  expiresAt: string
}
```

同一用户、同一条件摘要和同一 `requestId` 重试返回同一快照。

### 4.2 快照结果

`GET /miniapp/ideal/snapshots/{snapshotNo}/results?cursor={cursor}`

```ts
interface IdealResultPageVO {
  snapshotNo: string
  status: 'active' | 'expired'
  summary: IdealConditionSummary
  resultCount: number
  unlockableCount: number
  items: IdealResultItemVO[]
  nextCursor?: string
  pricing: IdealPricingVO
}

type IdealResultItemVO =
  | {
      itemNo: string
      unlocked: false
      blurAvatarUrl: string
      ageBand: string
      cityName: string
      matchedConditionNames: string[]
    }
  | {
      itemNo: string
      unlocked: true
      candidateNo: string
      profile: ProfileDisplayModel
      communicationMode: 'PRIVATE_MESSAGE'
      unlockExpiresAt: string
    }
```

未解锁分支不能出现 `candidateNo/nickname/school/exactAge/originalAvatarUrl`。

### 4.3 报价与确认

| 方法 | 路径 | 说明 |
|---|---|---|
| POST | `/miniapp/ideal/unlock/quote` | `snapshotNo + itemNos`，单个或当前已加载选择 |
| POST | `/miniapp/ideal/unlock-all/quote` | `snapshotNo`，服务端选取全部有效未解锁项 |
| POST | `/miniapp/ideal/unlock/confirm` | `quoteToken + requestId`，原子扣币并返回逐项结果 |

```ts
interface IdealUnlockQuoteVO {
  quoteToken: string
  quoteExpiresAt: string
  snapshotNo: string
  candidateCount: number
  originalCost: number
  discountPercent: number
  discountAmount: number
  payableCost: number
  currentBalance: number
  balanceEnough: boolean
  retentionDays: number
}
```

确认成功响应包含 `paidCost/newBalance/unlockedItems`，重复 `requestId` 返回原结果，不返回 `coinCost=0` 的伪成功。

### 4.4 记录、历史与帮助

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/miniapp/ideal/search-records?cursor={cursor}` | 最近 20 次，10 条/页 |
| GET | `/miniapp/ideal/unlocks?status={all|active|inactive}&cursor={cursor}` | 20 条/页，服务端状态筛选 |
| GET | `/miniapp/ideal/help` | 动态价格、折扣、上限、保留期和正文片段 |

失效历史仅返回 `unlockNo/scene/snapshotNo/unlockedAt/expiresAt/status/cost`，`profile=null`。

## 5. 商业化管理接口

现有 `GET/PUT /admin/commercial/config` 的 `settings` 新增：

```ts
interface CommercialSettings {
  idealBatchMax: number
  idealBatchDiscountPercent: number
  idealRetentionDays: number
  // 其余既有字段保持不变
}
```

- 后端校验 0–100，写入 `app_config`。
- 配置日志继续保存完整前后 JSON 快照和 `changeSummary`，响应映射中文配置项与 `changeReason`。
- 小程序只能读取必要的派生配置，不暴露管理端配置聚合或审计日志。

## 6. 共享主页模型

```ts
interface ProfileDisplayModel {
  userId: number
  nickname: string
  avatar: string
  heroPhoto?: string
  photos: string[]
  gender?: string
  age?: number
  height?: number
  currentCity?: string
  hometownCity?: string
  school?: string
  identityLabel?: string
  industryLabel?: string
  occupationLabel?: string
  company?: string
  annualIncomeLabel?: string
  tags: string[]
  introduction?: string
  certifications: Array<'AVATAR' | 'REAL_NAME' | 'EDUCATION'>
  liked: boolean
  matched: boolean
  matchNo?: string
  communicationMode: 'WHISPER' | 'PRIVATE_MESSAGE'
}
```

空标签、自我介绍、相册和扩展资料区块整块不渲染；本人预览和他人主页使用相同显隐函数。

## 7. 错误到 UI 状态映射

| 业务 code | 页面处理 |
|---|---|
| `RECOMMEND_CORE_ACCESS_REQUIRED` | 跳 PRD-01 准入拦截 |
| `RECOMMEND_FILTER_INVALID` | 保留草稿，字段级提示 |
| `RECOMMEND_VIP_REQUIRED` | 打开会员引导 |
| `RECOMMEND_FILTER_VERSION_CONFLICT` | 保留草稿，刷新版本后要求再次确认 |
| `RECOMMEND_DICTIONARY_UNAVAILABLE` | 已保存值只读，禁保存 |
| `IDEAL_DEPENDENT_PROFILE_MISSING` | 置灰条件并引导完善资料 |
| `IDEAL_SNAPSHOT_EXPIRED` | 只展示摘要和重新筛选 |
| `IDEAL_QUOTE_EXPIRED` | 刷新报价，不扣币 |
| `IDEAL_BATCH_LIMIT_EXCEEDED` | 提示缩小条件，不截断候选 |
| `ASSET_BALANCE_NOT_ENOUGH` | 打开充值承接页，返回后重新报价 |
| `RECOMMEND_CANDIDATE_UNAVAILABLE` | 移除当前项，加载下一项 |
