# PRD-08 视觉 Token 与组件映射

## 1. 坐标与适配规则

- 蓝湖生成页面宽度为 750px，生产小程序样式值按原数值写成 rpx；在 375px 设备上 `750rpx = 375px`。
- 蓝湖基线 PNG 为 1500px 宽，即 2x 的 750rpx 设计证据，不能把 PNG 像素值直接写进样式。
- 页面内容必须适配真实 `statusBarHeight`、微信原生胶囊矩形和底部安全区；设计稿中的状态栏/胶囊只作为位置参考。
- 主视口 375×812，补充验证 390×844；长页使用自然滚动，不按长图总高锁死容器。

## 5. 布局与安全区

- 常规页面横向内容边距：24–32rpx；推荐人物大卡宽 700rpx，左右各 25rpx。
- 顶部区域由状态栏、导航栏和内容头组成；原生胶囊右侧边距采用 `wx.getMenuButtonBoundingClientRect()` 实测值。
- 推荐人物图顶部卡圆角 32rpx，图片区与白色资料区重叠；头像为 150rpx 白描边圆形并上浮。
- 底部自定义 Tab 使用项目现有统一组件，推荐中心按钮为 150rpx 圆形上浮结构；底部 Tab 图标继续使用包内资源。
- 主操作按钮高度约 98rpx；底部面板主按钮左右 55rpx 边距；点击区域不得小于 88rpx。
- 地址/年龄面板固定在底部安全区上方，背景遮罩覆盖页面但不能覆盖微信原生胶囊层级。
- 011/012、015、019 是自然长页；按钮与底部 Tab 的关系按设计分别采用 sticky 或页面尾部布局，禁止把长图高度写死。

## 7. 图标实现约束

1. 返回、历史、偏好设置、筛选、定位、清除、悄悄话、心动、VIP 和历史信息图标优先使用 `推荐-切图` 的原始无损切图。
2. 微信胶囊、状态栏不使用切图，不在业务代码中重复绘制。
3. 性别、定位、认证、刷新、箭头、货币等图标必须使用独立 `Image` 或项目 SVG/PNG 组件，禁止使用 Unicode 字符近似。
4. 非底部 Tab 静态图标上传 OSS 后，只从 `miniapp/src/constants/ossIcons.ts` 引用；上传前禁止压缩、转换、缩放或添加 CDN 处理参数。
