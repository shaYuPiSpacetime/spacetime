# 官网隐私政策

> 适用于 `www.shikongxiehou.com` 的免费活动服务。备案服务项目仍需以通信管理部门登记信息为准。

**版本：**1.2

**个人信息处理者：**上海兴家立业网络科技有限公司

**联系渠道：**https://www.shikongxiehou.com/report（无需登录，申请处理个人信息时请留下手机号或邮箱以便核验及回复）

## 一、处理目的、方式与信息种类

1. **注册和登录：**处理手机号、短信验证码、协议同意版本及时间，用于身份验证、提供账号服务和记录用户同意。验证码短期保存，登录状态通过安全 Cookie 维持。
2. **活动和报名：**处理用户填写的昵称、活动标题、正文、图片、时间、地点、线下预计费用及报名记录，用于展示活动、人工审核和免费报名。审核通过的活动内容及发布者昵称向访问者公开；手机号不在活动页公开。
3. **一对一私聊：**处理会话关系、文字和图片消息、发送时间，用于活动相关沟通及内容治理。聊天图片审核通过前仅发送者可见；经单独授权的审核人员在说明原因并留下日志后，可查看必要的聊天内容。
4. **举报与安全：**处理举报对象、原因、可选回复渠道、处置记录，以及登录、发帖、聊天和管理操作的时间、IP 地址、浏览器标识，用于处理投诉、排查故障和满足安全审计要求。

## 二、共享、委托处理与公开范围

我们使用阿里云短信服务发送验证码，并使用阿里云对象存储保存活动和聊天图片。我们按服务所需范围向受托方提供必要信息并要求其采取保护措施。报名者与活动发起人可在活动场景查看必要的昵称和报名关系；聊天正文不向其他用户公开。除依法履行义务或经用户另行授权外，不向无关第三方提供个人信息。

## 三、保存期限与安全措施

账号、活动、报名、会话及举报信息在提供服务所需期间保存；用户提出删除请求后，按法律要求及争议处理需要核验并处理。登录、发帖、聊天和管理操作的审计日志至少保留六个月；留存期内的违规内容审核证据不会因前台下架而立即清除。我们采用传输加密、图片访问控制、权限管理和操作留痕等措施保护信息。

## 四、用户权利及办理方式

用户可以在网站查看自己的活动、报名和聊天记录。需要查询、更正、删除个人信息、撤回同意、注销网站账号或了解处理规则时，请通过上述联系渠道提出请求并留下可用于核验及回复的联系方式。我们会核验请求人身份，并按适用法律规定答复和处理；法律要求继续保存的信息将停止除存储和必要安全保护以外的处理。

## 五、政策更新

本政策发生重要变化时，我们将在网站展示更新版本，并在依法需要时重新取得用户同意。继续使用前请阅读最新版本。
