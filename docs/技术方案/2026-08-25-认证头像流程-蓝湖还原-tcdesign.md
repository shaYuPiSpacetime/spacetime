# 认证头像流程蓝湖还原技术方案

## 范围与基线

- 端：微信小程序，默认视口 375×812，并兼容不同屏幕高度。
- 页面：基础资料、认证-添加头像、认证-添加头像-裁剪照片。
- 蓝湖页面：`认证-添加头像`，画板 ID `78269abb-a95f-4872-8d18-9cee0a6a7e1d`。
- 基线截图：`docs/验收报告/截图证据/2026-08-25-认证头像流程/设计基线/认证-添加头像.png`。
- 验收门禁：结构与关键首屏 97%，整体 95%。

## 实现方案

1. 所有“去认证/立即认证”入口固定先进入 `/pages/verification/basic`；基础资料保存成功后进入 `/pages/verification/avatar`。
2. 添加头像页保留真实图片、文本、来源选择浮层和按钮事件。人物示例、勾选、三条规则图标、四张反例均使用蓝湖 MCP 无损切图，并通过 OSS 常量引用。
3. 裁剪框保持蓝湖 `538:652` 比例；宽度受视口左右 25px 安全边距约束，高度受短屏可用空间约束；最终使用 `(windowHeight - areaHeight) / 2` 垂直居中。
4. 裁剪图片继续使用 `MovableArea/MovableView` 支持平移缩放，确认后通过 Canvas 输出固定 `1076×1304` 图片并提交审核。

## 组件与 token 映射

| 设计元素 | 实现 |
|---|---|
| 主按钮 | `VerificationBottomAction`，`#2876FF` |
| 页面背景及四步进度 | `VerificationShell` |
| 头像说明素材 | `miniappOssIcons.verificationAvatar*` |
| 裁剪交互 | `MovableArea`、`MovableView`、`Canvas` |

## 风险与验证

- 不把按钮、气泡文字或来源浮层烘焙进整页图片。
- OSS 上传凭据不进入源码；页面仅消费生成后的公网常量。
- 运行截图依赖微信开发者工具环境；缺少该环境时以蓝湖基线、静态门禁和构建结果记录限制。
