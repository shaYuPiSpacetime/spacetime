# 偏好设置城市筛选蓝湖还原技术方案

| 项 | 内容 |
|---|---|
| 日期 | 2026-10-09 |
| 页面 | 小程序「偏好设置」 |
| 视觉基线 | 用户提供的偏好设置现状截图、编辑资料「现居地」参考截图 |
| 改动范围 | 居住地偏好新增城市交互 |

## 1. 目标与边界

- 将偏好设置中原生 `multiSelector` 城市滚轮替换为编辑资料「现居地」同款底部弹层。
- 复用省市双列、选中蓝底、中国/海外入口、圆角遮罩和底部蓝色确认按钮。
- 保留目标城市最多 3 个、不可重复、保存时至少 1 个城市的既有业务约束。
- 家乡偏好选择器、推荐参数接口及后端数据结构不在本次改动范围内。

## 2. 组件与数据映射

| 设计元素 | 代码映射 |
|---|---|
| 底部白色圆角弹层 | `LanhuRegionSheet` -> `BottomPicker` |
| 中国/海外地区国家 | `LanhuRegionSheet` 顶部分区标签 |
| 省/市双列 | 两个真实 `ScrollView`，不使用背景图或透明热区 |
| 当前选中蓝底 | `#E3F1FE` 选中行 |
| 确认按钮 | `BottomPicker` 真实按钮，回传 province/city code |
| 城市标签 | `RecommendPreferenceVO.targetCities` |

## 3. 交互闭环

1. 用户点击居住地偏好后的“＋”。
2. 页面以最近一次已选城市为初始位置；无已选项时定位到地区树第一项。
3. 用户滚动或点击省、市列并点击“确认”。
4. 页面按城市 code 去重，重复时提示“该城市已添加”；达到 3 个时阻止继续添加。
5. 新城市写入当前偏好草稿，最终仍由“保存偏好设置”统一提交。

## 4. 验收标准

- 偏好设置不再调用微信原生 `multiSelector`。
- 弹层结构、间距、颜色与编辑资料现居地组件一致。
- 点击、滚动、确认、遮罩关闭均由真实可见组件承载。
- 原有城市删除、数量限制和保存逻辑不回归。
- TypeScript 构建通过，针对性回归测试通过。
