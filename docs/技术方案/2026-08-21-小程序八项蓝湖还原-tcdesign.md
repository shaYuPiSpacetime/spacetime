# 小程序八项蓝湖还原技术方案

## 1. 范围与门禁

- 端：Taro 微信小程序，设计逻辑画布按 750rpx 映射，验收视口 375×812。
- 页面组：登录资料页、消息、千寻币、三重认证弹窗、主页预览、千寻互动。
- 设计来源：用户提供的 5 个蓝湖设计链接；缺少 `tid` 的链接统一补同项目团队 ID `428e8368-c279-4369-947b-a5828487924d`。
- 交付门禁：关键首屏不低于 97%，整体不低于 95%。每个页面组执行“设计结构→基线截图→实现→运行截图→差异修复”。
- 图片规则：只使用蓝湖原始无损 PNG/WebP 字节；非底部静态图上传 OSS；文字、按钮、Tab、弹窗操作区均使用真实组件。

## 2. 设计基线与实现映射

### 2.0 登录资料页

- 性别、出生日期、身份、学历、现居地与手机号登录页统一复用 `LoginNextButton`。
- 未点亮态以蓝湖“手机号登录”页为基线，点亮态以“手机号登录-点亮”页为基线。
- 两态都直接使用蓝湖 `126×126px` 完整按钮 PNG，运行尺寸 `126×126rpx`、圆角 `63rpx`；不再由 CSS 重画圆底、阴影或箭头。
- 未点亮源文件 SHA-256 为 `a43559fd148b762dec607b2d08acd74ed2408829d2bae17d040e16b37665a98d`，点亮源文件 SHA-256 为 `c86718e94cb9feb0fdbbbf33ae553618abe834af70518b4f364350ddea4ea03c`；OSS 返回字节与本地源文件一致。
- 按钮本体仍是绑定真实事件的 `View`；未点亮态拦截提交，点亮态才调用当前页的 `onClick`。

### 2.1 消息页

- 蓝湖 image ID：`626cd513-005e-4df8-8456-b5280872ba23`。
- 画布：1500×3248 PNG，对应 750×1624 逻辑画布。
- MCP 原始切图：
  - 悄悄话三头像：224×108 RGBA PNG，运行宽度约 112rpx；不含卡片背景。
  - 喜欢我的人头像：196×196 RGBA PNG，运行尺寸 100rpx；未读红点必须由组件绘制。
- 页面结构和文案沿用真实组件，替换 `messageAvatarWhisperGroup` 与 `messageAvatarLikedBlurred` 的 OSS 源文件。

### 2.2 千寻币页

- 蓝湖 image ID：`632e7124-051e-420d-a15d-5782ed10a090`。
- 余额卡背景：MCP 原始图层 1400×376 RGBA PNG，对应 700×188rpx；图片不含余额、数字和“明细”控件。
- 套餐固定由后台返回设计基线三档 `1000/99`、`3000/268`、`6000/428`；副标题优先读取 `packageDesc`，避免把后台套餐名称误当设计副标题。
- 套餐卡使用 `240×184rpx`、卡间距 `8rpx`、推荐卡对齐偏移 `153rpx`、轨道上内边距 `16rpx`。币数使用 `30rpx/40rpx`、字重 500；原价使用 `20rpx/28rpx`；折扣使用 `18rpx/24rpx`；价格使用 `40rpx/44rpx`。币种小图仍为独立图片。
- 余额背景已登记到 OSS 原样上传清单，并以独立 `Image` 铺底，余额与明细继续用真实组件覆盖。背景 SHA-256 为 `336188059244211afa9e9a96c120b1246e48c71af8e2d79f512b105fb59dd670`；币种小图 SHA-256 为 `245196965e796a209279ce7d555d6b985ff931b1acde032366a6b269423a1f98`。
- 充值协议以当前稿 `《时空邂逅充值协议》` 为准；默认态、协议勾选态、协议确认底栏、充值须知和支付结果层均由真实组件承载。

### 2.3 三重认证弹窗

- 蓝湖 image ID：`60d2baa1-3b46-4fb0-8473-50577938fda5`，状态 `childImg=4`。
- 入口：推荐、我的、个人主页；点击后在当前页面叠加真实弹窗，不再路由跳转。

### 2.4 主页预览

- 蓝湖 image ID：`08308a03-82cf-43e1-bd40-a502fa089f6a`，状态 `childImg=0`。
- 字段映射：头像右侧胶囊只绑定 `emotionalStatus`（感情状态），不再用 `datingGoal` 或 `maritalStatus` 回填；基础资料卡在地区信息后新增分隔线和独立 `datingGoal`（脱单目标）行，顺序与设计稿一致。
- 全局同步：编辑资料主页预览与用户公开主页复用 `ProfilePreviewPage`；推荐首页的同结构资料卡同步采用相同映射，避免三个入口字段语义不一致。
- 接口契约：公开资料接口继续返回 `datingGoal`、`emotionalStatus` 和 `maritalStatus` 三个独立字段，并在服务层通过资料字典转换为展示标签；前端禁止展示原始枚举 code。
- 空值规则：自己的主页预览保留“脱单目标：待完善”编辑提示；公开主页与推荐首页在字段为空时隐藏独立目标行。

### 2.5 千寻互动

- 统一字体基线为蓝湖“千寻互动-互动-点赞暂无数据”，image ID：`30f3f15e-756b-4b94-a486-5034caf58a33`。
- MCP 基线为 `page/lanhu-mcp-assets/screenshots/30f3f15e-756b-4b94-a486-5034caf58a33.png`，源图 `1500×3248`，对应逻辑视口 `375×812`。
- 字体映射：导航 `32/45rpx`、姓名 `32/44rpx`、简介 `24/34rpx`、统计标签 `24/34rpx`、统计数字 `38/48rpx`、主 Tab `28rpx`、筛选胶囊 `26/36rpx`、空态标题 `28/42rpx`、空态说明 `28/40rpx`、主按钮 `32/44rpx`。
- 未选筛选胶囊底色固定为 `#F8F9FB`。评论过、点赞过、解锁过共用 `FilterTabs` 和 `InteractionEmpty`，保证三种空态字号、行高和位置一致。

## 3. 组件与数据策略

- 复用现有 `miniapp/src/pages/chat/index.tsx`、`coins/index.tsx`、`community/index.tsx` 和资料预览组件。
- 三重认证弹窗抽为共享组件，通过父页面局部状态控制可见性；可见元素本身承接点击事件。
- 主页预览字段仍读取真实资料数据，禁止用蓝湖文案硬编码业务值。
- 切图下载仅作为设计基线；运行态统一引用 `miniapp/src/constants/ossIcons.ts` 生成的公网 URL。
- 登录资料页两态完整按钮分别由 `miniappOssIcons.loginNextDisabled` 和 `miniappOssIcons.loginNextActive` 提供，所有资料步骤和手机号页共享同一组件，不允许页面级重复实现。

## 4. 验证

- 静态门禁：不引用蓝湖 CDN、参考图目录或整页截图；无透明热区；弹窗操作区均为真实组件。
- 构建：`cd miniapp && npm run build:h5` 与项目现有蓝湖校验脚本。
- 截图：375×812 默认态及三重认证/获赞/动态弹窗态；逐页记录差异与评分。
- 千寻币 H5 截图使用本机 E2E 回环接口和固定登录构建；`rpx` 截图换算只注入忽略目录 `miniapp/dist/`，不进入生产源码。微信状态栏与右上角系统胶囊属于宿主层，不在 H5 运行截图内重复绘制。
