# 千寻互动点赞空态字体统一蓝湖还原技术方案

## 1. 目标与范围

以蓝湖“千寻互动-互动-点赞暂无数据”为唯一视觉基线，统一千寻互动页首屏资料区、主 Tab、互动筛选与空态区域的字体层级。本次不改变接口、路由、状态管理和交互行为。

## 2. 设计基线

- 蓝湖画板 ID：`30f3f15e-756b-4b94-a486-5034caf58a33`
- 本地基线：`docs/验收报告/截图证据/2026-07-22-千寻66稿/蓝湖基线/042.png`
- 画板逻辑尺寸：375×812，源图尺寸：1500×3248

## 3. 字体与组件映射

| 区域 | 字号/行高 | 说明 |
|---|---:|---|
| 导航标题 | 32/45rpx | 沿用统一 `NativeNavigation` |
| 用户姓名 | 32/44rpx | 半粗体 |
| 用户简介 | 24/34rpx | 灰色单行省略 |
| 资料统计标签 | 24/34rpx | 灰色 |
| 资料统计数字 | 38/48rpx | 深蓝色半粗体，按验收反馈放大 |
| 主 Tab | 28rpx | 激活态半粗体 |
| 筛选胶囊 | 26/36rpx | 激活白字，未激活背景 `#F8F9FB` |
| 空态标题 | 28/42rpx | 灰色 |
| 空态说明 | 28/40rpx | 灰色 |
| 主按钮 | 32/44rpx | 白色半粗体 |

资料头、主 Tab 和筛选栏均为共享组件函数，三种互动空态复用同一字体规则，避免各状态单独漂移。所有按钮继续使用真实 `View`/`Text` 并绑定现有事件。

## 4. 验证策略

1. 专项 Node 门禁检查关键字号、行高与未选胶囊色值。
2. 执行小程序 TypeScript/正式构建，排除样式改动引入的编译问题。
3. 在微信开发者工具 375×812 视口截取“点赞过暂无数据”，与 `042.png` 同尺寸比较。
4. 验收报告记录差异清单、截图证据与还原度评分；未取得运行截图前不宣称最终高还原闭环。
