# 编辑资料与主页预览顶部区域统一设计描述

## 1. 还原范围

- 页面：`编辑资料-资料填写`、`主页预览`。
- 蓝湖项目：`d9c9e50f-fee5-47ca-bd6b-ae05c0d5332b`。
- 编辑资料设计图：`31e3d794-01ec-499d-b42c-7b868a9e9f3b`。
- 主页预览设计图：`461285cf-e519-4d13-b60b-17b73b5bb862`。
- 本轮只调整顶部导航以下的评分、真实性提示、主背景图及其与下一卡片的衔接，不改动资料业务接口和后续卡片内容。

## 2. 蓝湖基线

以 750rpx 逻辑画布为基准：

| 区域 | 几何/规则 |
| --- | --- |
| 顶部导航 | 高 `182rpx` |
| 编辑资料评分卡 | `700×138rpx`，导航后直接排列 |
| 评分浮标 | `128×43rpx` |
| 评分轨道 | `652×10rpx`，浮标下方 `19rpx` |
| 真实性提示 | `700×88rpx`，距评分卡 `20rpx` |
| 两页主背景图 | `700×828rpx`，圆角 `32rpx` |
| 图片裁切 | `aspectFill`，同一 URL 必须呈现相同裁切内容 |
| 编辑资料更多照片卡 | 向上覆盖主图底部 `105rpx` |
| 头像 | `188×188rpx`，位于主图左下并高于后续白色卡片 |

## 3. 数据与组件映射

| 蓝湖区域 | 运行态数据 | 组件/实现 |
| --- | --- | --- |
| 主背景图 | `profile.profileBgImage`，为空时使用编辑资料设计兜底图 | `ProfileHeroImage` |
| 圆头像 | `profile.avatar`，为空使用默认头像 | `ProfileHeroCard` / `ProfilePreviewHero` |
| 姓名 | `profile.nickname` | 两页各自的信息叠层 |
| 评分 | `profile.profileScore` | `ProfileScoreCard` |
| 资料预览 | 当前编辑页组合出的 `ProfilePreviewModel` | `ProfilePreviewPage` |

编辑资料和主页预览共同消费 `profileHeroImage`，不再维护编辑页专属的第二份主图状态，避免上传背景后两页显示分叉。

## 4. 组件策略

- 新增 `ProfileHeroImage`，集中管理 `700×828rpx`、`32rpx` 圆角与 `aspectFill`。
- 编辑资料与主页预览只保留各自的信息叠层，背景图几何和裁切由共享组件提供。
- 编辑资料主图外层不创建独立层叠上下文；更多照片白卡覆盖主图底部，头像与姓名使用更高层级保持可见。
- 评分卡移除原有 `35rpx` 顶部空白，恢复与顶部导航的蓝湖节奏。

## 5. 状态和交互

- 真实背景：两页即时显示同一背景 URL。
- 缺省背景：两页显示同一编辑资料设计兜底图，尺寸与裁切仍一致。
- 点击“更换背景”：仍走原背景上传、保存接口；成功后只更新统一背景状态。
- 点击圆头像：仍走头像上传与认证链路，不影响背景图。
- 页面切换：编辑资料与主页预览不重新请求，直接复用当前模型，避免视觉闪动。

## 6. 验收门禁

- 静态门禁：共享宽高、圆角、裁切、统一数据源、评分间距和前后层级。
- 构建门禁：`npm run build:weapp`。
- 运行态证据：微信开发者工具 iPhone 12/13 Pro，逻辑视口 `390×844`，分别截图编辑资料与主页预览真实内容状态。
