# 登录城市图标与出生日期样式蓝湖还原技术方案

## 范围与基线

- 页面：`pages/login/address`、`pages/login/age`。
- 城市图标来源：用户提供的 76×92px RGBA PNG，SHA-256 为 `34daa393244a6db9cd506b03bbcd38625035cfc8d95a7850e4a01fecf544aa5a`。
- 出生日期基线：蓝湖 `登录-年龄选择`，`image_id=4ca59342-02bc-4052-b553-0baca9dbd8c9`，沿用 2026-08-03 已验收的五行坐标。

## 组件映射

| 元素 | 实现 |
| --- | --- |
| 选择城市图标 | `Image` + `miniappOssIcons.loginCityLocation`，38×46rpx，原字节 OSS 上传 |
| 旧城市图标 | 删除三层 `View` 的边框/旋转临摹 |
| 出生日期静止态 | 保留选中、相邻、远端三档色阶和蓝湖五行坐标 |
| 出生日期交互 | 年、月、日三个并排的原生单列 `PickerView`，各自处理 `pickstart/pickend/change` |

## 交互不变量

1. 单列滑动不修改其他两列索引。
2. 当前滑动列显示后续数值，静止列保持蓝湖五行样式。
3. 月份导致日期超出月末时，仅执行日期合法性收敛。
4. 不使用透明热区、截图交互或手写滚动物理。
