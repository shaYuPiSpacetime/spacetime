# 心动访客会员独立页蓝湖还原技术方案

## 1. 范围

- 端：微信小程序。
- 页面：心动未开通会员页、独立「时空邂逅会员」页、相互喜欢页、单人解锁弹窗、千寻币充值入口。
- 设计源：蓝湖项目「时空邂逅0625」，独立会员页 `image_id=c2cf99b4-3edd-4535-9ad9-ae9d39e594bc`。
- 视口：设计画布 750×1624，对应运行态 375×812。
- 门禁：关键首屏 ≥97%，整体 ≥95%。

## 2. 根因

1. “解锁全部访客”错误跳转 `/pages/membership/index`，复用了“我的 → 开通会员”的会员中心 UI。
2. 会员中心中段由套餐/权益接口数组驱动，接口失败或本地库未初始化时静默空白。
3. 胶囊左侧图标由 CSS 方框和文本心形拼接，不是蓝湖图标，也没有点击事件。
4. 单人解锁“只看 ta”直接切换成功态，未进入千寻币充值页。

## 5. 路由与交互

```text
解锁全部访客 -> /pages/heart/membership-unlock
胶囊左侧图标 -> /pages/heart/mutual
单人解锁「只看 ta」 -> /pages/coins/index?sourceScene=likes_unlock_one
单人解锁「解锁全部」 -> /pages/heart/membership-unlock
```

页面按钮均为真实可见组件绑定事件，不使用截图热区。

## 6. 数据与异常态

- 优先使用 `/miniapp/vip/packages`、`/miniapp/vip/benefits` 的真实数据与真实套餐 ID。
- 接口空或失败时保留蓝湖基线展示，避免中段消失；占位套餐不可创建订单，点击提示刷新。
- 支付逻辑复用业务 hook，不复用会员中心视觉组件。

## 7. 素材缺口

- 蓝湖 MCP 对心动页只返回人物位图，没有顶部“双卡片+空心爱心”独立切片。
- 采用蓝湖 2x 原稿无损提取 PNG，禁止缩放、格式转换、质量压缩和 CDN 处理参数；通过仓库上传脚本原字节上传。

## 8. 验证

- 静态门禁：`node scripts/validate-heart-message-lanhu.mjs`。
- OSS 校验：`npm run assets:verify-icons`。
- 构建：`MINIAPP_DEV_FIXED_LOGIN=true ./node_modules/.bin/taro build --type weapp`。
- 视觉：375×812 截图逐项对比蓝湖；关键首屏低于 97% 不交付。
