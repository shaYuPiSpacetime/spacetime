# 会员中心会员背景蓝湖还原技术方案

## 1. 目标与范围

- 页面：微信小程序“会员中心” `/pages/membership/index`。
- 设计来源：蓝湖项目 `d9c9e50f-fee5-47ca-bd6b-ae05c0d5332b`，画板“会员中心-全”版本 5，设计 ID `20c08860-3c5c-4518-980f-cc41861430c2`。
- 本次仅替换会员卡无文案背景，不修改头像、昵称、会员状态、套餐、权益、支付或记录入口。

## 2. 设计基线

蓝湖 MCP 对目标画板返回一张可下载切图。视觉检查确认该切图仅包含深色卡片底色、圆角和右侧会员装饰纹理，不包含头像、文字、按钮或点击热区。

| 项目 | 值 |
|---|---|
| 原始格式 | 透明 PNG |
| 原始尺寸 | `1400 × 536` |
| 像素密度 | 2× |
| 运行尺寸 | `700rpx × 268rpx` |
| 圆角 | 由源切图保留 |
| SHA-256 | `a763ac89b03bfd3c6544bd5bf94dd6030ba6507859a10251ae14c6fbdea64261` |

设计证据：

- `page/lanhu-mcp-assets/designs/20c08860-3c5c-4518-980f-cc41861430c2.json`
- `page/lanhu-mcp-assets/screenshots/membership-center-all-v5.png`

## 3. Token 与组件映射

| 蓝湖元素 | 生产实现 |
|---|---|
| 会员卡背景 | `miniappOssIcons.memberHeroBackground` + `Image` |
| 用户头像 | 保留动态 `Image` |
| 昵称、状态和有效期 | 保留动态 `Text` / `View` |
| 查看记录 | 保留真实点击组件 |

## 4. 实现方案

1. 通过蓝湖 MCP 下载 2× PNG，禁止压缩、缩放、裁切和格式转换。
2. 原始文件保存为 `miniapp/src/assets/lanhu/membership-center/member-hero-bg.png`。
3. 通过 `npm run assets:upload-icons` 原字节上传 OSS，生成 `miniappOssIcons.memberHeroBackground`。
4. 在 `MemberHero` 底层渲染 `700rpx × 268rpx` 背景图。
5. 删除 `MemberHeroPattern` CSS 近似几何纹理，保留 `#2B2B2B` 容器底色作为加载失败兜底。
6. 更新静态门禁，防止回退至 CSS 近似背景或带文案旧整图。

## 5. 验证方案

- 本地源图与 OSS 文件 SHA-256 一致。
- 会员权益专项门禁及商业化 UI 门禁通过。
- 微信小程序编译、页面注册、生产配置与包体门禁通过。
- 微信开发者工具自动化可用时生成运行态截图；不可用时登记限制，不将静态结果冒充运行态截图。
