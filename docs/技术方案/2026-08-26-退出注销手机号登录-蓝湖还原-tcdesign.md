# 退出/注销后手机号登录蓝湖还原技术方案

## 范围与设计基线

- 端：微信小程序，基准视口 375×812。
- 页面状态：手机号默认态、手机号已输入态、未勾协议弹窗态、验证码输入态、重新发送态、自动登录态。
- 设计来源：蓝湖项目“时空邂逅0625”，画板 `登录-01`，`image_id=f69c7dbd-409d-4a64-af20-9397371219d7`；结构、预览和切图均通过蓝湖 MCP 获取。
- 输入手机号与勾选态补充来源：画板 `登录-02（输入手机号）`，`image_id=6efce5da-6c6b-448c-b387-809c140a9dd5`。
- 素材：复用现有星空背景、品牌图及 OSS 登录图标，不新增包内非 Tab 图标。

## 交互流程

1. 用户主动退出登录后 `reLaunch` 到手机号登录页；账号注销或登录态失效返回 401 时清理本地账号信息并进入同一页面。
2. 输入合法手机号后点击“获取验证码”。
3. 已勾协议时直接发码；未勾协议时显示底部协议弹窗。
4. 点击“同意并继续”同步记录同意状态、发送验证码并进入验证码页。
5. 验证码采用 4 位真实 `Input`，可见数字格由真实组件绘制；输入满 4 位自动调用手机号登录。
6. 登录成功后复用 `resumeAfterLogin`，按账号当前准入状态恢复业务页面。

## Token 与组件映射

| 设计元素 | 实现 |
|---|---|
| 星空登录背景与品牌 | 蓝湖导出的 `login-scene-bg.jpg` 已内置完整 Logo 与标语，页面不得再叠加 `loginBrand` |
| 手机号输入 | Taro `Input` + 蓝湖 MCP 2× 手机切图（96×96 源图，运行 24×24px） |
| 主按钮 | 白底、蓝字、16rpx 圆角真实 `View` |
| 协议选择 | 蓝湖 MCP 2× 未选中与勾选切图（均为 64×64 源图，运行 16×16px）及真实文本链接 |
| 微信入口 | 蓝湖 MCP 2× 微信切图（176×176 源图，运行 44×44px） |
| 协议弹窗 | 底部渐变卡片、遮罩、真实确认按钮 |
| 验证码 | 4 个可见状态格 + 覆盖范围内的真实数字 `Input` |

## 边界与异常

- 非法手机号不发码并展示错误提示。
- 发码失败停留当前页；登录失败清空验证码供重新输入。
- 倒计时内禁止重复发码，结束后允许重新发送。
- 首次打开小程序的“立即使用”流程保持不变，本方案仅改变主动退出后的入口。
