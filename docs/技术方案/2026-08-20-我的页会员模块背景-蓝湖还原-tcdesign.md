# “我的”页会员模块背景蓝湖还原技术方案

## 1. 目标与范围

- 页面：微信小程序“我的”页 `/pages/profile/index`。
- 设计来源：蓝湖项目 `d9c9e50f-fee5-47ca-bd6b-ae05c0d5332b`，父画板 `a2fd5bfd-5e7b-47e6-85d9-6e3641c021cc`，版本 5。
- 本次仅替换会员横幅背景，不修改会员状态、标题文案、按钮文案、到期时间或点击逻辑。
- 文字、会员标识和按钮继续由真实组件渲染，背景切图不包含交互控件。

## 2. 设计基线

蓝湖 `VIP` 图层的逻辑坐标为 `x=25, y=512, width=700, height=128`。该图层同时提供：

- PNG 原始切图：`1400 × 256`，2 倍像素密度；
- SVG 原始切图：`700 × 128`，与逻辑尺寸一致；
- 圆角：`12`；
- 水平渐变：`#151515 -> #484848`；
- 右上装饰：`#F7D9A5`、`20%` 不透明度。

生产实现采用蓝湖同一图层导出的原始 SVG：

- `miniapp/src/assets/profile/vip-banner-bg.svg`
- SHA-256：`249036dd558343817865c3dece45bc8e067721e73f3e1ff59a7de8a613ea6f04`
- 文件大小：约 `4.6 KiB`

SVG 与蓝湖源文件仅存在文件末尾换行差异，图形节点、渐变、路径、尺寸和透明度未改动。

## 3. 实现方案

1. 在 `VipBanner` 容器首层渲染 `vip-banner-bg.svg`。
2. 背景使用 `scaleToFill`，固定为 `700rpx × 128rpx`，与蓝湖逻辑尺寸一一对应。
3. 删除原 `VipBannerPattern` 近似手绘背景，避免渐变色和右上图案偏差。
4. 保留 `VipBannerMark`、状态标题、续费/开通按钮、到期日和父容器点击事件，确保交互仍为真实组件。
5. 保留 `#1B1B1B` 作为加载失败时的底色，不参与正常显示。

## 4. 资源与包体决策

- 未使用带标题和按钮的历史整图 `vip-banner.webp`，避免图片伪交互。
- 蓝湖 2 倍 PNG 原图约 `164 KiB`，直接进入主包会触发项目 `1.50 MiB` 门槛。
- 本机缺少 `backend/.env.local`，无法执行自有 OSS 上传；没有生成或猜测远程地址。
- 改用蓝湖同图层原始 SVG 后，视觉定义不变，主包回落至 `1.39 MiB`。

## 5. 验证清单

- 会员横幅仍为 `700rpx × 128rpx`、`12rpx` 圆角。
- 未开通、已开通、已过期三态复用同一背景。
- 背景图不包含标题、按钮或点击热区。
- 会员专项静态门禁通过。
- Taro 微信端编译通过。
- 页面注册、发布产物和包体门禁通过。
