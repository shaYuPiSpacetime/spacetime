# “我的”页会员图标蓝湖还原技术方案

## 1. 目标与范围

- 页面：微信小程序“我的”页 `/pages/profile/index`。
- 设计来源：蓝湖项目 `d9c9e50f-fee5-47ca-bd6b-ae05c0d5332b`，画板“我的”版本 5，设计 ID `a2fd5bfd-5e7b-47e6-85d9-6e3641c021cc`。
- 本次仅替换会员横幅左侧会员图标，不修改背景、文案、按钮、会员状态或点击逻辑。

## 2. 设计基线

蓝湖 MCP 返回两个 `VIP` 图层及五张可下载切图。结合图层顺序、截图位置和切图尺寸，横幅左侧会员图标对应：

| 项目 | 值 |
|---|---|
| 原始格式 | 透明 PNG |
| 原始尺寸 | `96 × 76` |
| 像素密度 | 2× |
| 运行尺寸 | `48rpx × 38rpx` |
| 运行坐标 | `left: 28rpx; top: 45rpx` |
| SHA-256 | `5c94fbdefacc9d34923f7685a3ec71d96adb8b50ef8665f5158eeb74d11ffee3` |

MCP 结构数据和设计预览分别保存于：

- `page/lanhu-mcp-assets/designs/a2fd5bfd-5e7b-47e6-85d9-6e3641c021cc.json`
- `page/lanhu-mcp-assets/screenshots/profile-mine-v5.png`

## 3. Token 与组件映射

| 蓝湖元素 | 生产实现 |
|---|---|
| 会员图标 | `miniappOssIcons.profileVipMark` + 独立 `Image` |
| 横幅背景 | 保留 `vip-banner-bg.svg` |
| 标题与按钮 | 保留真实 `Text` / `View` 及点击事件 |

## 4. 实现方案

1. 使用蓝湖 MCP 下载 2× PNG，不缩放、不裁切、不转码。
2. 源文件落盘为 `miniapp/src/assets/profile/vip-mark.png`。
3. 通过 `npm run assets:upload-icons` 原字节上传 OSS，由脚本生成 `miniappOssIcons.profileVipMark`。
4. 删除 `VipBannerMark` 的 CSS 旋转方框近似绘制，改用独立可见 `Image`。
5. 更新会员专项静态门禁，禁止回退到 CSS 近似图标。

## 5. 验证方案

- 核对本地与 OSS 文件 SHA-256 完全一致。
- 运行会员权益页面静态门禁和 0901 文档修复回归。
- 编译微信小程序并运行页面注册、生产配置和包体门禁。
- 使用微信开发者工具自动化生成运行态截图；若本机自动化端口不可用，明确登记限制，不用静态结果冒充运行态截图。
