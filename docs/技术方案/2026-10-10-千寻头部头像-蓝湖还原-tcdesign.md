# 千寻头部头像定位修正

范围：仅千寻头部本人头像的位置、尺寸和点击区。沿用成家、时空邂逅、立业菜单及现有头像资源。

设计来源：用户附件 `codex-clipboard-1430dadf-bd95-4fd6-9fd1-843460aa97d0.png`，1500x3248。现状来源：`codex-clipboard-c78d5711-d181-42db-a4a4-1bbddad93e72.jpg`。归一到750rpx：头像直径约48rpx，图片与胶囊间距约20rpx，头像与胶囊垂直居中。附件无字体、原生设备参数标注，本次不调整其他页面元素。

| 元素 | 实现 |
| --- | --- |
| 头像 | 现有Image，48rpx，圆角24rpx |
| 点击区 | 64rpx，图片居中，距胶囊12rpx |
| 水平位置 | `calc(原生胶囊left像素 - 76rpx)` |
| 垂直位置 | `calc(原生胶囊中心像素 - 32rpx)` |
| 异常兜底 | 保留非微信端/API异常的固定位置 |

之前使用88rpx点击区并要求胶囊左侧至少497rpx，较宽胶囊可能被拒绝并回退固定坐标；窗口宽度兜底与实际设备宽度不一致时也可能放大位置偏差。这些路径已通过布局回归复现，用户Android设备的实际坐标尚未采集。本次保留有效胶囊坐标，以原生像素锚点定位头像，不再将该锚点换算成rpx；校验允许胶囊right超出兜底窗口宽度，但left须在窗口内且矩形有效。

验证：沿用千寻头部头像定位测试用例，补充112px宽胶囊及375px兜底/393px实际宽度组合；获取成家及时空邂逅模拟器截图。真机Android结果单独标记，不能以单测代替。
