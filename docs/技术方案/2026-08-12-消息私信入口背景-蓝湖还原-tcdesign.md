# 消息私信入口背景还原技术说明

## 目标

消息首页右侧“私信”入口使用用户提供的完整无文案 PNG 背景，文字与点击继续使用真实组件，保证视觉、交互和资源发布链路闭环。

## 设计基线

- 原始素材：680×316px RGBA PNG，SHA-256 为 `61f35677170f82465ab6d10eb6395e2f51bd22bf9966710b520b1035e54ffffc`。
- 运行尺寸：340×158rpx，与源图保持严格 2 倍像素密度和相同宽高比。
- 裁切策略：原始字节上传，不缩放、不裁切、不转换格式、不压缩。
- 文案“私信”“有个小秘密只告诉你”保留为独立 `Text` 组件；入口保留为真实 `View` 点击组件。

## 实现映射

| 基线 | 实现 |
| --- | --- |
| 背景源文件 | `miniapp/src/assets/lanhu/message/home-private-card-bg.png` |
| OSS 上传清单 | `messageHomePrivateCardBackground` |
| 运行时引用 | `miniappOssIcons.messageHomePrivateCardBackground` |
| 卡片尺寸 | 340×158rpx |
| 图片模式 | `aspectFill`；源图等比，因此无实际裁切 |
| 点击区域 | `message-home-private-entry` 整卡入口 |
| 装饰层事件 | `pointerEvents: none`，不拦截卡片触摸 |

## 验证口径

- 静态门禁校验源图尺寸、OSS 引用、运行尺寸、独立点击入口及旧插画移除。
- 公网回读文件必须与本地源文件 SHA-256 完全一致。
- 375×812 H5 隔离运行态验证视觉显示、170×79px 映射尺寸及点击进入私信列表。
- 生产小程序构建必须关闭本地固定登录与 E2E 地址。
