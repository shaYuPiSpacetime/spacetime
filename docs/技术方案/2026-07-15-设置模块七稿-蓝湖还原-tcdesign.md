# 设置模块七稿蓝湖还原技术方案

## 1. 范围

蓝湖设置组包含 7 张稿：`设置`、`设置-退出登录`、`设置-注销账号`、`设置-注销账号-点亮`、`设置-注销账号-注销提醒`、`设置-注销账号-提示`、`关于我们`。其中 3 张为页面，4 张为交互状态，目标为微信小程序 375×812。

## 2. 设计基线

| 项目 | 蓝湖基线 |
| --- | --- |
| 画布 | 750×1624，按 2x 设计 |
| 页面背景 | `linear-gradient(90deg, rgba(233,253,251,.6), rgba(234,238,249,.6) 48.49%, rgba(248,250,239,.6))` |
| 导航标题 | `#0C285A`，32rpx/45rpx，居中 |
| 正文 | `#595F77`，28rpx/40rpx |
| 次要文字 | `#999999` |
| 主按钮 | `#2876FF`，8rpx 圆角 |
| 设置内容宽度 | 700rpx，行内有效宽度 660rpx |
| 注销卡片 | 700rpx、18rpx 圆角；原因项 640rpx、12rpx 圆角 |
| 弹窗 | 620rpx、32rpx 圆角、遮罩层；左右按钮等高 |
| 点击目标 | 不小于 88×88rpx |

## 3. 页面与状态映射

| 蓝湖稿 | 运行态 |
| --- | --- |
| 设置 | `/pages/settings/index` |
| 设置-退出登录 | 设置页 `logoutDialogOpen=true` |
| 设置-注销账号 | `/pages/settings/account-cancel` 未选原因 |
| 设置-注销账号-点亮 | 已选原因且按钮可用 |
| 设置-注销账号-注销提醒 | `cancelDialogOpen=true` |
| 设置-注销账号-提示 | 提交成功后的居中提示 |
| 关于我们 | `/pages/settings/about` |

## 4. 数据和闭环

- 设置聚合：`GET /miniapp/settings/home`，驱动手机号、微信、入口名称、跳转目标和版本号。
- 注销状态：`GET /miniapp/account/cancel-status`，驱动冷静期、阻断原因和撤销态。
- 提交/撤销：`POST /miniapp/account/cancel`、`POST /miniapp/account/cancel/revoke`。
- 退出登录：先 `POST /miniapp/logout`，成功后清理本地登录态并重启到登录页；失败保留登录态。
- 合规内容：优先使用设置聚合的 `jumpTarget`；公告使用公共内容接口。
- Logo：蓝湖无 slice，使用 MCP 原始 1500×3248 PNG 在 2x 坐标 `(622,626,256,256)` 无缩放裁切，原字节上传 OSS。

## 5. 组件映射

| 设计元素 | 工程落点 |
| --- | --- |
| 导航和安全区 | 复用 `LanhuSubNav` |
| 页面背景、字体、间距 | `pages/settings/settings.scss` token |
| 列表行 | `SettingsRow` 真实组件 |
| 对话框 | `SettingsDialog`，真实遮罩和按钮 |
| 勾选框 | Taro `View` + 明确可见勾选图形和点击事件 |
| 文本输入 | Taro `Textarea` |
| Logo | `miniappOssIcons.settingsAboutLogo` |

## 6. 验收门禁

1. 7 个蓝湖状态均有 375×812 微信运行截图。
2. 页面入口、接口路径、退出/注销闭环由自动化门禁覆盖。
3. 构建产物每个页面只注册一次 `Page`。
4. 禁止空文案、透明热区、整页截图交互、本地图标与 OSS 混用。
5. 每页关键首屏评分不低于 97%，整体不低于 95%。
