# 推荐三重认证弹窗蓝湖还原技术方案

- 设计稿：`推荐-三重认证弹窗`，ID `a61d6319-1419-40bd-8a26-d557122bc96c`
- 目标视口：375×812，底部弹层态
- 实现页面：`miniapp/src/pages/recommend/index.tsx`
- 素材：总可信度盾牌、头像认证、实名认证、学历认证 4 张蓝湖 2x PNG 切图
- 素材链路：蓝湖原图落盘后由 `assets:upload-icons` 原字节上传 OSS，小程序仅引用 `ossIcons.ts`
- 交互约束：姓名、认证数、学校、可信度及“我知道了”按钮继续使用真实组件。

## Token / 组件映射

| 设计元素 | 实现 |
|---|---|
| 蓝色圆形认证图标 | 100rpx `Image` |
| 总可信度盾牌 | 184rpx 绝对定位装饰图，文本独立叠加 |
| 遮罩 | `rgba(0,0,0,.58)` |
| 底部面板 | 白色，顶部 32rpx 圆角，适配安全区 |
| 主按钮 | 真实 `View` 按钮，蓝色背景 |
