# 编辑资料整体蓝湖还原技术方案

日期：2026-08-05

## 目标

在不改变现有 PRD-01 接口和审核语义的前提下，完成编辑资料主页面及二级页面的蓝湖视觉、交互和数据回显闭环。

## 设计基线

- 主页面：`miniapp/.lanhu-ref/lanhu-full-2026-07-07/images/05-编辑资料.webp`
- 已填写态：`12-编辑资料-资料填写.webp`
- 二级页：`50-基本资料.png`、`51-爱听的歌曲.png`、`52-关于我.png`、`57-自我介绍.png`、`82-我的标签.png`
- 语音状态：`46/47/48/49/55/80` 系列设计稿。

## 实现设计

### 关于我摘要

新增纯领域映射 `profileAboutPresentation.ts`，固定主页面三个摘要入口：

1. `meetingPreference`：见面便好。
2. `preferredActivities`：喜欢的见面活动。
3. `housingStatus`：住房情况。

接口列表只负责提供内容，不再决定主页面数量和顺序。本人编辑页优先展示最新提交内容，最新内容为空时回退已生效内容。

### 主页面视觉

- 评分卡、胶囊、轨道与圆点按 750rpx 蓝湖尺寸重建，并让评分胶囊随分数同步移动。
- 主照片 700×734rpx，六宫格采用 198×198rpx 与 27rpx 列间距。
- 基础资料、认证、关于我和歌曲使用 OSS 官方图标或独立 CSS 矢量图形。
- 右箭头、播放、暂停、删除、确认、展开图标不再依赖字体字符。
- 自我介绍、歌曲和语音同时覆盖空态与已保存回显态。

### 二级页面与交互

- `LanhuSubNav` 使用透明背景，页面渐变贯穿状态栏与内容区。
- 标签点击先乐观更新，再进入串行保存队列，避免网络请求期间吞点击。
- 关于我分类使用真实后端 question key，选择与保存均优先回显本人最新提交。
- 歌曲页统一使用蓝湖音乐圆盘，标题恢复为“爱听的歌曲”。
- 语音保留录制管理器单例与真实计时，确认弹层文案和图形按设计稿还原。

## 数据流

`编辑资料初始化 → 并行读取主页/基本资料/标签/介绍/关于我/语音/歌曲 → 领域映射 → 页面渲染`

子页面保存后通过 `PROFILE_UPDATED_EVENT` 只更新对应区域；父页面记录并恢复滚动位置，不重新拉取整页。
