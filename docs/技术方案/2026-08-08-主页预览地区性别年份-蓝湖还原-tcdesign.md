# 主页预览地区、性别与年份蓝湖还原技术记录

日期：2026-08-08

## 1. 范围与门禁

- 页面：微信小程序“编辑资料 -> 主页预览”首屏资料区。
- 设计画板：蓝湖主页预览 `461285cf-e519-4d13-b60b-17b73b5bb862`。
- 设计基线：`docs/验收报告/截图证据/2026-07-10-主页预览/蓝湖基线-主页预览-首屏-750x1626.png`。
- 运行视口：微信开发者工具 iPhone 12/13 Pro，`390 x 844`。
- 验收阈值：关键首屏不低于 97%，整体不低于 95%。

## 2. 根因

1. 基本资料保存的是省市 code；主页摘要只读取新接口的 `locationCityLabel`、`hometownCityLabel`。线上接口暂未携带标签时，已有地区被误判为空。
2. 主页预览性别图标固定引用女性红色切图，没有消费 `gender` code。
3. 主页预览资料行读取 `age` 且遗漏星座，与蓝湖示例“97年丨双鱼座”不一致。
4. 头像宽 `188rpx`、左边距 `30rpx`，右缘为 `218rpx`；旧文字起点为 `208rpx`，发生贴靠和重叠。蓝湖文字起点约为 `238rpx`。

## 3. 设计基线与组件映射

| 设计项 | 基线 | 实现落点 |
| --- | --- | --- |
| 头像 | `188rpx`，左 `30rpx` | `ProfilePreviewHero` |
| 昵称/状态起点 | 左 `238rpx`，与头像留 `20rpx` | `profile-preview-identity` |
| 昵称和感情状态 | 同一左边缘、纵向排列 | identity 容器 `alignItems: flex-start` |
| 女性图标 | 红色蓝湖切图 `24 x 34rpx` | `profilePreviewGender` |
| 男性图标 | 蓝色男性切图 `32 x 32rpx` | 复用现有 OSS `qianxunGenderMale` |
| 出生信息 | 两位年份，如“97年” | `buildBasicProfileBirthYearText` |
| 星座 | 位于身高之后 | `basic.zodiac` |
| 居住地 | 中文城市，不展示行政区 code | `buildBasicProfileLocationText` |

目标画板只提供女性资料态；男性状态复用项目已有蓝湖男性图标，不新增近似字符图标，不把图标打入本地包。

## 4. 数据闭环

```text
基础资料接口 code/label
        +
省市树 provinceCities
        ↓
buildBasicProfileLocationText
        ↓
编辑资料摘要 + 主页预览资料卡
```

- 优先使用接口中文标签。
- 旧接口无标签时，按省市树用 code 查找中文名称。
- 字典查不到时保持空值，不向用户暴露六位行政区 code。
- 出生年份直接从 `birthday` 提取，不用当前年龄反推；星座紧随身高展示。
- 性别图标直接按 `MALE/FEMALE` 映射。

## 5. 测试策略

- RED：复现“有 code 无 label 显示为空”和缺少出生年份映射。
- GREEN：省市树兜底、年份领域函数、动态性别图标和蓝湖间距落地。
- 静态门禁：校验男性/女性图标分支、`238rpx` 起点和同左边缘布局。
- 完整构建：执行小程序全部 prebuild 门禁与 `build:weapp`。
- 运行验收：微信开发者工具真实接口数据截图。
