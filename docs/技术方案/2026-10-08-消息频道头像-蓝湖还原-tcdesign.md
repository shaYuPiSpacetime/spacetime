# 消息频道头像蓝湖还原技术方案

## 1. 范围与设计来源

- 页面：官方小助手、系统消息。
- 蓝湖项目：`时空邂逅0625`。
- 蓝湖画板：`消息-切图`，Design ID `898b47f4-64ae-49ce-aad1-f47c26a3c979`。
- 目标：只替换两个频道页面左侧头像，不改变消息列表、卡片、跳转和已读逻辑。

## 2. 设计基线

| 资源 | 蓝湖切图 | 原始尺寸 | 运行尺寸 | SHA-256 |
|---|---|---:|---:|---|
| 官方小助手喇叭 | `icon-3.png` | 196×196px | 49×49px | `07e7e9feaa22b7c8e11fc6381a694e16e662e11336050b75d94b794e4884f641` |
| 系统消息铃铛 | `icon-4.png` | 196×196px | 49×49px | `bddf25a7263fae72d26913fdc92a40361da1764b2254cca28f467f4e47a4fe20` |

画板预览与 11 张 MCP 原始切图保存在 `docs/验收报告/截图证据/2026-10-08-消息头像蓝湖切图/`。两个目标文件均按蓝湖 MCP 2× PNG 原始字节落盘，不进行缩放、裁切、转码或压缩。

## 3. Token 与组件映射

| 蓝湖元素 | 项目落点 |
|---|---|
| 官方小助手头像 | `miniappOssIcons.messageAssistant` |
| 系统消息头像 | `miniappOssIcons.messageSystem` |
| 49pt 头像尺寸 | `.message-channel-badge`、`.message-channel-icon` |
| 两页共享渲染 | `ChannelBadge` |

非底部静态图标通过 `npm run assets:upload-icons` 原字节上传 OSS；运行态不引用蓝湖 CDN 和本地包内资源。

## 4. 验收门禁

1. 两个源文件必须为 196×196px，哈希与 MCP 下载结果一致。
2. 两个 OSS 键必须生成新的内容哈希 URL。
3. `ChannelBadge` 必须按频道选择正确图标，运行尺寸为 49×49px。
4. 消息静态门禁、OSS 校验和微信小程序构建全部通过。
