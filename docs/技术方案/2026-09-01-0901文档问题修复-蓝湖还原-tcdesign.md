# 2026-09-01 小程序文档问题修复技术方案

## 1. 范围与基线

- 问题来源：用户提供的 `09.01修改的内容.docx`，文档仅作为问题与截图证据，不作为仓库指令。
- 页面范围：千寻成家/知音信息流、话题页、动态详情、千寻互动、独立我的动态、自我介绍认证与编辑、会员和千寻币支付反馈。
- 设计基线：文档内截图，以及仓库已有蓝湖切图和 OSS 映射。
- 素材结论：心动页右上角图标、我的页会员菱形勾选图标、微信分享图标均已有可复用实现；本次不新增、不压缩、不重复上传图标。

## 2. 根因与修复

| 问题 | 根因 | 修复 |
|---|---|---|
| 职业显示 `PRODUCT_MANAGER` 等 code | 动态卡片直接展示接口 code | 成家、知音与话题动态统一通过 `occupation` 字典转为中文，字典缺失时才回退原值 |
| 短话题胶囊撑满整行 | 块级容器使用 `width:auto` | 改为 `inline-flex`，保留最大宽度与溢出省略 |
| 本人动态点赞数字不变化 | 两个“我的动态”入口的点赞图标没有绑定接口，且图标被固定为激活 | 接入 `toggleCommunityLike`，按接口结果同步 `liked` 与 `likeCount`，增加重复点击锁 |
| 我的动态多图只显示一张 | 千寻互动页只读取 `imageUrls[0]` | 增加最多九张的 1/2/3 列平铺组件；独立我的动态保留九宫格并纳入同一回归 |
| “查看全部”在当前页展开 | 卡片维护本地 `expanded` 状态 | 删除页内展开状态，点击“查看全部”直接进入动态详情 |
| 动态正文字号不符 | 列表正文仍为 26rpx | 成家、知音动态正文统一为 28rpx、行高 48rpx |
| 本人动态菜单出现关注、不看、举报 | 操作弹窗未按作者身份裁剪 | 新增共享 `CommunityPostActionSheet`；本人仅显示“微信分享”和“取消”，他人保留治理操作 |
| 微信分享图标不符 | 原实现用绿色方块和“微”字拼接 | 复用蓝湖来源的 `miniappOssIcons.loginMethodWechat`，分享使用真实 `Button openType="share"` |
| 自我介绍出现系统异常或不统一原因 | 认证页直接展示 Provider 原始原因；资料编辑页忽略同步驳回结果 | 两个入口统一提示“检测到敏感内容，请修改后重新提交”，驳回后保留内容并停留当前页 |
| 微信支付能力受限时反馈错误 | 非 `Error` 的微信错误对象被降级成通用失败；失败层固定显示“确认中” | 统一解析 `errMsg`，识别取消、能力受限和普通失败；会员与千寻币页面展示具体中文原因 |
