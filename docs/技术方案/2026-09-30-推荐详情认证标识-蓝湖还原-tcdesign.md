## 数据与组件

公开资料接口已提供 `certifications`，只包含当前生效且通过认证的 `AVATAR / REAL_NAME / EDUCATION`。用户详情此前传入空认证数组，导致认证区隐藏。

1. 将接口 code 映射为固定三个认证项目：头像、实名、学历；只有返回的项目点亮，未返回、缺失或未知 code 不点亮。
2. 公开主页认证区三项固定可见；无相册时仍展示。
3. 总“三重认证”徽标要求三项全部通过，避免部分认证时误显示全部通过。
4. 公开主页不展示可信度百分比，按正式版 PRD-08 的认证徽章规则处理。
