# 我的与会员中心细节蓝湖还原技术方案

## 1. 背景与范围

需求来源为腾讯文档待处理清单及用户本轮明确补充：

- “我的”：调整头像细节、头像与右侧文字间距；
- “会员中心”：金额字体不能全部加粗，协议区域按设计稿收为一行。

本轮只处理以上两项，不扩展腾讯文档中的其他历史待处理行，不修改后端接口和数据库。

## 2. 设计基线

设计来源：

- 蓝湖页面“我的”：`miniapp/.lanhu-ref/我的/我的.png`；
- 蓝湖页面“会员中心-全”：`miniapp/.lanhu-ref/会员中心/会员中心-全.png`；
- 蓝湖 MCP 图层数据，按 375px 逻辑宽度换算为 750rpx。

## 3. 根因

### 3.1 我的

头像图片原为 112rpx，页面横坐标 31rpx 到 143rpx；昵称从 148rpx 开始，可视间距仅 5rpx。设计稿头像可视区域结束于 129rpx，昵称从 149rpx 开始，间距应为 20rpx。

### 3.2 会员中心

- 时长和月均价直接设置 `fontWeight: 700`，造成金额信息整体过粗；
- 时长“12个月”未拆分数字与单位，无法还原两级字号；
- 协议容器设置 `flexWrap: 'wrap'`，两个并列文本在窄屏下会折成两到三行；
- 底部金额使用 30rpx / 700，与蓝湖 24rpx 中等字重不符。

## 4. 实现

### 4.1 我的

- 头像底座改为 110rpx，头像图片改为 98rpx；
- 昵称定位改为 `left: 124rpx; top: 2rpx`；
- 地区/年龄定位改为 `left: 124rpx; top: 58rpx`；
- 头像资料整体点击区高度扩为 124rpx，覆盖头像和资料进度标识；
- 增加稳定元素 ID，供微信运行态量测使用。

### 4.2 会员中心

- 新增 `splitDurationLabel`，将时长数字与单位分开渲染；
- 套餐标题、时长、月均价、原价、底部金额按蓝湖字号和字重调整；
- 协议改为单个嵌套文本节点，父容器和文本同时禁止换行；
- 保留原有套餐接口、选择、支付和会员状态逻辑，不改变业务链路。
