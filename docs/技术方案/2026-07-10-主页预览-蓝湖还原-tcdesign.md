# 主页预览蓝湖还原技术方案

## 1. 范围与验收目标

- 页面：微信小程序“编辑资料 -> 主页预览”默认态。
- 蓝湖父画板：`08308a03-82cf-43e1-bd40-a502fa089f6a`（编辑资料）。
- 蓝湖目标子画板：`461285cf-e519-4d13-b60b-17b73b5bb862`（主页预览）。
- 设计画布：`750 x 6803`，实现单位按 Taro `rpx` 一比一映射。
- 验收门禁：关键首屏还原度不低于 97%，整体还原度不低于 95%。
- 交互范围：返回、编辑资料/主页预览切换、分享按钮；交互控件必须为真实组件。

## 4. 实现边界

- 修改 `ProfilePreviewPage.tsx`：按蓝湖结构重建预览内容，不修改编辑资料表单业务。
- 修改 `ProfilePreviewTopNav.tsx`：按激活/未激活状态分别映射字号、行高和下划线尺寸。
- 新增静态门禁：校验关键尺寸、文案、素材引用和禁止整页截图/透明热区。
- 保留当前页内切换方式，禁止重新引入对底部 Tab 页的非法 `navigateTo`。

## 5. 验证方式

1. 运行静态蓝湖门禁，先失败再实现至通过。
2. 运行 ESLint 和微信小程序构建。
3. 启动 H5 开发预览，在 `375 x 812` 与 `414 x 896` 截图。
4. 与蓝湖 `750 x 6803` 基线逐段核对结构、尺寸、字体、素材和裁剪。
5. 将截图、差异清单、评分和未闭环项写入验收报告。
