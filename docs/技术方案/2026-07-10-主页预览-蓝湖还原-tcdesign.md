# 主页预览蓝湖还原技术方案

## 设计来源与范围

- 用户提供链接的当前画板为“编辑资料”，其中顶部含“主页预览”入口。
- 主页预览设计基线为同一蓝湖项目中 `image_id=461285cf-e519-4d13-b60b-17b73b5bb862`，本地参考图：`miniapp/.lanhu-ref/lanhu-full-2026-07-07/images/03-主页预览.webp`。
- 画布源图为 `750 x 6803`，按 iOS @2x 换算为逻辑画布 `375 x 3401.5`；验收首屏视口为 `375 x 812`。
- 覆盖状态：默认预览态、编辑资料与主页预览的双标签切换、返回、分享按钮点击。

## 设计基线表

| 区域     | 视觉与尺寸基线                                                      | 组件落点                          |
| -------- | ------------------------------------------------------------------- | --------------------------------- |
| 页面背景 | 浅青、浅蓝、浅黄的横向柔和渐变                                      | 预览页根容器                      |
| 顶部     | 返回箭头、双标题、蓝色下划线、微信原生胶囊预留区                    | `ProfilePreviewTopNav`            |
| 首图     | 700rpx 宽圆角人物图，底部渐变信息层，左下头像、昵称、认证与情感状态 | `ProfilePreviewHero`              |
| 基础资料 | 白色圆角卡，性别/年龄/身高体重/星座和常住地/家乡两行                | `ProfilePreviewBasicInfo`         |
| 内容卡片 | 白底、圆角、蓝色点缀标题；标签使用彩色胶囊                          | 标签、介绍、认证、歌曲、MBTI 组件 |
| 相册     | 三张 700rpx 宽、圆角图片，位于介绍、认证和歌曲区块之间              | `ProfilePreviewPhoto`             |

## Token 与组件映射

| 设计元素 | 实现方式                                                         |
| -------- | ---------------------------------------------------------------- |
| 品牌蓝   | `#2876FF`                                                        |
| 标题深蓝 | `#0C285A`                                                        |
| 主体白卡 | `#FFFFFF`，圆角 `24rpx` 到 `32rpx`                               |
| 弱文本   | `#7F8494` 或 `#9EA5B5`                                           |
| 页面边距 | `25rpx`，卡片内容内边距 `26rpx` 到 `32rpx`                       |
| 顶部标签 | 共享组件，依据菜单胶囊实际位置计算安全区与文字中心               |
| 相册素材 | 使用已有主图组件化占位；待蓝湖导出独立相册切片后可单独替换图片源 |

## 交互与路由

1. 编辑资料页点“主页预览”调用 `Taro.navigateTo('/pages/profile/index?variant=preview')`。
2. 主页预览页点“编辑资料”或左上返回，优先返回原编辑页；无页面栈时回退至 `/pages/profile/edit`。
3. 分享图标是可见的真实组件，点击调用平台分享能力或给予可见反馈。
4. 不使用整页截图、透明热区、空白覆盖层承接点击。

## 素材缺口

- 蓝湖 MCP 对主页预览画板返回 `totalSlices=0`。
- 设计中的三张相册人物图没有独立切图；当前仅有编辑资料主图 `edit-hero-photo.jpg` 可复用。
- 本轮不从整页参考图裁剪照片；验收报告必须将该缺口列为素材差异，并限制素材维度评分。

## 验收门禁

- 首屏默认态：页面结构、导航和首图信息层需匹配参考稿。
- 静态门禁：完整预览区块、真实跳转、无整页参考图运行引用。
- 截图核对：375×812 首屏与全长页截图均须留存；因相册素材缺失，最终评分不得将素材项标为完全闭环。
