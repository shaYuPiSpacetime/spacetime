# 推荐私信按钮背景蓝湖还原技术说明

## 目标与范围

- 页面：小程序推荐页 `/pages/recommend/index`。
- 状态：服务端返回 `communicationMode=PRIVATE_MESSAGE`，中间操作按钮展示“私信”。
- 目标：消除底部整条背景对候选资料的遮挡，保持跳过、私信、喜欢三个真实组件及原有交互不变。
- 设计基线：`docs/验收报告/截图证据/2026-08-05-PRD08推荐理想型-蓝湖还原/设计基线/002.png`，逻辑画布 375×812。

## 根因

`RecommendActions` 使用 `left: 0`、`right: 0`、`height: 166rpx` 和高层级渐变背景。该容器覆盖整屏宽度，私信状态出现时会在候选内容与底部 Tab 之间形成一条不属于设计稿的遮罩。

## 还原映射

| 项目 | UI 基线 | 实现 |
| --- | --- | --- |
| 操作区 | 仅包裹三个悬浮控件 | `left: 94rpx; width: 562rpx; height: 166rpx` |
| 操作区背景 | 无整条背景 | `background: transparent`，无渐变或背景图 |
| 中间按钮 | 蓝色胶囊 | `290rpx × 92rpx`，圆角 `46rpx` |
| 两侧图标 | 圆形真实切图 | 各 `98rpx × 98rpx`，继续使用 OSS 图标 |
| 控件间距 | 三控件居中排列 | `gap: 38rpx` |
| 交互 | 跳过、私信、喜欢 | 保留原事件绑定，不增加透明热区 |

组合宽度为 `98 + 38 + 290 + 38 + 98 = 562rpx`，以 `left: 94rpx` 在 750rpx 画布上水平居中。

## 回归门禁

- 静态门禁校验透明背景、定宽容器、禁止渐变、真实按钮节点。
- 微信运行夹具强制构造 `PRIVATE_MESSAGE` 状态，校验“私信”文案、实际尺寸、位置、透明背景和无背景图。
- 正式构建恢复生产接口配置，并执行项目全部构建前门禁和产物门禁。

## 风险与回退

- 本次不修改接口、状态机、按钮点击逻辑、TabBar 或 OSS 素材，影响范围仅为推荐页操作区布局。
- 如需回退，只需恢复 `RecommendActions` 外层布局；运行态门禁会阻止整条渐变遮罩再次引入。
