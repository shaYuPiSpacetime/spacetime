| 蓝湖元素 | 生产实现 |

## 4. 实现与验证

1. 原始 2× PNG 无压缩、无缩放、无格式转换落盘。
2. 通过 `npm run assets:upload-icons` 原字节上传 OSS，并由生成文件统一引用。
3. 删除搜索、入口背景与图标的 CSS 近似绘制，保留容器底色作为图片加载失败兜底。
4. 更新 PRD-08 静态门禁，验证六个 OSS 常量、页面引用、标题和正文行高。
5. 执行小程序构建、页面注册、生产配置、包体门禁；微信自动化可用时补充运行态截图，不可用时如实登记。
