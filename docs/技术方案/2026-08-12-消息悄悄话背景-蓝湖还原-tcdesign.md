# 消息悄悄话入口背景还原技术说明

## 目标

消息首页左侧“悄悄话”入口使用用户提供的完整无文案 PNG 背景；标题、头像组与点击入口继续使用真实组件，不改变右侧私信入口和消息列表。

## 设计基线

- 原始素材：680×316px RGBA PNG，SHA-256 为 `1e609a1f5efb8e8e514d254f04533a05aa072cda3680088093e99f7d4ffa484c`。
- 运行尺寸：340×158rpx，与源图保持严格 2 倍像素密度和相同宽高比。
- 裁切策略：原始字节上传，不缩放、不裁切、不转换格式、不压缩。
- 文案“悄悄话”和头像组保留为独立真实组件，背景只承载蓝色圆环与 YO 装饰。

## 实现映射

| 基线 | 实现 |
| --- | --- |
| 背景源文件 | `miniapp/src/assets/lanhu/message/home-whisper-card-bg.png` |
| OSS 上传清单 | `messageHomeWhisperCardBackground` |
| 运行时引用 | `miniappOssIcons.messageHomeWhisperCardBackground` |
| 卡片尺寸 | 340×158rpx |
| 图片模式 | `aspectFill`；源图等比，因此无实际裁切 |
| 点击区域 | `message-home-whisper-entry` 整卡入口 |
| 装饰层事件 | `pointerEvents: none`，不拦截触摸 |

## 状态与验证

- 默认态：蓝色背景、真实标题、真实头像组。
- 点击态：整卡进入悄悄话列表，原交互不变。
- 静态门禁校验源图尺寸/哈希、OSS 引用、运行尺寸、独立点击入口、旧 YO 插画移除。
- H5 375×812 隔离运行态核对 170×79px 映射尺寸、OSS 地址与点击跳转。
- 发布构建必须关闭固定登录和本地 E2E 地址。
