## 根因与闭环结果

| 问题 | 根因 | 闭环结果 |
| --- | --- | --- |
| 头像来源浮层遮挡取消按钮 | 来源浮层与固定底部按钮同层，底部按钮仍挂载 | 来源浮层打开时卸载固定按钮，浮层提升至 `zIndex: 40` |
| 更多照片第二行不回显 | 后端相册 VO 丢失 `sortOrder`，前端又按返回下标压缩 | 后端恢复并排序 `sortOrder`，前端按 0-5 固定槽位合并，上传后局部回显 |
| 输入框显示“请选择” | 输入型字段和选择型字段共用了同一个动态占位文案 | 新增 `common_input_placeholder`，按字段类型读取动态文案 |
| 更新认证进入错误页面 | 原页面复用了认证引导中心 | 新增独立“我的认证”详情页，头像、实名、学历分别展示状态与详情 |
| 子页返回滚回顶部、明显卡顿 | 保存后重定向或父页重新请求整屏数据 | 子页通过 EventChannel 回传局部数据，父页保持 ScrollView 位置，不做整页刷新 |
| 标签、关于我、歌曲保存后不回显 | 子页保存结果没有通知父页 | 标签、关于我、自我介绍、歌曲均回传最新数据并立即局部更新 |
| MBTI 类型仍显示 | 编辑页和主页预览仍挂载 MBTI 模块 | 两处均移除 MBTI 模块与相关状态 |
| 歌曲首屏无数据 | 空关键词 Mock 只返回单条命中逻辑，页面未主动拉推荐 | 空关键词返回推荐列表，页面首屏主动加载 |
| 主页预览报 `EmptyText is not defined` | 预览页引用未定义组件 | 改为真实 `Text` 空态，微信运行态切换无异常 |
| 我的认证深层页面返回后状态不更新 | 详情页只在首次挂载时加载 | 使用 `useDidShow` 局部刷新并回传认证状态，父页原位更新 |
