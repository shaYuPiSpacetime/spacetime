- 静态门禁要求：所有页面只能引用共享 `LoginNextButton`，不得恢复页面级箭头样式或字符箭头。

### 消息页

### 千寻币页

- MCP 基线：`设计基线/02-千寻币页-632e7124-mcp-current.png`；运行截图：`运行截图/02-千寻币页-375x812.png`；协议勾选态：`运行截图/02-千寻币页-协议勾选-375x812.png`；像素差异：`差异/02-千寻币页-diff.png`。
- 修复余额卡：移除近似 CSS 水印，改用 MCP 原始 `1400×376` RGBA 背景图作为独立 `Image`；余额、数字和“明细”仍由真实组件绘制。原文件 SHA-256 为 `336188059244211afa9e9a96c120b1246e48c71af8e2d79f512b105fb59dd670`，已原样上传 OSS。
- 修复套餐区：币种小图替换为当前 MCP 原始字节（SHA-256 `245196965e796a209279ce7d555d6b985ff931b1acde032366a6b269423a1f98`）。卡片调整为 `240×184rpx`、间距 `8rpx`、推荐卡偏移 `153rpx`、轨道上内边距 `16rpx`；币数、原价、折扣和价格分别采用 `30/40`、`20/28`、`18/24`、`40/44rpx` 的字号/行高组合。
- 修复套餐数据映射：蓝湖默认三档为 `1000/¥99`、`3000/¥268`、`6000/¥428`；首档副标题使用后台 `packageDesc=多看50位嘉宾`，本地蓝湖演示数据同步为三档，正式页面仍读取真实接口。

- 用途区继续使用 8 个独立 OSS 图标与真实文本；MCP 整组切图仅作为差异参考，未把可交互页面烘焙为整图。

- H5 验收仅在忽略目录 `miniapp/dist/` 内启用 `rpx→px` 截图换算和滚动条隐藏；该换算不进入小程序源码或发布包。
