## 3. 差异与处理

| 差异 | 处理 |
|---|---|
| 公开详情不显示认证区 | 接入接口 `certifications`，映射为固定三项 |
| 部分通过时总徽标可能误报“三重认证” | 总徽标改为检查头像、实名、学历全部通过；仅通过项各自点亮 |
| 全未认证时原可见性判断隐藏整个区块 | 公开主页三项固定可见，未通过置灰 |
| 灰色图标存在方形底色 | 未点亮图标加圆形裁切、灰阶和较低透明度 |
| 截图中有可信度百分比 | 正式 PRD-08 明确不展示；公开主页隐藏该数值区 |
| 长昵称可能挤压总徽标 | 昵称限制可用宽度并省略溢出；总徽标禁止收缩 |
