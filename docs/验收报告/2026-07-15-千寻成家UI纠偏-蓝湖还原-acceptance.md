## 3. 根因与处理

| 问题 | 根因 | 当前处理 |
|---|---|---|
| Tab 点击后闪烁 | 推荐页手工渲染一次，框架 custom TabBar 又渲染一次；custom 首帧默认“我的” | 删除页面内 TabBar；按当前路由同步初始化；无路由时不错误点亮 |
| 图标未点亮 | 普通 Tab 只有一套灰色图标，仅额外叠蓝点 | 增加 normal/active 两套资源，并按 `isOn` 切换 |
| 胶囊重叠 | 页面在微信原生胶囊位置又画一套假胶囊 | 删除假胶囊；用 `getMenuButtonBoundingClientRect` 计算头像安全位置 |
| 头像不一致 | 页头写死蓝湖人物素材 | 统一读取 `/miniapp/profile/home-detail.profile.avatar` |
| 字体与 Tab 过大 | 一级 36/30 且 800；二级总宽 700、单项 220 | 按蓝湖 token 收敛为 32/28 和 344/108 |
| 切换时整页闪白 | 每次切换都清空内容并显示 LoadingCards | 按场景缓存，只有首次无缓存时显示骨架 |
| 同城、热门串台 | 请求无场景序列保护，慢响应可覆盖新 Tab | 每个场景维护请求序列，过期响应丢弃 |
| 热门假数据 | 生产页硬编码话题、封面、头像和 2.2 亿浏览 | 删除运行态假话题；等待后端丰富话题接口 |
| 旧验收失真 | 同城全、热门都使用 `variant=hot`，截图哈希相同 | 禁用生产 `variant`；旧报告标记作废；新脚本点击真实 CITY/HOT 并校验哈希不同 |
