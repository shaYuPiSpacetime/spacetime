# 实名认证提交按钮底部布局验收报告

## 1. 验收范围

- 页面：`/pages/verification/real-name`
- 变更：提交按钮从错误的顶部位置移动至页面底部安全区上方
- 基线截图：`docs/验收报告/截图证据/2026-08-20-实名认证提交按钮底部布局-before.png`
- 页面状态：未提交、空表单、协议已勾选、按钮禁用

## 2. 差异与修复

| 维度 | 基线问题 | 修复结果 |
|---|---|---|
| 布局 | 提交按钮位于导航下方，遮挡“实名认证”标题 | 改为滚动区外的固定底部操作栏 |
| 安全区 | 未形成有效底部定位 | 使用 `24rpx + env(safe-area-inset-bottom)` |
| 响应式 | 绝对纵坐标缺失，设备高度变化时位置不可控 | 固定相对视口底部，不依赖屏幕高度 |
| 交互 | 原按钮绑定真实提交事件 | 继续调用原 `handleSubmit` |
| 状态 | 禁用态、提交中态已存在 | 原状态逻辑保留；提交中时避免重复提交 |
| 内容遮挡 | 固定操作区可能覆盖滚动内容 | 容器存在操作区时增加 `220rpx` 底部留白 |
