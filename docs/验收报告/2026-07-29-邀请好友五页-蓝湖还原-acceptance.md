## 3. 页面闭环说明

### 3.1 邀请首页三态

- 主视觉使用蓝湖人物独立插画，标题、导航和说明均为真实文本。
- 奖励关系式、邀请按钮、活动说明入口、查看全部入口均为真实组件，未使用整页截图或透明热区。
- `recentRecords.length` 驱动有记录/空记录状态。
- `successCount`、`progressCurrent`、`progressMax` 和 `ladders` 驱动当前阶段与后续三档展示；“完成 20 人”不是客户端写死分支。
- 分享继续使用微信 `openType="share"`；不支持时保留可归因链接复制降级。

### 3.2 邀请记录

- 顶部汇总来自邀请首页接口，列表来自邀请记录分页接口。
- 关系记录和 `rewardItems` 转换为与蓝湖一致的扁平奖励时间流。
- 注册奖励、阶梯额外奖励、金额、时间和头像均由真实数据映射。
- 下拉刷新、触底分页、加载、空态、失败重试均保留。

### 3.3 活动说明

- 标题和正文排版按蓝湖“活动说明”画板重构。
- 继续使用 PRD-06 当前配置，保留安全 HTML 清洗、HTTPS WebView、最近成功缓存和不可用重试三态。
- 客户端不写死线上活动规则；截图中的正文由视觉夹具复现蓝湖样例。

## 4. 环境与数据说明

- 真实链路检查使用测试环境接口，确认能够读取累计邀请、累计到账、邀请记录和阶梯奖励；未连接本机 MySQL 或 Redis。
- 五张固定截图通过无状态 HTTP 视觉夹具稳定复现蓝湖的有记录、0 人、20 人、记录流和规则正文，仅用于截图对照，不持久化任何业务数据。
- H5 截图不包含微信客户端系统状态栏与胶囊按钮；生产小程序仍由 `NativeNavigation` 按运行设备的状态栏和菜单按钮指标布局，没有用图片模拟系统控件。

## 5. 素材与规则门禁

- 包内只新增两张非交互独立插画：`invite-hero.png`、`invite-empty.png`。
- 按项目规则尝试进入 OSS 上传链路时，发现测试环境缺少 `DEV_OSS_ENDPOINT`、`DEV_OSS_BUCKET_NAME`、`DEV_OSS_ACCESS_KEY_ID`、`DEV_OSS_ACCESS_KEY_SECRET`，因此停止写入。
- 小型分享、用户、货币、人物和礼物图标改用 DOM/CSS 原生绘制；没有把同一图标同时作为本地与远程资源，也没有修改 OSS 生成清单。
- 导航、按钮、Tab、列表、弹窗操作区均未烘焙进截图，没有透明热区或 `opacity: 0` 点击层。
