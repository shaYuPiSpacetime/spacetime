# 千寻 66 稿蓝湖还原验收报告

## 一、验收结论

- 验收对象：蓝湖项目中千寻区域的 66 张设计稿。
- 蓝湖入口：<https://lanhuapp.com/web/#/item/project/stage?tid=428e8368-c279-4369-947b-a5828487924d&pid=d9c9e50f-fee5-47ca-bd6b-ae05c0d5332b>
- 本轮巡检状态：刷新无限骨架屏、成家首次挂载、知音同页 Tab、悦目、诚意贴、真实交互和原生胶囊对齐已完成代码落地。
- 验证状态：静态门禁、ESLint、微信小程序完整构建、后端单测和包体门禁通过。
- 还原方式：真实 Taro 组件、真实路由与真实接口；未使用整页设计截图、透明热区或不可见控件冒充运行页面。
- 评分边界：本轮改造后的悦目、诚意贴尚未生成有效的真实数据运行截图，因此暂不给出新的像素还原分，不沿用旧截图分数冒充本轮结果。

### 1.1 本轮现场图根因与修复

1. 现场图中的三块空白卡是 `pages/index/index` 准入骨架屏，不是成家信息流空态。
2. 准入请求异常时旧逻辑只弹 Toast，没有把 `ready` 置为 `true`，因此页面会永久停在骨架屏。
3. 现已改为：优先复用已缓存的服务端准入态；失败时退出骨架屏，展示明确错误与“重新加载”；首次挂载成家组件时由 `useEffect` 主动请求数据，不再仅依赖错过的子组件 `useDidShow`。

### 1.2 导航、回复与互动 Tab 巡检

针对本轮反馈继续完成以下闭环：

1. 千寻“关注 / 同城 / 热门”二级菜单不再使用 `Math.max(176, …)` 强制下压，改为相对一级菜单固定偏移 `70rpx`，一级下划线与二级菜单间保留约 `17rpx` 视觉间隙。
2. 新增统一 `NativeNavigation` 与 `MiniappBackIcon`：只读取微信原生菜单矩形做垂直中心线、安全区和导航高度计算，不绘制右上角胶囊；动态详情、发布动态、话题、千寻互动、我的动态均已迁移。
3. 动态详情和话题页原先自绘的顶部三点控件已移除；页面内动态操作仍保留真实可见的卡片操作入口。
4. 评论“回复”现在会记录父评论 ID、被回复用户 ID，立即聚焦输入框并切换“回复某人”占位提示；提交时通过既有真实评论接口携带回复关系。动态操作菜单中的“回复”也会关闭菜单并聚焦输入框。
5. 千寻互动的“互动 / 浏览记录 / 我的动态”三个内容区改为一次挂载、显隐切换；“我的动态”不再通过 `redirectTo` 跳页，避免组件销毁、页面过渡和空白闪屏。
6. 横向巡检并统一了通用自定义导航、搜索/设置二级导航、资料编辑/预览、认证流程、登录资料页、心动/消息和会员导航壳；源码中已无字体返回符号 `‹`，统一由 CSS 箭头组件绘制。

## 三、落地范围

### 3.1 千寻独立分包

新增 `pages/qianxun` 独立分包，包含：

- 发布动态 `compose`
- 动态详情 `post-detail`
- 社区话题列表 `topics`
- 话题详情 `topic`
- 千寻互动 `interactions`
- 我的动态 `my-posts`
- 知音 `kindred`

原 `pages/recommend/post` 已迁出主包并删除，首页千寻中心图改用 OSS 公网资源。当前路由总数 73：主包 14 页，分包 59 页。

### 3.2 真实交互与数据

- 成家页已接通关注、同城、热门、个人中心、知音、详情、话题和评论入口。
- “知音”已改为千寻页内一级 Tab，不再 `navigateTo` 到独立页；内部使用“悦目 / 诚意贴”二级 Tab。
- 悦目页改为审核通过的用户公开照片双列卡片，展示缘分标签、学历学校、在线时间，支持进入用户主页和真实心动切换；不再从热门动态首图拼照片墙。
- 诚意贴独立查询 `sincere_post`，已接通作者主页、关注、悖悖话/私信入口、评论、点赞、话题、举报、屏蔽动态、微信原生分享与发布诚意贴。
- 顶部成家/知音/立业和本人头像共享 `QianxunHeader`，根据 `getMenuButtonBoundingClientRect()` 实时计算原生胶囊中线、头像右侧间距、二级 Tab 和内容起始位置。
- 发布页支持正文、图片、话题、上传进度、草稿返回确认、发布成功与失败回执。
- 详情页支持详情、评论、发表评论、点赞、关注、举报和操作菜单。
- 话题页支持热门/最新切换及参与话题。
- 互动页覆盖互动、浏览记录、我的动态及关注/粉丝/获赞入口。
- 我的动态消费真实本地发布回执，并支持已发布内容删除、发布中和失败状态。

本轮新增接口：

- `GET /miniapp/community/yuemu`
- `POST /miniapp/community/yuemu/{targetUserId}/like`
- `GET /miniapp/community/sincere-posts`

### 3.3 明确缺口

- 当前开发库未执行仓库已有迁移 `deploy/sql/prod/056_prd02_relation_feedback.sql`，缺少 `app_user.anonymous_no`；固定登录初始化因此在启动后退出。
- 本轮尝试对共享开发库执行最小、可重复补丁时被安全门禁拒绝，未绕过、未修改共享库。
- 因后端无法带真实数据启动，且微信 IDE 自动截图接口本轮持续超时，悦目与诚意贴的新运行截图暂缺。恢复条件是：由获授权的开发库管理流程执行既有 056 迁移，再重跑 `node scripts/capture-qianxun-current-ui.cjs`。
- 悖悖话/私信入口已携带真实作者、头像与资料进入既有编辑器，但仓库当前的 `MessageService` 仍是内存 Mock Provider；本报告只验收入口与页面交互，不宣称悖悖话已写入服务端。
- 既有互动聚合、关注列表、粉丝列表及“只看我的动态”服务端查询接口仍未补齐，不影响本轮悦目/诚意贴主路径。
