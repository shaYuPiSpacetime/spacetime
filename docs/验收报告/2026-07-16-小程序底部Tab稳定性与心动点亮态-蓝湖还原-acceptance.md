# 小程序底部 Tab 蓝湖切图与互斥切换验收报告

## 验收范围

- 五个底部入口：千寻、心动、推荐、消息、我的。
- 4 组普通/点亮态蓝湖切图与推荐圆钮。
- 连续切换、快速连点、导航失败回滚与缓存页面状态同步。
- 自定义 TabBar 在微信开发者工具中的稳定挂载。

## 设计基线

- 蓝湖父页面：“我的”，设计 ID `a2fd5bfd-5e7b-47e6-85d9-6e3641c021cc`。
- 蓝湖子画板：“切图”，设计 ID `35cbbbef-696f-4d80-bf36-2a6db73ebade`，版本 3。
- 蓝湖 MCP 返回 13 张切图，本次使用其中 9 张：4 组普通/点亮态 80×80 PNG，以及推荐圆钮 268×268 PNG。
- 所有运行素材均按蓝湖下载原文件落盘，未压缩、未缩放、未转格式。

## 闭环结果

1. 千寻、心动、消息、我的均使用蓝湖普通/点亮两套 PNG；推荐使用蓝湖完整圆钮 PNG。
2. active 切图已经包含蓝色高光，运行代码不再叠加通用蓝点，也不再混用旧 SVG。
3. `app.config.ts` 的 5 组原生兜底图标已按普通/点亮态正确映射。
4. 五个缓存页面实例订阅唯一共享 key，点击千寻时只有千寻点亮，点击心动时只有心动点亮。
5. 普通态与点亮态图片常驻，通过透明度互斥切换，连续点击无换图闪烁。
6. 同一路由内快速点击心动、我的时只受理首个事务，500ms 后未发生二次乱跳。
7. 应用配置和微信开发者工具配置均已关闭 `requiredComponents`，重启项目后自定义 TabBar 稳定挂载。
