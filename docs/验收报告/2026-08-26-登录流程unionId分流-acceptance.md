# 登录流程 unionId 分流验收报告

## 范围

设计来源为用户截图，覆盖登录入口分流、首次用户五步准入、自我介绍微信授权及三重认证跳转。

## 静态验收

- 已新增 unionId 优先、openId 回退的服务端识别逻辑。
- 历史用户恢复资料续填会话，首次用户创建资料续填会话；点击“立即使用”均直接进入当前待完成的准入步骤。
- 同城内容保持可浏览，头像、详情、话题、评论、更多、关注、点赞、私信/悄悄话、发布及个人入口均统一受未认证弹窗保护。
- 五步准入继续使用现有真实页面和接口，地址完成后沿用项目未认证准入状态。
- 自我介绍“下一步”为真实 `Button openType=getPhoneNumber`；未达到 20 字时禁用，授权失败不提交，授权成功后保存并跳转三重认证。
- 未新增本地图标或混用 OSS 图标，未将交互控件烘焙进图片。

## 验证结果

- `npx tsc --noEmit`：项目既有依赖声明及存量源码错误导致失败；输出未出现本次新增文件错误。
- `npx taro build --type weapp`：通过（Webpack 编译成功）；仅保留项目既有包体积告警。
- 后端 Maven：当前环境无 `mvn`/`mvnw`，未执行。
- 微信运行态截图：待具备后端运行环境和微信开发者工具登录态后补充，当前不声明达到 95% 高还原门禁。

## 待运行验收

1. 首次微信：立即使用 → 性别 → 年龄 → 身份 → 学历 → 地址 → 同城未认证态。
2. 历史微信：立即使用 → 原登录方式弹层。
3. 自我介绍不足 20 字按钮禁用；达到 20 字按钮点亮。
4. 点击下一步出现微信手机号授权；拒绝时停留，允许时进入三重认证。
