## 3. 差异闭环

| 原差异 | 修复结果 |
|---|---|
| 顶部同时出现“成家立业”和“社区话题” | 页面级关闭原生导航，只保留“社区话题” |
| 左上角两个返回箭头 | 微信运行态只剩统一返回箭头 |
| 图片/视频/表情使用字符占位 | 改为独立线性 View 图形，图片与视频包含蓝色点缀 |
| 空白发布态提前显示加图方块 | 空白态隐藏；已有图片且不足 9 张时才出现 |
| 底部出现设计稿不存在的 `0/9` | 已移除 |
| 默认自动选择首个话题 | 改为“添加话题”；路由或草稿带入时才显示选中态 |
| 话题胶囊缺少独立图标结构 | 已补蓝色 `#` 圆标、添加箭头与选中关闭态 |
