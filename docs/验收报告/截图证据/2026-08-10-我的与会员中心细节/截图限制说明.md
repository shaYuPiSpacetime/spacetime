# 截图限制说明

微信开发者工具自动化端口可以完成页面跳转、元素查询、尺寸量取和文案断言，但当前机器的 `miniProgram.screenshot` 指令返回 `timeout waiting for automator response`。项目既有运行态脚本也记录过相同的开发者工具截图限制。

本轮未使用 H5 截图替代小程序截图，因为 Taro 内联 `rpx` 在 H5 构建下的渲染基线与微信小程序不同，会产生失真。验收采用以下证据组合：

1. 仓库内蓝湖原始设计图；
2. 蓝湖 MCP 图层坐标与字号；
3. 微信小程序运行态元素尺寸和文案量测；
4. 静态契约测试与微信小程序构建结果。

待开发者工具恢复截图权限后，可直接执行：

```bash
cd miniapp
WX_AUTO_PORT=9473 PROFILE_MEMBERSHIP_SKIP_BUILD=true node scripts/verify-profile-membership-detail-runtime.cjs
```
