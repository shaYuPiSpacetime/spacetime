## 2. 关键改动

1. 浏览记录从旧 `/me/view-history` 切换到真实 `/me/interactions?type=viewed`，保留互动时间与完整动态。
2. 新增稳定日期分组与格式化层，分组标题使用 `YYYY年MM月DD日`，卡片底部使用 `MM-DD`。
3. 新增共享千寻图标组件，统一女性/男性、评论、点赞及点赞激活态。
4. 互动页三个主 Tab 常驻，切换不再重建整页；内容面板、用户区、统计区按蓝湖纵向基线对齐。
5. 后端历史查询只返回仍为 `published` 的动态；本人动态排除 `deleted`、`blocked`。
6. 清空浏览记录收口到右上角操作菜单与二次确认，不在页面内增加设计稿外按钮。
