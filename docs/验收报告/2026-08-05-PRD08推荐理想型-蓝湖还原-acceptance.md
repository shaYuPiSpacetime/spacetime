## 4. 设计差异闭环

| 原差异 | 最终处理 |
|---|---|
| 推荐 Tab 错误复用家园聚合页 | 改为真实推荐候选与等待状态 |
| 推荐上限页入口图标不完整 | 使用 OSS 悄悄话图标、独立同城图标和会员徽章 |
| 理想型结果首卡顶部被裁剪 | 固定 ScrollView 起点，移除越界负边距 |
| 结果标签不足两行 | 卡片高度和标签区按设计扩展 |
| 地址把国家类型作为滚轮列 | 改为“中国/海外地区国家”独立 Tab |
| 地址选中行文字被背景遮挡 | 蓝色选中背景下沉到原生滚轮下层 |
| 海外入口可点但无数据 | 由后端能力字段禁用并展示原因，不伪造国家字典 |
| 帮助页写死 200 币/9 折/90 天 | 单价、折扣和保留期全部读取后端动态配置 |
| 历史记录缺少不可变命中条件 | 从快照候选读取创建时摘要 |
| 解锁全部由客户端算价 | 改为服务端报价令牌和确认扣币 |

## 5. 动态数据差异说明

以下差异属于设计样例与运行数据不同，不是视觉缺陷：

- 设计稿中的人物、城市、年龄、学校和动态图片为样例；运行截图使用契约 Mock 或真实接口字段。
- 设计稿帮助页示例为 200 千寻币/位，运行配置为 100 千寻币/位；页面按后端返回展示。
- 地址设计样例为河南/开封，运行数据为江苏/南京；滚轮结构和选中态一致。
- 结果首张卡的解锁顺序由运行数据决定；已解锁与未解锁两种组件均已覆盖。
