## 三、Demo 闭环

1. 千寻首页切换到“热门”后加载话题聚合，话题板块位于动态列表之前。
2. 点击主话题或关联话题进入话题详情；点击“全部话题”进入分页话题列表。
3. 话题详情从服务端加载话题资料和动态；“热门 / 最新”切换会重新请求服务端排序结果，不在客户端伪排序。
4. 动态卡片支持进入详情、作者主页、评论、点赞和联系作者。
5. 点击“参与话题”进入发布页并保留 `topicId/topicName`；发布完成返回详情后自动刷新。
6. 加载失败有明确错误和重试，空话题、空动态有可见空态，所有可见主操作都有反馈。

## 四、正式接口

| Method | Path | 用途 |
| --- | --- | --- |
| GET | `/miniapp/community/topics/home` | 热门页主话题与 4 个关联话题 |
| GET | `/miniapp/community/topics?page=1&size=10` | 社区话题分页列表 |
| GET | `/miniapp/community/topics/{id}` | 话题详情与统计 |
| GET | `/miniapp/community/topics/{id}/posts?sort=HOT\|LATEST&page=1&size=10` | 话题动态分页与排序 |

参与发布继续复用 `POST /miniapp/community/posts` 并携带 `topicId`；提交后先进入 `PENDING`，后台复用既有 `POST /admin/community/posts/{id}/audit` 审核，审核通过后进入话题公共列表。完整字段契约已写入 `docs/移动端文档/miniapp-api.md` 第 16 节。

## 五、交互巡检结果

- 首页刷新：准入失败不会再永久停留在骨架屏，成家组件首次挂载会主动加载。
- 一级 Tab：成家、知音、立业在同一千寻页切换；知音内部悦目/诚意贴保持同页状态。
- 二级 Tab：关注、同城、热门内容区稳定切换；热门话题只在热门态渲染。
- 动态：详情、作者、评论回复、点赞、关注、举报、分享、发布和删除均有真实事件或明确反馈。
- 互动：互动、浏览记录、我的动态改为常驻内容区显隐，避免切换销毁导致闪烁。
- 跨页同城：互动空态“去千寻同城看看”不再误跳底部推荐页，现会返回千寻并自动切换同城。
- 历史深链：旧“我的动态”页的浏览记录、关注、粉丝、获赞均进入对应状态，不再全部落到互动默认页。
- 导航：千寻详情、发布、话题、互动、我的动态均使用统一 `NativeNavigation`；返回箭头样式一致并按系统菜单中线对齐。
- 消息入口：YO 悄悄话和私信图形保持各自独立无损素材，按原始比例显示。
