# 2026-08-04 未认证与基本资料蓝湖还原验收

## 验收范围

- 未认证首页“立即完善”按钮圆角。
- 认证基本资料与编辑基本资料的字段顺序、组合行和卡片分组。
- 家乡二级地区选择弹层。
- 空昵称的系统生成、展示、编辑和后端持久化。

## 蓝湖基线

- 未认证按钮圆角：13.5px，对应小程序 27rpx。
- 基本资料白卡圆角：18px，对应 36rpx。
- 编辑资料保存按钮圆角：20px，对应 40rpx。
- 第一组：昵称、性别、出生日期、现居地、身高/体重、家乡、身份、婚姻状况。
- 第二组：毕业院校、最高学历、行业、职业、公司、年收入。
- 地区弹层：国内/海外标题区、省市双列滚轮、唯一“确认”按钮。

## 实现结果

- 未认证“立即完善”由过圆的 40rpx 调整为 27rpx。
- 资料字段不再按接口数组下标切卡，改为稳定业务行映射；枚举值、字段显隐和提交 code 仍读取接口配置。
- 现居地、家乡改为省市组合行，身高/体重改为双列组合行。
- 编辑资料保存按钮改为第二张卡片后的流式布局，不再固定悬浮遮挡字段。
- 任意字段弹层打开时隐藏页面级保存/下一步，弹层只保留“确认”。
- 家乡滚轮启用增强滚动并隐藏原生滚动条。
- 昵称为空时按用户 ID 稳定生成“用户+四位编号”；页面可点击修改。后端在登录和读取基本资料时补齐并持久化，前端兼容尚未部署该逻辑的旧接口。
