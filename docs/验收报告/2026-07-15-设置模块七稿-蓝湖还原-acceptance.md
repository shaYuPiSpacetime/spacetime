## 2. 设计基线与组件映射

- 画布：750×1624；验收设备：微信开发者工具 375×812，像素比 2。
- 页面背景、字体、颜色、700rpx 内容宽度、98rpx 设置行、注销原因卡片、620rpx 弹窗均按蓝湖 MCP 原始 HTML/CSS 参数实现。
- 列表行、方形勾选框、文本输入区、底部按钮、遮罩和弹窗均为真实组件并绑定事件。
- 除底部 Tab 外的 Logo 使用蓝湖 2x 原图无缩放裁切，经 OSS 上传后引用 `miniappOssIcons.settingsAboutLogo`。
- 没有把整页设计稿用作背景，没有透明热区，没有 `opacity: 0` 伪交互。

## 3. 业务闭环

- 设置页读取 `/miniapp/settings/home`，手机号、微信绑定状态、合规入口和版本号来自接口。
- 退出登录先调用 `/miniapp/logout`，成功后清理本地登录态并重启到登录页。
- 注销页读取 `/miniapp/account/cancel-status` 和公共配置，原因选择、其他原因输入、协议提醒、提交、冷静期与撤销链路均已接通。
- 提交与撤销分别调用 `/miniapp/account/cancel`、`/miniapp/account/cancel/revoke`；截图验收使用微信请求 Mock，未真实写入注销申请。
- 关于我们读取动态版本号、用户协议、隐私政策、公告栏和备案配置；公告与文章详情使用公共内容接口。
- 后端设置聚合已按真实 `openid` 区分微信绑定状态，并排除手机号登录使用的 `phone_` 占位值。

## 5. 差异闭环

首轮截图发现并完成以下回修：

1. 设置页注销入口从白色卡片改为蓝湖底部灰色文字，设置行高度改为 98rpx。
2. 注销页从普通单选列表改为“选择原因”页签、三张 640rpx 原因卡和常驻大输入区。
3. 原因勾选改为右侧 30rpx 方形控件；选中“其他”后显示蓝底白勾并启用输入。
4. 底部按钮恢复“取消注销 / 仍要注销”，尺寸、禁用色和激活色与原稿一致。
5. 退出与注销弹窗恢复蓝湖固定纵向锚点、620rpx 宽度、32rpx 圆角和填充按钮。
6. 提交成功恢复为 288×98rpx 半透明灰色提示，不再使用全屏遮罩或成功图标。
7. 关于我们恢复 Logo、版本、合规列表与备案号的原稿纵向节奏。

## 6. 验收口径

- 七个运行态均有最终微信截图证据。
- 关键控件几何、文案、颜色和状态按蓝湖 MCP 原始参数复核。
- 自动化专项门禁覆盖路由、接口、退出/注销状态、OSS Logo 和伪交互禁令。
- 构建注册门禁要求 63 个页面各自 `Page=1`，共享脚本 `Page=0`，应用 `App=1`。
