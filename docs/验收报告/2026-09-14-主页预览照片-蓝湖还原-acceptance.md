# 主页预览照片 - 局部验收

## 范围与基线

仅验收用户反馈第2项的内容排列，不进行整页样式改造。设计来源为用户提供的主页预览截图，目标顺序为“自我介绍 → 第一张照片 → 我的认证 → 第二张照片”。复用原有图片卡、字体、圆角、间距及认证组件。

375×812、本机 Chrome、实际 TSX 内容组件的 HTML 适配结果。导航和头图不在截图范围；相册以仓库原有图片构造6个独立 URL 样例，关于我使用10条样例数据。截图不代表反馈账号的线上数据或微信真机。

| 状态 | 证据 | 观察 |

## 差异清单与结论

| 项目 | 修复结果 |
|---|---|
| 自我介绍后被关于我插入 | 关于我移至全部相册图片之后 |
| 第一张照片与认证、第二张照片的顺序 | 与用户提供的可见设计区域一致 |
| 6张照片是否丢失或截断 | 实际组件渲染树及浏览器图片节点均保留6张，顺序正确 |
| 空照片是否留下大块空位 | 无有效 URL 时不渲染图片卡 |
| 本人预览与公开主页是否分叉 | 两种模式继续共用同一实现，均通过回归 |
