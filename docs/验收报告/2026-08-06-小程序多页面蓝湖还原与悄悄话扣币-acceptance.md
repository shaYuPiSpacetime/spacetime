## 业务闭环

悄悄话链路为：动态详情打开弹层 → 服务端预检查 → 文本安全检查 → 优先消耗每日免费权益 → 否则原子扣减千寻币 → 写入千寻币流水与悄悄话记录 → 幂等返回结果。

数据库迁移脚本：`deploy/sql/prod/067_prd03_whisper_send_closure.sql`。该脚本需随本次后端版本部署后执行，生产环境才会具备 `app_whisper` 表。
