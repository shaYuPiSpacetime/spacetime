# 2026-10-10 千寻头部头像蓝湖还原验收

## 验收范围

- 小程序千寻页面顶部本人头像。
- 成家、时空邂逅一级菜单切换后的头像位置。
- 微信原生胶囊左侧间距、垂直居中和点击区避让。

设计基线为用户提供的 UI 稿 `codex-clipboard-1430dadf-bd95-4fd6-9fd1-843460aa97d0.png`；现状基线为 `codex-clipboard-c78d5711-d181-42db-a4a4-1bbddad93e72.jpg`。

## 实现与差异

| 项目 | UI 稿基线 | 实现结果 |
| --- | --- | --- |
| 头像 | 胶囊左侧、垂直居中 | 原生胶囊像素坐标锚定，垂直居中 |
| 可见头像 | 约 48rpx | 48rpx，圆形 |
| 胶囊间距 | 约 20rpx | 图片与胶囊约 20rpx；点击区保留 12rpx |
| 点击区 | 不覆盖一级菜单或胶囊 | 64rpx，布局测试确认不重叠 |
| 异常设备 | 未提供 | 胶囊 API 异常时使用安全兜底坐标 |

## 运行态证据

微信开发者工具模拟器视口约 390×844，原生胶囊为 `left=296, top=51, width=87, height=32`。最终头像点击区为 `left=257, top=51`，头像图片尺寸为 `24×24px`，图片左侧约 `261.5px`，与胶囊左侧保持约 `10.5px` 可见间距，未覆盖胶囊。
