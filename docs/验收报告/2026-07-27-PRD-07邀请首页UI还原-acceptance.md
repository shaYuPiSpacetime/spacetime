## 3. 设计差异闭环

| 轮次 | 发现差异 | 修复 |
|---|---|---|
| 第 1 轮 | 人物裁切带入 UI 稿右侧边框 | 缩小裁切窗口并右移，最新截图不再出现边框 |

| 第 2 轮 | 标题同时存在真实文字和伪元素内容，语义重复 | 保留真实标题文字，伪元素仅保留装饰背景 |

## 4. 已知素材缺口

UI 稿没有独立人物插画源文件。当前实现从已确认基线中裁切人物区域，仅作为非交互装饰；所有标题、文案、图标、按钮、进度和链接均由真实组件实现。拿到独立无损插画后可等位替换，不影响功能或布局。
