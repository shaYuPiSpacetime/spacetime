# 心动单人解锁充值页蓝湖还原验收报告

## 1. 验收范围

- 蓝湖设计：`ffa585ea-0136-407a-9930-ae8c26da0128`（千寻币-充值）。
- 心动单人解锁弹窗点击“只看ta”进入独立充值页，不复用“我的-千寻币”资产中心页。
- 独立页按蓝湖还原三头像关系场景、消耗与余额、充值套餐、底部充值区和协议确认弹层。

## 2. 根因与路由边界

原实现把“只看ta”直接导航到通用 `/pages/coins/index`，`sourceScene` 仅影响支付成功后的返回行为，页面结构仍是余额卡、用途卡等资产中心内容，因此与单人解锁设计稿不一致。

修复后路由边界如下：

| 场景 | 页面 | 结果 |
| --- | --- | --- |
| 我的-千寻币 | `/pages/coins/index` | 保持原通用资产中心，不修改 |
| 心动弹窗-只看ta | `/pages/coins/unlock-recharge?sourceScene=likes_unlock_one` | 新增独立场景充值页 |

- 蓝湖 MCP 对该 Sketch 节点返回完整设计图和 token，但没有可用独立 slice/layer；已登记素材层缺口。
- 头像使用仓库既有蓝湖模糊人物素材，金币图标使用 OSS 清单 `miniappOssIcons.coinGold`，未新增包内非底部静态图标。
- 页面首次渲染使用蓝湖套餐占位保证结构稳定；接口返回后展示真实余额与真实套餐。
