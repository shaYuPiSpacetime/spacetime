## 4. 差异与修复记录

| 初始差异 | 根因 | 修复结果 |
|----------|------|----------|
| 编辑消费场景无完整回显 | 仅表格内联输入，缺少稳定 ID 编辑模型 | 增加完整编辑弹窗，回显名称、图标、说明、价格、保留期、状态和 ID |
| 原价、折扣、移动端标签丢失 | 小程序 VO 和适配层缺字段 | 后端 VO、前端契约、卡片适配全链路补齐 |
| 用途图标失效 | 数据库存逻辑键，小程序按 URL 直接使用 | 增加逻辑键到 OSS 图标清单映射，兼容旧键和 HTTPS URL |
| 切换 Tab 后草稿消失 | Tab 切换重新加载接口 | Tab 只切视图，不覆盖本地未保存配置 |
| 弹窗底部按钮不可见 | 长表单超过视口高度 | 表单区内部滚动，规则说明和确认区常驻，E2E 验证按钮在视口内 |
| 输入框、主按钮样式不生效 | 设计 token 定义在错误根类名 `.commerce-page` | token 改绑实际 `.commerce-demo-page`，并加入静态门禁 |
| 接口失败仍可能看见旧 Demo | 前后端历史兜底 | 配置失败置空、保存禁用、小程序无 Demo 回退 |
