# 新账号基础资料二阶段状态验收

## 修复目标

首登准入资料（性别、年龄、身份、学历、地址）与认证基础资料提交状态必须分离。新账号完成准入后点击“立即认证”，首次必须进入基础资料页；基础资料点击“下一步”保存成功后，后续才进入头像流程。

## 实现

- `app_user` 新增 `basic_profile_completed`，开发数据库迁移已执行。
- 首登五项保存不修改该字段，默认保持 `0`。
- 认证基础资料 PUT 保存成功后写入 `1`。
- 基础资料查询仅在“已提交标记为 1 且动态必填字段完整”时返回 `basicProfileCompleted=true`。
- 前端认证入口优先查询基础资料；未完成时不请求后续认证记录，直接进入基础资料页。
- 页面入栈失败时降级为替换当前页。
