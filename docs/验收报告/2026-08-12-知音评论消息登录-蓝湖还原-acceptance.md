## 数据与交互闭环

- 评论接口新增作者性别、出生年份、现居城市和职业字段，评论行可按设计稿展示作者元信息。
- 一级评论支持回复、点赞、长按操作；点击子回复时携带根评论 ID，后续回复不会继续向右产生第三层。
- 评论“最新/最早”切换真实生效；一级评论按选择排序，线程内回复按时间正序展示。
- 知音卡片图片异常时回退默认头像，心动按钮阻止事件冒泡，不会误进用户主页。
- 手机号登录字段和获取验证码仍为真实输入与事件组件，没有使用截图热区。

## 运行态截图限制

微信开发者工具未开启 HTTP 自动化端口；本地 H5 已成功编译并返回 HTTP 200，但浏览器插件加载本机原生模块时被 macOS Team ID 代码签名策略拦截。因此本轮没有生成新的运行态截图，不把静态门禁结果冒充截图证据。视觉评分仅表示代码尺寸、切图与蓝湖图层数据的基线一致度；发布体验版后仍建议在真机各抽查一张悦目列表、评论回复、消息首页和手机号登录截图。
