# 登录、动态上传与三处 UI 细节验收报告

## 验收结论

代码、静态门禁、领域测试和小程序生产构建通过。登录与上传根因已修复；充值须知完成微信运行态坐标核验；心动完整关系链路运行态通过。微信公众平台 `uploadFile` 合法域名仍属于发布账号外部配置，体验版发布前必须保持已配置。

## 变更闭环

| 项目 | 根因 | 修复 | 验收 |
| --- | --- | --- | --- |
| 登录卡顿 | 登录后无条件查询完整 `init-status`；推广归因无时间预算 | 登录响应直接导航；归因等待上限 150ms；同步防重复点击 | 登录/PRD01/推广门禁通过 |
| 动态图片失败 | 最多 3 路并发、无重试、错误误分类 | 串行上传、20 秒超时、两次自动重试、每次重新签票、精确错误分类 | 图片上传 7 项领域测试通过 |
| 私信 icon | 源切图正确，但运行时漏掉切图相对卡片的 18rpx 偏移 | 保持 OSS 原图，恢复 top=18rpx | 消息 18 稿门禁通过 |
| 充值须知 | Flex 在 paddingTop 后又二次居中，且尺寸回退 | 明确 absolute 定位，恢复 620×538rpx 与正文规格 | 微信运行态 outerWxml 为 left=33px、top=200px、322×279px（390px 视口换算一致） |
| 心动胶囊重叠 | 图标 left=506rpx 写死 | 读取 menuLeft 动态计算 12rpx 安全间距 | 心动静态门禁与关系反馈全链路运行态通过 |

- `npm run build:weapp`：通过。
- 构建注册门禁：84 个页面均 `Page=1`，共享脚本 `Page=0`，`App=1`。
- 包体门禁：主包 1.35 MiB，千寻分包 112.7 KiB，总包 2.09 MiB。
- 登录、PRD01、PRD02、PRD06、PRD07、消息、心动、社区、页面隔离等构建前门禁全部通过。
- 关系反馈与互动链路微信运行态自动化通过；开发者工具后续截图接口超时已记录限制说明。
