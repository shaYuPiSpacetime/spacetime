# 编辑资料蓝湖还原需求分析

## 背景

用户要求按蓝湖稿一次性闭环还原编辑资料相关页面，不能整页切图，后续需要接后台数据；本轮仅做小程序移动端 UI 与静态验收，不执行编译、构建、热编译。

## 范围

1. 下载蓝湖项目 93 张 UI 稿到本地参考库，形成 manifest、下载报告和缺失切片清单。
2. 编辑资料页继续作为小程序启动验收页，按钮保持可点击。
3. “更新认证”进入新页面 `/pages/verification/my-certification`。
4. 自我介绍、我的标签、关于我、爱听的歌曲走独立页面，左上角返回编辑资料。
5. 语音介绍按蓝湖底部弹窗实现，不再跳独立语音页。
6. `lanhuDemo.json`、规范文档、静态验收脚本同步到 93 张稿口径。

## 非目标

- 不执行编译、构建、热编译。
- 不把蓝湖整页图放入运行包。
- 不接真实后台接口，本轮继续使用结构化 mock 数据。

## 验收口径

- 运行资产不得引用 `miniapp/.lanhu-ref` 下整页参考图。
- 静态脚本全部通过。
- 扫描无旧语音独立页入口和旧 `profile/edit?variant` 聚合路由。
- `git diff --check` 在本轮涉及目录通过。
