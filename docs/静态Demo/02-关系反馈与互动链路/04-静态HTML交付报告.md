## 5. 关键演示路径

1. 打开主入口，在场景控制台切换心动、访客、相互喜欢。
2. 点击任一模糊卡，查看动态 100 币单条解锁弹层。
3. 余额 320 时确认扣币，观察余额变为 220、目标卡原位清晰。
4. 重置后切换余额 80，演示余额不足与快捷套餐。
5. 切换“下一次扣币=失败”，验证 Toast、余额不变、按钮恢复可重试。
6. 切换会员到期、认证拦截、网络失败、空态和加载态。
