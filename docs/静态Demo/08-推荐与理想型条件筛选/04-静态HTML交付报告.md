## 2. 已完成能力

- 推荐 + 理想型双 Tab。
- 推荐位置/年龄基础筛选与周边城市开关；目标城市默认当前城市，限制 1～3 个。
- VIP 身高、体重、学历、家乡、学校、专业高级筛选。
- 普通用户可见高级条件名称，点击高级区域进入会员页模拟；返回刷新权益并保留基础筛选草稿。
- 17 个理想型条件、依赖本人资料隐藏与严格 AND 结果；分类无可见项时整体隐藏。
- 推荐首屏仅展示单张候选摘要卡；点击卡片进入详情，底部为跳过、悄悄话、喜欢，不新增条件摘要或详情按钮。
- 推荐筛选基础项与会员高级项在一个连续页面展示，普通用户可见高级条件名称和锁定态。
- 详情不展示可信度百分比，不使用“填写自己的同类资料后可查看”互惠限制；保留候选公开标签，并补齐举报和不再推荐交互。
- 推荐无候选复用蓝湖人物缺省图，展示“当前条件下暂未找到推荐人”和“去千寻同城看看”，进入 PRD-05 千寻同城；达到浏览上限展示绝对重置时间，会员不重复展示开通入口，不运行实时倒计时。
- 三天回看普通用户展示会员承接，会员按最近三个日期展示“推荐 N 人 / 跳过 N 人”汇总和候选查看入口。
- 理想型模糊结果、最多 5 人、单次/批量扣币、余额不足、成功解锁。
- 未完成三项认证仍可浏览、查看详情、跳过和筛选；喜欢与悄悄话弹出认证提示，认证返回原候选且不自动执行原操作。
- 推荐加载或操作网络失败时只提示“网络错误”，保留当前页和候选卡；再次触发原操作即可重试。
- 候选失效时，跳过静默切换；详情、喜欢、悄悄话或更多操作提示“该用户已注销”后切换下一位。
- 筛选草稿返回使用“是否保存该设置”确认；结果快照缺失时按最近一次已保存筛选重查，不恢复平台默认条件。
- 悄悄话成功进入 PRD-03 对应候选人的会话页；回看查看失败提示“查看失败，请返回后重新查看”并保留当前页。
- “不再推荐”仅从推荐和理想型结果剔除，不模拟全局拉黑。
- 筛选记录、历史解锁与失效状态。
- 管理端只读配置归属；没有独立 PRD-08 后台或算法 CRUD。
- 总览、移动端工作台和管理端已统一为既有 Demo 的蓝色共享外壳；手机内部保留 PRD-08 产品视觉。

## 3. 演示方法

1. 打开 `html/miniapp.html`。
2. 左侧页面目录或上方“快速页面”可直达 8 个有效业务页面，二者选中态同步。
3. “未认证 / 已认证”验证浏览权限、喜欢/悄悄话认证拦截，以及认证返回不自动执行。
4. “普通用户 / VIP 用户”验证高级筛选会员承接和三天回看权限。
5. “资料完整 / 资料缺失”验证校友、兴趣相似、感情观相合及空分类直接隐藏。
6. 在推荐页使用“下次操作网络失败”，验证错误提示、现场保留与再次触发重试。
7. “余额充足 / 余额不足”验证千寻币解锁成功与失败分支。
8. “等待：无候选 / 等待：达到上限”验证新版缺省图、千寻同城跳转、绝对重置时间和会员分支。
9. “候选失效：开启 / 回看查看失败：开启”验证动作分流与固定错误提示。

## 5. 生产实现注意事项

- 生产构建禁止启用本 Demo Mock 或固定用户编号。
- 候选图片改用用户私有 OSS，未解锁接口不得下发清晰身份。
- VIP、回看、千寻币价格、余额和订单全部引用 PRD-04。
- 地区、学校、专业和标签必须使用稳定 code；缺失按不匹配。
- 推荐仅在用户开启后补周边城市；理想型永不自动放宽。
