关键闭环

Demo 优先串联用户能直接感知的业务链路。

  1. 推荐发现调整位置、年龄和 VIP 条件，浏览、跳过或喜欢候选。
  2. 主动筛选选择理想型条件，严格按已选条件生成匿名结果。
  3. 付费解锁校验批量上限、动态单价和千寻币余额，成功后展示公开资料。

边界说明

本 Demo 使用本地 mock 数据，不连接真实接口、数据库或支付链路。

明确包含

推荐、理想型、基础/VIP 筛选、三天回看、记录、匿名结果和解锁状态。

明确排除

认证状态筛选、测评特征、匹配分、模型训练、算法权重和独立运营看板。
