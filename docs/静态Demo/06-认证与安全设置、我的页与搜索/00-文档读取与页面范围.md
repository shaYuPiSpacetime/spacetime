## 不纳入本 Demo

| 能力 | 原因 |
|------|------|
| 安全中心独立页 | 一期不做；安全提示内容由代码固定 |
| 搜索热词 | 2026-07-14 用户确认删除 |
| App 用户详情重复实现 | 设置与安全区块并入 PRD-01 现有用户详情，06 Demo 只记录承接关系 |
| 后台反馈箱 | 一期删除；举报归 PRD-03/05，移动端仅保留联系客服 |
| 一期范围说明页 | 不作为后台菜单或独立 Demo 页面，仅在 PRD 记录 |
| 通知设置页 | PRD-03 收敛为不做用户自助通知设置 |
| 黑名单、不看 TA、关键词自助管理 | 一期隐私设置只保留账号注销 |
| 真实接口和数据库 | 静态 Demo 使用本地 mock 数据 |
