# PRD-06 静态 Demo 页面元素清单

## 移动端

| 页面/区块 | 核心元素 | 交互 |
|-----------|----------|------|
| 我的页 | 状态栏、胶囊按钮、头像、昵称、三重认证、城市/年龄/星座、编辑资料、三项统计、提升人气、会员横幅、千寻币、邀请好友、菜单、底部 Tab | 提升人气、会员、权益卡、菜单和底部 Tab 点击 toast |
| 设置页 | 手机号、微信绑定、隐私设置、清单、关于我们、退出登录 | 入口行点击、退出登录提示 |
| 搜索页 | 搜索框、热词、历史词、用户/动态/话题 Tab、结果列表 | 热词点击、Tab 切换、违规词提示 |
| 注销确认 | 流程步骤、注销原因、风险提示、后悔期按钮 | 提交后 toast |
| 帮助反馈 | 帮助入口、反馈箱说明、降级说明 | 展示承接口径 |

## 管理后台

| 页面/区块 | 核心元素 | 交互 |
|-----------|----------|------|
| 后台框架 | 白色侧栏、固定顶栏、顶部 Tab、管理员信息 | 顶部入口跳转、退出 toast |
| 概览 | 一期后台页面、内容配置入口、用户安全列表、超范围入口指标 | 刷新、保存配置 toast |
| 应用配置 | 协议/关于/搜索/我的页面/设置页面 Tab、配置 Key、配置值、公开、状态 | 保存 toast |
| 移动端入口配置 | 我的页/设置页/帮助客服 Tab、入口名称、入口 Key、跳转类型、跳转目标、排序、状态 | 编辑 toast、变更记录 toast |
| 公告与协议配置 | 协议政策/公告/帮助 Tab、内容类型、标题、版本、状态、生效时间 | 新增、预览 toast |
| 内容列表 | 标题搜索、状态筛选、公告/帮助/安全内容/关于我们表格 | 查询、重置 toast |
| 反馈箱 | 筛选区、反馈表格、状态标签 | 查询 toast |
| 注销申请 | 筛选区、注销表格、后悔期状态 | 查询 toast |
| 搜索配置 | 结果类型与文案、安全提示内容、热词表、屏蔽词表 | 编辑/保存/查询 toast |
| 一期范围裁剪 | 纳入 Demo 与不纳入一期清单 | 只读展示 |

## 视觉系统

| 项 | 口径 |
|----|------|
| 移动端主色 | 亮蓝 `#2d8cff`，用于提升人气和底部推荐态 |
| 移动端辅助色 | 金色会员、蓝色千寻币、紫色邀请好友 |
| 后台主色 | 参考真实 frontend 后台蓝色主色 `#2f80ff` |
| 背景 | 移动端浅青蓝渐变；后台使用浅蓝灰 `#eef4ff` 与白色卡片 |
| 圆角 | 8px |
| 表格 | 高密度但保留行距，状态用轻量标签 |
| 移动端 | “我的页”按用户 UI 图还原；其他 PRD 补充态保持手机框 + 小程序原生感头部 |
| 后台 | 参考真实 frontend：白色 170px 侧栏、68px 固定顶栏、蓝色 active、卡片表格 |
