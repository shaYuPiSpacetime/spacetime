## 已覆盖闭环

- 移动端：进入签到页 → 查看动态阶梯 → 签到 → 成功弹窗 → 今日禁用 → 最近记录更新。
- 异常态：奖励处理中、活动关闭、网络错误，以及 H5 缺失/未发布/加载失败时的原生基础规则兜底。
- 移动端规则：点击签到规则 → 统一 H5 容器 → 显示来源域名与内容版本；动态奖励数据不写入 H5。
- 管理后台：编辑周期与奖励 → 二次确认发布 → 版本递增 → 查看变更日志；H5 内容可独立预览、发布和换版，不改变奖励配置版本。
- 记录查询：用户业务编号、日期和发奖状态筛选、重置、表格与分页外观。
- 边界：不含福利首页、任务、活动福利、兑换、抽奖、广告翻倍、补签、人工改余额和导出。

## 门禁结论

PRD 已达到静态 Demo、技术方案和测试用例编写所需的产品信息完整度；正式生产上线仍需甲方提供/确认视觉稿、默认周期和逐日奖励数值，并完成 PRD-04 千寻币入账联调。Demo 数据全部为 mock，不代表生产配置。
