# PRD-10 Demo 页面元素清单

## 移动端

- 顶部导航：返回、每日签到、签到规则。
- 摘要：连续签到天数、当前周期累计奖励。
- 奖励轨道：第 N 天、当日总奖励、已签/今日/待签到。
- 主操作：立即签到；状态为已签到、奖励处理中或活动关闭时禁用。
- 最近记录：日期、周期日、奖励、到账状态。
- 内容页：签到规则通过统一 H5 容器展示；Demo 可切换原生基础规则兜底。
- Demo 状态：可签到、已签到、奖励处理中、活动关闭、网络错误。

## 管理后台

- 状态栏：活动状态、今日签到人数、今日发币、失败数、当前版本。
- 规则 Tab：活动开关、周期、基础奖励、逐日额外奖励、发布；签到规则 H5 标题、URL、版本、预览和独立发布。
- 记录 Tab：用户编号、日期、状态筛选；结果表格和分页。
- 弹层：发布确认、停用确认、变更日志抽屉。
- 禁止能力：人工补签、修改连续天数、修改余额、记录导出。
