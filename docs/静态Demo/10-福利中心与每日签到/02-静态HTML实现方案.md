# PRD-10 静态 HTML 实现方案

## 文件职责

| 文件 | 职责 |
|------|------|
| `html/index.html` | 模块总览与两个端入口 |
| `html/miniapp.html` | 移动端真实控件和状态容器 |
| `html/admin.html` | 后台规则、记录、筛选、表格与抽屉 |
| `html/mock/demo-data.js` | 演示配置、签到记录、变更日志 |
| `html/assets/demo.css` | 视觉 token、响应式布局和组件状态 |
| `html/assets/demo.js` | 签到、筛选、配置发布、启停、弹层交互 |

## 视觉系统

- 背景：真白与冷灰 `#f6f7f9`；正文 `#20242c`；次级文本 `#737985`。
- 主操作：珊瑚红 `#ff5c59`；奖励：暖金 `#f5b928`；成功：`#26a65b`。
- 移动端为单列开放布局；后台以细边框表单和表格为主，不转成卡片网格。
- 交互控件全部由 HTML/CSS/JS 绘制，视觉概念图不作为页面背景。
