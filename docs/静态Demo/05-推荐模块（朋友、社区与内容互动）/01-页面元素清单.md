# PRD-05 静态 Demo 页面元素清单

| 页面/区域 | 新增真实组件 | 核心状态 |
|-----------|--------------|----------|
| 信息流卡片 | 申请认识、收藏按钮、评论预览、查看全部评论 | 收藏/未收藏、单条屏蔽、作者屏蔽 |
| 话题卡片 | 最新动态摘要、参与者头像、参与人数、浏览量 | 有预览/无预览 |
| 发布页 | 保存草稿、恢复草稿、上传状态演示、重试、删除 | queued/uploading/success/failed |
| 千寻互动中心 | 获赞统计卡、四类历史 Tab、历史卡片、清空浏览记录 | 四类列表与空态 |
| 关注粉丝列表 | 关注/粉丝 Tab、用户卡、关注/回关按钮 | 已关注/未关注/空态 |
| 动态互动用户 | 点赞/收藏/评论 Tab、用户卡、主页入口 | 三类列表与空态 |
| 社区打招呼 | 申请认识标题、招呼模板、发送确认 | 可发送/待回复/余额不足由既有链路承接 |
| 更多操作 | 屏蔽当前内容、不看 TA 动态、取消不看 TA 动态 | hide_post/hide_author_posts/unhide_author_posts |

所有交互入口均为可见真实按钮，不使用透明热区或整页截图冒充组件。
