# PRD-05 静态 Demo 页面元素清单

| 页面/区域 | 新增真实组件 | 核心状态 |
|-----------|--------------|----------|
| 同城信息流 | 资料城市只读标识、空态说明与真实跳转按钮 | 现居城市由 PRD-01 固定必填；当前城市无内容时刷新/去热门 |
| 信息流卡片 | 作者主页入口、申请认识/直达消息、互动人数、点赞、评论预览 | 未建立/已建立互动关系 |
| 热门话题入口 | 参与者头像、参与人数、浏览量 | 字段不足时逐项降级 |
| 话题列表 | 封面、名称、简介、内容数、热度 | 连续列表/“暂无数据”通用空态 |
| 发布页 | 保存草稿、放弃并返回、上传状态演示、重试、删除 | 放弃时清草稿并直接刷新来源列表；上传态为 queued/uploading/success/failed |
| 我的动态 | 每条动态的待复核、已驳回标识与原因入口 | 待复核/驳回/公开 |
| 发布失败反馈 | 页面中央短时反馈层、失败图标、失败标题和具体原因 | 提交未创建内容记录时展示，自动消失并保留表单 |
| 悦目 | 双列用户照片、缘分标签、学历学校、在线时间、心动按钮 | 点击卡片进入他人主页；不使用动态首图数据 |
| 诚意贴 | 作者资料、正文、图片、活跃时间、话题、申请认识、评论、点赞和悬浮发布按钮 | 与动态同字段结构，无独立标题和排序切换 |
| 更多操作反馈 | 页面中央半透明灰色反馈层 | 复用蓝湖反馈结构，按关注/不看最终结果替换文案 |
| 动态详情 | 申请认识、互动人数、最新/最早评论排序、内容不可见灰色反馈 | 最新/最早、无评论、已下架/已删除/暂不可见 |
| 举报弹窗 | 单选原因列表、取消按钮 | 首次提交/同对象处理中重复提交 |
| 千寻互动中心 | 获赞统计卡、四类历史 Tab、历史卡片、清空浏览记录 | 四类列表与空态 |
| 关注粉丝列表 | 关注/粉丝 Tab、用户卡、关注/回关按钮、取消关注确认弹窗 | 已关注/未关注/通用空态 |
| 动态互动用户 | 点赞/评论 Tab、用户卡、主页入口 | 两类列表与“暂无点赞/暂无评论”通用空态 |
| 他人主页 | 已审核资料、认证、关注/粉丝/获赞统计、公开动态、关系主操作 | 申请认识/直接发消息 |
| 社区打招呼 | “YO悄悄话”底部弹窗、目标资料、60 字输入、千寻币消耗、发送与会员提示 | 空输入/文字点亮/发送结果；失败复用通用反馈 |
| 更多操作 | 分享、关注/取消关注、不看 TA 动态/取消不看、举报 | post/user/comment 对象菜单 |

所有交互入口均为可见真实按钮，不使用透明热区或整页截图冒充组件。
