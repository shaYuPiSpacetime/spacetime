## 3. 还原度说明

本轮目标是补齐蓝湖已有功能与正式 PRD 的业务缺口，视觉上沿用既有 PRD-05 Demo 的字体、卡片、按钮、间距和手机框架。由于蓝湖画板没有提供全部异常态的精确标注值，本报告不对像素级高保真给出虚高评分；业务结构、可见组件和交互语义已形成可验收基线。

## 4. 已知限制

- 静态 Demo 不持久化刷新后的草稿、举报幂等记录和“不看 TA 动态”结果。
- 图片上传进度为前端状态演示，不调用真实 OSS。
- 解锁记录只展示 PRD-04 返回结果，不模拟真实扣费或资产流水。
- YO 悄悄话弹窗演示模块 08 已上传的默认态和文字点亮态，不在 PRD-05 内模拟充值链路。
- 同城 Demo 使用固定 mock 资料城市验证主页面；存量空值用户由 PRD-01 上游拦截补录，本 Demo 只呈现当前城市无内容状态。
- 本轮使用本地 HTTP 服务完成新增交互回归；未新增像素级对比截图，既有截图仅作为既往页面证据。
