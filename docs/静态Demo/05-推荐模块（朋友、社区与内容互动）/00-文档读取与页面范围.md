# PRD-05 静态 Demo 文档读取与页面范围

## 1. 需求来源

| 优先级 | 来源 | 用途 |
|--------|------|------|
| 1 | 蓝湖“千寻”完整页面组 | 识别已设计状态、文案和交互入口 |
| 2 | `需求文档-正式版/定稿：05-推荐模块（朋友、社区与内容互动）` | 业务规则、状态、权限和验收唯一正式来源 |
| 3 | `一期上线目标.md` | 范围边界；独立“不看 TA 动态”管理页不在一期 |

## 2. 当前实现范围

- `APP-05-PAGE-interaction-center`：评论过、点赞过、解锁过、浏览记录、获赞统计。
- `APP-05-PAGE-follow-relations`：关注/粉丝列表。
- `APP-05-PAGE-post-interactors`：动态点赞/评论用户列表，复用“千寻互动-互动-评论/点赞通用”UI。
- 现有发布页增加草稿、单图上传状态和重试；提交成功后不弹业务结果提示，待复核/驳回状态在“我的动态”每条卡片展示；提交失败时复用蓝湖中央反馈样式展示“发布失败”和具体原因，并保留表单。
- 话题列表不提供搜索、推荐/全部分区或最新帖子预览；动态详情提供申请认识、互动人数和最新/最早评论排序。
- 热门与话题列表空态统一显示“暂无数据”；话题详情保留话题快照，不为停用话题增加独立详情状态。
- 发布动态不提供 @Ta；草稿与提交载荷均不保存提及用户。
- 更多操作按 UI 稿展示分享、关注/取消关注、不看 TA 动态/取消不看和举报；不提供单条内容屏蔽。
- 未建立互动关系时展示“申请认识”并打开 `YO悄悄话-弹窗`；关系建立后消息动作直接进入 PRD-03，不设置社区私信中转页。
- 个人动态区他人视图同时承接他人主页资料、认证、关系动作与公开动态。

## 3. 明确不扩展的范围

- 不新增 `APP-PAGE-087 不看 TA 动态页` 或黑名单自助管理页。
- 不在 PRD-05 重建 PRD-04 解锁状态机或 PRD-03 通知/私信状态机。
- 不在 PRD-05 重复实现模块 08 的千寻币消耗确认、余额不足和充值入口 UI。
- 本期不提供动态收藏能力。
- 本期不提供 @Ta、社区私信中转页、独立婚恋用户主页或单条内容屏蔽。
- 同城仅按当前用户已审核资料城市展示；现居城市由 PRD-01 固定必填，存量空值用户先补录；资料城市只读，本页不提供跨城市浏览能力，也不申请 GPS 定位权限。
- 关注粉丝列表取消关注复用蓝湖“千寻-成家-取消关注”确认弹窗；动态内容不可见复用“千寻-成家-热门-发布失败”中央灰色反馈层。
- 社区“申请认识”复用蓝湖“YO悄悄话-弹窗”及文字点亮态，输入限制为 1-60 字。
- 本轮扩展现有视觉体系，不进行整体重设计。
