可直接打开：

```text
docs/静态Demo/05-推荐模块（朋友、社区与内容互动）/html/index.html
```

也可在仓库根目录启动本地静态服务后访问：

```bash
python3 -m http.server 18705
```

```text
http://127.0.0.1:18705/docs/静态Demo/05-推荐模块（朋友、社区与内容互动）/html/index.html
```
