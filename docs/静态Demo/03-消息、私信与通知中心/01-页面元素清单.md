## 1. 移动端元素

| 页面 | 核心元素 | 状态/交互 |
|------|----------|-----------|
| 消息列表 | 顶部标题、通知入口、官方消息卡片、私信会话列表、未读红点、认证引导 | 主态、未认证空态、无会话空态、99+ 红点 |
| 私信对话 | 顶部导航、消息流、输入区、更多菜单、举报/拉黑入口 | 可发送、女性保护禁发、会话失效、发送失败重试 |
| 官方助手 | 官方消息气泡、引导卡片、不可回复提示 | 纯文本、跳转卡片、加载失败提示 |

| 悄悄话消息 | 悄悄话卡片、等待提示、回复弹窗、忽略确认、更多菜单 | 接收方待处理、发送方等待、已回复、已忽略、失效 |
| 通知中心 | 一级类型筛选、业务类型筛选、通知列表、全部已读 | 全部、互动、邀请响应、空态、筛选无结果 |
| 通知详情 | 标题、正文、业务变量、跳转按钮 | 进入置已读、目标失效提示 |
| 邀请响应 | 邀请人卡片、关系状态、奖励提示、查看规则、推荐好友 | 成功、处理中、异常、从通知进入置已读 |

## 3. 关键业务链路

| 链路 | Demo 表现 |
|------|-----------|
| 未认证进入消息 Tab | 消息列表保留官方消息和通知入口，私信区显示认证引导 |
| 匹配后普通私信 | 消息列表进入私信对话，可发送文本；女性保护状态禁发 |
| 悄悄话破冰 | 接收方回复后触发匹配成功；发送方 pending 状态不能重复发送 |
| 通知邀请响应 | 通知中心点击 `jumpType=invite_response` 通知，直接进入邀请响应页并置已读 |
| 后台排查 | 运营在消息通知记录查询页按 `M03-ENUM-admin-record-type` 查询记录并打开详情 |
| 合并承接 | 用户管理字段补充由 01 用户卡片模块补充弹窗承接，举报字段补充展示在原页面语境，不生成孤立菜单页 |
