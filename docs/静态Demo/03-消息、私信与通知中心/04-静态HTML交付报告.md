# 2026-07-13 移动端复核修订

- 消息首页入口统一为“悄悄话 / 私信”，补充独立私信列表页。
- 悄悄话列表与详情拆分；接收方仅提供回复，不提供暂不回应按钮。
- 待回复满 7 天由后台定时任务或延迟队列自动结束，并从到期时间起进入 7 天冷却。
- 删除蓝湖扫帚/清理图标；列表删除仅作为左滑状态规则，不常驻展示。
- 官方小助手、系统消息直接全文展示；移除旧通知筛选、通知详情和邀请响应脚本。
