关键闭环

  • 未完成三重认证或账号受限时，只看必要安全系统消息与对应引导移动端
  • 消息首页固定官方助手、系统消息、悄悄话，并仅展示最近三条私信移动端
  • 匹配成功后进入普通私信；女性保护只限制发送，不限制进入移动端
  • 悄悄话回复、匹配、普通会话和状态一次提交；任一步失败全部回滚移动端
  • 已扣费但未有效送达时原路退款；发送方不可见已读、明确拒绝和拉黑原因移动端
  • 治理、资产、邀请、社区、平台与安全消息在同一全文流按曝光批次置已读移动端
  • 后台通用查询不返回正文，导出永不包含正文后台
  • 聊天举报在 PRD-05 案件页按条授权查看冻结证据，全部访问写审计后台合并

边界说明

以下边界已按 PRD-03 正式版和一期上线目标写入 Demo。

不做通知设置页

移动端不展示用户自助通知设置入口；后台不做完整通知偏好中心。

不做独立 IM 工作台

后台通过用户卡片模块补充弹窗、消息通知记录、配置页和举报处理承接，不新增 IM 会话运营工作台。

普通私信只在匹配后开放

废止互关私信旧口径；未匹配尝试发送普通私信会被拦截。

跨 PRD 只承接

资产事实归 PRD-04，邀请事实和页面归 PRD-07，举报案件事实归 PRD-05；PRD-03 只生成面向用户的消息快照。
