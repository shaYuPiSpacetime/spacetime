关键闭环

Demo 优先还原可演示的业务链路，而不是孤立页面截图。

  • 未完成三重认证用户进入消息 Tab，只看官方消息、通知和认证引导移动端
  • 匹配成功后进入普通私信；女性保护期内男性侧禁发移动端
  • 悄悄话支付成功后发送；回复即匹配，暂不回应匿名结束，7 天未处理自动超时移动端
  • 已扣费但未有效送达时原路退款；发送方不可见已读、明确拒绝和拉黑原因移动端
  • 通知中心点击 `invite_response` 通知，直接进入邀请响应页并置已读移动端
  • 后台按 `M03-ENUM-admin-record-type` 查询私信、悄悄话、官方消息和通知后台
  • 聊天举报在举报处理原页面展示上下文，处罚联动会话失效和站内通知后台合并

边界说明

以下边界已按 PRD-03 正式版和一期上线目标写入 Demo。

不做通知设置页

移动端不展示用户自助通知设置入口；后台不做完整通知偏好中心。

不做独立 IM 工作台

后台通过用户卡片模块补充弹窗、消息通知记录、配置页和举报处理承接，不新增 IM 会话运营工作台。

普通私信只在匹配后开放

废止互关私信旧口径；未匹配尝试发送普通私信会被拦截。

跨 PRD 只承接

千寻币和会员归 PRD-04，邀请关系和奖励归 PRD-07，举报处理复用后台举报能力。
