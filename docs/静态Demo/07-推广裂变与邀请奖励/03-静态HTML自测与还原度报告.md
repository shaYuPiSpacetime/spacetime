## 4. 业务验收

- 规则页无顶部统计区域，仅两个奖励Tab。
- 邀请规则以 H5 容器呈现：内容配置归 PRD-06，邀请成功、基础奖励、阶梯奖励等正文口径归 PRD-07。
- H5 正常态展示当前版本；取新失败且有缓存时展示缓存提示；无缓存时展示不可用和重试入口。
- 固定模式隐藏阶梯区；阶梯模式显示档位，问号提示包含20元、5/10/20档和第1/5/8人示例。
- 第5人展示20元基础+50元阶梯两条流水，第8人只发20元。
- 关系来源只有普通用户、校园代理；列表无状态/风险字段并显示当前已发放奖励。
- 奖励状态只有待发放、已发放、发放失败。
- 校园代理状态为可点击按钮；二维码支持真实本地PNG下载，复制能力具有权限降级提示。
- 结算周期为自然月，状态只有待确定、已确定，操作只有确定结算。
