## 2. 首页结构与数据绑定

- `miniapp.html#home` 使用真实 DOM 构建主视觉、注册奖励卡、邀请进度卡、邀请记录卡和规则卡。
- `renderInviteHome()` 读取 `PRD07_DATA.mobile`，绑定注册奖励、成功人数、累计到账、完整阶梯、当前/最大进度和最近三条记录。
- 阶梯通过数组动态渲染，不依赖固定三档；Demo 的 5/+50、10/+100、20/+200 只用于复现当前 UI 画板。
- “立即邀请”正常时打开现有分享弹层；`share-unavailable` 状态下复制邀请链接并显示 Toast。
- 活动说明进入邀请规则 H5，查看全部进入邀请记录页。

## 3. 状态设计

| `data-mobile-state` | 页面表现 |
|---|---|
| `normal` | 汇总、完整阶梯、最近三条记录正常展示 |
| `loading` | 保留主视觉，数据区显示骨架占位 |
| `empty` | 汇总与阶梯正常，邀请记录卡显示空态 |
| `network-error` | 数据区显示错误卡和重新加载 |
| `share-unavailable` | 首页正常；点击立即邀请复制链接 |
| `reward-failed` | 邀请记录页仅展示发放失败记录 |
| `h5-cache` | 规则页展示最近成功缓存提示 |
| `h5-unavailable` | 规则页展示无缓存不可用态 |

## 4. 素材策略

- 人物插画没有独立源文件，使用 `<img>` 加固定裁切窗口从确认 UI 基线中取得非交互人物区域。
- 裁切图不承载标题、按钮、卡片、进度或链接，也没有透明热区。
- 邀请记录头像复用项目已有无损 PNG，并复制到 Demo 自有资源目录。
- 运行态没有远程脚本、远程样式或网络请求。

## 6. 门禁

- 静态门禁要求注册奖励说明、全量阶梯、最近记录、新状态与动态 Mock 字段。
- 静态门禁明确禁止普通用户首页出现二维码、邀请码、保存二维码和千寻币用途区。
- 浏览器门禁验证首页数据、完整阶梯、最近三条记录、分享弹层、分享降级、加载/空记录/网络错误状态。
- 原邀请记录、规则 H5、管理端菜单、抽屉、校园代理二维码和结算回归继续执行。
