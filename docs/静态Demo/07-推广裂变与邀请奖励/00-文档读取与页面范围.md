## 3. 固定口径

- 完成注册即邀请成功；邀请关系永久有效且无状态字段。
- 来源仅普通用户、校园代理。
- 阶梯奖励仅在累计人数恰好命中档位时额外发放，并独立生成奖励流水。
- 奖励状态仅待发放、已发放、发放失败。
- 代理结算按上一个自然月自动生成，状态仅待确定、已确定。
- 邀请规则 H5 的标题、URL、版本、状态由 PRD-06 配置；邀请资格、奖励事件、金额和阶梯算法仍以 PRD-07 为准。
- 当前 H5 加载失败时展示最近成功缓存；无缓存时展示重试和返回，不硬编码完整规则冒充最新内容。
- 普通用户首页不展示二维码、邀请码、保存二维码或“千寻币能做什么”。
- 首页展示全部已启用阶梯，画板中的 5/+50、10/+100、20/+200 是演示数据，不是默认配置。
- “立即邀请”优先调起分享弹层；分享能力不可用时复制个人邀请链接。

## 4. 演示边界

校园代理二维码仍支持“保存成图片”和浏览器支持时的“复制图片”。除此之外，业务操作只更新本地 Mock。Demo 不调用真实 API，不写数据库，不接入登录、OSS、支付或消息系统；所有交互均由真实 HTML 控件实现。
