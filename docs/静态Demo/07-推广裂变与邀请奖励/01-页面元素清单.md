# PRD-07 页面元素清单

## 1. 移动端

| 页面 | 核心信息 | 真实控件 | 状态/反馈 |
|---|---|---|---|
| 邀请好友首页 | 完成注册成功口径、注册奖励、成功人数、到账奖励、完整阶梯、最近三条邀请、规则摘要 | 立即邀请、活动说明、查看全部、重新加载 | 正常、加载中、空记录、网络错误、分享不可用、分享弹层 |
| 邀请记录 | 好友、完成注册时间、累计已发奖励、基础/阶梯明细 | 全部/待发放/已发放/发放失败筛选 | 空态、发放失败 |
| 邀请规则 H5 | H5 版本/更新时间、PRD-06 配置来源、PRD-07 业务来源、新用户资格、永久关系、基础奖励、阶梯额外奖励 | 返回、联系客服、重新加载 | 当前版本、最近成功缓存、无缓存不可用 |

## 2. 管理端

| 页面/视图 | 核心字段 | 操作 |
|---|---|---|
| 推广规则配置 | 普通邀请/推广员两个Tab、固定/阶梯模式、5类事件、人数档位、额外金额 | 模式切换、问号提示、增档、保存发布 |
| 邀请关系 | 关系编号、来源对象、被邀请用户、来源类型、绑定时间、当前已发放奖励 | 查询、重置、导出、详情抽屉 |
| 关系详情抽屉 | 关系信息、事件时间线、奖励记录与合计 | 关闭、切换记录 |
| 邀请奖励流水 | 奖励对象、动态阶梯事件、对应用户、金额、三种状态 | 查询、重置、查看关系、失败重试、导出 |
| 校园代理 | 代理编号/名称、学校校区、扫码点击数、注册数、应发/已发/待结算奖金、状态 | 新增、状态按钮、详情、二维码、导出 |
| 代理详情抽屉 | 代理汇总、5列奖金明细、5列结算记录 | 关闭 |
| 二维码弹窗 | 代理专属二维码 | 保存成图片、复制图片 |
| 代理结算 | 结算单、代理、自然月周期、金额、生成时间、状态、结算时间 | 查询、确定结算、导出 |

## 3. 公共交互要求

- 移动端主操作最小高度44px，管理端控件保持共享后台尺寸。
- 发布、状态修改、失败重试和确定结算使用二次确认。
- 详情全部在当前列表页以抽屉打开，关闭后保留列表状态。
- 只读角色禁用所有`data-write`控件。
- 普通用户首页不得出现二维码、邀请码、保存二维码或千寻币用途区；校园代理二维码弹窗不受影响。
