# 兼容说明 - APP-03-PAGE-official-message-detail 官方消息详情页（已废弃）

| 版本 | 日期 | 修改人 | 变更摘要 |
|------|------|--------|----------|
| 版本04 | 2026-07-31 | Codex | 从有效页面树移除，旧链接统一迁移到系统消息全文页 |

- 本页不是 PRD-03 一期有效页面，不计入 7 个页面范围，不设计、不开发、不验收独立 UI。
- 历史路由如仍携带合法 `noticeNo`，客户端应打开 `APP-03-PAGE-notification-center` 并在列表中定位该条消息；消息不存在、过期或不属于当前用户时，打开系统消息首页并给出轻提示。
- 新数据不得生成 `jumpType=notification_detail` 或本页路由。
- 已读规则遵循 `M03-SM-notification-read`：仅对系统消息全文页中成功加载并曝光的消息 ID 批量确认，不因历史路由访问而直接置全部已读。
- 正式业务规则见 `../../PRD-03_模块公共定义.md`，有效页面规格见 `APP-06_通知中心页.md`。
