## 4. 自检结论

| 检查项 | 结论 |
|--------|------|
| 是否仍保留用户自助通知设置页 | 否，已按一期目标移除 |
| 是否仍保留互关即可私信旧口径 | 否，普通私信统一为匹配成功后开放 |
| 是否仍使用“成家币”作为正式虚拟币名 | 否，正式文档使用“千寻币”，旧称仅在原始资料中存在 |
| 是否有普通待确认标记遗留 | 无；未准备事项进入本清单，不阻塞 PRD 初稿 |
| 是否仍要求配置消息 KMS | 否；消息数据按受控明文落库，依靠接口权限、案件上下文、查看原因、审计和数据库基础设施权限保护 |
| 是否覆盖一期消息页面 | 是，固定覆盖 6 个有效移动端页面；独立私信列表已合并到消息首页，通知详情和邀请响应不属于一期页面 |
