## 3. 明确不需要补稿的页面

| 页面/能力 | 原因 | 处理 |
|-----------|------|------|
| 用户自助通知设置页 | 一期目标明确不做 | 不出稿 |
| 后台完整通知偏好中心 | 一期目标明确不做 | 不出稿 |
| 独立 IM 工作台 | 超出本期范围 | 不出稿 |
| 黑名单管理页 | 一期不做完整黑名单管理 | 不出稿 |
| 独立完整私信列表页 | 能力已合并到消息首页 | 保留页面 ID 历史记录，不出稿、不建设路由 |
| 悄悄话忽略/拒绝/撤回/删除 | 冻结需求明确不提供 | 不出稿 |
| 独立通知详情页 | 系统消息在全文流内展示 | 不出稿 |
| 邀请响应页 | 已移交 PRD-07 | PRD-03 不出稿 |
