## 1. 目标与范围

让运营安全配置每日基础奖励、连续签到额外奖励及活动开关，并查看签到发奖结果。

| 需求 ID | 能力 | 优先级 |
|---------|------|--------|
| `ADM-10-REQ-01` | 查询当前签到配置及版本 | P0 |
| `ADM-10-REQ-02` | 编辑 1-31 天阶梯周期、基础奖励和周期内各天额外奖励 | P0 |
| `ADM-10-REQ-03` | 二次确认后发布配置或启停活动 | P0 |
| `ADM-10-REQ-04` | 查询签到记录和奖励状态 | P0 |
| `ADM-10-REQ-05` | 配置、预览并独立发布签到规则 H5，保留原生兜底 | P0 |

## 2. 边界

- 不支持后台人工补签、修改连续天数或直接修改用户余额。
- 不建设任务、兑换、抽奖、券或商品管理。
- 奖励失败仅由系统重试；人工补偿通过 PRD-04 资产调整流程处理并留审计。

## 3. 权限与审计

引用 `ADM-10_端内定义.md`。配置发布、启停及查看失败详情均记录 PRD-10 模块内变更日志；日志记录变更前后配置快照但不记录登录凭证，并由签到规则配置页内的日志抽屉查看。

## 4. 数据、依赖与影响面

| 项目 | 口径 |
|------|------|
| 核心实体 | 签到配置版本 1:N 签到记录；签到记录 0..1 对应 PRD-04 资产流水 |
| PRD-04 依赖 | 查询资产流水号和发奖结果；不可用时保留签到记录与奖励处理中/失败态 |
| 权限系统 | 提供查看与配置权限；不可用时整页无权限，不允许降级放行 |
| 影响页面 | 新增“福利中心 -> 签到规则配置”菜单；不新增独立签到记录菜单 |

## 5. 上线与回滚

- 首次上线创建默认关闭的 v1 配置，不迁移历史签到数据。
- 内部账号验证发布、签到、发奖和记录查询闭环后再开启活动。
- 回滚前先关闭活动；保留配置快照、签到记录、变更日志和资产流水，禁止删除已发奖励。
- 生产环境不得启用 Demo mock 数据或绕过权限。
