# 页面规格 - ADM-10-PAGE-signin-config 签到规则配置页

- **路由**：`/welfare/signin/config`

- **设计稿**：待补充

## 1. 页面定位与布局

运营配置签到开关、1-31 天阶梯周期、基础奖励和逐日额外奖励，并查询签到发奖记录。

```text
状态卡：活动状态 / 今日签到人数 / 今日发币 / 发奖失败数 / 查看变更日志
Tab：规则配置 | 签到记录
规则：开关、周期天数、基础奖励、动态阶梯表、版本、生效时间、发布按钮
记录：用户编号、日期、连续天数、奖励、状态、流水号
```

| 画板 ID | 画板 | 优先级 |
|---------|------|--------|
| `ADM-10-signin-01` | 规则配置 | P0 |
| `ADM-10-signin-02` | 发布/停用确认 | P0 |
| `ADM-10-signin-03` | 签到记录及失败筛选 | P1 |
| `ADM-10-signin-04` | 变更日志抽屉 | P0 |

## 2. 筛选

记录 Tab 支持用户业务编号精确搜索、签到日期范围、奖励状态筛选；点击查询触发，条件写入 URL。

## 4. 操作表

| 操作 ID | 操作 | 条件 | 权限 | 确认 | 成功 | 失败 | 影响 |
|---------|------|------|------|------|------|------|------|
| `ADM-10-PAGE-signin-config-ACT-publish` | 发布配置 | 校验通过且有变更 | 配置权限 | “新规则仅影响发布后的签到，确认发布？” | 版本递增并生效 | 保留草稿并提示 | 写 PRD-10 变更日志 |
| `ADM-10-PAGE-signin-config-ACT-toggle` | 启停活动 | 状态变化 | 配置权限 | 提示关闭会中断连续签到 | 状态更新 | 状态不变 | 写 PRD-10 变更日志 |
| `ADM-10-PAGE-signin-config-ACT-query` | 查询记录 | 任意 | 查看权限 | 否 | 刷新列表 | 保留条件 | 无 |
| `ADM-10-PAGE-signin-config-ACT-view-log` | 查看变更日志 | 任意 | 查看权限 | 否 | 打开日志抽屉，展示操作人、时间、动作、原因和前后值 | 加载失败提示重试 | 只读，不提供删除或编辑 |

## 5. 联动、状态与列表

- 关闭活动时奖励表仍可编辑，但发布前必须二次确认。
- 阶梯天数缺失、重复、越界或奖励非整数时阻断发布；活动开启时不允许空奖励表。
- 周期调整后动态增删阶梯行；缩短周期前提示被移除天数，延长周期必须补齐新增天数奖励。
- 页面覆盖加载、无记录、网络错误、无权限、活动启用/关闭、配置冲突和资产服务降级状态。
- 记录默认按签到时间倒序，每页 20 条，支持 20/50/100，不支持批量修改或导出敏感信息。
