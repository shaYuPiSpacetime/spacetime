## 1. 页面定位与布局

运营配置签到开关、1-31 天阶梯周期、基础奖励和逐日额外奖励，并查询签到发奖记录。

```text
状态卡：活动状态 / 今日签到人数 / 今日发币 / 发奖失败数 / 查看变更日志
Tab：规则配置 | 签到记录
规则：开关、周期天数、基础奖励、动态阶梯表、版本、生效时间、发布按钮
规则内容：H5 标题、HTTPS URL、内容版本、发布状态、预览与独立发布
记录：用户编号、日期、连续天数、奖励、状态、流水号
```

| 画板 ID | 画板 | 优先级 |
|---------|------|--------|
| `ADM-10-signin-01` | 规则配置 | P0 |
| `ADM-10-signin-02` | 发布/停用确认 | P0 |
| `ADM-10-signin-03` | 签到记录及失败筛选 | P1 |
| `ADM-10-signin-04` | 变更日志抽屉 | P0 |

## 2. 筛选

| 筛选 ID | 筛选名 | 类型 | 选项来源 | 多选 | 默认值 | 可清除 |
|---------|--------|------|----------|------|--------|--------|
| `ADM-10-PAGE-signin-config-FILTER-user-code` | 用户业务编号 | 输入框 | 用户输入，精确匹配 | 否 | 空 | 是 |
| `ADM-10-PAGE-signin-config-FILTER-sign-date` | 签到日期 | 日期范围 | 北京时间自然日 | 否 | 最近 7 天 | 是 |

## 5. 联动、状态与列表

- 关闭活动时奖励表仍可编辑，但发布前必须二次确认。
- 阶梯天数缺失、重复、越界或奖励非整数时阻断发布；活动开启时不允许空奖励表。
- 周期调整后动态增删阶梯行；缩短周期前提示被移除天数，延长周期必须补齐新增天数奖励。
- 记录默认按签到时间倒序，每页 20 条，支持 20/50/100，不支持批量修改或导出敏感信息。

### 5.1 状态与异常

| 状态类型 | 触发 | 页面表现 | 可执行操作 | 引用 |
|----------|------|----------|------------|------|
| 加载态 | 首次进入或切换 Tab | 配置区骨架屏、记录表 loading | 无 | — |
| 空态 | 默认条件下无签到记录 | “暂无签到记录，活动开启并有用户签到后将在此展示” | 切换规则配置 | — |
| 搜索无结果 | 筛选后 0 条 | “未找到符合条件的记录” | 重置筛选 | — |
| 网络错误 | 查询超时/断网 | 保留上次数据并提示“加载失败，请重试” | 重试 | — |
| 无权限 | 缺少查看权限 | 隐藏整页并显示无权限页 | 返回首页 | `ADM-10_端内定义.md` |
| 业务态-启用 | `M10-CFG-enabled=true` | 状态卡显示运行中，允许编辑并发布新版本 | 发布、关闭 | `M10-CFG-enabled` |
| 业务态-关闭 | `M10-CFG-enabled=false` | 状态卡显示已关闭，配置仍可编辑 | 发布、开启 | `M10-CFG-enabled` |
| 业务态-配置冲突 | 提交版本落后 | 不覆盖服务端；保留本地草稿并显示冲突横幅 | 刷新后重新编辑 | `M10-ERR-config-conflict` |
| 降级态 | PRD-04 查询不可用 | 配置 Tab 可用；记录中的到账信息显示“暂不可查询” | 稍后重试 | `M10-SM-reward` |
| 降级态-H5 | H5 预览不可达或超时 | 保留草稿，提示“页面暂时无法访问”；不影响奖励配置和签到能力 | 修改 URL、重试 | `GLB-RULE-h5-content-container` |

### 5.2 查询与列表

- 默认排序：`createdAt desc`；支持按签到时间排序。
- 传统分页，默认每页 20 条，支持 20/50/100；不支持跨页勾选和批量操作。
- 不自动轮询；用户点击查询或翻页刷新。空态文案按 5.1 节展示。

## 6. 验收标准

| AC ID | 场景 | 类型 | 优先级 |
|-------|------|------|--------|
| `ADM-10-AC-config-validation` | 非法阶梯配置被阻断 | 异常 | P0 |
| `ADM-10-AC-publish-snapshot` | 发布只影响新签到 | 正常 | P0 |
| `ADM-10-AC-disable-confirm` | 停用明确提示连续签到中断 | 正常 | P0 |
| `ADM-10-AC-audit` | 配置前后值进入 PRD-10 模块内变更日志并可从本页查看 | 正常 | P0 |
| `ADM-10-AC-rule-content` | 签到规则 H5 可独立预览、发布、换版和降级 | 正常/异常 | P0 |

```gherkin
Given 运营拥有 welfare:signin:config 权限且当前配置版本为 v3
When 运营填写完整的 1-31 天阶梯并确认发布
Then 系统生成 v4 配置、写入 M10-EVT-config-published 和变更日志，历史签到与奖励不追溯变更

Given 阶梯存在缺日、重复、越界或非整数奖励
When 运营点击发布
Then 系统按 M10-ERR-config-invalid 阻断发布，保留草稿并定位首个错误字段

Given 两名运营同时基于 v3 编辑且其中一人已发布 v4
When 另一人提交 v3 草稿
Then 系统返回 M10-ERR-config-conflict，不覆盖 v4，并保留本地草稿供刷新后核对

Given 活动正在运行且运营点击关闭
When 运营在“关闭后用户将无法签到且连续签到中断，确认关闭？”中确认
Then 活动立即关闭、写入变更日志；取消确认时状态不变

Given 查看者拥有查看权限且存在签到发奖记录
When 按用户业务编号、北京时间日期和 M10-ENUM-reward-status 查询
Then 结果按签到时间倒序分页展示，已发放记录可见资产流水号，失败摘要不向只读客服展示内部原因

Given 运营填写有效标题和已登记业务域名下的 HTTPS H5 URL
When 运营预览并确认发布签到规则
Then M10-CFG-rule-content 内容版本递增且立即生效，奖励配置版本不变，移动端按 GLB-RULE-h5-content-container 打开新版本

Given H5 URL 非 HTTPS、域名未登记或页面不可达
When 运营尝试发布或预览
Then 系统阻断发布并保留草稿，移动端继续使用上一已发布版本；无可用版本时展示原生基础规则
```
