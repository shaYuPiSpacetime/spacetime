## 2. 找茬问题处理结论

| 问题 | 处理结论 | 文档落点 |
|------|----------|----------|
| `C-01` / `M01-01` / `M02-01` 核心准入冲突 | 已解决：候选人进入推荐池仍要求实名、头像、学历三项认证；浏览者登录、账号正常且基础资料可用即可浏览，只有喜欢与悄悄话要求三项认证 | PRD-01 `M01-RULE-core-access`、`M08-RULE-candidate-pool`、`M08-RULE-viewer-auth` |
| 认证状态筛选与三项认证候选池重复 | 已解决：删除认证状态筛选 | `M08-DEC-05`、推荐筛选设置页 |
| `C-08` 隐私隐藏是否影响推荐 | 已解决：隐藏只影响展示；固定条件可用于判定但不得向筛选方返回隐藏原值，隐私政策需披露 | `M08-RULE-display-privacy`、前置准备 `M08-PREP-05` |
| `C-13` / `M08-01` 测评是否参与推荐 | 本期不做：全部测评和测评特征移出一期 | 模块公共定义第 8 节 |
| `M08-02` 模型冷启动 | 已解决：一期没有模型与训练门槛，直接固定条件筛选 | `M08-RULE-recommend-filter` |
| `C-14` / `M08-04` 精选定位 | 本期不做：精选入口隐藏，产品收敛为推荐 + 理想型 | 双 Tab 页面与一期目标 |
| `M08-05` 异性规则 | 已解决：引用 PRD-01 一期异性匹配规则 | `M08-RULE-candidate-pool` |
| `M08-06` 无候选与降级 | 已解决：无候选使用蓝湖新版缺省态并进入 PRD-05 千寻同城；服务失败不伪装为空态，不自动放宽 | 等待页、`M08-RULE-no-candidate-handoff` |
| `M08-07` 推荐解释 | 本期不做：无分数、无 SHAP，仅展示实际命中的已选条件 | `M08-RULE-ideal-blur` |
| `M08-08` 默认年龄 | 已解决：本人年龄 ±5 岁并裁剪到平台范围，可由用户修改 | `M08-PARAM-age-default-radius` |
| `M08-09` 小城市候选不足 | 已解决：推荐仅在用户开启后补周边城市；理想型不放宽 | `M08-RULE-location-expansion` |
| `M08-10` 见面偏好页面归属 | 本期不做：移出 PRD-08，不展示入口、不注册路由、不提供 PRD-08 接口 | `[已废弃] APP-08-PAGE-meeting-preference`、模块公共定义第 8/9 节 |
| `M08-11` 推荐详情互惠查看 | 已解决：候选资料是否展示只取决于候选公开范围与账号/资料有效性，不要求查看者先填写同类资料 | `M08-RULE-display-privacy`、推荐详情页 |
| `M08-12` 蓝湖 `可信度 92%` | 本期不做百分比：它不是匹配分，但缺少计算与申诉口径；保留头像、实名、学历认证徽章 | 推荐详情页、蓝湖差异清单 |
| `M08-13` 推荐回看粒度 | 已解决：以蓝湖按日“推荐 N 人 / 跳过 N 人”汇总为准，不建设精细行为流水和列表内喜欢操作 | `M08-RULE-replay`、推荐回看页 |
| `M08-14` 资料依赖条件呈现 | 已解决：本人资料不足时直接隐藏对应理想型条件；分类内无可见项时隐藏分类，不展示置灰项或完善资料入口 | `M08-RULE-dependent-condition`、推荐与理想型页 |
| `M08-15` 目标城市数量 | 已解决：默认当前城市，至少 1 个、最多 3 个；达到上限隐藏添加入口，删除后恢复，零城市禁止保存 | `M08-RULE-target-city`、推荐筛选设置页 |
| `M08-16` 高级筛选会员承接 | 已解决：普通用户可见高级条件名称，点击高级区域直接进入 PRD-04 会员页；返回刷新权益并保留基础筛选草稿 | `M08-RULE-vip-filter`、推荐筛选设置页 |
| `M08-17` 网络失败重试 | 已解决：仅 Toast“网络错误”，保留当前页、卡片和草稿；不自动重放，用户再次触发原操作重试 | `M08-RULE-network-retry`、推荐与理想型页 |
| `M08-18` 候选操作时失效 | 已解决：跳过静默切换；详情、喜欢、悄悄话和更多操作提示“该用户已注销”后切换 | `M08-RULE-candidate-unavailable`、APP-01/APP-04 |
| `M08-19` 筛选结果快照失效 | 已解决：只清除结果快照并按最近一次已保存筛选重查，不恢复平台默认条件 | `M08-RULE-filter-result-restore`、APP-02 |
| `M08-20` 不再推荐语义 | 已解决产品规则：仅 PRD-08 场景排除，不影响消息、主页和动态；蓝湖弹窗仍需修正文案 | `M08-RULE-never-recommend-scope`、APP-04、蓝湖 UI 缺失清单 |
| `M08-21` 回看查看失败 | 已解决：提示“查看失败，请返回后重新查看”并保留当前回看页，失效候选隐藏 | `M08-RULE-replay`、APP-06 |
| `A08-01` 至 `A08-07` 算法后台 | 本期不做：无参数、训练、模型版本、解释或看板；系统字典沿用既有管理能力 | `M08-RULE-admin-boundary` |
| `M01-30` 敏感字段展示 | 已解决 PRD-08 相关范围：参与筛选不等于公开展示 | `M08-RULE-display-privacy` |

相关问题已回写 `PRD找茬确认问题清单.md`，当前 PRD-08 无普通待确认标记。
