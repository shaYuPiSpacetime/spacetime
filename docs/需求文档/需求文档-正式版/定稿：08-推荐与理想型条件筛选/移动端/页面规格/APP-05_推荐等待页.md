# 页面规格 - APP-08-PAGE-waiting 推荐等待页

| 版本 | 日期 | 修改人 | 变更摘要 |
|------|------|--------|----------|
| 版本03 | 2026-08-09 | Codex | 同步蓝湖新版无候选缺省态，主操作改为进入千寻同城；浏览上限只展示绝对重置时间，不做倒计时 |
| 版本02 | 2026-08-06 | Codex | 对应蓝湖两张现有等待稿，明确无候选/浏览上限、重置时间及普通用户/会员分支 |
| 版本01 | 2026-07-16 | Codex | 承接无候选与浏览额度结束两类等待状态 |

- **页面路由**：`/pages/recommend/waiting/index?reason=no_candidate|browse_limit`
- **入口来源**：推荐 Tab 本轮没有可展示候选
- **对应设计稿**：蓝湖 `推荐-筛选未找到合适的人`、`推荐-每天推荐人员达到上限`；旧 `推荐-暂无数据`不再作为无候选最终稿

## 1. 页面定位

在推荐候选暂时耗尽或 PRD-04 明确返回当日浏览额度为 0 时，为用户提供可执行的后续入口，避免无限 loading 或伪造候选。无候选时承接到 PRD-05 千寻同城；额度结束时按商业化权益展示下一步。

## 2. 布局（给 UI）

### 2.1 整体布局

```text
导航：返回
居中插画
状态标题与说明
主操作：去千寻同城看看 / 三天回看（按原因）
次操作：开通会员（仅普通用户达到上限时）
```

### 2.2 区块说明

| 原因 | 标题 | 主操作 | 次操作 |
|------|------|--------|--------|
| `no_candidate` | 当前条件下暂未找到推荐人 | 去千寻同城看看 | 无 |
| `browse_limit` | 今天的推荐已看完，并展示下次重置时间 | 三天回看 | 普通用户显示开通会员；会员不重复显示会员按钮 |

### 2.3 弹层

点击开通会员时打开 PRD-04 VIP 引导；本页不自建套餐或价格弹窗。

### 2.4 UI 画板拆分

| 画板 ID | 画板 | 内容 |
|---------|------|------|
| `APP-08-WT-01` | 蓝湖 `推荐-筛选未找到合适的人` | 复用人物缺省图，展示“当前条件下暂未找到推荐人”和“去千寻同城看看” |
| `APP-08-WT-02` | 蓝湖 `推荐-每天推荐人员达到上限`改稿 | 浏览上限、北京时间绝对重置时间；普通用户展示会员入口，会员用户隐藏会员入口；不绘制实时倒计时 |
| `APP-08-WT-S01` | 页面旁状态标注 | 权益服务错误时不宣称额度用完，展示重试；不新增整页画板 |

### 2.5 编辑控件口径

本页为状态页，无表单编辑；所有按钮跳转或重试。

## 3. 筛选与搜索

本页无搜索、无筛选控件；无候选状态的主操作进入 PRD-05 `APP-05-PAGE-community-city`。

## 4. 字段表

| 字段 ID | 显示名 | 类型 | 必填 | 取值范围 | 校验规则 | 默认值 | 可编辑 | 敏感级别 | 数据来源 |

| `APP-08-PAGE-waiting-FIELD-next-reset-at` | 额度重置时间 | datetime/null | 条件必填 | 北京时间未来时间 | `browse_limit` 必须返回并展示；其他原因返回 null | null | 否 | 普通 | PRD-04 |
| `APP-08-PAGE-waiting-FIELD-vip-effective` | 会员有效 | bool | 是 | true/false | 服务端计算 | false | 否 | 普通 | PRD-04 |

| `[已废弃] APP-08-PAGE-waiting-FIELD-condition-summary` | 当前条件摘要 | object | 否 | 不在蓝湖等待稿展示 | 不实现；字段 ID 不复用 | 空对象 | 否 | 敏感；仅本人可见 | — |

## 5. 操作表

| 操作 ID | 操作 | 触发条件 | 前置权限 | 二次确认 | 成功态 | 失败态 | 影响 |
|---------|------|----------|----------|----------|--------|--------|------|
| `APP-08-PAGE-waiting-ACT-community-city` | 去千寻同城看看 | `no_candidate` | 已登录且基础资料可用 | 否 | 进入 PRD-05 `APP-05-PAGE-community-city` | 路由失败保留当前空态并提示重试 | 不修改已保存筛选 |
| `APP-08-PAGE-waiting-ACT-vip` | 开通会员 | `browse_limit` 且无会员 | 已登录 | 否 | 打开 PRD-04 VIP 引导 | 打开失败提示重试 | 返回后刷新额度 |
| `APP-08-PAGE-waiting-ACT-replay` | 三天回看 | `browse_limit` | 已登录且基础资料可用 | 否 | 进入回看页；普通用户由回看页承接会员态 | 打开失败提示重试 | 不消耗额度 |
| `APP-08-PAGE-waiting-ACT-retry` | 重新加载 | 权益/推荐服务错误 | 已登录且基础资料可用 | 否 | 按真实原因刷新页面 | 继续错误态 | 不伪造候选 |
| `APP-08-PAGE-waiting-ACT-back` | 返回推荐 | 任意正常原因 | 已登录且基础资料可用 | 否 | 返回双 Tab 推荐 | 无 | 保留当前筛选 |

## 6. 数据联动规则

| 触发 | 影响 | 行为 | 引用 |
|------|------|------|------|
| 调整筛选保存后返回 | 等待原因 | 重新查询；有候选则离开等待页 | `M08-RULE-recommend-filter` |
| 会员购买成功 | 剩余额度/回看 | 重新查询 PRD-04 权益，不使用本地假值 | `M08-RULE-browse-quota` |
| 权益服务失败 | 页面原因 | 不得将 null/错误当作 0 | `M08-RULE-browse-quota` |
| 浏览上限返回 `nextResetAt` | 重置时间 | 按北京时间格式化为绝对日期时间并静态展示；页面不启动秒级或分钟级倒计时 | `M08-RULE-no-candidate-handoff` |

## 7. 状态与异常

| 状态类型 | 触发 | 表现 | 操作 |
|----------|------|------|------|
| 加载态 | 复核原因/权益 | 插画骨架和禁用按钮 | 返回 |
| 空态 | `no_candidate` | 蓝湖人物缺省图与“当前条件下暂未找到推荐人” | 去千寻同城看看 |
| 错误态 | 原因复核失败 | `暂时无法加载推荐状态` | 重试 |
| 无权限态 | 未登录/账号异常/基础资料不可用 | 按 PRD-01 处理；未完成三项认证仍可使用等待页 | 去登录/处理账号资料 |
| 业务态-额度结束 | `browse_limit` | 今日看完说明与绝对重置时间 | VIP/回看 |
| 业务态-普通无回看 | 回看权益无效 | 回看按钮锁定 | 开通会员 |
| 降级态 | PRD-04 不可用 | 不显示额度数或重置时间 | 重试/返回 |

## 8. 查询与列表

本页无列表和分页；每次前台激活页面重新复核等待原因与权益。不得自动轮询候选或在后台持续刷新，也不得根据本地时钟运行重置倒计时。

## 9. 验收标准

| AC ID | 场景 | 类型 | 优先级 |
|-------|------|------|--------|
| `APP-08-AC-wait-no-candidate` | 无候选可进入千寻同城 | 正常 | P0 |
| `APP-08-AC-wait-limit` | 额度为 0 才显示看完 | 正常 | P0 |
| `APP-08-AC-wait-service-fail` | 权益错误不误判额度 | 异常 | P0 |

```gherkin
Given 推荐接口返回 0 条且剩余浏览数大于 0或为 null
When 进入等待页
Then 原因为 no_candidate，展示“当前条件下暂未找到推荐人”和“去千寻同城看看”，不展示“今日额度已用完”

Given 用户处于 no_candidate 状态
When 点击“去千寻同城看看”
Then 进入 PRD-05 APP-05-PAGE-community-city，返回后已保存筛选条件保持不变

Given PRD-04 权益服务请求失败
When 推荐没有下一张卡
Then 页面进入错误态并提供重试，不把请求失败转换为 remainingBrowseCount=0

Given 推荐接口确认 reason=browse_limit
When 用户进入等待页
Then 必须展示服务端 `nextResetAt` 对应的北京时间绝对日期时间且不显示实时倒计时；普通用户展示会员入口，会员用户不展示会员入口
```

## 10. 关联

引用 `M08-ENUM-waiting-reason`、`M08-RULE-browse-quota`、`M08-TXT-empty-recommend` 和 PRD-04 会员权益。
