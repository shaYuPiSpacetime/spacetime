- **页面路由**：`/pages/recommend/index?tab=recommend|ideal`
- **入口来源**：底部一级入口“荐”；历史推荐/理想型路由兼容跳转
- **对应设计稿**：蓝湖 `推荐-首屏`、`推荐-筛选未找到合适的人`、`推荐-三重认证弹窗`；理想型状态按 2.4 节继续补齐
- **所属模块**：`模块PRD_APP-08_推荐与理想型条件筛选.md`

## 1. 页面定位

已登录、账号正常且基础资料可用的用户发现婚恋候选人的统一入口。推荐 Tab 展示条件过滤后的真实候选卡片；理想型 Tab 选择更严格的资料/标签条件并进入付费解锁结果。浏览者未完成三项认证也可浏览；喜欢和悄悄话单独触发认证校验。页面不展示匹配分、测评结果、精选、推荐解释或可信度百分比；候选人的公开“我的标签”属于资料内容，正常展示。

## 2. 布局（给 UI）

### 2.1 整体布局

```text
顶部安全区：页面标题 / 推荐筛选图标（仅推荐 Tab）
固定 Tab：推荐｜理想型
推荐 Tab：单张候选卡 -> 跳过/悄悄话/喜欢 -> 回看入口；点击候选卡进入详情
理想型 Tab：位置、年龄 -> 分类条件标签 -> 筛选记录/历史解锁 -> 固定底部“选好了”
底部一级导航：荐高亮
```

### 2.2 区块说明

| 区块 | 位置 | 内容 | 折叠 | 记忆状态 |
|------|------|------|------|----------|
| 双 Tab | 顶部 | 推荐、理想型 | 否 | 记住本次会话最后 Tab；新会话默认推荐 |
| 推荐卡片 | 推荐 Tab 主区 | 公开头像、昵称、年龄、城市、公开资料摘要 | 否 | 保留当前游标 |
| 推荐动作区 | 卡片底部 | 跳过、悄悄话、喜欢；点击卡片进入详情 | 否 | 否 |
| 理想型基础区 | 理想型顶部 | 共用目标城市、年龄 | 否 | 是 |
| 理想型条件区 | 理想型主体 | 外在、教育、经济、家庭、兴趣、感情分类标签 | 否 | 是 |
| 理想型提交区 | 底部固定 | 已选数量、“选好了” | 否 | 否 |

### 2.3 弹层

| 弹层 | 触发 | 内容 | 关闭 |
|------|------|------|------|

| 悄悄话弹窗 | 推荐卡点击悄悄话 | PRD-03/04 消息与付费内容 | 按对应模块规则 |

### 2.5 编辑控件口径

| 区域 | 展现 | 控件 | 新增/删除 | 保存 |
|------|------|------|-----------|------|
| 推荐 Tab | 卡片流 | 点击/滑动动作 | 不适用 | 操作即提交 |
| 理想型基础条件 | 胶囊按钮 | 城市选择器、年龄范围选择器 | 城市至少 1 个、最多 3 个；满 3 个隐藏添加入口 | 选择后更新本地草稿；提交时保存共享条件 |

## 3. 筛选与搜索

本页不提供关键词搜索。推荐条件从偏好接口读取；理想型条件为固定集合。城市选择器支持按城市中文名搜索，搜索对象仅为地区字典，不搜索用户。

## 6. 数据联动规则

| 触发 | 影响 | 联动行为 | 引用 |
|------|------|----------|------|
| 推荐筛选保存 | 两个 Tab 基础条件 | 同步新城市和年龄；推荐立即刷新 | `M08-RULE-shared-basic-filter` |
| 页面返回/重新进入且结果快照不可用 | 推荐结果 | 清除失效结果快照，按最近一次已保存筛选重新查询；不重置偏好 | `M08-RULE-filter-result-restore` |
| 理想型修改城市/年龄并提交 | 推荐偏好 | 原子保存共享条件后创建快照 | `M08-SM-filter-profile` |
| 会员到期 | 推荐查询 | 高级值仍保存但不参与推荐查询；首页不展示高级条件数量 | `M08-RULE-vip-filter` |
| 选择本地人 | 目标城市 | 以当前目标城市逐一比较；不允许无城市 | `M08-IDEAL-local` |
| 本人资料不足/补齐后返回 | 依赖条件 | 不足时隐藏条件与空分类；补齐后重新展示，不自动选中 | `M08-RULE-dependent-condition` |

## 7. 状态与异常

| 状态类型 | 触发 | 页面表现 | 用户操作 | 引用 |
|----------|------|----------|----------|------|
| 加载态 | 首次进入/Tab 首载 | 区块骨架屏，Tab 可见 | 返回 | `APP-08-UI-loading` |
| 空态-推荐 | 推荐 0 候选 | 蓝湖人物缺省插图与“当前条件下暂未找到推荐人” | 去千寻同城看看 | `M08-RULE-no-candidate-handoff` |
| 空态-理想型草稿 | 未选附加条件 | 基础城市年龄正常，标签均未选 | 直接筛选/选择条件 | `M08-RULE-ideal-match` |
| 错误态 | 推荐加载/动作网络失败 | 保留当前内容并 Toast“网络错误” | 再次触发原操作 | `M08-RULE-network-retry` |
| 无权限态 | 未登录/账号异常/基础资料不可用 | 登录或按 PRD-01 处理 | 去登录/处理账号资料 | `M08-RULE-viewer-auth` |
| 业务态-未认证互动 | 未认证用户点击喜欢/悄悄话 | 三项认证提示；候选仍展示 | 稍后认证/去认证 | `M08-ERR-interaction-auth-required` |
| 业务态-VIP锁定 | 点击高级筛选/回看 | PRD-04 VIP 引导 | 开通/取消 | `M08-ERR-vip-required` |
| 业务态-候选失效 | 当前卡在操作时失效 | 跳过静默切换；其他动作提示“该用户已注销”后切换 | 继续 | `M08-RULE-candidate-unavailable` |
| 降级态-字典 | 字典不可用 | 推荐使用已保存 code；理想型禁止新提交 | 重试 | `M08-ERR-dictionary-unavailable` |

## 8. 查询与列表

- 推荐卡片每次 20 条，使用不透明游标；按 `M08-RULE-result-order` 稳定排序。
- 卡片剩余 5 条时预加载下一页；不得重复展示同一游标已返回对象。
- 理想型 Tab 本身不查询候选，只有点击“选好了”才创建快照。
- 不支持批量选择推荐卡、关键词搜索或客户端自行排序。

## 9. 验收标准

| AC ID | 场景 | 类型 | 优先级 |
|-------|------|------|--------|
| `APP-08-AC-default-tab` | 进入荐默认推荐 Tab | 正常 | P0 |

| `APP-08-AC-no-cert-filter` | 页面无认证状态筛选 | 正常 | P0 |
| `APP-08-AC-ideal-and` | 理想型全部条件 AND | 正常 | P0 |
| `APP-08-AC-dependent-hidden` | 本人资料缺失条件及空分类隐藏 | 异常 | P0 |

```gherkin
Given 用户已登录、账号正常、基础资料可用且无保存偏好
When 用户从“荐”进入页面
Then 默认打开推荐 Tab，使用现居城市和本人年龄前后 5 岁查询，页面不展示认证状态筛选、匹配分、推荐解释或可信度百分比，候选公开“我的标签”正常展示

Given 浏览者未完成实名、头像或学历认证
When 浏览推荐并依次查看详情、跳过、点击喜欢
Then 详情与跳过正常可用；点击喜欢弹出三项认证提示，认证完成返回原候选人且不自动执行喜欢，用户需再次点击

Given 用户选择“985/211”“博士学历”“喜欢旅行”
When 点击“选好了”
Then 只有同时满足三个条件及共享位置、年龄的候选进入快照；0 候选时不自动删除任何条件

Given 当前用户未填写学校
When 在理想型 Tab 查看“校友”
Then “校友”不展示；若所属分类过滤后无其他条件，整个分类不展示，页面没有置灰状态或资料补全入口

Given 当前推荐卡为 A 且下次喜欢请求发生网络错误
When 用户点击喜欢
Then 页面保留候选 A 并 Toast“网络错误”；用户再次点击喜欢时才重新发起原操作

Given 候选在卡片展示后认证失效
When 用户点击查看详情
Then Toast“该用户已注销”，当前卡片移除并继续下一位，不向用户展示内部失效原因

Given 候选在卡片展示后已失效
When 用户点击跳过或左滑
Then 不弹提示，直接切换下一位；若改为点击喜欢、悄悄话、详情或更多操作，则提示“该用户已注销”后切换下一位

Given 当前筛选下没有可展示候选
When 页面进入 no_candidate 状态并点击“去千寻同城看看”
Then 使用蓝湖人物缺省图并进入 PRD-05 APP-05-PAGE-community-city，返回后仍按最近一次已保存筛选查询
```
