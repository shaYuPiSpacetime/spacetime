# PRD-08 蓝湖 UI 差异核查明细

> 核查范围：蓝湖“推荐”分组 32 张 UI 稿；“缺省页-切图”9 张 PNG 素材
> 最终核查日期：2026-08-09
> 最终事实源：同目录《蓝湖UI缺少页面清单.md》

## 1. 最终结论

32 张 UI 稿已覆盖 PRD-08 的 8 个有效页面，不缺独立页面，也不需要为加载、错误、空态和确认弹窗另出整页稿。UI 的红字说明和新补画板均纳入设计基线。

## 3. 缺省图使用口径

“缺省页-切图”是公共素材板，不是页面稿：

- 无候选使用“暂无关注的人”人物插图，页面文案为“当前条件下暂未找到推荐人”。
- 回看无记录可复用“暂无任何数据”插图。
- 数据加载失败、网络不给力、搜索不到内容分别按实际业务错误使用。
- 页面标题、说明、按钮必须由真实组件绘制，不能烘焙在切图中。

## 4. 唯一待修正差异

`推荐/不看他弹窗`当前文案描述了“收不到消息、互相看不到主页和动态”，属于全局拉黑语义，与 PRD-08 的“不再推荐”不一致；确认按钮“重新发送”也与操作无关。

UI 修改为：

- 标题：`不再推荐这位嘉宾？`
- 说明：`确认后，该用户将不再出现在你的推荐和理想型结果中。`
- 按钮：`取消`、`确认不再推荐`

除上述文案修正外，无 UI 补稿项。
