# 页面规格 - APP-08-PAGE-replay 推荐回看页

| 版本 | 日期 | 修改人 | 变更摘要 |
|------|------|--------|----------|
| 版本01 | 2026-07-16 | Codex | 按 PRD-04 三天回放权益建立回看列表 |

- **页面路由**：`/pages/recommend/replay/index`
- **入口来源**：推荐 Tab、推荐等待页、会员权益入口
- **对应设计稿**：尚未提供；按 2.4 节输出

## 1. 页面定位

向具备 PRD-04 `three_day_replay` 权益的会员展示最近 3 天在推荐场景中浏览或跳过的有效候选人，方便重新查看和发起关系动作。回看不改变筛选条件、不消耗推荐浏览额度。

## 2. 布局（给 UI）

### 2.1 整体布局

```text
导航：返回 / 三天回看
日期分组：今天、昨天、前天（北京时间）
候选卡片列表：头像、昵称、年龄、城市、浏览时间、上次动作
卡片操作：查看详情、喜欢
加载更多 / 空态
```

### 2.2 区块说明

| 区块 | 内容 | 规则 |
|------|------|------|
| 权益说明 | 最近 3 天回看 | 不展示权益剩余次数 |
| 日期分组 | 北京时间自然日 | 只显示存在记录的日期 |
| 回看卡片 | 当前有效公开资料 | 失效候选不返回 |

### 2.3 弹层

无本页专属弹层；权益失效时调用 PRD-04 VIP 引导，喜欢动作按 PRD-02。

### 2.4 UI 画板拆分

| 画板 ID | 画板 | 内容 |
|---------|------|------|
| `APP-08-RP-01` | 正常列表 | 日期分组与候选卡片 |
| `APP-08-RP-02` | 空态 | 最近 3 天无有效记录 |
| `APP-08-RP-03` | 无权益态 | 会员权益引导 |
| `APP-08-RP-04` | 加载/错误态 | 骨架、重试 |

### 2.5 编辑控件口径

本页为只读列表；关系操作点击即提交，不支持批量选择或删除回看记录。

## 3. 筛选与搜索

不提供搜索和筛选；时间范围固定最近 3 个北京时间自然日。

## 4. 字段表

| 字段 ID | 显示名 | 类型 | 必填 | 取值范围 | 校验规则 | 默认值 | 可编辑 | 敏感级别 | 数据来源 |
|---------|--------|------|------|----------|----------|--------|--------|----------|----------|
| `APP-08-PAGE-replay-FIELD-candidate-no` | 候选业务编号 | string | 是 | 有效业务编号 | 实时候选校验 | 无 | 否 | 敏感；UI不直接展示 | 推荐服务 |
| `APP-08-PAGE-replay-FIELD-avatar` | 头像 | image | 是 | 当前有效公开头像 | 签名 URL | 无 | 否 | 敏感；禁止导出 | PRD-01 |
| `APP-08-PAGE-replay-FIELD-nickname` | 昵称 | string | 是 | PRD-01 有效昵称 | 当前公开值 | 无 | 否 | 普通 | PRD-01 |
| `APP-08-PAGE-replay-FIELD-age` | 年龄 | int | 是 | 平台年龄范围 | 服务端计算 | 无 | 否 | 敏感；不导出 | PRD-01 |
| `APP-08-PAGE-replay-FIELD-city` | 城市 | string | 是 | 地区字典名称 | 不返回经纬度 | 无 | 否 | 敏感；不导出 | PRD-01 |
| `APP-08-PAGE-replay-FIELD-viewed-at` | 浏览时间 | datetime | 是 | 最近 3 天 | 北京时间展示 | 无 | 否 | 普通 | 推荐浏览记录 |
| `APP-08-PAGE-replay-FIELD-last-action` | 上次动作 | enum | 是 | `view/skip/detail/like` | 只展示用户自身动作 | `view` | 否 | 敏感；仅本人 | 推荐/PRD-02 |
| `APP-08-PAGE-replay-FIELD-liked` | 已喜欢 | bool | 是 | true/false | 实时关系状态 | false | 否 | 敏感 | PRD-02 |

## 5. 操作表

| 操作 ID | 操作 | 触发条件 | 前置权限 | 二次确认 | 成功态 | 失败态 | 影响 |
|---------|------|----------|----------|----------|--------|--------|------|
| `APP-08-PAGE-replay-ACT-detail` | 查看详情 | 候选有效 | `three_day_replay` 权益 | 否 | 进入卡片详情 | 候选失效后移除 | 不消耗浏览额度 |
| `APP-08-PAGE-replay-ACT-like` | 喜欢 | 未喜欢且候选有效 | PRD-02 | 否 | 更新已喜欢态 | 按 PRD-02 处理 | 来源仍为 `fate` |
| `APP-08-PAGE-replay-ACT-vip` | 开通会员 | 无回看权益 | 已登录 | 否 | 打开 VIP 引导 | 打开失败提示重试 | 返回后刷新权益 |
| `APP-08-PAGE-replay-ACT-load-more` | 加载更多 | 有下一游标 | 回看权益 | 否 | 追加列表 | 失败保留已有项 | 无重复项 |

## 6. 数据联动规则

| 触发 | 影响 | 行为 | 引用 |
|------|------|------|------|
| 会员到期 | 页面 | 清空真实列表缓存，进入权益引导态 | PRD-04 |
| 候选失效 | 列表 | 请求时剔除；已显示项详情失败后移除 | `M08-RULE-candidate-pool` |
| 回看喜欢成功 | 关系状态 | 列表当前项更新，不重新排序 | PRD-02 |

## 7. 状态与异常

| 状态类型 | 触发 | 表现 | 操作 |
|----------|------|------|------|
| 加载态 | 首次加载 | 列表骨架 | 返回 |
| 空态 | 3 天内无有效记录 | `最近三天还没有可回看的嘉宾` | 返回推荐 |
| 错误态 | 网络失败 | 保留已有列表 + 重试 | 重试 |
| 无权限态 | 无权益/未核心准入 | VIP 引导或 PRD-01 拦截 | 开通/完善 |
| 业务态-有记录 | 正常 | 日期分组列表 | 详情/喜欢 |
| 业务态-已喜欢 | 当前项已喜欢 | 按钮显示已喜欢 | 详情 |
| 降级态 | 资料服务异常 | 不返回旧缓存敏感资料，展示重试 | 重试 |

## 8. 查询与列表

默认每页 20 条，按 `viewedAt desc, candidateNo asc` 游标分页；同一候选多次浏览只展示最近一次并聚合上次动作。固定最近 3 天，不跨页全选、不导出、不轮询。

## 9. 验收标准

| AC ID | 场景 | 类型 | 优先级 |
|-------|------|------|--------|
| `APP-08-AC-replay-vip` | 仅权益有效可查看 | 正常/异常 | P0 |
| `APP-08-AC-replay-three-days` | 严格最近 3 天 | 正常 | P1 |
| `APP-08-AC-replay-no-quota` | 回看不扣浏览额度 | 正常 | P0 |

```gherkin
Given 用户有三天回放权益且剩余推荐浏览数为 0
When 在回看页打开一名有效候选详情
Then 可以正常查看，remainingBrowseCount 不变，返回后列表位置保持

Given 会员权益在页面打开期间到期
When 用户加载下一页
Then 服务端拒绝返回真实列表，客户端清理敏感缓存并展示 PRD-04 会员引导
```
