# 页面规格 - APP-08-PAGE-replay 推荐回看页

| 版本 | 日期 | 修改人 | 变更摘要 |
|------|------|--------|----------|
| 版本03 | 2026-08-09 | Codex | 同步 UI 第二轮答复：权益到期回未开通态、失效候选隐藏、查看失败使用固定 Toast 并保留当前页 |
| 版本02 | 2026-08-06 | Codex | 按用户确认以蓝湖回看稿为准：保留每日推荐/跳过汇总和查看按钮，取消单条精确动作、时间与喜欢操作要求 |

- **页面路由**：`/pages/recommend/replay/index`
- **入口来源**：推荐 Tab、推荐等待页、会员权益入口
- **对应设计稿**：蓝湖 `三天回看`、`三天回看-已开通会员`

## 1. 页面定位

向具备 PRD-04 `three_day_replay` 权益的会员展示最近 3 个北京时间自然日的推荐汇总与有效候选人，方便重新查看候选详情。回看不改变筛选条件、不消耗推荐浏览额度。

## 2. 布局（给 UI）

### 2.1 整体布局

```text
导航：返回 / 三天回看
日期分组：最近 3 个北京时间自然日，显示日期和“推荐 N 人 / 跳过 N 人”
候选列表：头像、昵称、出生年份、城市、职业
卡片操作：查看
无记录日期：“这一天你没来，无推荐嘉宾”
底部说明：“仅展示最近 3 天推荐嘉宾，珍惜当下”
```

### 2.2 区块说明

| 区块 | 内容 | 规则 |
|------|------|------|
| 权益说明 | 最近 3 天回看 | 不展示权益剩余次数 |
| 日期分组 | 最近 3 个北京时间自然日及推荐/跳过汇总 | 三个日期均展示；无记录日期展示蓝湖空文案 |
| 回看卡片 | 当前有效公开资料与“查看”按钮 | 失效候选不返回；不展示精确浏览时间、最近动作和喜欢状态 |

### 2.3 弹层

无本页专属弹层；权益失效时调用 PRD-04 VIP 引导。

### 2.4 UI 画板拆分

| 画板 ID | 画板 | 内容 |
|---------|------|------|
| `APP-08-RP-01` | 正常列表 | 蓝湖日期分组、每日汇总、候选行与“查看” |
| `APP-08-RP-02` | 空态 | 最近 3 天无有效记录 |
| `APP-08-RP-03` | 无权益态 | 会员权益引导 |
| `APP-08-RP-04` | 加载/错误态 | 骨架、重试 |

### 2.5 编辑控件口径

本页为只读列表；仅支持查看候选详情，不支持批量选择、删除回看记录或直接喜欢/取消喜欢。

## 3. 筛选与搜索

不提供搜索和筛选；时间范围固定最近 3 个北京时间自然日。

## 5. 操作表

| 操作 ID | 操作 | 触发条件 | 前置权限 | 二次确认 | 成功态 | 失败态 | 影响 |
|---------|------|----------|----------|----------|--------|--------|------|
| `APP-08-PAGE-replay-ACT-detail` | 查看详情 | 候选有效 | `three_day_replay` 权益 | 否 | 进入卡片详情 | Toast“查看失败，请返回后重新查看”，保留当前回看页；若确认候选失效则同时从列表移除 | 不消耗浏览额度 |
| `[已废弃] APP-08-PAGE-replay-ACT-like` | 喜欢/取消喜欢 | 蓝湖回看页无该操作 | — | — | 不实现 | — | ID 不复用 |
| `APP-08-PAGE-replay-ACT-vip` | 开通会员 | 无回看权益 | 已登录 | 否 | 打开 VIP 引导 | 打开失败提示重试 | 返回后刷新权益 |
| `APP-08-PAGE-replay-ACT-load-more` | 加载更多 | 有下一游标 | 回看权益 | 否 | 追加列表 | 失败保留已有项 | 无重复项 |

## 6. 数据联动规则

| 触发 | 影响 | 行为 | 引用 |
|------|------|------|------|
| 会员到期 | 页面 | 清空真实列表缓存，直接进入未开通/购买会员状态 | PRD-04 |
| 候选失效 | 列表 | 请求时直接剔除；已显示项确认失效后移除，不保留不可用占位 | `M08-RULE-candidate-pool` |
| 日期跨日 | 日期分组 | 页面重新前台激活时按北京时间重算最近 3 天，移除窗口外日期并补入新日期 | `M08-PARAM-replay-days` |

## 7. 状态与异常

| 状态类型 | 触发 | 表现 | 操作 |
|----------|------|------|------|
| 加载态 | 首次加载 | 列表骨架 | 返回 |
| 空态 | 3 天内无有效记录 | `最近三天还没有可回看的嘉宾` | 返回推荐 |
| 错误态-列表加载 | 首次或翻页失败 | 保留已有列表并提供重试 | 重试 |
| 错误态-查看失败 | 点击候选“查看”失败 | Toast“查看失败，请返回后重新查看”，保留当前回看页 | 返回后重新查看 |
| 无权限态 | 无回看权益或未登录/账号异常/基础资料不可用 | VIP 引导或按 PRD-01 处理；未完成三项认证不影响页面权限 | 开通/登录/处理账号资料 |
| 业务态-有记录 | 正常 | 日期汇总、候选行和“查看”按钮 | 查看详情 |
| 业务态-单日无记录 | 最近 3 天中的某日无记录 | `这一天你没来，无推荐嘉宾` | 无 |
| 降级态 | 资料服务异常 | 不返回旧缓存敏感资料，展示重试 | 重试 |

## 8. 查询与列表

默认每页 20 条候选记录，按 `date desc, candidateNo asc` 游标分页；同一候选同一自然日只展示一次。接口同时返回三个日期的 `recommendedCount/skippedCount`，包括 0 记录日期。固定最近 3 天，不跨页全选、不导出、不轮询。

## 9. 验收标准

| AC ID | 场景 | 类型 | 优先级 |
|-------|------|------|--------|
| `APP-08-AC-replay-vip` | 仅权益有效可查看 | 正常/异常 | P0 |
| `APP-08-AC-replay-three-days` | 严格最近 3 天 | 正常 | P1 |
| `APP-08-AC-replay-no-quota` | 回看不扣浏览额度 | 正常 | P0 |

```gherkin
Given 用户有三天回放权益且剩余推荐浏览数为 0
When 在回看页打开一名有效候选详情
Then 可以正常查看，remainingBrowseCount 不变，返回后列表位置保持

Given 会员权益在页面打开期间到期
When 用户加载下一页
Then 服务端拒绝返回真实列表，客户端清理敏感缓存并直接展示未开通/购买会员状态

Given 会员最近 3 天中昨天没有打开推荐页
When 用户进入三天回看
Then 昨天日期仍展示，并显示“这一天你没来，无推荐嘉宾”；有记录日期展示“推荐 N 人 / 跳过 N 人”和候选查看入口

Given 用户在回看页点击某候选的“查看”
When 详情请求失败
Then Toast“查看失败，请返回后重新查看”并保留当前回看页；若服务端确认候选失效，该候选同时从列表隐藏
```
