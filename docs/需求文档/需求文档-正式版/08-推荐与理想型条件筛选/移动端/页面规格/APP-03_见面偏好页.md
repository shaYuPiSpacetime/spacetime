# 页面规格 - APP-08-PAGE-meeting-preference 见面偏好页

| 版本 | 日期 | 修改人 | 变更摘要 |
|------|------|--------|----------|
| 版本01 | 2026-07-16 | Codex | 保留见面偏好页面并明确一期不参与筛选 |

- **页面路由**：`/pages/recommend/meeting-preference/index`
- **入口来源**：推荐 Tab 辅助入口；PRD-01 编辑资料页面组
- **对应设计稿**：尚未提供；按 2.4 节输出

## 1. 页面定位

用户保存见面节奏与喜欢的见面活动，作为个人资料和后续互动参考。一期不将本页字段用于推荐或理想型过滤，避免形成未确认的隐性规则。

## 2. 布局（给 UI）

### 2.1 整体布局

```text
导航栏：返回 / 见面偏好
说明：这些选择用于资料展示，不影响一期推荐结果
见面偏好：系统字典启用项，单选
喜欢的见面活动：系统字典启用项，多选
底部固定：保存
```

### 2.2 区块说明

| 区块 | 位置 | 内容 | 是否折叠 |
|------|------|------|----------|
| 页面说明 | 顶部 | 明确“不影响一期推荐结果” | 否 |
| 见面偏好 | 主体上部 | 系统字典单选项 | 否 |
| 见面活动 | 主体下部 | 系统字典多选项 | 否 |
| 保存区 | 底部固定 | 保存按钮 | 否 |

### 2.3 弹层

仅草稿变化后返回时展示确认弹窗：`见面偏好尚未保存，是否放弃修改？`。

### 2.4 UI 画板拆分

| 画板 ID | 画板 | 内容 |
|---------|------|------|
| `APP-08-MP-01` | 正常编辑态 | 单选见面偏好、多选活动、说明与保存 |
| `APP-08-MP-02` | 已保存态 | 原值回显和保存成功反馈 |
| `APP-08-MP-03` | 字典空态 | 无启用项、联系客服/返回 |
| `APP-08-MP-04` | 字典错误态 | 保留旧值、重试 |
| `APP-08-MP-05` | 未保存返回确认 | 继续编辑/放弃 |

### 2.5 编辑控件口径

| 区域 | 展现 | 控件 | 新增/删除 | 保存 |
|------|------|------|-----------|------|
| 见面偏好 | 标签组 | 单选 Chip | 字典固定，不可新增删除 | 页面级保存 |
| 见面活动 | 标签流 | 多选 Chip | 字典固定，不可新增删除 | 页面级保存 |

## 3. 筛选与搜索

本页为轻量表单，不提供搜索和列表筛选；选项按系统字典排序全部展示。

## 4. 字段表

| 字段 ID | 显示名 | 类型 | 必填 | 取值范围 | 校验规则 | 默认值 | 可编辑 | 敏感级别 | 数据来源 |
|---------|--------|------|------|----------|----------|--------|--------|----------|----------|
| `APP-08-PAGE-meeting-preference-FIELD-preference` | 见面偏好 | enum/null | 否 | `meeting_preference` 启用 code | 单选；停用历史值只读显示 | null | 本人 | 敏感；按资料公开设置展示 | PRD-01/系统字典 |
| `APP-08-PAGE-meeting-preference-FIELD-activities` | 喜欢的见面活动 | array | 否 | `preferred_activity` 启用 code | 多选、去重、数量上限取 PRD-01 字段配置 | 空数组 | 本人 | 敏感；按资料公开设置展示 | PRD-01/系统字典 |
| `APP-08-PAGE-meeting-preference-FIELD-updated-at` | 最近保存时间 | datetime/null | 否 | 合法服务端时间 | 客户端不可提交 | null | 否 | 普通 | 资料服务 |

## 5. 操作表

| 操作 ID | 操作 | 触发条件 | 前置权限 | 二次确认 | 成功态 | 失败态 | 影响 |
|---------|------|----------|----------|----------|--------|--------|------|
| `APP-08-PAGE-meeting-preference-ACT-select` | 选择见面偏好 | 字典可用 | 核心准入通过 | 否 | 草稿单选更新 | 字典项停用时不可选 | 不立即保存 |
| `APP-08-PAGE-meeting-preference-ACT-activity` | 选择活动 | 字典可用且未超上限 | 核心准入通过 | 否 | 草稿多选更新 | 超上限提示 | 不立即保存 |
| `APP-08-PAGE-meeting-preference-ACT-save` | 保存 | 草稿合法且有变化 | 核心准入通过 | 否 | toast 成功并刷新资料完整度 | 网络/校验失败保留草稿 | 更新 PRD-01 资料，不刷新推荐 |
| `APP-08-PAGE-meeting-preference-ACT-back` | 返回 | 任意 | 核心准入通过 | 有未保存变化时确认 | 返回来源页 | 无 | 放弃时不写库 |

## 6. 数据联动规则

| 触发 | 影响 | 行为 | 引用 |
|------|------|------|------|
| 字典项停用 | 历史值 | 保留中文历史值并标“已停用”，不可重新选择 | PRD-01 字典规则 |
| 保存成功 | 推荐/理想型 | 不刷新、不改变候选顺序或筛选结果 | `M08-RULE-meeting-preference` |
| 资料完整度开启计分 | PRD-01 | 由 PRD-01 资料服务重新计算，不在本页写死分值 | `M01-RULE-profile-score` |

## 7. 状态与异常

| 状态类型 | 触发 | 表现 | 操作 |
|----------|------|------|------|
| 加载态 | 查询资料/字典 | 表单骨架 | 返回 |
| 空态 | 无任何启用选项 | `暂时没有可选的见面偏好` | 返回 |
| 错误态 | 请求失败 | 保留旧值/草稿，提示重试 | 重试 |
| 无权限态 | 未核心准入 | PRD-01 拦截 | 去完善 |
| 业务态-未填写 | 两字段为空 | 未选中态 | 选择并保存 |
| 业务态-已填写 | 有保存值 | 正常回显 | 修改 |
| 降级态 | 字典不可用 | 旧值只读，保存禁用 | 重试 |

## 8. 查询与列表

本页无列表分页；两个字典一次返回全部启用项，按系统排序。页面不轮询、不自动保存。

## 9. 验收标准

| AC ID | 场景 | 类型 | 优先级 |
|-------|------|------|--------|
| `APP-08-AC-meeting-save` | 保存见面偏好 | 正常 | P1 |
| `APP-08-AC-meeting-no-filter` | 保存不影响推荐 | 正常 | P0 |
| `APP-08-AC-meeting-dict-fail` | 字典失败不清空旧值 | 异常 | P1 |

```gherkin
Given 用户已保存推荐筛选条件和当前推荐游标
When 在见面偏好页修改并保存见面偏好
Then PRD-01 资料更新成功，但推荐偏好版本、理想型条件和当前推荐顺序均不变化

Given 见面偏好字典加载失败且用户已有历史值
When 页面进入降级态
Then 历史值只读回显，保存按钮禁用，不清空或覆盖原值
```
