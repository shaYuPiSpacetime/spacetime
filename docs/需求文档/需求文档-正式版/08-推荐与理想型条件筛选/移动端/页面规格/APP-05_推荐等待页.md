# 页面规格 - APP-08-PAGE-waiting 推荐等待页

| 版本 | 日期 | 修改人 | 变更摘要 |
|------|------|--------|----------|
| 版本01 | 2026-07-16 | Codex | 承接无候选与浏览额度结束两类等待状态 |

- **页面路由**：`/pages/recommend/waiting/index?reason=no_candidate|browse_limit`
- **入口来源**：推荐 Tab 本轮没有可展示候选
- **对应设计稿**：尚未提供；按 2.4 节输出

## 1. 页面定位

在推荐候选暂时耗尽或 PRD-04 明确返回当日浏览额度为 0 时，为用户提供可执行的后续入口，避免无限 loading 或伪造候选。无候选时可以调整条件；额度结束时按商业化权益展示下一步。

## 2. 布局（给 UI）

### 2.1 整体布局

```text
导航：返回
居中插画
状态标题与说明
主操作：调整筛选 / 开通会员（按原因）
次操作：查看回看 / 返回推荐 / 稍后再来
```

### 2.2 区块说明

| 原因 | 标题 | 主操作 | 次操作 |
|------|------|--------|--------|
| `no_candidate` | 暂时没有符合条件的嘉宾 | 调整筛选 | 返回推荐 |
| `browse_limit` | 今天的推荐已看完 | 权益可购买时开通会员；否则稍后再来 | 三天回看/返回 |

### 2.3 弹层

点击开通会员时打开 PRD-04 VIP 引导；本页不自建套餐或价格弹窗。

### 2.4 UI 画板拆分

| 画板 ID | 画板 | 内容 |
|---------|------|------|
| `APP-08-WT-01` | 无候选 | 调整筛选与返回 |
| `APP-08-WT-02` | 浏览额度结束-普通用户 | 会员引导与回看锁定 |
| `APP-08-WT-03` | 浏览额度结束-会员 | 稍后再来和三天回看 |
| `APP-08-WT-04` | 权益服务错误 | 不宣称额度用完，展示重试 |

### 2.5 编辑控件口径

本页为状态页，无表单编辑；所有按钮跳转或重试。

## 3. 筛选与搜索

本页无搜索、无筛选控件；“调整筛选”进入 `APP-08-PAGE-filter-settings`。

## 4. 字段表

| 字段 ID | 显示名 | 类型 | 必填 | 取值范围 | 校验规则 | 默认值 | 可编辑 | 敏感级别 | 数据来源 |
|---------|--------|------|------|----------|----------|--------|--------|----------|----------|
| `APP-08-PAGE-waiting-FIELD-reason` | 等待原因 | enum | 是 | `M08-ENUM-waiting-reason` | 必须由推荐接口返回，客户端路由值需复核 | 无 | 否 | 普通 | 推荐/权益服务 |
| `APP-08-PAGE-waiting-FIELD-next-reset-at` | 额度重置时间 | datetime/null | 否 | 北京时间未来时间 | 仅 `browse_limit` 且服务端提供时展示 | null | 否 | 普通 | PRD-04 |
| `APP-08-PAGE-waiting-FIELD-vip-effective` | 会员有效 | bool | 是 | true/false | 服务端计算 | false | 否 | 普通 | PRD-04 |
| `APP-08-PAGE-waiting-FIELD-replay-effective` | 回看有效 | bool | 是 | true/false | `three_day_replay` 权益 | false | 否 | 普通 | PRD-04 |
| `APP-08-PAGE-waiting-FIELD-condition-summary` | 当前条件摘要 | object | 否 | 城市、年龄、高级条件数量 | 不返回敏感原始候选数据 | 空对象 | 否 | 敏感；仅本人可见 | 偏好服务 |

## 5. 操作表

| 操作 ID | 操作 | 触发条件 | 前置权限 | 二次确认 | 成功态 | 失败态 | 影响 |
|---------|------|----------|----------|----------|--------|--------|------|
| `APP-08-PAGE-waiting-ACT-filter` | 调整筛选 | `no_candidate` | 核心准入 | 否 | 进入筛选设置 | 路由失败提示重试 | 不自动改条件 |
| `APP-08-PAGE-waiting-ACT-vip` | 开通会员 | `browse_limit` 且无会员 | 已登录 | 否 | 打开 PRD-04 VIP 引导 | 打开失败提示重试 | 返回后刷新额度 |
| `APP-08-PAGE-waiting-ACT-replay` | 三天回看 | 权益有效 | 核心准入+会员权益 | 否 | 进入回看页 | 权益失效改为会员引导 | 不消耗额度 |
| `APP-08-PAGE-waiting-ACT-retry` | 重新加载 | 权益/推荐服务错误 | 核心准入 | 否 | 按真实原因刷新页面 | 继续错误态 | 不伪造候选 |
| `APP-08-PAGE-waiting-ACT-back` | 返回推荐 | 任意正常原因 | 核心准入 | 否 | 返回双 Tab 推荐 | 无 | 保留当前筛选 |

## 6. 数据联动规则

| 触发 | 影响 | 行为 | 引用 |
|------|------|------|------|
| 调整筛选保存后返回 | 等待原因 | 重新查询；有候选则离开等待页 | `M08-RULE-recommend-filter` |
| 会员购买成功 | 剩余额度/回看 | 重新查询 PRD-04 权益，不使用本地假值 | `M08-RULE-browse-quota` |
| 权益服务失败 | 页面原因 | 不得将 null/错误当作 0 | `M08-RULE-browse-quota` |

## 7. 状态与异常

| 状态类型 | 触发 | 表现 | 操作 |
|----------|------|------|------|
| 加载态 | 复核原因/权益 | 插画骨架和禁用按钮 | 返回 |
| 空态 | `no_candidate` | 无候选文案 | 调整筛选 |
| 错误态 | 原因复核失败 | `暂时无法加载推荐状态` | 重试 |
| 无权限态 | 未核心准入 | PRD-01 拦截 | 去完善 |
| 业务态-额度结束 | `browse_limit` | 今日看完说明 | VIP/回看/稍后 |
| 业务态-普通无回看 | 回看权益无效 | 回看按钮锁定 | 开通会员 |
| 降级态 | PRD-04 不可用 | 不显示额度数或重置时间 | 重试/返回 |

## 8. 查询与列表

本页无列表和分页；每次前台激活页面重新复核等待原因与权益。不得自动轮询候选或在后台持续刷新。

## 9. 验收标准

| AC ID | 场景 | 类型 | 优先级 |
|-------|------|------|--------|
| `APP-08-AC-wait-no-candidate` | 无候选可调整筛选 | 正常 | P0 |
| `APP-08-AC-wait-limit` | 额度为 0 才显示看完 | 正常 | P0 |
| `APP-08-AC-wait-service-fail` | 权益错误不误判额度 | 异常 | P0 |

```gherkin
Given 推荐接口返回 0 条且剩余浏览数大于 0或为 null
When 进入等待页
Then 原因为 no_candidate，展示调整筛选，不展示“今日额度已用完”

Given PRD-04 权益服务请求失败
When 推荐没有下一张卡
Then 页面进入错误态并提供重试，不把请求失败转换为 remainingBrowseCount=0
```

## 10. 关联

引用 `M08-ENUM-waiting-reason`、`M08-RULE-browse-quota`、`M08-TXT-empty-recommend` 和 PRD-04 会员权益。
