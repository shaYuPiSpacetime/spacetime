# 页面规格 - APP-08-PAGE-recommend-ideal 推荐与理想型页

| 版本 | 日期 | 修改人 | 变更摘要 |
|------|------|--------|----------|
| 版本01 | 2026-07-16 | Codex | 双 Tab 主页面正式规格 |

- **页面路由**：`/pages/recommend/index?tab=recommend|ideal`
- **入口来源**：底部一级入口“荐”；历史推荐/理想型路由兼容跳转
- **对应设计稿**：用户提供了理想型参考截图；正式 Figma/蓝湖链接尚未提供，设计画板按 2.4 节输出
- **所属模块**：`模块PRD_APP-08_推荐与理想型条件筛选.md`

## 1. 页面定位

完成核心准入用户发现婚恋候选人的统一入口。推荐 Tab 展示条件过滤后的真实候选卡片；理想型 Tab 选择更严格的资料/标签条件并进入付费解锁结果。页面不展示匹配分、测评结果、精选或推荐解释。

## 2. 布局（给 UI）

### 2.1 整体布局

```text
顶部安全区：页面标题 / 推荐筛选图标（仅推荐 Tab）
固定 Tab：推荐｜理想型
推荐 Tab：当前条件摘要 -> 单张候选卡 -> 跳过/喜欢/悄悄话 -> 见面偏好/回看入口
理想型 Tab：位置、年龄 -> 分类条件标签 -> 筛选记录/历史解锁 -> 固定底部“选好了”
底部一级导航：荐高亮
```

### 2.2 区块说明

| 区块 | 位置 | 内容 | 折叠 | 记忆状态 |
|------|------|------|------|----------|
| 双 Tab | 顶部 | 推荐、理想型 | 否 | 记住本次会话最后 Tab；新会话默认推荐 |
| 推荐条件摘要 | 推荐 Tab 顶部 | 城市、年龄、高级条件数量 | 是 | 是 |
| 推荐卡片 | 推荐 Tab 主区 | 公开头像、昵称、年龄、城市、公开资料摘要 | 否 | 保留当前游标 |
| 推荐动作区 | 卡片底部 | 跳过、喜欢、悄悄话、详情 | 否 | 否 |
| 理想型基础区 | 理想型顶部 | 共用目标城市、年龄 | 否 | 是 |
| 理想型条件区 | 理想型主体 | 外在、教育、经济、家庭、兴趣、感情分类标签 | 否 | 是 |
| 理想型提交区 | 底部固定 | 已选数量、“选好了” | 否 | 否 |

### 2.3 弹层

| 弹层 | 触发 | 内容 | 关闭 |
|------|------|------|------|

### 2.5 编辑控件口径

| 区域 | 展现 | 控件 | 新增/删除 | 保存 |
|------|------|------|-----------|------|
| 推荐 Tab | 卡片流 | 点击/滑动动作 | 不适用 | 操作即提交 |
| 理想型基础条件 | 胶囊按钮 | 城市选择器、年龄范围选择器 | 城市最多 3 个 | 选择后更新本地草稿；提交时保存共享条件 |
| 理想型条件 | 分类标签流 | 多选 Chip | 固定集合，不可新增删除 | 点击切换本地草稿；“选好了”统一提交 |

## 3. 筛选与搜索

本页不提供关键词搜索。推荐条件从偏好接口读取；理想型条件为固定集合。城市选择器支持按城市中文名搜索，搜索对象仅为地区字典，不搜索用户。

## 6. 数据联动规则

| 触发 | 影响 | 联动行为 | 引用 |
|------|------|----------|------|
| 推荐筛选保存 | 两个 Tab 基础条件 | 同步新城市和年龄；推荐立即刷新 | `M08-RULE-shared-basic-filter` |
| 理想型修改城市/年龄并提交 | 推荐偏好 | 原子保存共享条件后创建快照 | `M08-SM-filter-profile` |
| 会员到期 | 推荐高级条件摘要 | 条件数变为 0，高级值仍保存 | `M08-RULE-vip-filter` |
| 选择本地人 | 目标城市 | 以当前目标城市逐一比较；不允许无城市 | `M08-IDEAL-local` |
| 本人资料补齐后返回 | 依赖条件 | 重新计算可用性，不自动选中 | `M08-RULE-dependent-condition` |

## 7. 状态与异常

| 状态类型 | 触发 | 页面表现 | 用户操作 | 引用 |
|----------|------|----------|----------|------|
| 加载态 | 首次进入/Tab 首载 | 区块骨架屏，Tab 可见 | 返回 | `APP-08-UI-loading` |
| 空态-推荐 | 推荐 0 候选 | 空态文案、调整筛选 | 调整筛选/稍后重试 | `M08-TXT-empty-recommend` |
| 空态-理想型草稿 | 未选附加条件 | 基础城市年龄正常，标签均未选 | 直接筛选/选择条件 | `M08-RULE-ideal-match` |
| 错误态 | 网络/服务失败 | 保留上次成功内容 + 重试 | 重试 | 移动端通用错误态 |
| 无权限态 | 未登录/未核心准入 | 登录或 PRD-01 拦截 | 去登录/完善 | `M08-ERR-core-access-required` |
| 业务态-VIP锁定 | 点击高级筛选/回看 | PRD-04 VIP 引导 | 开通/取消 | `M08-ERR-vip-required` |
| 业务态-候选失效 | 当前卡失效 | 无痕移除并加载下一张 | 继续 | `M08-ERR-candidate-unavailable` |

## 8. 查询与列表

- 推荐卡片每次 20 条，使用不透明游标；按 `M08-RULE-result-order` 稳定排序。
- 卡片剩余 5 条时预加载下一页；不得重复展示同一游标已返回对象。
- 理想型 Tab 本身不查询候选，只有点击“选好了”才创建快照。
- 不支持批量选择推荐卡、关键词搜索或客户端自行排序。

## 9. 验收标准

| AC ID | 场景 | 类型 | 优先级 |
|-------|------|------|--------|
| `APP-08-AC-default-tab` | 进入荐默认推荐 Tab | 正常 | P0 |
| `APP-08-AC-core-gate` | 未完成三项认证不得读候选 | 异常 | P0 |
| `APP-08-AC-no-cert-filter` | 页面无认证状态筛选 | 正常 | P0 |
| `APP-08-AC-ideal-and` | 理想型全部条件 AND | 正常 | P0 |
| `APP-08-AC-dependent-disabled` | 本人资料缺失条件禁用 | 异常 | P0 |

```gherkin
Given 用户已完成 PRD-01 三项认证且无保存偏好
When 用户从“荐”进入页面
Then 默认打开推荐 Tab，使用现居城市和本人年龄前后 5 岁查询，页面不展示认证状态筛选、匹配分或测评标签

Given 用户选择“985/211”“博士学历”“喜欢旅行”
When 点击“选好了”
Then 只有同时满足三个条件及共享位置、年龄的候选进入快照；0 候选时不自动删除任何条件

Given 当前用户未填写学校
When 在理想型 Tab 查看“校友”
Then “校友”置灰，点击后展示资料补全引导，且不会提交空学校筛选

Given 候选在卡片展示后认证失效
When 用户点击查看详情
Then 返回 M08-ERR-candidate-unavailable，当前卡片移除并继续下一位，不向用户展示内部失效原因
```
