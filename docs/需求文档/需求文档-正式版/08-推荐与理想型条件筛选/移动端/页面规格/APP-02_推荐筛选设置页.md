# 页面规格 - APP-08-PAGE-filter-settings 推荐筛选设置页

| 版本 | 日期 | 修改人 | 变更摘要 |
|------|------|--------|----------|
| 版本04 | 2026-08-09 | Codex | 同步蓝湖 `偏好设置-点击返回`，统一保存/不保存返回逻辑，并明确结果快照缺失时按已保存条件重查 |
| 版本03 | 2026-08-09 | Codex | 按 UI 回复固化城市 1～3 个与添加入口，非会员点击高级区直达会员页，返回刷新权益并保留草稿 |
| 版本02 | 2026-08-06 | Codex | 按用户确认保持蓝湖连续页面布局，删除认证筛选；基础/高级字段、会员视觉与选择入口均以现稿为准 |
| 版本01 | 2026-07-16 | Codex | 删除认证状态筛选，建立免费基础与 VIP 高级筛选规格 |

- **页面路由**：`/pages/recommend/filter/index`
- **入口来源**：推荐 Tab 右上筛选图标
- **对应设计稿**：蓝湖 `偏好设置`、`偏好设置-已开通会员`、`偏好设置-点击返回`

## 1. 页面定位

用户维护推荐 Tab 的固定筛选偏好。基础筛选免费，高级筛选由 PRD-04 `advanced_filter` 权益控制；页面不配置算法参数，也不展示认证状态。

## 2. 布局（给 UI）

### 2.1 整体布局

```text
导航栏：返回 / 偏好设置
连续表单上半区：目标城市（默认当前城市，1～3 个）+ 添加城市、周边城市开关、年龄双滑杆
连续表单下半区：高级筛选会员标识；身高、体重双滑杆；学历多选；家乡/学校/专业选择
底部固定：恢复默认｜保存
```

### 2.2 区块说明

| 区块 | 内容 | 普通用户 | 会员 |
|------|------|----------|------|
| 基础筛选 | 位置、周边城市、年龄 | 可编辑 | 可编辑 |
| 高级筛选 | 紧接基础区向下展示身高、体重、学历、家乡、学校、专业 | 显示字段名称和会员样式；点击任一内容直接进入“时空邂逅会员”页面 | 可编辑 |
| 保存区 | 恢复默认、保存 | 仅保存基础 | 保存基础和高级 |

### 2.3 弹层

| 弹层 | 触发 | 内容 | 关闭 |
|------|------|------|------|
| 城市选择器 | 蓝湖稿内添加/编辑城市入口 | 搜索城市、多选；默认当前城市，至少 1 个、最多 3 个 | 完成/取消 |
| 字典选择器 | 蓝湖稿内学历/家乡/学校入口 | 字典搜索与多选；不另出整页稿 | 完成/取消 |
| 专业选择器 | 蓝湖稿内专业入口 | 已填写专业/标准化专业全称搜索；不另出整页稿 | 完成/取消 |
| 会员承接页 | 普通用户点击高级区任一内容 | 直接进入 PRD-04“时空邂逅会员”页面；不在本页重复绘制套餐 | 返回筛选/完成购买 |
| 未保存返回确认 | 草稿变化后返回 | `温馨提示` / `是否保存该设置？` | 不保存/保存 |

### 2.4 UI 画板拆分

| 画板 ID | 画板 | 内容 |

| `APP-08-FS-02` | 高级筛选-会员 | 六类高级条件正常编辑 |

| `APP-08-FS-04` | 城市选择器 | 搜索、多选、1～3 个边界、满 3 个隐藏添加入口 |

| `APP-08-FS-07` | 字典降级 | 已保存值只读、重试 |

### 2.5 编辑控件口径

| 区域 | 展现 | 控件 | 新增/删除 | 保存 |
|------|------|------|-----------|------|
| 目标城市 | 标签列表 | 城市选择器 | 默认当前城市；至少 1 个、最多 3 个；满 3 个隐藏添加入口，删除后恢复 | 页面级保存；0 个时禁用 |
| 周边城市 | 表单行 | Switch | 不适用 | 页面级保存 |
| 年龄/身高/体重 | 表单卡片 | 双滑杆 + 数字回显 | 不适用 | 页面级保存 |
| 学历 | 标签组 | 多选 Chip | 固定字典项 | 页面级保存 |
| 家乡/学校/专业 | 表单行 | 搜索选择器 | 多选值可删除 | 页面级保存 |

## 3. 筛选与搜索

本页本身为筛选表单。城市、学校、专业选择器支持输入防抖 300ms 搜索；城市/学校按名称前缀与包含匹配，仅将选中项的业务 code 保存；专业按标准化全称选择，不保存任意模糊关键词。

## 5. 操作表

| 操作 ID | 操作 | 触发条件 | 前置权限 | 二次确认 | 成功态 | 失败态 | 影响 |
|---------|------|----------|----------|----------|--------|--------|------|
| `[已废弃] APP-08-PAGE-filter-settings-ACT-switch-basic` | 基础筛选 Tab | 蓝湖连续布局无该 Tab | — | — | 不实现 | — | ID 不复用 |
| `[已废弃] APP-08-PAGE-filter-settings-ACT-switch-advanced` | 高级筛选 Tab | 蓝湖连续布局无该 Tab | — | — | 不实现 | — | ID 不复用 |
| `APP-08-PAGE-filter-settings-ACT-edit-city` | 选择城市 | 字典可用 | 已登录且基础资料可用 | 否 | 草稿更新；满 3 个隐藏添加入口 | 0 个城市禁用保存并提示；字典错误提示重试 | 不立即查询 |
| `APP-08-PAGE-filter-settings-ACT-edit-advanced` | 编辑高级条件 | `vipEffective=true` | 会员 | 否 | 草稿更新 | `M08-ERR-vip-required` | 不立即查询 |
| `APP-08-PAGE-filter-settings-ACT-vip` | 点击任一高级筛选内容 | `vipEffective=false` | 已登录 | 否 | 直接进入 PRD-04“时空邂逅会员”页面 | 打开失败提示重试 | 当前基础草稿保留 |
| `APP-08-PAGE-filter-settings-ACT-reset` | 恢复默认 | 页面正常 | 已登录且基础资料可用 | 是：`恢复为当前城市和默认年龄范围？高级条件也会清空。` | 本地草稿恢复默认 | 无 | 尚未写库，需再保存 |
| `APP-08-PAGE-filter-settings-ACT-save` | 保存 | 校验通过且有变更 | 已登录且基础资料可用 | 否 | toast 成功，返回推荐 Tab 刷新 | 版本冲突刷新并保留草稿；其他错误原地提示 | `M08-EVT-filter-saved` |

## 6. 数据联动规则

| 触发 | 影响 | 联动行为 | 引用 |
|------|------|----------|------|
| 城市数量变化 | 添加入口/保存按钮 | 达到 3 个隐藏添加入口，删除后恢复；删除到 0 个时禁用保存并提示“请至少选择一个城市” | `M08-RULE-target-city` |
| 会员到期 | 高级字段 | 保留回显，全部锁定且本次查询不生效 | `M08-RULE-vip-filter` |
| 会员页开通后返回 | 全页草稿/高级字段 | 重新查询权益；基础草稿原样保留，高级字段原地转为可编辑，保存值重新生效 | `M08-SM-filter-profile` |
| 开启周边城市 | 理想型 | 理想型执行时仍关闭扩展，开关不清空 | `M08-RULE-shared-basic-filter` |
| 学校/专业字典无结果 | 选择器 | 不允许保存随意输入文本 | `M08-RULE-missing-data` |
| 页面返回/重新进入且上次结果快照不存在 | 推荐结果 | 清除失效结果快照，使用最近一次成功保存的筛选条件重新查询；不得恢复平台默认筛选 | `M08-RULE-filter-result-restore` |

## 7. 状态与异常

| 状态类型 | 触发 | 表现 | 操作 | 引用 |
|----------|------|------|------|------|
| 加载态 | 查询偏好/字典 | 表单骨架 | 返回 | `APP-08-UI-loading` |
| 空态 | 无高级条件 | 高级页展示未设置提示，不视为错误 | 添加条件 | — |
| 错误态 | 偏好请求失败 | 错误页，禁止以默认值覆盖 | 重试/返回 | 通用错误态 |
| 无权限态 | 未登录/账号异常/基础资料不可用 | 按 PRD-01 处理；未完成三项认证不属于本页无权限 | 去登录/处理账号资料 | `M08-RULE-viewer-auth` |
| 业务态-普通 | 无会员 | 基础可编辑，高级锁定 | 开通会员 | `M08-ERR-vip-required` |
| 业务态-会员 | 权益有效 | 全部可编辑 | 保存 | `M08-RULE-vip-filter` |
| 降级态 | 字典不可用 | 已保存值只读回显，保存禁用 | 重试 | `M08-ERR-dictionary-unavailable` |
| 并发态 | 版本冲突 | 提示其他设备已更新 | 刷新后重试 | `M08-ERR-filter-conflict` |

## 8. 查询与列表

选择器每页 20 条，输入防抖 300ms；城市/学校按业务 code 去重。页面表单不自动保存、不轮询；从会员页返回时只刷新权益状态，并保留进入会员页前的全部基础筛选草稿。

## 9. 验收标准

| AC ID | 场景 | 类型 | 优先级 |
|-------|------|------|--------|
| `APP-08-AC-basic-free` | 普通用户可保存位置年龄 | 正常 | P0 |
| `APP-08-AC-advanced-vip` | 高级筛选仅会员生效 | 正常/异常 | P0 |
| `APP-08-AC-no-auth-filter` | 无认证状态区块 | 正常 | P0 |
| `APP-08-AC-version-conflict` | 并发保存不覆盖 | 异常 | P0 |

```gherkin
Given 普通用户进入推荐筛选设置页
When 从上至下查看同一连续表单
Then 位置、年龄可编辑，高级六项名称可见；点击高级区任一内容直接进入“时空邂逅会员”页面，页面没有基础/高级 Tab，也不展示认证状态筛选

Given 当前城市为杭州且用户依次添加宁波、上海
When 城市数量达到 3 个后删除宁波，再删除杭州和上海
Then 达到 3 个时添加入口隐藏，删除宁波后重新显示；删除到 0 个时保存禁用并提示“请至少选择一个城市”

Given 普通用户已将目标城市草稿改为杭州、宁波且年龄改为 26–32
When 点击任一高级条件进入会员页并开通后返回
Then 重新查询到会员权益，高级条件可编辑，杭州、宁波和 26–32 岁草稿保持不变

Given 会员保存两个城市、年龄 25-31、身高 165-180 和博士学历
When 点击保存
Then 服务端按同字段 OR、跨字段 AND 保存新版本，返回推荐 Tab 后立即用新条件刷新

Given 同一用户已在另一设备更新偏好版本
When 当前页面提交旧版本
Then 返回 M08-ERR-filter-conflict，不覆盖新数据，并允许用户刷新后重新确认草稿

Given 用户修改筛选草稿后点击返回
When 弹出“温馨提示 / 是否保存该设置？”
Then 点击“保存”成功提交后返回；点击“不保存”丢弃本次草稿后返回；保存失败留在当前页且草稿不丢失

Given 用户返回推荐页时上次结果快照已失效
When 客户端无法查到该结果快照
Then 只清除失效结果并按最近一次已保存筛选重新查询，不把用户偏好恢复为平台默认值
```
