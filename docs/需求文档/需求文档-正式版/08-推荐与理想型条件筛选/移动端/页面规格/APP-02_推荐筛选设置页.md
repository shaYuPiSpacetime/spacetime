# 页面规格 - APP-08-PAGE-filter-settings 推荐筛选设置页

| 版本 | 日期 | 修改人 | 变更摘要 |
|------|------|--------|----------|
| 版本01 | 2026-07-16 | Codex | 删除认证状态筛选，建立免费基础与 VIP 高级筛选规格 |

- **页面路由**：`/pages/recommend/filter/index`
- **入口来源**：推荐 Tab 右上筛选图标
- **对应设计稿**：参考用户提供的“偏好设置”截图；正式稿按 2.4 节输出

## 1. 页面定位

用户维护推荐 Tab 的固定筛选偏好。基础筛选免费，高级筛选由 PRD-04 `advanced_filter` 权益控制；页面不配置算法参数，也不展示认证状态。

## 2. 布局（给 UI）

### 2.1 整体布局

```text
导航栏：返回 / 偏好设置
Tab：基础筛选｜VIP 高级筛选
基础：目标城市 + 添加城市、周边城市开关、年龄双滑杆
高级：身高、体重双滑杆；学历多选；家乡/学校/专业选择
底部固定：恢复默认｜保存
```

### 2.2 区块说明

| 区块 | 内容 | 普通用户 | 会员 |
|------|------|----------|------|
| 基础筛选 | 位置、周边城市、年龄 | 可编辑 | 可编辑 |
| 高级筛选 | 身高、体重、学历、家乡、学校、专业 | 锁定预览 + 开通引导 | 可编辑 |
| 保存区 | 恢复默认、保存 | 仅保存基础 | 保存基础和高级 |

### 2.3 弹层

| 弹层 | 触发 | 内容 | 关闭 |
|------|------|------|------|
| 城市选择器 | 添加/编辑城市 | 搜索城市、最近选择、最多 3 个 | 完成/取消 |
| 字典选择器 | 学历/家乡/学校 | 字典搜索与多选 | 完成/取消 |
| 专业选择器 | 专业 | 已填写专业/标准化专业全称搜索 | 完成/取消 |
| VIP 引导 | 普通用户点击高级区 | PRD-04 高级筛选权益 | 关闭/开通 |
| 未保存返回确认 | 草稿变化后返回 | `筛选条件尚未保存，是否放弃修改？` | 继续编辑/放弃 |

### 2.4 UI 画板拆分

| 画板 ID | 画板 | 内容 |
|---------|------|------|
| `APP-08-FS-01` | 基础筛选 | 城市、周边开关、年龄、保存 |
| `APP-08-FS-02` | 高级筛选-会员 | 六类高级条件正常编辑 |
| `APP-08-FS-03` | 高级筛选-普通用户 | 锁定遮罩和开通按钮 |
| `APP-08-FS-04` | 城市选择器 | 搜索、多选、上限提示 |
| `APP-08-FS-05` | 学校/专业选择器 | 搜索结果、选中态、无结果 |
| `APP-08-FS-06` | 未保存返回确认 | 放弃/继续编辑 |
| `APP-08-FS-07` | 字典降级 | 已保存值只读、重试 |

### 2.5 编辑控件口径

| 区域 | 展现 | 控件 | 新增/删除 | 保存 |
|------|------|------|-----------|------|
| 目标城市 | 标签列表 | 城市选择器 | 最多 3 个，可逐个删除 | 页面级保存 |
| 周边城市 | 表单行 | Switch | 不适用 | 页面级保存 |
| 年龄/身高/体重 | 表单卡片 | 双滑杆 + 数字回显 | 不适用 | 页面级保存 |
| 学历 | 标签组 | 多选 Chip | 固定字典项 | 页面级保存 |
| 家乡/学校/专业 | 表单行 | 搜索选择器 | 多选值可删除 | 页面级保存 |

## 3. 筛选与搜索

本页本身为筛选表单。城市、学校、专业选择器支持输入防抖 300ms 搜索；城市/学校按名称前缀与包含匹配，仅将选中项的业务 code 保存；专业按标准化全称选择，不保存任意模糊关键词。

| 字段 ID | 显示名 | 类型 | 必填 | 取值范围 | 校验规则 | 默认值 | 可编辑 | 敏感级别 | 数据来源 |
|---------|--------|------|------|----------|----------|--------|--------|----------|----------|
| `APP-08-PAGE-filter-settings-FIELD-version` | 当前版本 | int | 是 | ≥0 | 更新必须一致 | 0 | 否 | 普通 | 偏好服务 |
| `APP-08-PAGE-filter-settings-FIELD-cities` | 对方所在城市 | array | 是 | 1-3 个城市 code | 去重；只允许启用城市 | 本人现居城市 | 普通用户/会员 | 敏感；不导出 | 地区字典/用户选择 |
| `APP-08-PAGE-filter-settings-FIELD-neighbor` | 允许推荐周边城市 | bool | 是 | true/false | 仅推荐场景生效 | false | 普通用户/会员 | 敏感；不导出 | 用户选择 |
| `APP-08-PAGE-filter-settings-FIELD-min-age` | 最小年龄 | int | 是 | PRD-01 年龄范围 | ≤最大年龄 | 本人年龄-5后裁剪 | 普通用户/会员 | 敏感；不导出 | 用户选择 |
| `APP-08-PAGE-filter-settings-FIELD-max-age` | 最大年龄 | int | 是 | PRD-01 年龄范围 | ≥最小年龄 | 本人年龄+5后裁剪 | 普通用户/会员 | 敏感；不导出 | 用户选择 |
| `APP-08-PAGE-filter-settings-FIELD-height-range` | 身高 | range/null | 否 | 140-220cm | 最小≤最大 | null | 有效会员 | 敏感；不导出 | 用户选择/PRD-01 |
| `APP-08-PAGE-filter-settings-FIELD-weight-range` | 体重 | range/null | 否 | 30-200kg | 最小≤最大 | null | 有效会员 | 敏感；不导出 | 用户选择/PRD-01 |
| `APP-08-PAGE-filter-settings-FIELD-education` | 学历 | array | 否 | `education_level` 启用 code | 去重 | 空数组 | 有效会员 | 敏感；不导出 | 系统字典 |
| `APP-08-PAGE-filter-settings-FIELD-hometown` | 家乡 | array | 否 | 地区省/市 code | 每项记录层级；去重 | 空数组 | 有效会员 | 敏感；不导出 | 地区字典 |

## 5. 操作表

| 操作 ID | 操作 | 触发条件 | 前置权限 | 二次确认 | 成功态 | 失败态 | 影响 |
|---------|------|----------|----------|----------|--------|--------|------|
| `APP-08-PAGE-filter-settings-ACT-switch-basic` | 基础筛选 Tab | 页面已加载 | 核心准入 | 否 | 展示基础表单 | 无 | 不保存 |
| `APP-08-PAGE-filter-settings-ACT-switch-advanced` | 高级筛选 Tab | 页面已加载 | 核心准入 | 否 | 会员编辑；普通用户锁定 | 权益查询失败按普通用户 | 不保存 |
| `APP-08-PAGE-filter-settings-ACT-edit-city` | 选择城市 | 字典可用 | 基础权限 | 否 | 草稿更新 | 字典错误提示重试 | 不立即查询 |
| `APP-08-PAGE-filter-settings-ACT-edit-advanced` | 编辑高级条件 | `vipEffective=true` | 会员 | 否 | 草稿更新 | `M08-ERR-vip-required` | 不立即查询 |
| `APP-08-PAGE-filter-settings-ACT-vip` | 开通高级筛选 | `vipEffective=false` | 已登录 | 否 | 打开 PRD-04 VIP 引导 | 打开失败提示重试 | 不修改高级值 |
| `APP-08-PAGE-filter-settings-ACT-reset` | 恢复默认 | 页面正常 | 核心准入 | 是：`恢复为当前城市和默认年龄范围？高级条件也会清空。` | 本地草稿恢复默认 | 无 | 尚未写库，需再保存 |
| `APP-08-PAGE-filter-settings-ACT-save` | 保存 | 校验通过且有变更 | 核心准入 | 否 | toast 成功，返回推荐 Tab 刷新 | 版本冲突刷新并保留草稿；其他错误原地提示 | `M08-EVT-filter-saved` |
| `APP-08-PAGE-filter-settings-ACT-back` | 返回 | 任意 | 核心准入 | 草稿有变更时确认 | 无变更直接返回；放弃后返回 | 无 | 不修改已保存值 |

## 6. 数据联动规则

| 触发 | 影响 | 联动行为 | 引用 |
|------|------|----------|------|
| 删除最后一个城市 | 保存按钮 | 阻断保存并提示至少选择一个城市 | `M08-ERR-filter-invalid` |
| 会员到期 | 高级字段 | 保留回显，全部锁定且本次查询不生效 | `M08-RULE-vip-filter` |
| 会员恢复 | 高级字段 | 自动恢复可编辑，保存值重新生效 | `M08-SM-filter-profile` |
| 开启周边城市 | 理想型 | 理想型执行时仍关闭扩展，开关不清空 | `M08-RULE-shared-basic-filter` |
| 学校/专业字典无结果 | 选择器 | 不允许保存随意输入文本 | `M08-RULE-missing-data` |

## 7. 状态与异常

| 状态类型 | 触发 | 表现 | 操作 | 引用 |
|----------|------|------|------|------|
| 加载态 | 查询偏好/字典 | 表单骨架 | 返回 | `APP-08-UI-loading` |
| 空态 | 无高级条件 | 高级页展示未设置提示，不视为错误 | 添加条件 | — |
| 错误态 | 偏好请求失败 | 错误页，禁止以默认值覆盖 | 重试/返回 | 通用错误态 |
| 无权限态 | 未核心准入 | PRD-01 拦截 | 去完善 | `M08-ERR-core-access-required` |
| 业务态-普通 | 无会员 | 基础可编辑，高级锁定 | 开通会员 | `M08-ERR-vip-required` |
| 业务态-会员 | 权益有效 | 全部可编辑 | 保存 | `M08-RULE-vip-filter` |
| 降级态 | 字典不可用 | 已保存值只读回显，保存禁用 | 重试 | `M08-ERR-dictionary-unavailable` |
| 并发态 | 版本冲突 | 提示其他设备已更新 | 刷新后重试 | `M08-ERR-filter-conflict` |

## 8. 查询与列表

选择器每页 20 条，输入防抖 300ms；城市/学校按业务 code 去重。页面表单不自动保存、不轮询；从 VIP 中心返回时只刷新权益状态。

## 9. 验收标准

| AC ID | 场景 | 类型 | 优先级 |
|-------|------|------|--------|
| `APP-08-AC-basic-free` | 普通用户可保存位置年龄 | 正常 | P0 |
| `APP-08-AC-advanced-vip` | 高级筛选仅会员生效 | 正常/异常 | P0 |
| `APP-08-AC-no-auth-filter` | 无认证状态区块 | 正常 | P0 |
| `APP-08-AC-version-conflict` | 并发保存不覆盖 | 异常 | P0 |

```gherkin
Given 普通用户进入推荐筛选设置页
When 查看基础和高级 Tab
Then 位置、年龄可编辑，高级六项锁定并可打开会员引导，页面任何位置都不展示认证状态筛选

Given 会员保存两个城市、年龄 25-31、身高 165-180 和博士学历
When 点击保存
Then 服务端按同字段 OR、跨字段 AND 保存新版本，返回推荐 Tab 后立即用新条件刷新

Given 同一用户已在另一设备更新偏好版本
When 当前页面提交旧版本
Then 返回 M08-ERR-filter-conflict，不覆盖新数据，并允许用户刷新后重新确认草稿
```
