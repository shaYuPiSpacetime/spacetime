# 页面规格 - APP-08-PAGE-card-detail 推荐卡片详情页

| 版本 | 日期 | 修改人 | 变更摘要 |
|------|------|--------|----------|
| 版本01 | 2026-07-16 | Codex | 推荐候选公开资料与关系动作规格 |

- **页面路由**：`/pages/recommend/detail/index?candidateNo={业务编号}`
- **入口来源**：推荐卡片、推荐回看；理想型已解锁对象跳统一用户主页，不进入本页
- **对应设计稿**：尚未提供；按 2.4 节输出

## 1. 页面定位

展示当前推荐候选在 PRD-01 中有效且允许公开的婚恋资料，并提供喜欢、悄悄话、举报、不再推荐等关系动作。本页不展示候选被筛中的隐藏字段、不显示推荐分或“为什么推荐”。

## 2. 布局（给 UI）

### 2.1 整体布局

```text
导航：返回 / 更多
头像与相册：仅已审核通过且公开的图片
身份摘要：昵称、年龄、现居城市、公开认证徽章
公开资料：身高、学历、学校等按候选公开设置展示
自我介绍/标签/扩展资料：只展示当前有效公开内容
底部固定动作：跳过/喜欢/悄悄话
```

### 2.2 区块说明

| 区块 | 内容 | 为空时处理 |
|------|------|------------|
| 图片区 | 主头像、相册 | 主头像必须存在；相册为空不展示轮播点 |
| 摘要区 | 昵称、年龄、城市、公开徽章 | 核心字段异常则候选失效并返回 |
| 资料区 | 公开基础和扩展资料 | 单字段为空或隐藏时整行不展示 |
| 动作区 | 跳过、喜欢、悄悄话 | 权限不足时按对应模块引导 |

### 2.3 弹层

| 弹层 | 触发 | 内容 | 关闭 |
|------|------|------|------|
| 更多操作 | 右上更多 | 举报、不再推荐 | 遮罩/取消 |
| 不再推荐确认 | 点击不再推荐 | `确定不再向你推荐该用户？` | 取消/确认 |
| 举报 | 点击举报 | 复用统一举报页面/弹层并传 `sourceScene=recommend` | 按举报模块规则 |
| 悄悄话 | 点击悄悄话 | PRD-03/04 流程 | 按对应规则 |

### 2.4 UI 画板拆分

| 画板 ID | 画板 | 内容 |
|---------|------|------|
| `APP-08-CD-01` | 完整资料态 | 图片、摘要、资料、底部动作 |
| `APP-08-CD-02` | 最小公开资料态 | 无相册/扩展资料时的紧凑布局 |
| `APP-08-CD-03` | 更多操作弹层 | 举报、不再推荐 |
| `APP-08-CD-04` | 候选失效态 | 提示后自动返回/加载下一位 |
| `APP-08-CD-05` | 网络错误态 | 保留上次内容与重试 |

### 2.5 编辑控件口径

本页为只读详情页，不编辑候选资料；关系动作点击即提交或转交对应模块。

## 3. 筛选与搜索

本页无搜索和筛选；路由只接收候选业务编号，不接受内部主键或客户端拼装用户资料。

## 4. 字段表

| 字段 ID | 显示名 | 类型 | 必填 | 取值范围 | 校验规则 | 默认值 | 可编辑 | 敏感级别 | 数据来源 |
|---------|--------|------|------|----------|----------|--------|--------|----------|----------|
| `APP-08-PAGE-card-detail-FIELD-candidate-no` | 用户业务编号 | string | 是 | 有效公开业务编号 | 与登录用户不同；服务端鉴权 | 无 | 否 | 敏感；不在 UI 直接展示 | 推荐服务 |
| `APP-08-PAGE-card-detail-FIELD-avatar` | 头像 | image | 是 | 已审核有效图片 URL | 私有签名/防盗链；不得返回失效头像 | 无 | 否 | 敏感；仅页面展示 | PRD-01 |
| `APP-08-PAGE-card-detail-FIELD-photos` | 相册 | image[] | 否 | PRD-01 对外有效照片 | 最多按 PRD-01 配置；逐张有效 | 空数组 | 否 | 敏感；禁止导出 | PRD-01 |
| `APP-08-PAGE-card-detail-FIELD-nickname` | 昵称 | string | 是 | 2-12 字 | 只返回审核有效值 | 无 | 否 | 普通 | PRD-01 |
| `APP-08-PAGE-card-detail-FIELD-age` | 年龄 | int | 是 | PRD-01 年龄范围 | 由生日服务端计算，不返回生日 | 无 | 否 | 敏感；不导出 | PRD-01 |
| `APP-08-PAGE-card-detail-FIELD-city` | 现居城市 | string | 是 | 地区字典中文名 | 只展示城市，不展示经纬度 | 无 | 否 | 敏感；不导出 | PRD-01 |
| `APP-08-PAGE-card-detail-FIELD-badges` | 认证徽章 | array | 是 | 头像/实名/学历均已通过 | 只展示公开徽章，不作筛选控件 | 三项 | 否 | 普通 | PRD-01 |
| `APP-08-PAGE-card-detail-FIELD-public-profile` | 公开资料 | object | 否 | PRD-01 当前有效且公开字段 | 隐藏/空字段不返回 key | 空对象 | 否 | 敏感；按字段控制 | PRD-01 |
| `APP-08-PAGE-card-detail-FIELD-source` | 来源场景 | enum | 是 | `recommend/replay` | 服务端校验来源令牌 | `recommend` | 否 | 普通 | 推荐服务 |
| `APP-08-PAGE-card-detail-FIELD-relation` | 当前关系状态 | object | 是 | PRD-02 有效状态 | 不返回后台失效原因 | 默认未喜欢 | 否 | 敏感 | PRD-02 |

## 5. 操作表

| 操作 ID | 操作 | 触发条件 | 前置权限 | 二次确认 | 成功态 | 失败态 | 影响 |
|---------|------|----------|----------|----------|--------|--------|------|
| `APP-08-PAGE-card-detail-ACT-back` | 返回 | 任意 | 已登录 | 否 | 回到原卡片位置 | 无 | 不重复计浏览 |
| `APP-08-PAGE-card-detail-ACT-skip` | 跳过 | 来源为推荐且候选有效 | 核心准入 | 否 | 返回并展示下一位 | 失败保留当前页 | 写推荐浏览动作 |
| `APP-08-PAGE-card-detail-ACT-like` | 喜欢 | PRD-02 允许喜欢 | PRD-02 | 否 | 状态更新为已喜欢 | 按 PRD-02 错误提示 | 来源 `fate` |
| `APP-08-PAGE-card-detail-ACT-whisper` | 悄悄话 | 候选有效 | PRD-03/04 | 按付费模块 | 打开消息流程 | 额度/余额/审核失败按对应模块 | 无 |
| `APP-08-PAGE-card-detail-ACT-report` | 举报 | 候选有效 | 已登录 | 举报提交页二次确认 | 提交成功返回当前页并提示 | 举报失败保留填写内容 | 统一举报记录 |
| `APP-08-PAGE-card-detail-ACT-never` | 不再推荐 | 候选有效 | 核心准入 | 是 | 从推荐与理想型实时结果剔除并返回 | 失败保留页面 | 生成场景屏蔽关系 |

## 6. 数据联动规则

| 触发 | 影响 | 行为 | 引用 |
|------|------|------|------|
| 喜欢成功 | 底部按钮 | 更新已喜欢态，不重复创建记录 | PRD-02 |
| 不再推荐成功 | 所有 APP-08 列表 | 候选实时剔除；历史解锁仅展示不可用状态 | `M08-RULE-candidate-pool` |
| 字段公开设置变化 | 详情字段 | 下次请求立即按最新公开值展示 | `M08-RULE-display-privacy` |
| 候选认证失效 | 页面 | 返回不可用并移除，不展示旧缓存 | `M08-ERR-candidate-unavailable` |

## 7. 状态与异常

| 状态类型 | 触发 | 表现 | 操作 |
|----------|------|------|------|
| 加载态 | 首次查询 | 详情骨架 | 返回 |
| 空态 | 非必填扩展资料全空 | 仅展示头像和基础摘要，不显示空标题 | 关系动作 |
| 错误态 | 网络失败 | 保留已加载内容，顶部提示 | 重试/返回 |
| 无权限态 | 未核心准入 | PRD-01 拦截 | 去完善 |
| 业务态-未喜欢 | 默认 | 喜欢按钮可用 | 喜欢 |
| 业务态-已喜欢 | PRD-02 已有有效喜欢 | 按钮显示已喜欢并禁重复提交 | 返回 |
| 业务态-不可用 | 候选失效/被拉黑 | 统一提示不可查看 | 返回 |
| 降级态 | 图片服务失败 | 占位图，不展示失效原图 URL | 重试 |

## 8. 查询与列表

本页单对象查询，不分页、不轮询。相册按 PRD-01 保存顺序展示；进入详情只记录一次浏览，返回重进可追加 PV，但回看页访问不消耗浏览额度。

## 9. 验收标准

| AC ID | 场景 | 类型 | 优先级 |
|-------|------|------|--------|
| `APP-08-AC-detail-public-only` | 只展示公开有效资料 | 正常 | P0 |
| `APP-08-AC-detail-no-reason` | 候选失效不泄露原因 | 异常 | P0 |
| `APP-08-AC-never-recommend` | 不再推荐全场景剔除 | 正常 | P0 |

```gherkin
Given 候选体重和住房情况参与了筛选但设置为不公开
When 用户进入推荐卡片详情
Then 服务端可用这些字段完成筛选，但详情响应与页面均不返回其原值，只展示候选允许公开的资料

Given 用户确认“不再推荐”某候选
When 屏蔽关系创建成功
Then 当前详情返回来源页，该候选从后续推荐和未解锁理想型结果中剔除，且操作可审计
```
