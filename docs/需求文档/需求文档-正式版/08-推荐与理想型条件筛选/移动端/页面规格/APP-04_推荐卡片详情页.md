# 页面规格 - APP-08-PAGE-card-detail 推荐卡片详情页

| 版本 | 日期 | 修改人 | 变更摘要 |

| 版本04 | 2026-08-09 | Codex | 按 UI 回复允许未认证查看详情/跳过，只在喜欢和悄悄话时弹三项认证提示 |

- **页面路由**：`/pages/recommend/detail/index?candidateNo={业务编号}`
- **入口来源**：推荐卡片、推荐回看；理想型已解锁对象跳统一用户主页，不进入本页
- **对应设计稿**：蓝湖 `推荐`、`推荐-信息完善`、`推荐-弹窗举报/不看他`、`用户举报`、`提交成功`、`推荐/不看他弹窗`；其中“不看他”相关画板需按本规格修正文案

## 1. 页面定位

展示当前推荐候选在 PRD-01 中有效且允许公开的婚恋资料，并提供喜欢、悄悄话、举报用户、不再推荐等关系动作。本页举报仅针对候选资料/账号，不属于聊天内容举报；本页不展示候选被筛中的隐藏字段、不显示推荐分、“为什么推荐”或可信度百分比。候选公开的“我的标签”正常展示。

## 2. 布局（给 UI）

### 2.1 整体布局

```text
导航：返回 / 更多
头像与相册：仅已审核通过且公开的图片
身份摘要：昵称、年龄、现居城市、公开认证徽章
公开资料：身高、学历、学校等按候选公开设置展示
自我介绍/标签/扩展资料：只展示当前有效公开内容
认证区：仅显示头像、实名、学历等认证徽章，不显示“可信度 92%”
底部固定动作：跳过/喜欢/悄悄话
```

### 2.2 区块说明

| 区块 | 内容 | 为空时处理 |
|------|------|------------|
| 图片区 | 主头像、相册 | 主头像必须存在；相册为空不展示轮播点 |
| 摘要区 | 昵称、年龄、城市、公开徽章 | 核心字段异常则候选失效并返回 |
| 资料区 | 公开基础和扩展资料 | 单字段为空或隐藏时整行不展示；不得因浏览者未填写同类资料而锁定 |
| 动作区 | 跳过、喜欢、悄悄话 | 权限不足时按对应模块引导 |

### 2.3 弹层

| 弹层 | 触发 | 内容 | 关闭 |
|------|------|------|------|
| 更多操作 | 右上更多 | 举报用户、不再推荐 | 遮罩/取消 |
| 不再推荐确认 | 点击不再推荐 | `不再推荐这位嘉宾？` / `确认后，该用户将不再出现在你的推荐和理想型结果中。` | 取消/确认不再推荐 |
| 举报用户 | 点击举报用户 | 复用 `APP-05-PAGE-report-modal`，传 `targetType=user`、`targetId=candidateNo`、`sourceScene=recommend`，不携带聊天上下文 | 按举报模块规则 |
| 悄悄话 | 点击悄悄话 | PRD-03/04 流程 | 按对应规则 |
| 三项认证提示 | 未认证浏览者点击喜欢/悄悄话 | 实名、头像、学历认证要求 | 稍后认证/去认证；认证返回原详情且不自动执行原操作 |

### 2.4 UI 画板拆分

| 画板 ID | 画板 | 内容 |
|---------|------|------|
| `APP-08-CD-01` | 完整资料态 | 以蓝湖 `推荐-信息完善` 为布局基线：图片、摘要、公开资料、底部动作 |
| `APP-08-CD-02` | 最小公开资料态 | 无相册/扩展资料时的紧凑布局 |
| `APP-08-CD-03` | 更多操作与确认 | 复用蓝湖举报/不再推荐补稿；不得使用“互相看不到主页和动态”等全局拉黑文案，按钮不得写“重新发送” |
| `APP-08-CD-04` | 候选失效态 | 提示后自动返回/加载下一位 |
| `APP-08-CD-05` | 网络错误态 | 保留上次内容与重试 |

### 2.5 编辑控件口径

本页为只读详情页，不编辑候选资料；关系动作点击即提交或转交对应模块。

## 3. 筛选与搜索

本页无搜索和筛选；路由只接收候选业务编号，不接受内部主键或客户端拼装用户资料。

## 5. 操作表

| 操作 ID | 操作 | 触发条件 | 前置权限 | 二次确认 | 成功态 | 失败态 | 影响 |
|---------|------|----------|----------|----------|--------|--------|------|
| `APP-08-PAGE-card-detail-ACT-back` | 返回 | 任意 | 已登录 | 否 | 回到原卡片位置 | 无 | 不重复计浏览 |
| `APP-08-PAGE-card-detail-ACT-skip` | 跳过 | 来源为推荐且候选有效 | 已登录且基础资料可用 | 否 | 返回并展示下一位 | 网络失败保留当前页并 Toast“网络错误” | 写推荐浏览动作 |
| `APP-08-PAGE-card-detail-ACT-like` | 喜欢 | PRD-02 允许喜欢 | 三项认证 + PRD-02 | 否 | 状态更新为已喜欢并展示下一位 | 未认证弹提示；网络失败保留当前候选；其他按 PRD-02 | 来源 `fate` |
| `APP-08-PAGE-card-detail-ACT-whisper` | 悄悄话 | 候选有效 | 三项认证 + PRD-03/04 | 按付费模块 | 发送成功后进入 PRD-03 对应候选人的悄悄话会话页 | 未认证弹提示；网络/额度/余额/审核失败保留当前候选 | 无 |

## 6. 数据联动规则

| 触发 | 影响 | 行为 | 引用 |
|------|------|------|------|
| 喜欢成功 | 底部按钮 | 更新已喜欢态，不重复创建记录 | PRD-02 |
| 不再推荐成功 | 所有 APP-08 列表 | 候选实时剔除；历史解锁记录保留；消息、主页和动态关系不改变 | `M08-RULE-never-recommend-scope` |
| 字段公开设置变化 | 详情字段 | 下次请求立即按最新公开值展示 | `M08-RULE-display-privacy` |
| 浏览者资料完整度变化 | 详情字段 | 不影响候选资料可见范围；不得出现“填写后可查看/立即完善”锁定块 | `M08-RULE-display-privacy` |
| 候选认证失效 | 页面 | 提示“该用户已注销”后返回并切换下一位，不展示内部失效原因或旧缓存 | `M08-RULE-candidate-unavailable` |

## 7. 状态与异常

| 状态类型 | 触发 | 表现 | 操作 |
|----------|------|------|------|
| 加载态 | 首次查询 | 详情骨架 | 返回 |
| 空态 | 非必填扩展资料全空 | 仅展示头像和基础摘要，不显示空标题 | 关系动作 |
| 错误态 | 网络失败 | 保留当前详情并 Toast“网络错误” | 再次触发原操作/返回 |
| 无权限态 | 未登录/账号异常/基础资料不可用 | 按 PRD-01 处理；未完成三项认证仍可查看详情 | 去登录/处理账号资料 |
| 业务态-未认证互动 | 点击喜欢/悄悄话 | 三项认证提示；详情不关闭 | 稍后认证/去认证 |
| 业务态-未喜欢 | 默认 | 喜欢按钮可用 | 喜欢 |
| 业务态-已喜欢 | PRD-02 已有有效喜欢 | 按钮显示已喜欢并禁重复提交 | 返回 |
| 业务态-不可用 | 候选在详情操作时失效 | 提示“该用户已注销” | 返回并切换下一位 |
| 降级态 | 图片服务失败 | 占位图，不展示失效原图 URL | 重试 |

## 8. 查询与列表

本页单对象查询，不分页、不轮询。相册按 PRD-01 保存顺序展示；进入详情只记录一次浏览，返回重进可追加 PV，但回看页访问不消耗浏览额度。

## 9. 验收标准

| AC ID | 场景 | 类型 | 优先级 |
|-------|------|------|--------|
| `APP-08-AC-detail-public-only` | 只展示公开有效资料 | 正常 | P0 |
| `APP-08-AC-detail-no-reason` | 候选失效不泄露原因 | 异常 | P0 |
| `APP-08-AC-never-recommend` | 不再推荐全场景剔除 | 正常 | P0 |
| `APP-08-AC-report-user-routing` | 推荐候选举报按用户对象提交 | 正常 | P0 |
| `APP-08-AC-detail-auth-action` | 未认证可看详情，喜欢/悄悄话才拦截 | 正常/异常 | P0 |
