# 页面规格 - APP-08-PAGE-ideal-records 理想型筛选记录页

| 版本 | 日期 | 修改人 | 变更摘要 |
|------|------|--------|----------|
| 版本01 | 2026-07-16 | Codex | 原“推荐记录”调整为理想型筛选快照记录 |

- **页面路由**：`/pages/ideal/records/index`
- **入口来源**：理想型 Tab“筛选记录”、理想型结果页
- **对应设计稿**：尚未提供；按 2.4 节输出

## 1. 页面定位

展示当前用户最近 20 次理想型筛选的条件摘要、结果数和快照状态。记录用于回看与再次筛选，不是系统主动推荐历史，也不展示算法分数。

## 2. 布局（给 UI）

### 2.1 整体布局

```text
导航：返回 / 筛选记录
记录列表：创建时间、城市年龄、条件标签、结果数、已解锁数、状态
操作：查看结果 / 再次筛选
加载更多（最多20条）/空态
```

### 2.2 区块说明

| 区块 | 内容 | 规则 |
|------|------|------|
| 条件摘要 | 城市、年龄、理想型条件中文名 | 使用创建时快照文案；停用项标“已停用” |
| 结果摘要 | 创建时结果数、当前解锁数 | 结果数不因实时失效回写 |
| 状态 | 可查看/已过期 | 过期不可查看结果 |

### 2.3 弹层

本页无删除、批量或付费弹层；再次筛选直接载入草稿，不自动提交。

### 2.4 UI 画板拆分

| 画板 ID | 画板 | 内容 |
|---------|------|------|
| `APP-08-RC-01` | 正常记录列表 | active/expired 混合记录 |
| `APP-08-RC-02` | 空态 | 无筛选记录和去理想型按钮 |
| `APP-08-RC-03` | 已过期记录 | 条件摘要、再次筛选 |
| `APP-08-RC-04` | 加载/错误 | 骨架、重试 |

### 2.5 编辑控件口径

本页为只读列表，不允许删除、改名或修改历史快照；“再次筛选”只把可解析条件载入理想型 Tab 草稿。

## 3. 筛选与搜索

不提供搜索或日期筛选；固定按创建时间倒序展示最近 20 条。

## 4. 字段表

| 字段 ID | 显示名 | 类型 | 必填 | 取值范围 | 校验规则 | 默认值 | 可编辑 | 敏感级别 | 数据来源 |
|---------|--------|------|------|----------|----------|--------|--------|----------|----------|
| `APP-08-PAGE-ideal-records-FIELD-snapshot-no` | 快照编号 | string | 是 | 当前用户有效业务编号 | UI 不直接展示 | 无 | 否 | 敏感 | 理想型服务 |
| `APP-08-PAGE-ideal-records-FIELD-created-at` | 筛选时间 | datetime | 是 | 合法服务端时间 | 北京时间展示 | 无 | 否 | 普通 | 理想型快照 |
| `APP-08-PAGE-ideal-records-FIELD-cities` | 目标城市 | array | 是 | 1-3 个快照中文名/code | 创建后不可变 | 无 | 否 | 敏感；仅本人 | 理想型快照 |
| `APP-08-PAGE-ideal-records-FIELD-age-range` | 年龄 | range | 是 | 平台年龄范围 | 创建后不可变 | 无 | 否 | 敏感；仅本人 | 理想型快照 |
| `APP-08-PAGE-ideal-records-FIELD-conditions` | 理想型条件 | array | 否 | 模块公共定义第 5.2 节条件 code 快照 | 保留创建时中文名；code 仍可解析 | 空数组 | 否 | 敏感；仅本人 | 理想型快照 |

## 5. 操作表

| 操作 ID | 操作 | 触发条件 | 前置权限 | 二次确认 | 成功态 | 失败态 | 影响 |
|---------|------|----------|----------|----------|--------|--------|------|
| `APP-08-PAGE-ideal-records-ACT-results` | 查看结果 | `status=active` | 核心准入 | 否 | 进入对应结果页 | 快照刚过期则进入过期态 | 不改变当前偏好 |
| `APP-08-PAGE-ideal-records-ACT-reuse` | 再次筛选 | 任意状态且条件可解析 | 核心准入 | 否 | 返回理想型 Tab 并载入草稿 | 停用/缺失条件标出并取消选中 | 不自动生成新快照 |
| `APP-08-PAGE-ideal-records-ACT-go-ideal` | 去设置理想型 | 空态 | 核心准入 | 否 | 返回理想型 Tab | 路由失败提示重试 | 无 |
| `APP-08-PAGE-ideal-records-ACT-load` | 加载更多 | 未到 20 条且有游标 | 核心准入 | 否 | 追加记录 | 失败保留已有列表 | 无重复记录 |

## 6. 数据联动规则

| 触发 | 影响 | 行为 | 引用 |
|------|------|------|------|
| 快照到期 | 查看结果按钮 | 变为已过期并隐藏查看，只保留再次筛选 | `M08-SM-ideal-snapshot` |
| 字典文案改名 | 历史摘要 | 继续展示创建时冗余文案，当前草稿展示新文案 | `M08-RULE-filter-record` |
| 条件 code 停用 | 再次筛选 | 不自动替换相近条件，提示已停用并取消选中 | `M08-RULE-missing-data` |
| 新解锁成功 | 解锁数 | 下次进入/刷新时重新聚合 | PRD-04 |

## 7. 状态与异常

| 状态类型 | 触发 | 表现 | 操作 |
|----------|------|------|------|
| 加载态 | 首次/翻页 | 列表骨架 | 返回 |
| 空态 | 0 条记录 | `还没有理想型筛选记录` | 去理想型 |
| 错误态 | 请求失败 | 保留已加载项 + 重试 | 重试 |
| 无权限态 | 未核心准入 | PRD-01 拦截 | 去完善 |
| 业务态-active | 90 天内 | 查看结果、再次筛选 | 两项操作 |
| 业务态-expired | 超过 90 天 | 只展示摘要、再次筛选 | 再次筛选 |
| 降级态 | PRD-04 聚合失败 | 解锁数显示 `--`，记录仍可查看 | 重试 |

## 8. 查询与列表

每页 10 条，最多 20 条，按 `createdAt desc, snapshotNo desc` 游标分页；不支持删除、导出、批量选择或自动轮询。

## 9. 验收标准

| AC ID | 场景 | 类型 | 优先级 |
|-------|------|------|--------|
| `APP-08-AC-record-twenty` | 最多最近 20 条 | 正常 | P1 |
| `APP-08-AC-record-expired` | 过期不可查看结果 | 异常 | P0 |
| `APP-08-AC-record-reuse` | 再次筛选不自动提交 | 正常 | P1 |

```gherkin
Given 一条筛选记录已过 90 天
When 用户打开记录页
Then 记录展示已过期、条件摘要和再次筛选，不展示查看结果入口

Given 历史条件中的“留学海归”标签已停用
When 用户点击再次筛选
Then 理想型 Tab 载入其他仍有效条件，“留学海归”标记已停用且不自动选中，不创建新快照
```

## 10. 关联

引用 `M08-RULE-filter-record`、`M08-SM-ideal-snapshot`、`M08-PARAM-ideal-record-retention-days`、`M08-PARAM-ideal-record-max` 与 PRD-04 解锁聚合。
