# ADM-07 端内定义 - 推广裂变管理后台

| 版本 | 日期 | 变更摘要 |
|---|---|---|
| 版本02 | 2026-07-17 | 菜单收敛为 5 页；关系/代理详情改抽屉；删除冻结和素材入口 |

## 1. 信息架构

```text
推广裂变
├── 规则配置
├── 邀请关系
│   └── 关系详情抽屉
├── 奖励流水
├── 校园代理
│   ├── 代理详情抽屉
│   └── 代理二维码弹窗
└── 代理结算
```

| 菜单 | 页面 ID | 职责 | 路由 |
|---|---|---|---|
| 规则配置 | `ADM-07-PAGE-promo-rule-config` | 普通邀请和代理奖励配置 | `/admin/promotion/rules` |
| 邀请关系 | `ADM-07-PAGE-invite-relation-list` | 永久有效关系列表 | `/admin/promotion/relations` |
| 奖励流水 | `ADM-07-PAGE-invite-reward-list` | 普通事件/阶梯额外奖励流水 | `/admin/promotion/rewards` |
| 校园代理 | `ADM-07-PAGE-agent-list` | 代理、二维码和推广统计 | `/admin/promotion/agents` |
| 代理结算 | `ADM-07-PAGE-agent-settlement` | 月度结算单与确定操作 | `/admin/promotion/settlements` |

| 逻辑视图 | 页面 ID | 承接形态 | 入口 |
|---|---|---|---|
| 关系详情 | `ADM-07-PAGE-invite-relation-detail` | 右侧抽屉 | 关系列表“查看详情” |
| 代理详情 | `ADM-07-PAGE-agent-detail` | 右侧抽屉 | 代理列表“查看详情” |

| 旧页面 ID | 状态 | 处理 |
|---|---|---|
| `ADM-07-PAGE-invite-reward-frozen` | `[已废弃]` | 无菜单、无路由、无运行态 |
| `ADM-07-PAGE-promo-material` | `[已废弃]` | 无菜单、无路由；二维码由代理列表承接 |

## 2. 权限矩阵

> 以现有 RBAC 菜单/按钮权限为准；可看到页面不等于可编辑规则。

| 能力 | 运营 `GLB-ROLE-operation` | 渠道运营 `GLB-ROLE-channel-op` | 财务 `GLB-ROLE-finance` | 超管 `GLB-ROLE-super-admin` |
|---|---:|---:|---:|---:|
| 查看规则/关系/奖励 | 允许 | 允许 | 允许 | 允许 |
| 发布普通邀请规则 | 允许 | 禁止 | 禁止 | 允许 |
| 发布代理奖励规则 | 禁止 | 允许 | 禁止 | 允许 |
| 新增/编辑/启停代理 | 禁止 | 允许 | 禁止 | 允许 |
| 查看/保存/复制代理二维码 | 允许 | 允许 | 禁止 | 允许 |
| 查看代理奖金和结算 | 允许 | 允许 | 允许 | 允许 |
| 确定结算 | 禁止 | 禁止 | 允许 | 允许 |
| 导出 | 按菜单按钮权限 | 按菜单按钮权限 | 按菜单按钮权限 | 允许 |

## 3. 审计要求

| 操作 | 二次确认 | 审计字段 |
|---|---:|---|
| 发布奖励规则 | 是 | 操作人、时间、旧值、新值、版本、结果 |
| 启用/停用代理 | 是 | 操作人、时间、代理编号、原状态、新状态 |
| 生成二维码 | 否 | 操作人、时间、代理编号、二维码编号、结果 |
| 确定结算 | 是 | 操作人、时间、结算单号、金额、结果 |
| 导出 | 是 | 操作人、时间、页面、筛选条件、字段范围、结果 |

## 4. 展示规范

| 对象 | 展示标识 | 说明 |
|---|---|---|
| 邀请关系 | `REL-yyyymmdd-xxxx` | 不展示内部主键 |
| 奖励流水 | `IRW-yyyymmdd-xxxx` | 阶梯流水事件名展示“阶梯奖励-累计N人” |
| 代理 | `AGT-yyyymmdd-xxxx` | 列表主标识称“代理编号” |
| 代理奖金 | `ABN-yyyymmdd-xxxx` | 详情抽屉奖金明细订单号 |
| 结算单 | `STL-yyyymm-xxxx` | 周期固定自然月 |

- datetime：`YYYY-MM-DD HH:mm:ss`。
- 金额：千寻币整数；代理奖金/结算金额保留两位小数。
- 关系只展示已创建的有效数据，不展示状态、风险、设备或 IP。
- 奖励状态仅使用 `M07-ENUM-invite-reward-status`。

## 5. 通用页面状态

| 状态 | 表现 | 可操作 |
|---|---|---|
| 加载 | 表格骨架/按钮 loading | 等待 |
| 空 | 对应页面空态文案 + 清除筛选 | 清除筛选/新增代理（仅代理页） |
| 错误 | “加载失败，请重试” | 重试 |
| 无权限 | 整页 403 或写按钮禁用 | 返回 |
| 只读 | 表单/状态按钮禁用并提示只读 | 查看 |
| 二维码失败 | 弹窗失败占位 | 重试生成 |

## 6. 结算任务边界

结算单由 `M07-RULE-agent-settlement-generate` 在北京时间每月 1 日 01:00 生成上一个自然月数据；页面不提供手动生成、登记打款、打款流水或状态回退。

## 7. 评审结论

- 五个菜单页面均有唯一职责与路由。
- 两个详情 PAGE ID 作为抽屉逻辑视图保留，不注册菜单/独立路由。
- 风控角色、冻结处理、素材管理、代理分组均已从 ADM-07 端内能力删除。
