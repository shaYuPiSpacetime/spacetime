# 页面规格 - ADM-07-PAGE-agent-list 校园代理列表页

> 版本：02｜更新日期：2026-07-17｜状态：已确认
> 对应设计稿：待补充；设计画板按第 2 节输出。

## 1. 页面定位

- 路由：`/admin/promotion/agents`。
- 目标：管理校园代理、查看推广和奖金汇总、编辑状态，并在代理行直接查看或生成专属二维码。
- 权限：`promotion:agent:view`、`promotion:agent:edit`、`promotion:agent:qrcode`、`promotion:agent:export`。

## 2. 布局

页面由标题操作区、筛选区、列表区、分页区组成。代理详情为右侧抽屉；二维码为居中弹窗。页面无推广分组筛选。

| UI画板 | 内容 | 关键状态 |
|---|---|---|
| 代理列表 | 筛选、10列表格 | 正常/空/加载/错误/无权限 |
| 新增代理 | 表单弹窗 | 正常/校验失败 |
| 状态确认 | 启停确认弹窗 | 启用/停用 |
| 二维码 | Canvas二维码与双按钮 | 生成中/成功/失败/复制受限 |

## 3. 筛选与搜索

| 条件 | 控件 | 格式/选项 | 默认值 | 说明 |
|---|---|---|---|---|
| 代理搜索 | 输入框 | 代理编号/代理名称 | 空 | 模糊匹配 |
| 学校/校区 | 级联选择 | 学校、校区 | 全部 | 仅显示有权限组织 |
| 状态 | 下拉框 | 启用、停用 | 全部 | 与列表状态按钮一致 |

### 4.2 新增/编辑字段

代理编号由系统生成；代理名称、学校、校区为必填；联系电话按权限脱敏展示。表单不包含推广分组、负责人、奖金规则组或结算周期。

## 6. 数据联动规则

- 二维码与代理一一对应并永久复用；二维码参数只包含不可猜测的代理推广标识，不暴露手机号等信息。
- “保存成图片”必须触发浏览器本地下载。
- “复制”优先通过 Clipboard API 复制PNG图片；浏览器不支持或权限被拒时明确提示用户使用保存功能，不伪造成功。
- 累计已发奖金按已确定结算单金额合计，不代表系统维护银行打款流水。

## 7. 状态与异常

支持加载中、空数据、加载失败、无权限。二维码支持生成中、加载失败、复制失败。状态更新失败时回滚按钮展示值。

## 8. 查询与列表

默认按创建时间倒序，分页大小20。排序字段支持扫码/点击数、注册数和三项奖金指标。

## 9. 验收标准

`ADM-07-AC-agent-qrcode`：**Given** 代理存在且管理员有二维码权限，**When** 点击二维码，**Then** 弹窗展示该代理永久二维码；保存触发PNG下载，复制能力不可用时明确提示改用保存。

`ADM-07-AC-agent-status`：**Given** 管理员有编辑权限，**When** 点击状态按钮并确认，**Then** 状态按`M07-SM-agent`流转；接口失败时回滚原按钮状态。

- 列表严格展示用户确认的九项业务字段，另有操作列。
- 页面不存在推广分组筛选或字段。
- 状态以按钮样式呈现，点击可编辑且失败会回滚。
- 点击二维码打开弹窗，弹窗有“保存成图片”和“复制”两个按钮，均有真实结果反馈。
- 点击代理名称或详情在当前页打开右侧抽屉。
