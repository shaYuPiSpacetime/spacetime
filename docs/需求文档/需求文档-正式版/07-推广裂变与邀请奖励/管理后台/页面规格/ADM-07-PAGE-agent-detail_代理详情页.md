# 页面规格 - ADM-07-PAGE-agent-detail 校园代理详情抽屉

> 版本：02｜更新日期：2026-07-17｜形态：逻辑视图（右侧抽屉）
> 对应设计稿：待补充；设计画板按第 2 节输出。

## 1. 页面定位

本规格保留历史 PAGE ID，但实现为校园代理列表中的右侧详情抽屉，不创建独立菜单或路由。

## 2. 布局

抽屉宽度建议860px，由代理概览、推广数据、奖金明细、结算记录和底部关闭按钮组成。详情不展示负责人字段。

| UI画板 | 内容 | 关键状态 |
|---|---|---|
| 代理详情抽屉 | 概览、奖金明细、结算记录 | 正常/加载/空/错误/无权限 |

## 3. 标题与概览

标题展示代理名称与状态；概览展示代理编号、学校/校区、联系电话（默认 `138****1234` 脱敏，仅具备敏感字段权限者可查看完整值且不可导出）、创建时间、扫码/点击数、注册数、应发奖金、已发奖金、待结算奖金。

| relatedUser | 对应用户 | 是 | 昵称+用户ID | 用户 | - | 否 | 触发奖金的被邀请人 | 手机号脱敏 | - |
| amount | 奖金金额 | 是 | ¥0.00 | 奖励流水 | ¥0.00 | 是 | 单条金额 | 否 | - |
| createdAt | 生成时间 | 是 | YYYY-MM-DD HH:mm:ss | 奖励流水 | - | 是 | - | 否 | - |

## 5. 操作表

| 操作 | 入口 | 前置条件 | 结果 | 二次确认 | 成功反馈 | 失败反馈 | 权限 |
|---|---|---|---|---|---|---|---|
| 关闭 | 抽屉右上角/底部 | - | 返回列表 | 否 | 抽屉关闭 | - | 查看 |
| 切换数据区 | 区块标题/Tab | 数据已加载 | 展示奖金或结算记录 | 否 | 即时切换 | 保留当前区并提示 | 查看 |

## 6. 数据联动规则

奖金明细包含五类基础奖励和动态阶梯奖励；结算记录只展示本代理自然月结算单。累计已发奖金等于已确定结算单金额合计。

## 7. 状态与异常

抽屉支持加载中、记录不存在、加载失败、无权限；两个明细区分别支持空数据和独立重试。

## 8. 查询与列表

奖金明细和结算记录均按时间倒序，各自独立分页，切换数据区不影响外层代理列表状态。

## 9. 验收标准

`ADM-07-AC-agent-drawer`：**Given** 管理员在代理列表打开详情，**When** 查看并关闭抽屉，**Then** 奖金明细与结算记录各保持5列，列表上下文不变且不出现负责人字段。

- 详情以右侧抽屉打开，不是菜单页面或独立路由。
- 页面无负责人字段。
- 奖金明细严格为订单号、事件类型、对应用户、金额、生成时间五列，阶梯事件显示具体人数档位。
- 结算记录严格为结算单号、周期、金额、状态、时间五列。
- 关闭抽屉后代理列表筛选和分页不变。
