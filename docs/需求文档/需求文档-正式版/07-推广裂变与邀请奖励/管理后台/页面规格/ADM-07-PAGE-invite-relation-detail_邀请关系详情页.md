# 页面规格 - ADM-07-PAGE-invite-relation-detail 邀请关系详情抽屉

> 版本：02｜更新日期：2026-07-17｜形态：逻辑视图（右侧抽屉）
> 对应设计稿：待补充；设计画板按第 2 节输出。

## 1. 页面定位

本规格保留历史 PAGE ID，但实现形态为邀请关系列表中的右侧详情抽屉，不创建独立菜单或路由。

## 2. 布局

抽屉宽度建议720px，由标题区、关系概览、用户信息、事件时间线、奖励流水和底部关闭按钮组成。

| UI画板 | 内容 | 关键状态 |
|---|---|---|
| 详情抽屉 | 概览、时间线、奖励表 | 正常/加载/空/错误/无权限 |

## 3. 入口与关闭

入口为邀请关系列表“详情”。支持关闭按钮、遮罩点击和 Esc 关闭；关闭后保留列表查询条件与分页。

## 4. 字段表

| 字段 | 展示名 | 必显 | 格式 | 数据来源 | 脱敏 | 空值 | 说明 | 可编辑 | 交互 |
|---|---|---:|---|---|---|---|---|---:|---|
| relationNo | 关系编号 | 是 | 文本 | 邀请关系 | 否 | - | 唯一编号 | 否 | 可复制 |
| relationType | 关系类型 | 是 | 标签 | 邀请关系 | 否 | - | 普通用户邀请/校园代理推广 | 否 | - |
| sourceObject | 来源对象 | 是 | 名称+编号 | 用户/代理 | 手机号脱敏 | - | 普通邀请人或校园代理 | 否 | - |
| invitee | 被邀请用户 | 是 | 昵称+手机号+用户ID | 用户 | 是 | - | 已完成注册 | 否 | - |
| bindTime | 绑定时间 | 是 | YYYY-MM-DD HH:mm:ss | 邀请关系 | 否 | - | 注册建关系时间 | 否 | - |
| paidRewardTotal | 当前已发放奖励 | 是 | 普通邀请：N千寻币；校园代理：¥0.00 | 奖励聚合 | 否 | 0千寻币/¥0.00 | 按关系类型显示单位，含阶梯奖励 | 否 | - |
| eventTimeline | 事件时间线 | 是 | 事件+时间 | 事件记录 | 否 | 暂无后续事件 | 注册、资料、实名、首付、首评 | 否 | - |
| rewardRecords | 奖励流水 | 是 | 表格 | 奖励流水 | 否 | 暂无奖励 | 事件、金额、状态、时间 | 否 | 支持分页 |

抽屉不展示绑定来源路径、设备、IP、风险结论、关系状态，也不提供冻结、解冻或判无效操作。

## 5. 操作表

| 操作 | 入口 | 前置条件 | 结果 | 二次确认 | 成功反馈 | 失败反馈 | 权限 |
|---|---|---|---|---|---|---|---|
| 关闭 | 抽屉右上角/底部 | - | 返回当前列表状态 | 否 | 抽屉关闭 | - | 查看 |
| 复制关系编号 | 编号旁图标 | 浏览器可用 | 写入剪贴板 | 否 | 提示复制成功 | 提示手动复制 | 查看 |
| 切换列表记录 | 关闭后点击其他行 | 记录存在 | 重新加载抽屉 | 否 | 展示新记录 | 展示错误态 | 查看 |

## 6. 数据规则

奖励合计只统计“已发放”流水；阶梯奖励作为独立事件展示。详情只读，不改变关系或奖励数据。

## 7. 状态与异常

抽屉支持加载中、加载失败、记录不存在和无权限。失败时可在抽屉内重试，不关闭列表页。

## 8. 查询与列表

奖励流水默认按生成时间倒序，抽屉内独立分页；事件时间线按发生时间正序。

## 9. 验收标准

`ADM-07-AC-relation-drawer`：**Given** 管理员在关系列表第N页且有筛选条件，**When** 点击详情并关闭抽屉，**Then** 抽屉不改变主路由，列表分页、筛选和滚动位置保持不变。

- 详情不是菜单页面，也不改变浏览器主路由。
- 抽屉内无绑定来源路径、设备/IP、风险结论和关系状态。
- 抽屉展示来源对象、被邀请用户、事件时间线和奖励合计。
- 关闭抽屉后列表筛选、分页和滚动位置保持不变。
