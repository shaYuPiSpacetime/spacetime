1. **字段表/操作表不标准** → 开发和测试需从叙述性文字中二次提取结构化信息，容易遗漏约束

3. **"首次评价奖励"事件缺失** → 配置了字段但没有触发枚举，可能遗漏实现
4. **文案配置承接页不明确** → 运营找不到改文案的地方

| P0 项 | 问题简述 |
|--------|----------|

| P0-02 | 操作表不符合8列标准（全部页面） |
| P0-03 | 验收标准未使用Given/When/Then格式（全部页面） |
| P0-04 | 缺少设计稿引用和UI画板拆分清单（全部页面） |
