# APP-07 端内定义 - 推广裂变与邀请奖励

> 版本：04｜更新日期：2026-07-27｜跨端口径见 `../PRD-07_模块公共定义.md`

## 1. 信息架构

| 一级入口 | 二级页面 | 页面 ID | 一句话职责 |
|---|---|---|---|
| 我的-服务区 | 推荐给好友 | `APP-07-PAGE-invite-home` | 展示邀请收益、进度和分享入口 |
| 邀请首页 | 邀请记录 | `APP-07-PAGE-invite-records` | 查看已建立关系及奖励发放情况 |
| 邀请首页 | 活动规则 | `APP-07-PAGE-invite-rules` | 使用 PRD-06 配置的 H5 解释注册成功和奖励规则 |

## 2. 登录态

未登录用户可见入口，点击后引导登录；已登录普通用户可通过“立即邀请”调起分享、查看完整阶梯进度与最近邀请记录。普通用户首页不展示二维码、邀请码或保存二维码操作；校园代理来源对被邀请用户无感知，代理二维码仍由管理后台承接。

## 3. UI 状态

| 场景 | 表现 | 文案 |
|---|---|---|
| 首页加载中 | 主视觉保留，数据卡片显示骨架占位 | 数据加载中 |
| 邀请记录无数据 | 空态插画+分享按钮 | 还没有邀请记录，快邀请同学一起玩 |
| 网络失败 | 首页框架内显示错误卡+重试 | 网络开小差了，请稍后重试 |
| 微信分享不可用 | 点击“立即邀请”后复制邀请链接 | 邀请链接已复制，请发送给好友 |
| 奖励待发放 | 灰蓝状态标签 | 奖励正在发放中 |
| 奖励发放失败 | 红色状态标签+刷新提示 | 发放失败，系统处理中，请稍后刷新 |
| 邀请规则 H5 加载失败且有缓存 | 顶部弱提示+最近成功版本内容 | 当前内容加载失败，正在展示最近成功版本 |
| 邀请规则 H5 加载失败且无缓存 | 页面错误态+重试和返回 | 内容暂不可查看，请稍后重试 |

移动端不展示关系冻结、关系无效、奖励冻结或奖励作废状态。不满足新用户、自邀、已绑定等资格时，在关系建立前直接拒绝。

## 4. 文案引用

APP-07 页面统一引用 `PRD-07_模块公共定义.md` 中的模块文案与枚举，不在端内重复创造状态。邀请规则 H5 的配置与版本引用 PRD-06 `M06-RULE-business-h5-content`，业务语义仍引用 `M07-RULE-invite-rules-h5`。
