| 版本 | 日期 | 修改人 | 变更摘要 |
|------|------|--------|----------|
| 版本02 | 2026-07-17 | Codex | 固定完成注册、永久关系和阶梯当次额外奖励口径 |
| 版本03 | 2026-07-20 | Codex | 按用户确认改为 PRD-06 配置的 H5 内容页，新增缓存降级与跨模块边界 |

- **页面 ID**：`APP-07-PAGE-invite-rules`
- **所属模块 PRD**：`模块PRD_APP-07_推广裂变与邀请奖励`
- **页面路由**：`/pages/promotion/invite-rules`
- **入口来源**：邀请首页“活动说明”、邀请规则摘要“查看完整规则”
- **对应设计稿**：待补充；设计画板按第 2.4 节输出
- **对应管理后台**：`ADM-06-PAGE-compliance-config` 的“业务规则 -> 邀请规则”

## 1. 页面定位

- **目标用户**：所有可进入邀请首页的用户。
- **核心任务**：在小程序共享 H5 容器内展示邀请参与资格、完成注册成功口径、当前奖励事件和阶梯额外奖励说明。
- **页面类型**：H5 内容容器页；入口和业务归 PRD-07，H5 配置归 PRD-06。

## 2. 布局

### 2.1 整体布局

```text
小程序导航栏：返回｜邀请规则
缓存降级提示（仅降级态显示）
┌──────────────────────────────┐
│ H5 内容区域                  │
│ 标题、版本、更新时间         │
│ 资格/成功条件/奖励/阶梯/FAQ  │
└──────────────────────────────┘
加载失败无缓存：错误图标、提示、重试、返回
```

### 2.2 区块说明

| 区块 | 位置 | 内容 | 是否可折叠 | 是否记住展开状态 |
|------|------|------|------------|------------------|
| 原生导航栏 | 顶部固定 | 返回、页面标题 | 否 | 否 |
| 缓存提示 | 导航栏下方 | 当前版本加载失败及缓存版本号 | 否 | 否 |
| H5 容器 | 主体 | PRD-06 返回的当前启用 URL | H5 自身决定 | 不由小程序保存 |
| 不可用态 | 主体 | 无缓存时的错误提示、重试和返回 | 否 | 否 |

### 2.3 弹层 / 抽屉 / 模态

本页无弹层、抽屉或模态；H5 内不得打开可修改奖励规则的表单。

### 2.4 UI 画板拆分

| 画板 ID | 画板名称 | 设计内容 | 备注 |

| `APP-07-invite-rules-02` | 邀请规则 H5-缓存降级 | 弱提示条、缓存版本和内容 | P0 |

### 2.5 编辑控件口径

本页为只读 H5 内容页，不提供编辑控件；标题、URL、版本和状态由 PRD-06 后台维护，邀请与奖励业务数值由 PRD-07 规则配置维护。

## 3. 筛选与搜索

本页为只读内容页，无列表查询、筛选或搜索。

### 5.3 页面级操作

| 操作 ID | 操作名 | 位置 | 触发条件 | 前置权限 | 二次确认 | 成功态 | 失败态 |
|---------|--------|------|----------|----------|----------|--------|--------|
| `APP-07-PAGE-invite-rules-ACT-back` | 返回 | 导航栏左侧 | 页面已打开 | 全部用户 | 否 | 返回邀请首页并保留原滚动位置 | 无历史页面时回邀请首页 |

## 6. 数据联动规则

| 触发字段 | 触发事件 | 影响字段 | 联动行为 | 备注 |
|----------|----------|----------|----------|------|
| H5 配置 | 页面进入 | URL、版本、更新时间 | 调用 PRD-06 `/api/app/h5-content/invite_rules` 获取当前启用版本 | 不调用 PRD-07 规则接口拼正文 |
| H5 容器 | 加载成功 | 内容来源、最近成功缓存 | 标记 current 并覆盖同内容键缓存 | 缓存版本随成功加载更新 |
| H5 容器 | 加载失败且有缓存 | 缓存提示、正文 | 标记 cache，展示最近成功版本与弱提示 | 不参与奖励计算 |
| H5 容器 | 加载失败且无缓存 | 不可用态 | 隐藏空白 WebView，展示重试和返回 | `M06-ERR-h5-cache-missing` |
| PRD-07 规则发布 | 运营验收 | H5 正文 | 必须核对内容；不自动改写 H5 | 冲突时实际发奖仍以 `M07-*` 为准 |

## 7. 状态与异常

| 状态类型 | 触发场景 | 页面表现 | 用户可做的操作 | 引用 |
|----------|----------|----------|----------------|------|
| 加载态 | 配置接口或 H5 加载中 | 原生导航栏+内容骨架屏，避免白屏 | 返回 | `GLB-RULE-h5-content-container` |
| 空态（无配置） | `invite_rules` 未初始化或 URL 为空 | 不可用态，不展示客户端硬编码规则 | 重试/返回 | `M06-ERR-h5-cache-missing` |
| 空态（正文为空） | H5 成功响应但无有效正文 | 按加载失败处理，尝试缓存 | 重试/返回 | `M07-RULE-invite-rules-h5` |
| 错误态（网络） | 配置接口或 H5 超时 | 有缓存则提示并展示缓存；无缓存则错误态 | 重试/返回 | `M06-ERR-h5-cache-missing` |
| 无权限态 | 本页面不要求登录 | 不出现无权限态；入口登录规则继承邀请首页 | 返回 | `APP-07_端内定义` |
| 业务态-当前版本 | 当前启用 H5 加载成功 | 展示当前标题、版本、更新时间和正文 | 阅读/返回 | `M06-RULE-business-h5-content` |
| 业务态-缓存版本 | 当前版本失败且存在缓存 | 顶部提示缓存版本，正文正常可读 | 重试/返回 | `M07-RULE-invite-rules-h5` |
| 降级态 | WebView/业务域名不可用 | 先缓存后错误态；不得跳外部浏览器 | 重试/返回 | `GLB-RULE-h5-content-container` |

## 8. 查询与列表

本页非列表页，不分页、不排序、不轮询；用户主动重试时重新请求当前配置。

## 9. 验收标准

| AC ID | 场景 | 类型 | 优先级 |
|-------|------|------|--------|
| `APP-07-AC-invite-rules-current` | 加载当前邀请规则 H5 | 正常 | P0 |
| `APP-07-AC-invite-rules-cache` | 当前 H5 失败后展示缓存 | 异常 | P0 |
| `APP-07-AC-invite-rules-no-cache` | 无当前内容且无缓存 | 异常 | P0 |
| `APP-07-AC-invite-rules-boundary` | H5 不改变奖励计算 | 安全 | P0 |

```text
AC-ID: APP-07-AC-invite-rules-current
Given PRD-06 的 invite_rules 为启用、版本 v4.1 且 URL 可访问
When  用户从邀请首页打开活动规则
Then  页面在共享 H5 容器展示 v4.1 内容并更新最近成功缓存，不展示有效期、每日封顶、设备/IP 风控、冻结或作废旧口径
```

```text
AC-ID: APP-07-AC-invite-rules-cache
Given 用户曾成功加载 v4.0，当前 v4.1 因网络失败不可访问
When  用户打开活动规则
Then  页面展示“当前内容加载失败，正在展示最近成功版本”及 v4.0 缓存内容；实际邀请和发奖继续按服务端 M07 规则执行
```

```text
AC-ID: APP-07-AC-invite-rules-no-cache
Given 当前 invite_rules 不可用且本机无最近成功缓存
When  用户打开活动规则
Then  页面不硬编码完整规则，展示“内容暂不可查看，请稍后重试”、重新加载和返回操作
```
