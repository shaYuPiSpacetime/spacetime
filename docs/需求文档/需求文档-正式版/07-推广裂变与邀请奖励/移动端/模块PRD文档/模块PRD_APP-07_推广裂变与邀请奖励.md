# 模块 PRD - 移动端-07 推广裂变与邀请奖励

> 版本：04｜更新日期：2026-07-27｜状态：已确认

## 1. 模块目标

通过普通用户分享入口和校园代理二维码完成一期拉新。被邀请人完成注册即建立永久邀请关系并计为邀请成功；后续资料、实名、首付、首评事件按后台规则分别发奖。奖励模式支持固定奖励和命中档位时一次性额外发放的阶梯奖励。

核心指标为分享/扫码点击数、完成注册数和奖励发放金额。

## 2. 用户与角色

| 角色 | 职责 |
|---|---|
| 普通邀请人 | 通过“立即邀请”分享个人邀请链接，查看累计成功人数、奖励、完整阶梯和最近邀请 |
| 被邀请人 | 通过邀请链接或代理二维码进入，并以新用户身份完成注册及后续事件 |
| 校园代理 | 通过专属二维码带来扫码、注册和奖励数据 |

## 3. 关键业务流程

1. 被邀请人通过普通用户分享链接或校园代理二维码进入，系统只记录点击来源。
2. 被邀请人首次完成注册时，校验新用户、自邀、已有关系和来源归属。
3. 校验通过后建立唯一且永久有效的邀请关系，并触发完成注册基础奖励。
4. 累计成功人数恰好命中启用阶梯档位时，额外生成一条阶梯奖励流水。
5. 资料完善、认证完成、首次会员、首次充值分别按配置生成基础奖励流水。
6. 奖励状态从待发放进入已发放；技术异常进入发放失败并由系统重试。

示例：完成注册奖励20千寻币，累计5人额外50千寻币、累计10人额外100千寻币、累计20人额外200千寻币。第1人奖励20千寻币；第5人产生20千寻币和50千寻币两条奖励；第8人只奖励20千寻币。该组数字仅用于解释当前设计画板，实际页面完整读取后台已发布档位。

异常请求不落关系：非新用户、自邀、已有邀请关系、重复绑定。模块不创建冻结、作废或无效关系记录。

## 4. 核心数据模型

| 实体 | 表名建议 | 关键字段 | 规则 |
|---|---|---|---|
| 邀请关系 | `promo_invite_relation` | relationId, sourceType, sourceObjectId, inviteeId, bindTime | inviteeId唯一，永久有效，无状态字段 |
| 邀请奖励流水 | `promo_invite_reward` | rewardId, relationId, eventType, amount, status, ruleSnapshot | 状态仅待发放/已发放/发放失败 |
| 来源点击 | `promo_invite_source_log` | sourceType, sourceObjectId, visitorKey, clickTime | 点击不等于建关系 |
| 千寻币流水 | `asset_coin_flow` | userId, type, amount | 普通邀请奖励写入PRD-04资产流水 |

## 5. 本期范围

- 我的页“推荐给好友”入口、邀请首页、H5 活动规则、邀请记录。
- 普通用户微信分享与邀请链接复制降级；普通用户首页不展示二维码、邀请码或保存二维码。
- 普通用户/校园代理两类来源识别和唯一关系绑定。
- 五类基础奖励、动态阶梯额外奖励及三种发放状态展示。
- 注册成功数、已发放奖励汇总、全部启用阶梯进度和最近三条邀请记录。

## 6. 本期不做

- 多级分销、提现钱包、代理移动工作台、自动打款、个人收款信息、税务和发票。
- 设备/IP风控、人工冻结处理、奖励作废、每日奖励封顶。
- 邀请关系有效期或关系状态管理。

## 7. 跨模块依赖

| 依赖 | 来源 | 处理 |
|---|---|---|
| 用户注册/资料/实名事件 | PRD-01 | 事件幂等后触发奖励 |
| 首次付费事件与千寻币流水 | PRD-04 | 支付成功回调触发，奖励写资产流水 |
| 通知中心 | PRD-03 | 通知失败不阻塞发放，异步重试 |
| 规则与阶梯档位 | ADM-07 | 固定成功口径，仅加载金额、模式和档位 |
| 微信分享 | 微信能力 | 失败时复制个人邀请链接并提示用户发送给好友 |
| 邀请规则 H5 | PRD-06 H5 内容配置 | 读取 `invite_rules` 当前启用版本；失败时展示最近成功缓存，无缓存则显示不可用态 |

## 8. 改动影响面

- 我的页新增入口。
- PRD-01注册成功后调用邀请绑定；后续事件调用奖励触发。
- PRD-04新增五类基础邀请奖励及`invite_ladder_reward`资产流水场景。
- 通知中心只保留奖励到账/发放失败相关模板，不创建冻结、无效模板。

## 9. 非功能性要求

- `inviteeId`建立唯一键，弱网重复绑定返回同一关系结果。
- 基础奖励幂等键为`relationId + eventType`；阶梯奖励幂等键为`rewardObjectId + thresholdSnapshot`。
- 阶梯流水保存规则版本、阈值和金额快照；规则更新不追溯历史档位。
- 邀请首页首屏目标500ms内；汇总、完整阶梯和最近邀请可由同一聚合接口返回。
- 被邀请人手机号仅脱敏展示。
- 邀请规则 H5 正常加载后缓存最近成功版本；缓存只用于展示降级，不参与邀请或奖励计算。

## 11. 上线与回滚

上线前无关系存量；规则发布后仅影响新事件。回滚可关闭邀请入口与新奖励触发，已建立关系和已发放奖励不逆向删除。
