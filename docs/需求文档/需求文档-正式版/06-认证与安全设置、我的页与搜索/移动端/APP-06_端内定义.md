## 2. 登录态与访问控制

| 用户状态 | 可见页面/能力 | 可操作能力 | 不满足时处理 |
|----------|---------------|------------|--------------|
| 未登录 | 可进入我的页、帮助与客服、关于我们、协议清单、搜索首页 | 搜索公开内容、查看 H5 合规内容 | 个人数据入口点击后引导登录 |
| 已登录但资料未完成 | 可进入我的页、设置、帮助、认证中心、合规清单、搜索 | 查看状态、联系客服、退出登录、进入认证/资料补全 | 核心互动入口展示认证/资料引导 |
| 已登录且满足 `M01-RULE-core-access` | 可查看全部已启用入口 | 使用自身权限内入口 | 具体能力引用各模块 |
| 账号冻结/停用/注销中 | 可查看必要账号状态、联系客服、撤销注销 | 不可进入核心互动和付费新增能力 | 我的页顶部展示账号限制提示 |

## 3. 移动端 UI 空态 / 错误态 / 降级态

| 场景 | 页面表现 | 默认文案 |
|------|----------|----------|
| 我的页入口未配置 | 展示基础入口和配置错误提示 | 部分入口暂不可用 |
| 用户摘要加载失败 | 保留入口骨架，头像昵称展示占位 | 资料加载失败，请稍后重试 |
| 认证状态未返回 | 认证卡片展示加载中 | 认证状态同步中 |
| 合规内容链接缺失 | 空态 + 返回 | 内容暂不可查看 |
| 搜索无结果 | 空态 + 修改关键词建议 | 没找到相关内容 |
| 搜索词违规 | toast + 不进入结果页 | 搜索内容不支持展示 |
| 注销命中阻断 | 阻断原因列表 + 联系客服 | 当前账号暂不可注销 |
| 账号处于后悔期 | 我的页和设置页展示后悔期提示 | 账号注销申请已提交，可在期限内撤销 |
