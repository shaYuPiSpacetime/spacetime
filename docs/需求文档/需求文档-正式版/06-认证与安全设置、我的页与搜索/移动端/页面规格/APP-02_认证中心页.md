# 页面规格 - APP-06-PAGE-cert-center 认证中心页

| 版本 | 日期 | 修改人 | 变更摘要 |
|------|------|--------|----------|
| 版本01 | 2026-07-08 | Codex | 创建页面规格 |

- **页面 ID**：`APP-06-PAGE-cert-center`
- **所属模块 PRD**：`模块PRD_APP-06_认证与安全设置、我的页与搜索`
- **页面路由**：`/pages/my/cert-center`
- **入口来源**：我的页认证卡片、核心准入拦截、设置页账号状态
- **对应设计稿**：当前未绑定蓝湖画板；设计画板按第 2.4 节输出
- **对应移动端 / 技术方案**：`MVP-PAGE-074`

## 1. 页面定位

- **目标用户**：已登录 App 用户
- **核心任务**：查看实名、头像、学历三重认证状态，进入 PRD-01 对应认证流程或查看失败原因
- **页面类型**：状态聚合页

## 2. 布局（给 UI）

### 2.1 整体布局

```text
┌────────────────────┐
│ 认证价值说明         │
├────────────────────┤
│ 实名认证状态卡片      │
│ 头像认证状态卡片      │
│ 学历认证状态卡片      │
├────────────────────┤
│ 常见问题 / 联系客服   │
└────────────────────┘
```

### 2.2 区块说明

| 区块 | 位置 | 内容 | 是否可折叠 | 是否记住展开状态 |
|------|------|------|------------|------------------|
| 顶部说明 | 顶部 | 三重认证价值、核心准入说明 | 否 | 否 |
| 认证卡片 | 主体 | 三项认证状态、按钮、失败原因摘要 | 否 | 否 |
| 帮助区 | 底部 | 常见问题、联系客服 | 否 | 否 |

### 2.3 弹层 / 抽屉 / 模态

| 弹层 | 触发方式 | 大小 | 内容 | 关闭方式 |
|------|----------|------|------|----------|
| 审核说明弹窗 | 点击审核中说明 | 底部弹窗 | SLA、不可催审、客服入口 | 关闭/知道了 |

### 2.4 UI 画板拆分（必填）

| 画板 ID | 画板名称 | 设计内容 | 备注 |
|---------|----------|----------|------|
| `APP-06-cert-01` | 认证中心-未完成 | 三项未通过和去认证入口 | P0 |
| `APP-06-cert-02` | 认证中心-审核中 | 审核中说明弹窗 | P0 |
| `APP-06-cert-03` | 认证中心-已通过 | 三项通过和权益说明 | P0 |
| `APP-06-cert-04` | 认证中心-失败态 | 驳回原因和重新认证 | P0 |

### 2.5 编辑控件口径

本页不直接编辑认证材料；点击去认证或重新认证跳转 PRD-01 对应页面。

## 3. 筛选与搜索

本页为状态聚合页，无筛选搜索。

## 4. 字段表

### 4.1 列表字段

| 字段 ID | 显示名 | 类型 | 必填 | 取值范围 | 校验规则 | 默认值 | 可编辑 | 敏感级别 | 数据来源 |
|---------|--------|------|------|----------|----------|--------|--------|----------|----------|
| `APP-06-PAGE-cert-center-FIELD-real-name-status` | 实名认证状态 | enum | 是 | `M01-ENUM-verification-status` | 状态缺失展示同步中 | not_submitted | 否 | 普通 | PRD-01 |
| `APP-06-PAGE-cert-center-FIELD-avatar-status` | 头像认证状态 | enum | 是 | `M01-ENUM-verification-status` | 状态缺失展示同步中 | not_submitted | 否 | 普通 | PRD-01 |
| `APP-06-PAGE-cert-center-FIELD-education-status` | 学历认证状态 | enum | 是 | `M01-ENUM-verification-status` | 状态缺失展示同步中 | not_submitted | 否 | 普通 | PRD-01 |

## 6. 数据联动规则

| 触发字段 | 触发事件 | 影响字段 | 联动行为 | 备注 |
|----------|----------|----------|----------|------|
| 三项认证状态 | 任一变化 | 核心准入 | 三项均 approved 且账号正常时展示已开放 | `M01-RULE-core-access` |
| 实名状态 | 未提审 | 学历认证按钮 | 学历按钮置灰并提示先提交实名 | PRD-01 |

## 7. 状态与异常

| 状态类型 | 触发场景 | 页面表现 | 用户可做的操作 | 引用 |
|----------|----------|----------|----------------|------|
| 加载态 | 首次进入 | 三张卡片骨架屏 | 无 | — |
| 空态（无数据） | 认证状态缺失 | 展示同步中 | 刷新/联系客服 | `M01-ENUM-verification-status` |
| 空态（搜索无结果） | 本页不适用 | 本节不适用 | 无 | — |
| 错误态（网络） | 请求失败 | toast + 重试 | 重试 | `M06-ERR-entry-disabled` |
| 无权限态 | 未登录 | 登录引导 | 去登录 | `GLB-ROLE-app-user` |
| 业务态-审核中 | 状态 reviewing | 展示预计说明，不可重复提交 | 查看说明 | `M01-ENUM-verification-status` |
| 业务态-驳回 | 状态 rejected | 展示驳回原因和重新认证 | 重新认证/联系客服 | `M01-RULE-reject-reason` |
| 降级态 | PRD-01 服务不可用 | 按钮置灰 + 稍后再试 | 联系客服 | PRD-01 |

## 8. 查询与列表

- **默认排序**：实名、头像、学历固定顺序。
- **分页**：不分页。
- **分页方式**：不适用。
- **列表轮询/实时刷新**：不轮询，下拉刷新。
- **批量选择**：不支持。
- **列表为空时引导**：联系客服或刷新。

## 9. 验收标准

| AC ID | 场景 | 类型 | 优先级 |
|-------|------|------|--------|
| `APP-06-AC-cert-status` | 三项认证状态正确展示 | 正常 | P0 |
| `APP-06-AC-cert-retry` | 驳回后重新认证 | 正常 | P0 |
| `APP-06-AC-cert-edu-precondition` | 学历实名前置 | 异常 | P0 |

```text
AC-ID: APP-06-AC-cert-edu-precondition
Given 当前用户实名状态为 not_submitted
When  用户点击学历认证卡片
Then  页面提示先提交实名认证，不进入学历认证表单
```
