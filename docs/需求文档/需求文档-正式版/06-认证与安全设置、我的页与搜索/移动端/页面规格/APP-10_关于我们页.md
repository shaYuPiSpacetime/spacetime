# 页面规格 - APP-06-PAGE-about 关于我们页

| 版本 | 日期 | 修改人 | 变更摘要 |
|------|------|--------|----------|
| 版本01 | 2026-07-08 | Codex | 创建页面规格 |

- **页面 ID**：`APP-06-PAGE-about`
- **所属模块 PRD**：`模块PRD_APP-06_认证与安全设置、我的页与搜索`
- **页面路由**：`/pages/my/about`
- **入口来源**：设置页 -> 关于我们
- **对应设计稿**：当前未绑定蓝湖画板；设计画板按第 2.4 节输出
- **对应移动端 / 技术方案**：`MVP-PAGE-068`、`MVP-PAGE-069`、`MVP-PAGE-070`、`MVP-PAGE-071`、`MVP-PAGE-072`；内容展示由 `APP-06-PAGE-policy-content` 承接

## 1. 页面定位

- **目标用户**：访客、App 用户
- **核心任务**：查看品牌信息、版本、用户协议、隐私政策、隐私摘要、平台规范和公告入口
- **页面类型**：关于与合规入口页

## 2. 布局（给 UI）

### 2.1 整体布局

```text
┌────────────────────┐
│ Logo / 产品名 / 版本  │
├────────────────────┤
│ 协议与政策入口        │
├────────────────────┤
│ 平台规范 / 公告栏      │
└────────────────────┘
```

### 2.2 区块说明

| 区块 | 位置 | 内容 | 是否可折叠 | 是否记住展开状态 |
|------|------|------|------------|------------------|
| 品牌区 | 顶部 | Logo、产品名、版本号 | 否 | 否 |
| 协议区 | 主体 | 用户协议、隐私政策、隐私摘要 | 否 | 否 |
| 平台区 | 主体 | 平台信息管理规范、公告栏 | 否 | 否 |

### 2.3 弹层 / 抽屉 / 模态

本页无弹层；内容页按 H5 或原生页打开。

### 2.4 UI 画板拆分（必填）

| 画板 ID | 画板名称 | 设计内容 | 备注 |
|---------|----------|----------|------|
| `APP-06-about-01` | 关于我们-主页面 | 品牌、版本、协议入口 | P0 |
| `APP-06-about-02` | 关于我们-链接缺失 | 缺失提示 | P1 |

### 2.5 编辑控件口径

本页无编辑控件。

## 3. 筛选与搜索

本页无筛选搜索。

| 字段 ID | 显示名 | 类型 | 必填 | 取值范围 | 校验规则 | 默认值 | 可编辑 | 敏感级别 | 数据来源 |

## 7. 状态与异常

| 状态类型 | 触发场景 | 页面表现 | 用户可做的操作 | 引用 |
|----------|----------|----------|----------------|------|
| 加载态 | 首次进入 | 骨架屏 | 无 | — |
| 空态（无数据） | 链接未配置 | 展示品牌和缺失提示 | 返回 | `M06-CFG-compliance-links` |
| 空态（搜索无结果） | 本页不适用 | 本节不适用 | 无 | — |
| 错误态（网络） | 查询失败 | toast + 重试 | 重试 | `M06-ERR-content-link-missing` |
| 无权限态 | 无 | 公开可访问 | 无 | — |
| 业务态-链接启用 | 内容启用 | 正常展示 | 打开 | `M06-ENUM-entry-status` |
| 降级态 | H5 缺失 | 入口置灰 | 稍后重试 | `M06-RULE-compliance-content` |

## 8. 查询与列表

- **默认排序**：后台配置排序。
- **分页**：不分页。
- **列表为空时引导**：返回设置页。
