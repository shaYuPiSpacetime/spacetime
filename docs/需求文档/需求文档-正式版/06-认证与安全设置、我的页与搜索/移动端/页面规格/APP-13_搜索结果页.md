# 页面规格 - APP-06-PAGE-search-result 搜索结果页

| 版本 | 日期 | 修改人 | 变更摘要 |
|------|------|--------|----------|
| 版本01 | 2026-07-08 | Codex | 创建页面规格 |

- **页面 ID**：`APP-06-PAGE-search-result`
- **所属模块 PRD**：`模块PRD_APP-06_认证与安全设置、我的页与搜索`
- **页面路由**：`/pages/search/result?keyword={keyword}&sourceScene={scene}`
- **入口来源**：搜索首页
- **对应设计稿**：当前未绑定蓝湖画板；设计画板按第 2.4 节输出
- **对应移动端 / 技术方案**：`MVP-PAGE-082`

## 1. 页面定位

- **目标用户**：访客、App 用户
- **核心任务**：按入口限定查看用户、动态、话题搜索结果
- **页面类型**：列表页

## 2. 布局（给 UI）

### 2.1 整体布局

```text
┌────────────────────┐
│ 搜索框（可修改关键词） │
├────────────────────┤
│ Tab：用户/动态/话题    │
├────────────────────┤
│ 当前 Tab 结果列表      │
└────────────────────┘
```

### 2.2 区块说明

| 区块 | 位置 | 内容 | 是否可折叠 | 是否记住展开状态 |
|------|------|------|------------|------------------|
| 搜索栏 | 顶部 | 关键词输入和取消 | 否 | 否 |
| Tab 区 | 搜索栏下 | 按 `sourceScene` 显示可用类型 | 否 | 是 |
| 结果区 | 主体 | 用户卡、动态卡、话题卡 | 否 | 是 |

### 2.3 弹层 / 抽屉 / 模态

本页无弹层；详情跳转到用户主页、动态详情或话题详情。

### 2.4 UI 画板拆分（必填）

| 画板 ID | 画板名称 | 设计内容 | 备注 |
|---------|----------|----------|------|
| `APP-06-search-result-01` | 搜索结果-用户 Tab | 用户结果卡 | P0 |
| `APP-06-search-result-02` | 搜索结果-动态 Tab | 动态结果卡 | P0 |
| `APP-06-search-result-03` | 搜索结果-话题 Tab | 话题结果卡 | P0 |
| `APP-06-search-result-04` | 搜索结果-无结果 | 空态 | P0 |
| `APP-06-search-result-05` | 搜索结果-降级态 | Tab 隐藏或服务异常 | P1 |

### 2.5 编辑控件口径

本页仅允许修改搜索框关键词重新搜索，不提供筛选器；年龄、城市、身高等筛选不属于 PRD-06。

## 3. 筛选与搜索

### 3.1 搜索

| 项 | 说明 |
|----|------|
| 搜索框位置 | 顶部 |
| 搜索字段 | 用户：昵称、成家号、公开城市；动态：标题、正文摘要、公开标签；话题：名称、简介；不搜索学校、职业、测评报告 |
| 搜索方式 | 模糊匹配 |
| 搜索触发 | 点击搜索或键盘搜索 |
| 搜索历史 | 搜索成功后写入最近 10 条 |
| 清空搜索 | 清空关键词后返回搜索首页 |

### 3.2 筛选条件

| 筛选 ID | 筛选名 | 类型 | 选项来源 | 是否多选 | 默认值 | 是否可清除 |
|---------|--------|------|----------|----------|--------|------------|
| `APP-06-PAGE-search-result-FILTER-tab` | 结果类型 | Tab | `M06-ENUM-search-result-type` 且受 `sourceScene` 限定 | 否 | 第一个可用 Tab | 否 |
| `APP-06-PAGE-search-result-FILTER-keyword` | 关键词 | 输入框 | 用户输入 | 否 | 路由关键词 | 是 |

### 3.3 筛选交互

- Tab 切换后保留关键词并查询当前类型。
- 来源场景不允许的 Tab 不展示。
- 用户结果不展示高敏字段；资料受限时降级展示。

详情字段由目标页面承接：用户主页、动态详情、话题详情。

本页不支持批量操作。

| 操作 ID | 操作名 | 位置 | 触发条件 | 前置权限 | 二次确认 | 成功态 | 失败态 |

| `APP-06-PAGE-search-result-ACT-load-more` | 加载更多 | 列表底部 | 有下一页 | 访客/用户 | 否 | 追加结果 | 网络错误 toast |

## 6. 数据联动规则

| 触发字段 | 触发事件 | 影响字段 | 联动行为 | 备注 |
|----------|----------|----------|----------|------|
| sourceScene | 页面加载 | Tab 列表 | 只展示允许结果类型 | `M06-RULE-search-scope` |
| 关键词 | 重新搜索 | 结果列表 | 重新查询并回到第 1 页 | `M06-RULE-search-block` |
| 内容状态 | 下架/删除 | 结果列表 | 不展示或展示已下架提示 | PRD-05 |

## 7. 状态与异常

| 状态类型 | 触发场景 | 页面表现 | 用户可做的操作 | 引用 |
|----------|----------|----------|----------------|------|
| 加载态 | 查询中 | 列表骨架 | 无 | — |
| 空态（无数据） | 当前 Tab 无结果 | 空态 + 修改关键词建议 | 返回搜索首页 | `M06-RULE-search-scope` |
| 空态（搜索无结果） | 所有 Tab 无结果 | 综合空态 | 修改关键词 | `M06-RULE-search-scope` |
| 错误态（网络） | 查询失败 | toast + 重试 | 重试 | `M06-ERR-search-empty-keyword` |
| 无权限态 | 目标页需登录 | 行点击后登录引导 | 去登录 | 目标模块 |
| 业务态-隐私降级 | 用户资料受限 | 展示头像/昵称等最小摘要 | 查看公开主页 | `M06-ENUM-search-block-reason` |
| 降级态 | PRD-05 未就绪 | 动态/话题 Tab 隐藏 | 搜用户 | 跨模块依赖 |

## 8. 查询与列表

- **默认排序**：综合相关度 + 后台基础排序。
- **可选排序**：无。
- **分页**：默认 20 条。
- **分页方式**：上拉加载更多。
- **列表轮询/实时刷新**：不轮询。
- **批量选择**：不支持。
- **列表为空时引导**：修改关键词或返回。

## 9. 验收标准

| AC ID | 场景 | 类型 | 优先级 |
|-------|------|------|--------|
| `APP-06-AC-search-result-scope` | 按入口限定 Tab | 正常 | P0 |
| `APP-06-AC-search-result-filter` | 下架/不可见过滤 | 正常 | P0 |
| `APP-06-AC-search-result-no-height` | 不展示身高筛选 | 正常 | P0 |

```text
AC-ID: APP-06-AC-search-result-scope
Given 用户从社区搜索入口进入搜索，sourceScene=community
When  用户搜索关键词
Then  结果页只展示动态和话题 Tab，不展示用户筛选条件、身高筛选或测评报告结果
```

```text
AC-ID: APP-06-AC-search-result-filter
Given 搜索结果中包含下架动态、停用话题或不可见用户
When  搜索结果页加载当前关键词
Then  页面过滤不可展示对象；若当前 Tab 无可展示结果，则展示无结果空态
```

```text
AC-ID: APP-06-AC-search-result-no-height
Given 用户从推荐或理想型场景进入搜索
When  用户打开搜索结果页
Then  页面不展示身高、年龄、城市等条件筛选控件，相关条件搜索由 PRD-08/PRD-02 承接
```
