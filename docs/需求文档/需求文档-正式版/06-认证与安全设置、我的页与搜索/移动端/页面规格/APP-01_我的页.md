# 页面规格 - APP-06-PAGE-my 我的页

| 版本 | 日期 | 修改人 | 变更摘要 |
|------|------|--------|----------|
| 版本01 | 2026-07-08 | Codex | 创建页面规格 |

- **页面 ID**：`APP-06-PAGE-my`
- **所属模块 PRD**：`模块PRD_APP-06_认证与安全设置、我的页与搜索`
- **页面路由**：`/pages/my/index`
- **入口来源**：底部 Tab -> 我的
- **对应设计稿**：当前未绑定蓝湖画板；设计画板按第 2.4 节输出
- **对应移动端 / 技术方案**：`MVP-PAGE-041`

## 1. 页面定位

- **目标用户**：未登录访客、已登录 App 用户
- **核心任务**：查看个人摘要，进入资料认证、会员资产、互动记录、推广、帮助客服和设置入口
- **页面类型**：个人中心聚合页

## 2. 布局（给 UI）

### 2.1 整体布局

```text
┌────────────────────┐
│ 顶部用户卡片/登录引导 │
├────────────────────┤
│ 认证与资料完成度提示   │
├────────────────────┤
│ 会员资产与核心入口宫格 │
├────────────────────┤
│ 互动/推广/服务入口分组 │
├────────────────────┤
│ 设置入口              │
└────────────────────┘
```

### 2.2 区块说明

| 区块 | 位置 | 内容 | 是否可折叠 | 是否记住展开状态 |
|------|------|------|------------|------------------|
| 用户卡片 | 顶部 | 头像、昵称、成家号、认证徽章、资料完成度 | 否 | 否 |
| 认证引导 | 用户卡片下方 | 三重认证状态与认证中心入口 | 否 | 否 |
| 核心入口 | 主体 | 会员、千寻币、喜欢我的、最近来访、我的动态、推荐给好友、签到 | 否 | 是 |
| 服务入口 | 主体下方 | 联系客服、关于我们 | 否 | 是 |
| 设置入口 | 底部 | 设置页入口 | 否 | 否 |

### 2.3 弹层 / 抽屉 / 模态

本页不直接弹层；退出登录、注销等由设置页承接。

### 2.4 UI 画板拆分（必填）

| 画板 ID | 画板名称 | 设计内容 | 备注 |
|---------|----------|----------|------|
| `APP-06-my-01` | 我的页-已登录正常态 | 用户卡片、认证、入口分组 | P0 |
| `APP-06-my-02` | 我的页-未登录态 | 登录引导、公开服务入口 | P0 |
| `APP-06-my-03` | 我的页-认证未完成态 | 认证引导卡和入口角标 | P0 |
| `APP-06-my-04` | 我的页-账号限制态 | 冻结/注销后悔期提示 | P0 |

### 2.5 编辑控件口径

本页为展示聚合页，无编辑控件；一期入口、排序和文案由客户端代码固定，不请求后台入口配置。

## 3. 筛选与搜索

本页不是列表查询页，无筛选搜索；搜索由 `APP-06-PAGE-search-home` 承接。

## 5. 操作表

### 5.1 行级操作

| 操作 ID | 操作名 | 触发条件 | 前置权限 | 二次确认 | 成功态 | 失败态 | 影响（副作用） |
|---------|--------|----------|----------|----------|--------|--------|----------------|
| `APP-06-PAGE-my-ACT-open-entry` | 打开入口 | 入口状态为 `enabled` | `GLB-ROLE-app-user` 或公开入口 | 否 | 跳转目标页 | `M06-ERR-entry-disabled` toast | 写入口点击埋点 |
| `APP-06-PAGE-my-ACT-open-cert` | 去认证中心 | 任意认证未通过或用户主动点击 | `GLB-ROLE-app-user` | 否 | 跳转认证中心 | 认证状态加载失败 toast | 无 |

### 5.2 批量操作

本页不支持批量操作。

### 5.3 页面级操作

| 操作 ID | 操作名 | 位置 | 触发条件 | 前置权限 | 二次确认 | 成功态 | 失败态 |
|---------|--------|------|----------|----------|----------|--------|--------|
| `APP-06-PAGE-my-ACT-login` | 登录 | 未登录用户卡片 | 未登录 | `GLB-ROLE-visitor` | 否 | 进入登录页 | 登录失败提示 |
| `APP-06-PAGE-my-ACT-refresh` | 下拉刷新 | 页面顶部 | 页面已加载 | 当前用户 | 否 | 刷新摘要和入口 | 网络错误 toast |

## 6. 数据联动规则

| 触发字段 | 触发事件 | 影响字段 | 联动行为 | 备注 |
|----------|----------|----------|----------|------|
| 核心准入状态 | 状态变化 | 认证引导卡 | 未开放时展示补齐引导，已开放时隐藏强提示 | `M01-RULE-core-access` |
| 跨模块能力 | 依赖模块未上线 | 固定入口列表 | 按依赖规则隐藏或跳施工中页 | `M06-RULE-my-entry-scope` |
| 会员状态 | 到期 | 会员入口角标 | 展示到期或未开通 | PRD-04 |

## 7. 状态与异常

| 状态类型 | 触发场景 | 页面表现 | 用户可做的操作 | 引用 |
|----------|----------|----------|----------------|------|
| 加载态 | 首次进入 | 用户卡片和入口骨架屏 | 无 | — |
| 空态（无数据） | 用户摘要为空 | 仍展示固定的设置和帮助入口 | 进入设置/帮助 | `M06-RULE-my-entry-scope` |
| 空态（搜索无结果） | 本页不适用 | 本节不适用 | 无 | — |
| 错误态（网络） | 摘要请求失败 | toast + 保留上次入口 | 重试 | `M06-ERR-entry-disabled` |
| 无权限态 | 未登录点击个人入口 | 登录引导 | 去登录 | `GLB-ROLE-visitor` |
| 业务态-认证未完成 | `M01-RULE-core-access` 未开放 | 认证引导卡 | 去认证中心 | `M01-RULE-core-access` |
| 业务态-注销后悔期 | 注销状态 `cooling_off` | 顶部风险提示 | 去隐私设置撤销 | `M06-SM-account-cancellation` |
| 降级态 | PRD-04/07 未就绪 | 隐藏角标或入口施工中 | 查看其他入口 | 跨模块依赖 |

## 8. 查询与列表

- **默认排序**：入口按客户端固定顺序展示。
- **可选排序**：无。
- **分页**：不分页。
- **分页方式**：不适用。
- **列表轮询/实时刷新**：不轮询，下拉刷新。
- **批量选择**：不支持。
- **列表为空时引导**：展示基础入口和帮助客服。

## 9. 验收标准

| AC ID | 场景 | 类型 | 优先级 |
|-------|------|------|--------|
| `APP-06-AC-my-login-state` | 未登录用户进入我的页 | 正常 | P0 |
| `APP-06-AC-my-cert-guide` | 未完成三重认证展示引导 | 正常 | P0 |
| `APP-06-AC-my-entry-scope` | 超范围入口不展示 | 正常 | P0 |
| `APP-06-AC-my-dependency-fallback` | 跨模块未就绪时降级 | 异常 | P1 |

```text
AC-ID: APP-06-AC-my-entry-scope
Given 一期固定入口清单不包含通知设置、安全中心、关键词屏蔽
When  用户进入我的页
Then  页面不展示这些入口，只展示 `APP-06_端内定义` 已列入一期的入口
```

```text
AC-ID: APP-06-AC-my-login-state
Given 用户未登录
When  用户进入我的页
Then  页面展示访客卡片和公开入口，点击个人数据入口时引导登录，不请求仅本人可见资产数据
```

```text
AC-ID: APP-06-AC-my-cert-guide
Given 用户已登录但三重认证未全部通过
When  用户进入我的页
Then  页面展示认证引导卡和认证中心入口，核心互动入口按 PRD-01 准入规则提示补齐认证
```

```text
AC-ID: APP-06-AC-my-dependency-fallback
Given PRD-04 资产服务暂不可用或返回会员/千寻币为空
When  用户进入我的页
Then  页面隐藏会员摘要、千寻币余额和资产角标，其余入口仍可正常展示
```
