## 3. 敏感操作审计要求

| 操作 | 是否二次确认 | 是否记录审计日志 | 审计日志保留 |
|------|--------------|------------------|--------------|
| 修改搜索屏蔽词 | 是 | 是 | >= 1 年 |
| 修改注销后悔期或阻断规则 | 是 | 是 | >= 1 年 |
| 导出反馈/注销列表 | 是 | 是 | >= 1 年 |
| 下线合规文档或协议链接 | 是 | 是 | >= 1 年 |
| 修改入口跳转地址 | 否 | 是 | >= 1 年 |
| 更新反馈处理状态 | 否 | 是 | >= 1 年 |

## 4. UI 空态 / 错误态 / 降级态

| 场景 | 页面表现 | 默认文案 |
|------|----------|----------|
| 反馈箱无数据 | 表格空态 | 暂无反馈 |
| 注销申请无数据 | 表格空态 | 暂无注销申请 |
| 搜索热词无数据 | 表格空态 + 新增入口 | 暂无搜索热词 |
| 搜索屏蔽词无数据 | 表格空态 + 新增入口 | 暂无屏蔽词 |
| 移动端入口未初始化 | 默认配置提示 + 初始化按钮 | 入口配置待初始化 |
| 合规链接缺失 | 风险提示条 | 合规内容未配置 |
| 无权限 | 菜单隐藏或按钮置灰 | 无操作权限 |
| 配置版本冲突 | 弹窗提示刷新 | 配置已被他人修改，请刷新 |
| 字典加载失败 | code 展示 + 重试 | 字典加载失败，请重试 |
