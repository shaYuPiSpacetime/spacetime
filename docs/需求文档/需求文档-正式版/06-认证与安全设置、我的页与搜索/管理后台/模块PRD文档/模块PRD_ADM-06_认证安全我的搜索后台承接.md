## 1. 模块目标

PRD-06 后台侧不新增独立一级系统，沿用用户准入、运营中心、移动端配置管理、用户安全设置等既有菜单，承接我的页/设置页入口配置、反馈箱、注销申请、搜索热词与屏蔽词、公告协议和安全提示内容配置。

**用户故事：** 作为运营、客服或风控人员，我想在既有后台菜单下维护移动端入口、内容、搜索和账号安全信息，以便支撑移动端我的页与设置页上线。

---

| 角色 | 在本模块中做什么 | 引用全局角色 |

## 3. 关键业务流程

### 3.1 入口配置发布流程

```text
运营进入移动端入口配置
-> 编辑我的页或设置页入口
-> 保存前校验路径、排序、状态
-> 系统生成配置版本并记录审计
-> 移动端刷新缓存后生效
```

### 3.2 反馈处理流程

```text
用户提交反馈
-> 后台反馈箱出现 submitted 记录
-> 客服查看详情与附件
-> 标记处理中并填写备注
-> 处理完成或关闭
-> 保留处理记录和审计
```

### 3.3 注销排查流程

```text
用户提交注销申请
-> 后台注销申请列表展示申请、阻断、后悔期状态
-> 客服查看阻断原因、会员/退款/处罚摘要
-> 可填写备注，不代用户直接注销
-> 后悔期结束由系统任务执行
```

### 3.4 搜索配置流程

```text
运营维护热词
风控维护屏蔽词
-> 保存时写配置版本和审计
-> 移动端搜索首页与结果过滤生效
-> 命中屏蔽词时移动端展示违规提示
```

## 6. 边界（本期不做）

| 不做的能力 | 原因 | 本期处理方式 | 后续计划 |
|------------|------|--------------|----------|
| 独立客服工单系统 | 一期只要反馈查看跟进 | 不建 SLA、分单、回复流 | 二期客服系统 |
| 熟人屏蔽后台 | 移动端不做 | 不建菜单 | 二期评估 |
| 搜索运营平台 | 一期只做热词/屏蔽词/基础配置 | 不做算法看板 | PRD-08 后续 |
| 注销审批流 | 一期用户自助申请 + 后悔期 | 后台只查和备注 | 二期审批 |
| 代用户修改隐私/关键词 | 敏感且易引发争议 | 禁止后台代改 | 如需另立授权流程 |

## 10. 非功能性需求

### 10.1 权限

所有页面使用后台 RBAC，接口需 `@RequirePermission`。权限矩阵见 `../ADM-06_端内定义.md`。

### 10.2 安全与合规

| 字段 | 加密存储 | 脱敏规则 | 留存时长 | 注销后处理 | 是否可导出 |
|------|----------|----------|----------|------------|------------|
| 手机号 | 是 | 138****1234 | 按账号合规周期 | 合规留存后匿名化 | 授权导出 |
| 反馈联系方式 | 是 | 邮箱/手机号脱敏 | 1 年或合规要求 | 匿名化 | 授权导出 |
| 注销申请备注 | 否 | 后台可见 | >= 1 年 | 保留审计 | 授权导出 |
| 搜索屏蔽词 | 否 | 后台权限可见 | 长期 | 不受用户注销影响 | 可导出配置 |

### 10.3 性能

- 后台列表默认每页 10 条，可选 10/20/50。
- 搜索热词、屏蔽词配置保存后 1 分钟内刷新缓存。
- 反馈箱和注销申请查询 P95 < 800ms。

### 10.4 并发与幂等

| 操作 | 并发场景 | 幂等方案 |
|------|----------|----------|
| 保存入口配置 | 多运营同时编辑 | 配置版本号乐观锁 |
| 保存搜索屏蔽词 | 重复词条 | word+matchType 唯一 |
| 更新反馈状态 | 多客服同时处理 | 状态版本号 + 处理日志追加 |
| 更新注销备注 | 多人备注 | 备注追加，不覆盖 |

### 10.5 埋点与审计

| 事件 | 触发时机 | 关键参数 |
|------|----------|----------|
| `admin_entry_config_save` | 保存入口配置 | operatorId, version |
| `admin_search_block_save` | 保存屏蔽词 | operatorId, wordCount |
| `admin_feedback_status_change` | 更新反馈状态 | feedbackId, fromStatus, toStatus |
| `admin_cancellation_view` | 查看注销详情 | requestId, operatorId |
