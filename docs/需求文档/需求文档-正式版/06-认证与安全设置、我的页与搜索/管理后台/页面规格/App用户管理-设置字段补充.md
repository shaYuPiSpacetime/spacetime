# 页面规格 - ADM-06-PAGE-app-user-settings-fields App 用户管理-设置字段补充

| 版本 | 日期 | 修改人 | 变更摘要 |
|------|------|--------|----------|
| 版本01 | 2026-07-08 | Codex | 创建页面规格 |

- **页面 ID**：`ADM-06-PAGE-app-user-settings-fields`
- **所属模块 PRD**：`模块PRD_ADM-06_认证安全我的搜索后台承接`
- **页面路由**：复用 PRD-01 `/admin/app-users`
- **入口来源**：用户准入 -> App 用户管理
- **对应设计稿**：当前未绑定蓝湖画板；设计画板按第 2.4 节输出
- **对应移动端 / 技术方案**：APP-06 我的页、设置页、搜索、注销

## 1. 页面定位

- **目标用户**：客服、运营、风控、超管
- **核心任务**：在 PRD-01 App 用户管理中补充 PRD-06 相关筛选、摘要字段和模块补充入口
- **页面类型**：原页面字段补充

## 2. 布局（给 UI）

### 2.1 整体布局

```text
继承 PRD-01 App 用户管理
筛选区：新增注销状态/搜索活跃筛选
卡片区：保留原卡片，不直铺大段设置字段
操作区：模块补充 -> 设置与安全 Tab
```

### 2.2 区块说明

| 区块 | 位置 | 内容 | 是否可折叠 | 是否记住展开状态 |
|------|------|------|------------|------------------|
| 筛选补充 | 原筛选区 | 注销状态、最近搜索活跃 | 否 | 否 |
| 卡片摘要 | 原卡片 | 注销状态小标签、最近搜索时间 | 否 | 否 |
| 模块补充入口 | 卡片操作区 | 打开设置与安全 Tab | 否 | 否 |

### 2.3 弹层 / 抽屉 / 模态

详情在 `ADM-06-PAGE-app-user-settings-section` 的模块补充 Tab 承接，本页不新增独立弹窗。

### 2.4 UI 画板拆分（必填）

| 画板 ID | 画板名称 | 设计内容 | 备注 |
|---------|----------|----------|------|
| `ADM-06-user-fields-01` | App 用户管理-PRD06字段补充 | 原页面筛选和卡片摘要补充 | 原页面补充 |
| `ADM-06-user-fields-02` | App 用户管理-筛选无结果 | 搜索无结果态 | 原页面补充 |

### 2.5 编辑控件口径

本页不提供编辑；客服不得代用户修改隐私、搜索历史、关键词等设置。

## 3. 筛选与搜索

### 3.1 搜索

| 项 | 说明 |
|----|------|
| 搜索框位置 | 继承 PRD-01 App 用户管理筛选区 |
| 搜索字段 | 用户编号、昵称、手机号；新增成家号精确匹配 |
| 搜索方式 | 手机号/成家号精确，昵称模糊 |
| 搜索触发 | 点击查询 |
| 搜索历史 | 后台不保留 |
| 清空搜索 | 重置按钮 |

### 3.2 筛选条件

| 筛选 ID | 筛选名 | 类型 | 选项来源 | 是否多选 | 默认值 | 是否可清除 |
|---------|--------|------|----------|----------|--------|------------|
| `ADM-06-PAGE-app-user-settings-fields-FILTER-cancellation-status` | 注销状态 | 下拉 | `M06-ENUM-cancellation-status` | 否 | 全部 | 是 |
| `ADM-06-PAGE-app-user-settings-fields-FILTER-search-active` | 最近有搜索 | 开关 | 是/否 | 否 | 全部 | 是 |

### 3.3 筛选交互

筛选条件变化后点击查询，分页回到第 1 页。

## 6. 数据联动规则

| 触发字段 | 触发事件 | 影响字段 | 联动行为 | 备注 |
|----------|----------|----------|----------|------|
| 注销状态 | 选择 cooling_off/cancelled | 列表 | 仅展示对应状态用户 | `M06-SM-account-cancellation` |
| 搜索日志摘要 | 异步聚合完成 | 最近搜索时间 | 展示最近 30 天最后一次有效搜索时间；聚合未完成或服务不可用显示 `-` | `searchLogSummary` |

## 7. 状态与异常

| 状态类型 | 触发场景 | 页面表现 | 用户可做的操作 | 引用 |
|----------|----------|----------|----------------|------|
| 加载态 | 查询中 | 继承原页面骨架 | 无 | PRD-01 |
| 空态（无数据） | 无用户 | 原页面空态 | 重置筛选 | ADM 全局态 |
| 空态（搜索无结果） | 筛选无命中 | 表格/卡片空态 | 重置 | ADM 全局态 |
| 错误态（网络） | 查询失败 | toast + 重试 | 重试 | — |
| 无权限态 | 无页面权限 | 菜单隐藏或无权限 | 无 | `ADM-06_端内定义.md` |
| 业务态-注销中 | 用户 cooling_off | 卡片展示注销标签 | 查看详情 | `M06-SM-account-cancellation` |
| 降级态 | 搜索日志服务不可用 | 最近搜索显示 `-` | 继续查看 | 跨模块依赖 |

## 8. 查询与列表

- **默认排序**：继承 PRD-01 创建时间倒序。
- **可选排序**：最近搜索时间、注册时间。
- **分页**：继承 PRD-01 App 用户主列表口径，每页 9 条。
- **分页方式**：传统分页。
- **批量选择**：继承原页面，不新增。

## 9. 验收标准

| AC ID | 场景 | 类型 | 优先级 |
|-------|------|------|--------|
| `ADM-06-AC-user-fields-filter` | 按注销状态筛选 | 正常 | P0 |
| `ADM-06-AC-user-fields-no-edit` | 不允许代改设置 | 正常 | P0 |

```text
AC-ID: ADM-06-AC-user-fields-filter
Given App 用户管理存在注销状态为 `cooling_off`、`cancelled` 和 `none` 的用户
When  后台用户在 PRD-06 补充筛选中选择 `cooling_off` 并点击查询
Then  列表仅展示处于注销后悔期的用户，分页和原页面其他筛选条件保持生效
```

```text
AC-ID: ADM-06-AC-user-fields-no-edit
Given 客服进入 App 用户管理
When  查看 PRD-06 字段补充
Then  页面只提供查询和查看入口，不提供代用户修改隐私设置或搜索历史的操作
```
