# 页面规格 - ADM-06-PAGE-cancellation-list 注销申请

| 版本 | 日期 | 修改人 | 变更摘要 |
|------|------|--------|----------|
| 版本01 | 2026-07-08 | Codex | 创建页面规格 |

- **页面 ID**：`ADM-06-PAGE-cancellation-list`
- **所属模块 PRD**：`模块PRD_ADM-06_认证安全我的搜索后台承接`
- **页面路由**：`/admin/user-safety/cancellations`
- **入口来源**：用户安全设置 -> 注销申请
- **对应设计稿**：当前未绑定蓝湖画板；设计画板按第 2.4 节输出
- **对应移动端 / 技术方案**：`APP-06-PAGE-privacy`、`APP-06-PAGE-cancellation-modal`

## 1. 页面定位

- **目标用户**：客服、风控、超管
- **核心任务**：查看注销申请、阻断原因、后悔期和备注
- **页面类型**：列表页

## 2. 布局（给 UI）

### 2.1 整体布局

```text
筛选栏
注销申请表格
分页
详情抽屉
备注弹窗
```

### 2.2 区块说明

| 区块 | 位置 | 内容 | 是否可折叠 | 是否记住展开状态 |
|------|------|------|------------|------------------|
| 筛选栏 | 顶部 | 用户、状态、申请时间、预计执行时间 | 否 | 否 |
| 表格 | 主体 | 申请编号、用户、状态、阻断、后悔期 | 否 | 是 |
| 详情抽屉 | 右侧 | 风险、资产、退款、处罚摘要、备注 | 否 | 否 |

### 2.3 弹层 / 抽屉 / 模态

| 弹层 | 触发方式 | 大小 | 内容 | 关闭方式 |
|------|----------|------|------|----------|
| 详情抽屉 | 查看详情 | 右侧 760px | 注销详情和备注 | 关闭 |
| 新增备注弹窗 | 点击新增备注 | 中央弹窗 | 备注输入 | 取消/保存 |

### 2.4 UI 画板拆分（必填）

| 画板 ID | 画板名称 | 设计内容 | 备注 |
|---------|----------|----------|------|
| `ADM-06-cancel-01` | 注销申请-列表 | 筛选、表格、分页 | P0 |
| `ADM-06-cancel-02` | 注销申请-详情抽屉 | 阻断、风险、备注 | P0 |
| `ADM-06-cancel-03` | 注销申请-备注弹窗 | 备注表单 | P1 |

### 2.5 编辑控件口径

后台不代用户提交或撤销注销；仅支持客服/风控追加备注。

## 3. 筛选与搜索

### 3.1 搜索

| 项 | 说明 |
|----|------|
| 搜索框位置 | 筛选栏 |
| 搜索字段 | 申请编号、成家号、手机号 |
| 搜索方式 | 精确匹配 |
| 搜索触发 | 点击查询 |
| 搜索历史 | 不保留 |
| 清空搜索 | 重置按钮 |

### 3.2 筛选条件

| 筛选 ID | 筛选名 | 类型 | 选项来源 | 是否多选 | 默认值 | 是否可清除 |
|---------|--------|------|----------|----------|--------|------------|
| `ADM-06-PAGE-cancellation-list-FILTER-status` | 注销状态 | 下拉 | `M06-ENUM-cancellation-status` | 否 | 全部 | 是 |
| `ADM-06-PAGE-cancellation-list-FILTER-request-time` | 申请时间 | 日期范围 | 用户选择 | 否 | 近 30 天 | 是 |
| `ADM-06-PAGE-cancellation-list-FILTER-blocked` | 是否阻断 | 下拉 | 是/否 | 否 | 全部 | 是 |

### 3.3 筛选交互

点击查询后列表回到第 1 页；状态选择 `cooling_off` 时可按预计执行时间排序。

## 4. 字段表

### 4.1 列表字段

| 字段 ID | 显示名 | 类型 | 必填 | 取值范围 | 校验规则 | 默认值 | 可编辑 | 敏感级别 | 数据来源 |
|---------|--------|------|------|----------|----------|--------|--------|----------|----------|
| `ADM-06-PAGE-cancellation-list-FIELD-request-no` | 申请编号 | string | 是 | 业务编号 | 唯一 | 无 | 否 | 普通 | 系统生成 |
| `ADM-06-PAGE-cancellation-list-FIELD-user-code` | 成家号 | string | 是 | 业务编号 | 不展示内部主键 | 无 | 否 | 普通 | PRD-01 |
| `ADM-06-PAGE-cancellation-list-FIELD-phone` | 手机号 | string | 否 | 脱敏手机号 | 无权限脱敏 | `-` | 否 | 敏感 | PRD-01 |
| `ADM-06-PAGE-cancellation-list-FIELD-status` | 注销状态 | enum | 是 | `M06-ENUM-cancellation-status` | 合法状态 | requested | 否 | 敏感 | PRD-06 |
| `ADM-06-PAGE-cancellation-list-FIELD-block-reasons` | 阻断原因 | json[] | 否 | 硬阻断/风险提示 | 列表摘要，详情展开 | 空 | 否 | 敏感 | PRD-04/风控 |
| `ADM-06-PAGE-cancellation-list-FIELD-request-time` | 申请时间 | datetime | 是 | yyyy-MM-dd HH:mm:ss | 系统写入 | 无 | 否 | 普通 | 系统生成 |
| `ADM-06-PAGE-cancellation-list-FIELD-cooling-end` | 预计执行时间 | datetime | 条件必填 | yyyy-MM-dd HH:mm:ss | 后悔期状态必填 | 无 | 否 | 敏感 | PRD-06 |

### 4.2 详情/表单字段

| 字段 ID | 显示名 | 类型 | 必填 | 取值范围 | 校验规则 | 默认值 | 可编辑 | 敏感级别 | 数据来源 |

## 5. 操作表

### 5.1 行级操作

| 操作 ID | 操作名 | 触发条件 | 前置权限 | 二次确认 | 成功态 | 失败态 | 影响（副作用） |
|---------|--------|----------|----------|----------|--------|--------|----------------|
| `ADM-06-PAGE-cancellation-list-ACT-view` | 查看详情 | 任意记录 | 注销查看权限 | 否 | 打开详情弹窗，展示申请、资产风险、后悔期、系统执行记录和备注 | 记录不存在 |
| `ADM-06-PAGE-cancellation-list-ACT-add-remark` | 新增备注 | 记录未归档 | 客服/风控 | 否 | 备注追加并审计 | 保存失败 |

### 5.2 批量操作

本页不支持批量操作。

### 5.3 页面级操作

| 操作 ID | 操作名 | 位置 | 触发条件 | 前置权限 | 二次确认 | 成功态 | 失败态 |
|---------|--------|------|----------|----------|----------|--------|--------|
| `ADM-06-PAGE-cancellation-list-ACT-export` | 导出 | 顶部 | 有查询结果 | 导出授权 | 是 | 创建导出任务 | 权限不足 |

## 6. 数据联动规则

| 触发字段 | 触发事件 | 影响字段 | 联动行为 | 备注 |
|----------|----------|----------|----------|------|
| 注销状态 | cooling_off | 预计执行时间 | 展示倒计时/日期 | `M06-SM-account-cancellation` |
| 阻断原因 | 非空 | 状态标签 | 展示暂不可注销 | `M06-RULE-account-cancellation-check` |
| 后悔期截止 | 定时任务触发 | 注销状态 | 重新校验通过则 `cancelled`；出现新硬阻断则保持 `cooling_off` 并记录暂停和重试时间 | `M06-RULE-cancellation-auto-execute` |

## 7. 状态与异常

| 状态类型 | 触发场景 | 页面表现 | 用户可做的操作 | 引用 |
|----------|----------|----------|----------------|------|
| 加载态 | 查询中 | 表格 loading | 无 | — |
| 空态（无数据） | 无申请 | 表格空态 | 调整筛选 | `M06-SM-account-cancellation` |
| 空态（搜索无结果） | 筛选无结果 | 空态 + 重置 | 重置 | — |
| 错误态（网络） | 查询失败 | toast + 重试 | 重试 | — |
| 无权限态 | 无页面权限 | 菜单隐藏或无权限 | 无 | `ADM-06_端内定义.md` |
| 业务态-后悔期 | cooling_off | 后悔期状态标签 | 查看详情 | `M06-SM-account-cancellation` |
| 降级态 | 资产/退款服务不可用 | 风险摘要显示同步失败 | 稍后刷新 | PRD-04 |

## 8. 查询与列表

- **默认排序**：申请时间倒序。
- **可选排序**：预计执行时间、申请时间。
- **分页**：默认 10 条，可选 10/20/50。
- **分页方式**：传统分页。
- **批量选择**：不支持。

## 9. 验收标准

| AC ID | 场景 | 类型 | 优先级 |
|-------|------|------|--------|
| `ADM-06-AC-cancellation-list` | 查询注销申请 | 正常 | P0 |
| `ADM-06-AC-cancellation-risk` | 展示风险和阻断 | 正常 | P0 |
| `ADM-06-AC-cancellation-no-approve` | 后台不做审批操作 | 正常 | P0 |
| `ADM-06-AC-cancellation-detail` | 详情弹窗字段完整 | 正常 | P0 |
| `ADM-06-AC-cancellation-auto-execute` | 到期由定时任务执行 | 正常/异常 | P0 |

```text
AC-ID: ADM-06-AC-cancellation-no-approve
Given 管理员进入注销申请详情
When  查看后悔期内申请
Then  页面只允许查看和追加备注，不提供代用户立即注销或撤销注销按钮
```
