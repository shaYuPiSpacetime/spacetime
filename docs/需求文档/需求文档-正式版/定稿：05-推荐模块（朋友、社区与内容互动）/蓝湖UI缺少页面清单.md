## 3. 最终产品口径

1. 知音一期只保留悦目、诚意贴和悄悄话破冰；觅知音不纳入一期。
2. 悦目以蓝湖“千寻-知音-悦目”为准：双列展示用户照片、缘分标签、学历学校、在线时间和心动按钮。
3. 诚意贴与动态只区分 `contentType` 和既定审核路径；发布字段、详情字段和互动结构相同，不设置独立标题、正文下限或诚意贴详情画板。
4. 悦目与诚意贴无数据时统一复用蓝湖“缺省页-切图”，文案为“暂无数据”。
5. 诚意贴不设置专属互动门槛画板；未认证复用“千寻-未认证出弹窗”，其他限制复用对应公共状态。
6. 社区更多操作不设置独立置灰不可用画板；不适用动作隐藏，正反动作按最终态切换，请求中使用通用 loading。
7. 发布失败、更多操作结果和内容不可见均复用蓝湖“千寻-成家-热门-发布失败”中央半透明灰色反馈层，按实际结果替换文案。
8. 动态提交成功后直接进入“我的动态”；待复核和驳回状态展示在对应动态卡片，不弹业务结果提示。
9. 图片全屏预览复用客户端通用组件；单图“上传成功”只表示文件上传完成。
10. 本期不提供 @Ta、收藏或切换城市功能；PRD-01 将现居城市设为固定必填，存量空值用户补录后才能进入核心页面。
11. 热门话题字段以 UI 稿为准，展示参与头像和浏览量；内容术语统一使用“诚意贴”。
12. 话题列表不设置搜索框、话题分区或最新帖子预览；话题停用只影响新发布选择，详情继续展示发布时快照。
13. 未建立互动关系时展示“申请认识”并打开 `APP-05-greeting-01` 对应的 `YO悄悄话-弹窗`；关系建立后隐藏该入口，消息动作直接进入 PRD-03 会话。
14. 婚恋用户主页与个人动态区他人主页为同一页面。
15. 内容举报使用“选择举报原因”弹窗，点击原因直接提交；重复举报只指同一举报人对同一对象类型和同一对象编号再次提交。
16. 取消关注确认复用蓝湖“千寻-成家-取消关注”，展示“温馨提示 / 确定取消关注吗？”及取消、确定按钮。
17. 点赞、评论用户空态复用通用互动空态；千寻币确认、余额不足和充值入口由模块 08 提供。
