## 1. 信息架构（菜单 / 页面树）

| 一级菜单 | 参考后台菜单名 | 一期承接页面 / 区块 | 页面 ID | 一句话职责 | 优先级 |
|----------|----------------|------------------|---------|------------|--------|
| 社区互动管理 | 内容与动态管理 -> 内容管理 | 内容管理 | `ADM-05-PAGE-content-manage` | 查询动态、诚意贴等社区内容，在详情抽屉内执行通过、驳回、下架和恢复 | P0 |
| 社区互动管理 | 内容与动态管理 -> 动态管理 | 动态管理 | `ADM-05-PAGE-moment-manage` | 独立管理普通动态流，查看媒体、分发、互动和展示状态，在详情抽屉内处理 | P0 |
| 社区互动管理 | 内容与动态管理 -> 评论管理 | 评论管理 | `ADM-05-PAGE-comment-audit` | 查询评论与回复，列表进入详情抽屉后处理屏蔽、恢复和复核 | P0 |
| 社区互动管理 | 内容与动态管理 -> 举报管理 | 举报处理 | `ADM-05-PAGE-report-handle` | 统一处理内容、评论、用户和聊天来源举报 | P0 |
| 社区互动管理 | 内容与动态管理 -> 话题管理 | 家园话题管理 | `ADM-05-PAGE-topic-manage` | 维护家园话题名称、简介、封面、排序、状态、推荐标记和内容统计 | P0 |
| 社区互动管理 | 内容与动态管理 -> 审核规则配置 | 社区配置 | `ADM-05-PAGE-community-config` | 配置社区 Tab、举报原因、发布规则、联系方式开关、抽检比例和审核规则 | P0 |

### 1.1 参考菜单映射口径

| 映射项 | 一期处理方式 |
|--------|--------------|
| 内容管理 | 承接到 `ADM-05-PAGE-content-manage`，覆盖社区内容列表、详情抽屉和内容处理 |
| 动态管理 | 承接到 `ADM-05-PAGE-moment-manage`，只管理普通动态流的分发、互动和展示状态 |
| 评论管理 | 承接到 `ADM-05-PAGE-comment-audit` |
| 举报管理 | 承接到 `ADM-05-PAGE-report-handle` |
| 话题管理 | 承接到 `ADM-05-PAGE-topic-manage`；若参考后台无独立菜单，则在社区互动管理中新增二级菜单 |
| 审核规则配置 | 承接到 `ADM-05-PAGE-community-config`，仅维护社区内容相关规则 |

## 2. 角色与权限矩阵

### 2.1 角色引用

| 角色 code | 显示名 | 本模块中承担的职责 |
|-----------|--------|-------------------|
| `GLB-ROLE-operation` | 运营 | 管理话题、配置社区入口和空态文案，查看内容表现 |
| `GLB-ROLE-auditor` | 审核员 | 处理内容审核、评论审核和举报 |
| `GLB-ROLE-customer-service` | 客服 | 查看授权范围内的内容、评论和举报记录，协助用户申诉和排查 |
| `GLB-ROLE-risk` | 风控 | 处理高风险举报、禁言周期、IP 封禁和冻结联动 |
| `GLB-ROLE-super-admin` | 超级管理员 | 配置高风险开关、恢复内容、查看完整审计 |

### 2.3 敏感操作审计要求

| 操作 | 是否二次确认 | 是否记录审计日志 | 审计日志保留 |
|------|-------------|-----------------|-------------|
| 驳回内容/评论 | 否 | 是 | >= 1 年 |
| 下架内容/屏蔽评论 | 是 | 是 | >= 1 年 |
| 恢复内容/恢复评论 | 是 | 是 | >= 1 年 |
| 举报成立并处罚 | 是 | 是 | >= 1 年 |
| 禁言用户 | 是，必须选择禁言周期 | 是 | >= 1 年 |
| IP 封禁/解除 IP 封禁 | 是，必须填写周期、范围和原因 | 是 | >= 1 年 |
| 启用/停用家园话题 | 是 | 是 | >= 1 年 |
| 编辑家园话题展示配置 | 否 | 是 | >= 1 年 |
| 修改联系方式开关 | 是 | 是 | >= 1 年 |
| 修改 IP 封禁开关或周期选项 | 是 | 是 | >= 1 年 |
| 导出审核/举报记录 | 是 | 是 | >= 1 年 |

## 3. UI 空态 / 错误态 / 降级态

| 场景 | 表现 | 默认文案 |
|------|------|----------|
| 内容管理列表无数据 | 表格空态 | 暂无社区内容 |
| 动态管理列表无数据 | 表格空态 | 暂无动态记录 |
| 评论管理列表无数据 | 表格空态 | 暂无评论记录 |
| 举报处理列表无数据 | 表格空态 | 暂无举报记录 |
| 家园话题列表无数据 | 表格空态 + 新增入口 | 暂无家园话题 |
| 社区配置未初始化 | 展示默认配置并提示保存 | 社区配置待初始化 |
| 无权限 | 菜单隐藏或按钮置灰 | 无操作权限 |
| 审核并发冲突 | toast + 刷新按钮 | 记录已被处理，请刷新 |
| 内容安全服务不可用 | 审核页展示服务异常标记 | 内容安全服务暂不可用 |
| 字典加载失败 | 显示 code 与重试入口 | 字典加载失败，请重试 |
