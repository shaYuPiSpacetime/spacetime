- **页面 ID**：`APP-05-PAGE-topic-list`
- **所属模块 PRD**：`模块PRD_APP-05_推荐模块（朋友、社区与内容互动）`
- **页面路由**：`/pages/qianxun/community/topics`
- **入口来源**：千寻 -> 成家 -> 话题
- **对应设计稿**：[蓝湖社区话题列表及通用空态](https://lanhuapp.com/web/#/item/project/stage?tid=428e8368-c279-4369-947b-a5828487924d&pid=d9c9e50f-fee5-47ca-bd6b-ae05c0d5332b)
- **对应移动端 / 技术方案**：`MVP-PAGE-008`

## 1. 页面定位

- **目标用户**：已登录用户
- **核心任务**：浏览后台启用话题并进入话题详情
- **页面类型**：列表页

## 2. 布局（给 UI）

### 2.1 整体布局

```
┌────────────────────┐
│       话题标题        │
├────────────────────┤
│ 话题卡片列表          │
└────────────────────┘
```

### 2.2 区块说明

| 区块 | 位置 | 内容 | 是否可折叠 | 是否记住展开状态 |
|------|------|------|------------|------------------|
| 页面标题 | 顶部 | 话题 | 否 | 否 |
| 话题列表 | 主体 | 后台启用话题的连续卡片列表 | 否 | 是 |

### 2.3 弹层 / 抽屉 / 模态

本页无弹层；话题详情由 `APP-05-PAGE-topic-detail` 承接。

### 2.4 UI 画板拆分（必填）

| 画板 ID | 画板名称 | 设计内容 | 备注 |
|---------|----------|----------|------|
| `APP-05-topic-list-01` | 话题列表-主页面 | 后台启用话题连续列表 | 无搜索框、无分区、无最新帖子预览 |
| `APP-05-topic-list-03` | 话题列表-暂无数据 | 复用“缺省页-切图”，文案“暂无数据” | 通用空态已有稿 |

### 2.5 编辑控件口径

本页为展示页，无编辑控件。

## 3. 筛选与搜索

### 3.1 搜索

本页不提供搜索框。

### 3.2 筛选条件

本页不提供前台筛选；仅返回后台启用话题。

### 3.3 筛选交互

本页无筛选交互，列表按服务端排序连续展示。

## 4. 字段表

### 4.1 列表字段

| 字段 ID | 显示名 | 类型 | 必填 | 取值范围 | 校验规则 | 默认值 | 可编辑 | 敏感级别 | 数据来源 |
|---------|--------|------|------|----------|----------|--------|--------|----------|----------|
| `APP-05-PAGE-topic-list-FIELD-cover` | 话题封面 | image | 是 | 图片 URL | 加载失败显示平台默认封面图；不得用话题名称或文字块替代 | 默认封面图片 | 否 | 普通 | 后台配置 |
| `APP-05-PAGE-topic-list-FIELD-name` | 话题名称 | string | 是 | 1-20 字 | 后台唯一 | 无 | 否 | 普通 | `M05-CFG-topic-dict` |
| `APP-05-PAGE-topic-list-FIELD-desc` | 话题简介 | string | 否 | 0-60 字 | 超出省略 | 无 | 否 | 普通 | 后台配置 |
| `APP-05-PAGE-topic-list-FIELD-content-count` | 内容数 | int | 是 | >=0 | 系统计算 | 0 | 否 | 普通 | 系统计算 |
| `APP-05-PAGE-topic-list-FIELD-hot` | 热度 | int | 否 | >=0 | 系统计算 | 0 | 否 | 普通 | 系统计算 |
| `APP-05-PAGE-topic-list-FIELD-status` | 话题状态 | enum | 是 | 启用/停用 | 停用不展示新增入口 | 启用 | 否 | 普通 | 后台配置 |

#### 列表字段附加属性

| 字段 ID | 默认排序 | 是否可排序 | 列宽 | 是否固定 | 是否可拖拽调整列宽 | 溢出处理 |
|---------|----------|------------|------|----------|--------------------|----------|
| `APP-05-PAGE-topic-list-FIELD-hot` | desc | 否 | 自适应 | 否 | 否 | 省略号 |

### 4.2 详情/表单字段

本页不展示详情表单；详情字段见 `APP-05-PAGE-topic-detail`。

## 5. 操作表

### 5.1 行级操作

| 操作 ID | 操作名 | 触发条件 | 前置权限 | 二次确认 | 成功态 | 失败态 | 影响（副作用） |
|---------|--------|----------|----------|----------|--------|--------|----------------|
| `APP-05-PAGE-topic-list-ACT-open-topic` | 查看话题 | 话题启用 | `GLB-ROLE-app-user` | 否 | 跳转话题详情页 | 话题已下线提示 | 增加话题浏览 |

### 5.2 批量操作

本页不支持批量操作。

### 5.3 页面级操作

| 操作 ID | 操作名 | 位置 | 触发条件 | 前置权限 | 二次确认 | 成功态 | 失败态 |
|---------|--------|------|----------|----------|----------|--------|--------|
| `APP-05-PAGE-topic-list-ACT-refresh` | 刷新 | 下拉 | 页面加载成功 | `GLB-ROLE-app-user` | 否 | 列表刷新 | 网络错误 toast |

## 6. 数据联动规则

本页无前台筛选联动；后台话题启停或排序变化后，刷新列表读取服务端最终结果。

## 7. 状态与异常

| 状态类型 | 触发场景 | 页面表现 | 用户可做的操作 | 引用 |
|----------|----------|----------|----------------|------|
| 加载态 | 首次进入 | 骨架屏 | 无 | — |
| 空态（无数据） | 无启用话题或列表请求未返回可展示数据 | 复用“缺省页-切图” + “暂无数据” | 返回 | `M05-CFG-topic-dict` |
| 空态（搜索无结果） | 本页无搜索 | 本节不适用 | — | — |
| 错误态（网络） | 请求超时 | 保持当前页并展示“暂无数据”，不直接展示失败原因或重试按钮 | 返回 | `M05-ERR-*` |
| 无权限态 | 未登录 | 登录引导 | 去登录 | `GLB-ROLE-app-user` |
| 业务态-启用 | 话题启用 | 正常展示 | 查看详情 | `M05-CFG-topic-dict` |
| 降级态 | 话题封面失败 | 平台默认封面图 | 继续浏览 | `M05-RULE-topic-cover-image` |

## 8. 查询与列表

- **默认排序**：后台排序值升序，同排序值按热度倒序
- **可选排序**：无
- **分页**：默认 20 条
- **分页方式**：下拉刷新 + 上拉加载更多
- **列表轮询/实时刷新**：不轮询
- **批量选择**：不支持
- **列表为空时的引导**：返回社区热门页

| AC ID | 场景 | 类型 | 优先级 |

| `APP-05-AC-topic-offline` | 话题下线后不可进入新增参与 | 异常 | P0 |


## 10. 关联

| 关联类型 | 引用 ID | 说明 |
|----------|---------|------|
| 依赖的模块配置项 | `M05-CFG-topic-dict` | 话题来源 |

| 依赖的其他页面 | `APP-05-PAGE-topic-detail` | 话题详情 |

## 11. 蓝湖最终字段口径

话题卡仅展示封面、名称、简介、内容数和热度；不展示最新帖子预览。列表不提供搜索框，也不拆分“推荐话题/全部话题”。
