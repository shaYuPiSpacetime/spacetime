- **页面 ID**：`APP-05-PAGE-community-hot`
- **所属模块 PRD**：`模块PRD_APP-05_推荐模块（朋友、社区与内容互动）`

- **入口来源**：千寻 -> 成家 -> 热门
- **对应设计稿**：[蓝湖“千寻-成家-热门”页面组](https://lanhuapp.com/web/#/item/project/stage?tid=428e8368-c279-4369-947b-a5828487924d&pid=d9c9e50f-fee5-47ca-bd6b-ae05c0d5332b)

- **补充承接**：`MVP-PAGE-004` 家园话题模块 / 话题入口作为本页 Tab/入口区承接；点击后进入 `APP-05-PAGE-topic-list`，目标页对应 `MVP-PAGE-008`

## 1. 页面定位

- **目标用户**：已登录用户
- **核心任务**：浏览近期互动热度较高的公开内容
- **页面类型**：信息流列表页

## 2. 布局（给 UI）

### 2.1 整体布局

```
┌────────────────────┐
│ 热门标题             │
├────────────────────┤
│ 关注 同城 热门 话题  │
├────────────────────┤
│ 热门内容卡片列表      │
└───────────发布按钮──┘
```

### 2.2 区块说明

| 区块 | 位置 | 内容 | 是否可折叠 | 是否记住展开状态 |
|------|------|------|------------|------------------|
| 热门说明 | 顶部 | 热门标题与内容列表 | 否 | 否 |
| 话题入口区 | 顶部 Tab/入口 | 家园话题入口横向卡片，展示话题名称、参与头像、参与人数和浏览量；点击进入话题列表页 | 否 | 否 |
| 内容流 | 主体 | 热门公开内容 | 否 | 是 |
| 发布按钮 | 右下角 | 进入发布动态页 | 否 | 否 |

### 2.3 弹层 / 抽屉 / 模态

| 弹层 | 触发方式 | 大小 | 内容 | 关闭方式 |
|------|----------|------|------|----------|
| 更多操作弹窗 | 点击卡片更多 | 底部弹窗 | 分享、关注/取消关注、不看 TA 动态/取消不看、举报 | 点击取消/遮罩 |
| 图片预览 | 点击图片 | 全屏 | 图片轮播预览 | 点击关闭 |

### 2.4 UI 画板拆分（必填）

| 画板 ID | 画板名称 | 设计内容 | 备注 |
|---------|----------|----------|------|
| `APP-05-hot-01` | 成家热门信息流-主页面 | 按 UI 稿展示热门内容卡和作者信息 | |
| `APP-05-hot-04` | 成家热门信息流-话题入口区 | 话题名称、参与头像、参与人数、浏览量；术语统一为“诚意贴” | MVP-PAGE-004 |
| `APP-05-hot-03` | 成家热门信息流-空态 | 复用“缺省页-切图”，文案“暂无数据” | 通用空态已有稿 |

图片全屏预览是图片点击后的通用运行态能力，复用客户端图片预览组件，不单独要求 UI 画板。

### 2.5 编辑控件口径

本页为信息流展示页，无表单编辑。

| 操作 ID | 操作名 | 触发条件 | 前置权限 | 二次确认 | 成功态 | 失败态 | 影响（副作用） |

## 6. 数据联动规则

| 触发字段 | 触发事件 | 影响字段 | 联动行为 | 备注 |
|----------|----------|----------|----------|------|
| 点赞状态 | 点击点赞 | 点赞态、点赞数 | 成功后更新卡片显示 | 以服务端最终状态为准 |
| 内容状态 | 下架/删除 | 内容卡片 | 从列表移除或刷新后不再返回 | `M05-SM-content-audit` |
| 评论状态 | 评论被屏蔽/删除 | 评论数 | 下次列表刷新或详情返回时按服务端统计数更新 | 允许短暂缓存不一致 |
| 话题入口区 | 点击 | 页面跳转 | 进入 `APP-05-PAGE-topic-list` | 入口区承接 `MVP-PAGE-004`，目标页对应 `MVP-PAGE-008`；入口区必须展示实际话题卡片，不得仅展示说明文案 |

## 7. 状态与异常

| 状态类型 | 触发场景 | 页面表现 | 用户可做的操作 | 引用 |
|----------|----------|----------|----------------|------|
| 加载态 | 首次进入 | 骨架屏 | 无 | — |
| 空态（无数据） | 无热门内容 | 复用“缺省页-切图” + “暂无数据” | 下拉刷新 | — |
| 空态（搜索无结果） | 本页无搜索 | 本节不适用 | — | — |
| 错误态（网络） | 请求超时 | toast + 重试 | 重试 | `M05-ERR-*` |
| 无权限态 | 未登录 | 登录引导 | 去登录 | `GLB-ROLE-app-user` |
| 业务态-published | 内容公开 | 正常展示 | 查看、点赞、评论、举报 | `M05-SM-content-audit` |
| 降级态 | 服务端排序结果暂不可用 | 展示已返回内容，不展示热度解释 | 刷新 | `M05-CFG-community-tabs` |

## 8. 查询与列表

- **默认排序**：热度倒序
- **可选排序**：无
- **分页**：默认 20 条
- **分页方式**：下拉刷新 + 上拉加载更多
- **列表轮询/实时刷新**：不轮询
- **批量选择**：不支持
- **列表为空时的引导**：下拉刷新

## 11. 蓝湖反向缺口补充

- 热门内容卡补充作者出生年、城市、职业、活跃描述、评论预览与“查看全部”入口。
- 家园话题入口卡按蓝湖最终稿展示最多 3 个 `participantAvatars`、`participantCount` 和 `viewCount`，不展示最新帖子预览。
- 未建立互动关系时，作者区“申请认识”打开 `YO悄悄话-弹窗`；更多操作只提供作者级“不看 TA 动态/取消不看”。

术语验收：所有内容类型文案统一使用“诚意贴”，不得使用“真诚交友帖”。
