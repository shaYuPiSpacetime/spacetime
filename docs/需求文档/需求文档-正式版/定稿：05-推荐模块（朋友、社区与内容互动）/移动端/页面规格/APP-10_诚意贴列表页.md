# 页面规格 - APP-05-PAGE-sincere-list 诚意贴列表页

| 版本 | 日期 | 修改人 | 变更摘要 |
|------|------|--------|----------|
| 版本06 | 2026-07-21 | Codex | 以蓝湖“千寻-知音-诚意贴”为准，删除独立标题和热门/最新切换；空态复用通用缺省页，认证与限制场景复用公共反馈 |
| 版本01 | 2026-07-06 | Codex | 创建页面规格 |

- **页面 ID**：`APP-05-PAGE-sincere-list`
- **所属模块 PRD**：`模块PRD_APP-05_推荐模块（朋友、社区与内容互动）`
- **页面路由**：`/pages/qianxun/zhiyin/sincere`
- **入口来源**：千寻 -> 知音 -> 诚意贴
- **对应设计稿**：[蓝湖“千寻-知音-诚意贴”及“缺省页-切图”](https://lanhuapp.com/web/#/item/project/stage?tid=428e8368-c279-4369-947b-a5828487924d&pid=d9c9e50f-fee5-47ca-bd6b-ae05c0d5332b)
- **对应移动端 / 技术方案**：`MVP-PAGE-015`

## 1. 页面定位

- **目标用户**：已登录用户
- **核心任务**：浏览诚意贴并进行关注、申请认识、评论、点赞或发布
- **页面类型**：列表页

## 2. 布局（给 UI）

### 2.1 整体布局

```
┌────────────────────┐
│ 悦目｜诚意贴          │
├────────────────────┤
│ 作者资料   关注  更多  │
│ 正文 / 查看全部       │
│ 图片                 │
│ 活跃时间  #话题       │
│ 申请认识 评论 点赞     │
│                ＋发布 │
└────────────────────┘
```

### 2.2 区块说明

| 区块 | 位置 | 内容 | 是否可折叠 | 是否记住展开状态 |
|------|------|------|------------|------------------|
| 知音 Tab | 顶部 | 悦目、诚意贴，诚意贴选中 | 否 | 是 |
| 内容列表 | 主体 | 作者资料、正文、图片、活跃时间、话题和互动操作 | 否 | 是 |
| 发布入口 | 右下悬浮 | “+”发布按钮 | 否 | 否 |

诚意贴卡片与普通动态使用同一内容字段和互动规则；列表可截断正文并展示“查看全部”，不设置独立标题。

### 2.3 弹层 / 抽屉 / 模态

| 弹层 | 触发方式 | 大小 | 内容 | 关闭方式 |
|------|----------|------|------|----------|
| 更多操作弹窗 | 点击更多 | 底部弹窗 | 分享、关注/取消关注、不看 TA 动态/取消不看、举报 | 点击取消/遮罩 |
| 未认证提示 | 未认证用户点击发布或互动 | 底部弹窗 | 复用蓝湖“千寻-未认证出弹窗” | 关闭/立即认证 |

认证审核中、驳回、失效、账号异常、禁言或 IP 限制均复用 PRD-01 或模块通用状态，不新增诚意贴专属画板。

### 2.4 UI 画板拆分（必填）

| 画板 ID | 画板名称 | 设计内容 | 备注 |
|---------|----------|----------|------|
| `APP-05-sincere-list-01` | 诚意贴列表-主页面 | 与动态同字段结构的诚意贴卡片列表 | 蓝湖稿完整覆盖，以 UI 稿为准 |
| `APP-05-sincere-list-02` | 诚意贴列表-空态 | 暂无数据 | 复用蓝湖“缺省页-切图”，不新增诚意贴专属画板 |

不设置 `APP-05-sincere-list-03` 独立互动门槛画板。

### 2.5 编辑控件口径

本页为展示页；发布入口进入 `APP-05-PAGE-post-publish` 并带入 `contentType=sincere_post`。

## 3. 筛选与搜索

本页不提供搜索、热门/最新切换或其他用户可见分区。服务端固定返回 `contentType=sincere_post` 的公开内容。

## 4. 字段表

### 4.1 列表字段

| 字段 ID | 显示名 | 类型 | 必填 | 取值范围 | 校验规则 | 默认值 | 可编辑 | 敏感级别 | 数据来源 |
|---------|--------|------|------|----------|----------|--------|--------|----------|----------|
| `APP-05-PAGE-sincere-list-FIELD-author-avatar` | 作者头像 | image | 是 | 已审核图片 URL | 加载失败展示平台默认头像 | 默认头像 | 否 | 普通 | PRD-01 用户资料 |
| `APP-05-PAGE-sincere-list-FIELD-author` | 作者昵称 | string | 是 | 1-20 字 | 已审核 | 平台用户 | 否 | 普通 | PRD-01 用户资料 |
| `APP-05-PAGE-sincere-list-FIELD-author-profile` | 作者摘要 | string | 否 | 出生年·城市·职业 | 缺失字段逐项隐藏 | 无 | 否 | 普通 | PRD-01 用户资料 |
| `APP-05-PAGE-sincere-list-FIELD-content` | 正文 | string | 是 | 1-500 字 | 与普通动态相同；列表超长截断 | 无 | 否 | 普通 | 社区内容 |
| `APP-05-PAGE-sincere-list-FIELD-images` | 图片 | image[] | 否 | 0-9 张 | 已审核图片 | 无 | 否 | 普通 | 社区内容 |
| `APP-05-PAGE-sincere-list-FIELD-active-text` | 活跃时间 | string | 是 | 相对时间 | 服务端生成 | 暂无活跃记录 | 否 | 普通 | 在线状态服务 |
| `APP-05-PAGE-sincere-list-FIELD-topic` | 话题 | enum | 是 | 发布时话题快照 | 停用后仍展示快照名 | 无 | 否 | 普通 | 社区内容快照 |
| `APP-05-PAGE-sincere-list-FIELD-comment-count` | 评论数 | int | 是 | >=0 | 系统计算 | 0 | 否 | 普通 | 系统计算 |
| `APP-05-PAGE-sincere-list-FIELD-like-count` | 点赞数 | int | 是 | >=0 | 系统计算 | 0 | 否 | 普通 | 系统计算 |

### 4.2 详情/表单字段

详情由 `APP-05-PAGE-post-detail` 按与普通动态相同的结构承接，仅 `contentType=sincere_post` 不同。

## 5. 操作表

### 5.1 行级操作

| 操作 ID | 操作名 | 触发条件 | 前置权限 | 二次确认 | 成功态 | 失败态 | 影响（副作用） |
|---------|--------|----------|----------|----------|--------|--------|----------------|
| `APP-05-PAGE-sincere-list-ACT-open-detail` | 查看全部/查看详情 | 内容状态 `published` | `GLB-ROLE-app-user` | 否 | 进入统一动态详情 | 内容不可见通用反馈 | 增加浏览 |
| `APP-05-PAGE-sincere-list-ACT-follow` | 关注/取消关注 | 作者不是本人 | `M05-RULE-interaction-gate` | 否 | 更新最终关注态 | 复用认证或通用失败反馈 | 更新社区弱关系 |
| `APP-05-PAGE-sincere-list-ACT-greeting` | 申请认识 | 未建立互动关系 | `M05-RULE-community-greeting-entry` | 否 | 打开 `YO悄悄话-弹窗` | 目标不可用反馈 | 记录来源内容 |
| `APP-05-PAGE-sincere-list-ACT-comment` | 评论 | 内容公开 | `M05-RULE-interaction-gate` | 否 | 进入详情评论区 | 复用认证或通用失败反馈 | 评论由详情页提交 |
| `APP-05-PAGE-sincere-list-ACT-like` | 点赞/取消点赞 | 内容公开 | `M05-RULE-interaction-gate` | 否 | 更新点赞最终态 | 复用认证或通用失败反馈 | 触发点赞事件 |
| `APP-05-PAGE-sincere-list-ACT-more` | 更多 | 内容公开 | `GLB-ROLE-app-user` | 否 | 打开社区更多操作 | 内容不可见通用反馈 | 无 |

### 5.2 页面级操作

| 操作 ID | 操作名 | 位置 | 触发条件 | 前置权限 | 二次确认 | 成功态 | 失败态 |
|---------|--------|------|----------|----------|----------|--------|--------|
| `APP-05-PAGE-sincere-list-ACT-publish` | 发布诚意贴 | 右下悬浮按钮 | 页面加载成功 | `M05-RULE-interaction-gate` | 否 | 进入同结构发布表单并带入 `sincere_post` | 未认证复用“千寻-未认证出弹窗”；其他限制复用通用反馈 |
| `APP-05-PAGE-sincere-list-ACT-refresh` | 刷新 | 下拉 | 页面加载成功 | `GLB-ROLE-app-user` | 否 | 列表刷新 | 通用网络反馈 |

## 6. 数据联动规则

| 触发字段 | 触发事件 | 影响字段 | 联动行为 | 备注 |
|----------|----------|----------|----------|------|
| 关注态 | 点击关注 | 关注按钮 | 按服务端最终态切换关注/已关注 | 幂等 |
| 点赞态 | 点击点赞 | 点赞图标/点赞数 | 按服务端最终态更新 | 幂等 |
| 互动关系 | 页面返回/刷新 | 申请认识 | 关系已建立后隐藏，显式消息动作直达 PRD-03 | `M05-RULE-community-contact-routing` |
| 发布入口 | 点击 | 发布表单 | 带入 `contentType=sincere_post`，字段结构与动态一致 | `M05-RULE-sincere-post` |

## 7. 状态与异常

| 状态类型 | 触发场景 | 页面表现 | 用户可做的操作 | 引用 |
|----------|----------|----------|----------------|------|
| 加载态 | 首次进入 | 卡片骨架 | 等待 | 通用态 |
| 空态（无数据） | 无诚意贴 | 复用蓝湖“缺省页-切图”，文案“暂无数据” | 发布诚意贴 | 通用空态 |
| 错误态（网络） | 请求超时 | 通用反馈 | 重试 | `M05-ERR-*` |
| 无权限态-未认证 | 未完成认证且点击互动/发布 | 复用蓝湖“千寻-未认证出弹窗” | 立即认证/关闭 | PRD-01 |
| 无权限态-其他 | 认证审核中/驳回/失效、账号异常、禁言或 IP 限制 | 复用对应公共状态或限制反馈 | 按公共流程处理 | PRD-01 / `M05-RULE-ip-block` |
| 业务态-published | 内容公开 | 正常展示 | 详情、关注、申请认识、评论、点赞、更多 | `M05-SM-content-audit` |
| 降级态 | 图片加载失败 | 图片占位，文字和操作保留 | 继续浏览 | 通用图片降级 |

## 8. 查询与列表

- **默认排序**：服务端默认顺序
- **可选排序**：无
- **分页**：默认 20 条，滚动加载更多
- **列表轮询/实时刷新**：不轮询
- **批量选择**：不支持
- **列表为空时的引导**：通用“暂无数据”与发布入口

| AC ID | 场景 | 类型 | 优先级 |

| `APP-05-AC-sincere-open-detail` | 点击正文进入同结构动态详情 | 正常 | P0 |
| `APP-05-AC-sincere-empty` | 无数据复用通用缺省页 | 空态 | P1 |

```
AC-ID: APP-05-AC-sincere-list
Given 用户已登录且存在公开诚意贴
When  进入诚意贴列表页

```
