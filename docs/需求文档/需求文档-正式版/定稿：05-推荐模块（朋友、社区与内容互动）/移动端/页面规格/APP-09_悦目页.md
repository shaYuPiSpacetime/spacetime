# 页面规格 - APP-05-PAGE-yuemu 悦目页

| 版本 | 日期 | 修改人 | 变更摘要 |
|------|------|--------|----------|
| 版本06 | 2026-07-21 | Codex | 以蓝湖“千寻-知音-悦目”为准，将页面调整为用户照片发现卡；空态统一复用“缺省页-切图” |
| 版本01 | 2026-07-06 | Codex | 创建页面规格 |

- **页面 ID**：`APP-05-PAGE-yuemu`
- **所属模块 PRD**：`模块PRD_APP-05_推荐模块（朋友、社区与内容互动）`
- **页面路由**：`/pages/qianxun/zhiyin/yuemu`
- **入口来源**：千寻 -> 知音 -> 悦目
- **对应设计稿**：[蓝湖“千寻-知音-悦目”及“缺省页-切图”](https://lanhuapp.com/web/#/item/project/stage?tid=428e8368-c279-4369-947b-a5828487924d&pid=d9c9e50f-fee5-47ca-bd6b-ae05c0d5332b)
- **对应移动端 / 技术方案**：`MVP-PAGE-014`

## 1. 页面定位

- **目标用户**：已登录用户
- **核心任务**：浏览匹配当前用户的照片用户卡片，查看缘分信息并表达心动
- **页面类型**：双列发现列表页

## 2. 布局（给 UI）

### 2.1 整体布局

```
┌────────────────────┐
│ 悦目｜诚意贴          │
│ 发现志同道合的朋友…   │
├────────────────────┤
│ 用户照片卡 │ 用户照片卡 │
│ 缘分标签   │ 缘分标签   │
│ 学历学校   │ 学历学校   │
│ 在线时间 ♥ │ 在线时间 ♥ │
└────────────────────┘
```

### 2.2 区块说明

| 区块 | 位置 | 内容 | 是否可折叠 | 是否记住展开状态 |
|------|------|------|------------|------------------|
| 知音 Tab | 顶部 | 悦目、诚意贴，悦目选中 | 否 | 是 |
| 引导文案 | Tab 下方 | “发现志同道合的朋友，即刻交流” | 否 | 否 |
| 用户卡片流 | 主体 | 双列照片、缘分标签、学历学校、在线时间和心动按钮 | 否 | 是 |

卡片图片区域按蓝湖固定双列卡片比例展示，文字与心动按钮使用真实组件绘制，不烘焙进图片。

### 2.3 弹层 / 抽屉 / 模态

本页不新增专属弹层。未满足心动准入时复用 PRD-01 通用认证状态；点击卡片进入统一他人主页。

### 2.4 UI 画板拆分（必填）

| 画板 ID | 画板名称 | 设计内容 | 备注 |
|---------|----------|----------|------|
| `APP-05-yuemu-01` | 悦目-主页面 | 双列用户照片发现卡 | 蓝湖稿完整覆盖，以 UI 稿为准 |
| `APP-05-yuemu-03` | 悦目-空态 | 暂无数据 | 复用蓝湖“缺省页-切图”，不新增专属画板或刷新按钮 |

### 2.5 编辑控件口径

本页为展示页，无编辑控件。

## 3. 筛选与搜索

本页不提供搜索或用户可见筛选。服务端按当前用户资料、双方可见性和账号状态返回候选用户。

## 4. 字段表

### 4.1 列表字段

| 字段 ID | 显示名 | 类型 | 必填 | 取值范围 | 校验规则 | 默认值 | 可编辑 | 敏感级别 | 数据来源 |
|---------|--------|------|------|----------|----------|--------|--------|----------|----------|
| `APP-05-PAGE-yuemu-FIELD-user-id` | 用户编号 | string | 是 | 业务编号 | 不直接展示 | 无 | 否 | 普通 | PRD-01 用户资料 |
| `APP-05-PAGE-yuemu-FIELD-photo` | 展示照片 | image | 是 | 已审核图片 URL | 仅展示审核通过且允许公开的照片，失败时平台默认图 | 默认图 | 否 | 普通 | PRD-01 用户资料 |
| `APP-05-PAGE-yuemu-FIELD-fate-label` | 缘分标签 | string | 是 | 1-20 字 | 服务端返回可解释标签 | 无 | 否 | 普通 | PRD-02 匹配信息 |
| `APP-05-PAGE-yuemu-FIELD-education-school` | 学历学校 | string | 否 | 学历·学校 | 仅展示已审核公开字段，缺失逐项隐藏 | 无 | 否 | 普通 | PRD-01 用户资料 |
| `APP-05-PAGE-yuemu-FIELD-online-text` | 在线时间 | string | 是 | 相对时间 | 服务端生成 | 暂无在线记录 | 否 | 普通 | 在线状态服务 |
| `APP-05-PAGE-yuemu-FIELD-liked` | 心动态 | bool | 是 | true/false | 返回最终关系态 | false | 否 | 普通 | PRD-02 关系服务 |

### 4.2 详情/表单字段

详情由 `APP-05-PAGE-user-posts` 他人主页承接。

## 5. 操作表

| 操作 ID | 操作名 | 触发条件 | 前置权限 | 二次确认 | 成功态 | 失败态 | 影响（副作用） |
|---------|--------|----------|----------|----------|--------|--------|----------------|
| `APP-05-PAGE-yuemu-ACT-open-profile` | 查看用户主页 | 用户仍可见 | `GLB-ROLE-app-user` | 否 | 进入统一他人主页 | 目标不可用提示并移除卡片 | 写 PRD-02 访客记录 |
| `APP-05-PAGE-yuemu-ACT-like` | 心动/取消心动 | 用户仍可见 | PRD-02 心动准入 | 否 | 心动态图标与最终关系态同步 | 复用 PRD-01/02 通用反馈 | 由 PRD-02 处理关系事件 |

## 6. 数据联动规则

| 触发字段 | 触发事件 | 影响字段 | 联动行为 | 备注 |
|----------|----------|----------|----------|------|
| 心动态 | 点击 | 心动按钮 | 以服务端最终态更新；重复点击执行反向操作 | PRD-02 |
| 用户可见性 | 刷新/返回 | 用户卡片 | 不可见用户从列表移除 | 不展示失效卡片 |

## 7. 状态与异常

| 状态类型 | 触发场景 | 页面表现 | 用户可做的操作 | 引用 |
|----------|----------|----------|----------------|------|
| 加载态 | 首次进入 | 双列卡片骨架 | 等待 | 通用态 |
| 空态（无数据） | 无可展示用户 | 复用蓝湖“缺省页-切图”，文案“暂无数据” | 切换诚意贴或稍后再看 | 通用空态 |
| 错误态（网络） | 请求超时 | 通用网络反馈 | 重试 | `M05-ERR-*` |
| 无权限态 | 未登录 | 登录引导 | 去登录 | `GLB-ROLE-app-user` |
| 业务态-normal | 用户可见 | 正常展示照片卡片 | 主页、心动 | `M05-RULE-yuemu-source` |
| 降级态 | 图片加载失败 | 平台默认图，保留其他字段 | 继续浏览 | 通用图片降级 |

## 8. 查询与列表

- **默认排序**：服务端推荐顺序
- **可选排序**：无
- **分页**：默认 20 条，滚动加载更多
- **列表轮询/实时刷新**：不轮询
- **批量选择**：不支持
- **列表为空时的引导**：复用通用“暂无数据”

| AC ID | 场景 | 类型 | 优先级 |

```
AC-ID: APP-05-AC-yuemu-list
Given 用户已登录且服务端返回可展示候选用户
When  进入悦目页
Then  页面按蓝湖双列卡片展示用户照片、缘分标签、学历学校、在线时间和心动按钮，不展示动态作者、点赞数或动态详情入口
```
