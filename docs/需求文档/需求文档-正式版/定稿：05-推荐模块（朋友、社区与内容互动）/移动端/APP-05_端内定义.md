## 2. 登录态与核心准入

| 用户状态 | 可见页面/能力 | 可操作能力 | 不满足时处理 |
|----------|---------------|------------|--------------|
| 未登录 | 可进入入口骨架和登录引导 | 无 | 引导微信登录 |
| 已登录且账号正常 | 可浏览公开动态、话题、悦目、诚意贴；可提交举报 | 浏览、举报 | 涉及互动时按下一行判断 |
| 已登录且满足 `M05-RULE-interaction-gate` | 可参与发布、评论、回复、点赞、关注和申请认识 | 全部本期互动 | 已建立互动关系后的消息动作仍以 `M03-RULE-private-chat-open` 为准 |
| 账号冻结/停用/注销中 | 可按账号规则查看必要历史提示 | 无新增互动 | 展示账号状态提示 |

## 3. 移动端 UI 空态 / 错误态 / 降级态

| 场景 | 页面表现 | 默认文案 |
|------|----------|----------|
| 关注信息流无内容 | 空态 + 推荐去热门浏览 | 还没有关注动态 |
| 同城无内容 | 保留资料城市只读标识，展示刷新和去热门入口 | 当前城市暂时没有新动态 |
| 热门无内容 | 复用蓝湖“缺省页-切图”通用空态 | 暂无数据 |
| 话题列表无数据 | 复用蓝湖“缺省页-切图”通用空态，不区分请求失败 | 暂无数据 |
| 话题详情无内容 | 保留话题快照头，内容区复用通用空态 | 暂无数据 |
| 悦目无内容 | 复用蓝湖“缺省页-切图”通用空态 | 暂无数据 |
| 诚意贴无内容 | 复用蓝湖“缺省页-切图”，保留发布入口 | 暂无数据 |
| 未认证用户点击互动/发布 | 复用蓝湖“千寻-未认证出弹窗” | 你还未认证 |
| 其他准入或限制不满足 | 复用 PRD-01 认证状态、账号状态或模块通用限制反馈，不置灰保留不可用操作 | 按实际原因提示 |
| 内容安全服务异常 | 提交进入人工复核，不在发布页弹业务提示 | 返回“我的动态”查看每条动态的待复核标识 |
| 字典加载失败 | 话题/举报原因显示重试入口 | 数据加载失败，请重试 |
| 图片上传达到上限 | 发布页隐藏添加入口并保留删除 | 最多上传 9 张图片 |
| 悦目加载更多结束 | 滚动加载结束，不显示独立按钮态 | 已加载全部 |
| 已建立互动关系 | 隐藏“申请认识”；头像/昵称进入他人主页，消息动作直接进入 PRD-03 会话 | 进入聊天 |
| 作者头像缺失或加载失败 | 展示平台默认头像图片，不展示姓名、姓氏首字或昵称文字头像 | 头像暂不可用 |
| 关注 Tab 无关注对象 | 空态 + 去热门入口 | 还没有关注任何人 |
| 已关注对象均无公开动态 | 空态 + 刷新入口 | 关注的人还没有发布动态 |
| 图片上传中 | 单图进度态，发布按钮禁用 | 图片上传中，请稍候 |
| 图片上传失败 | 单图失败态，提供重试/删除 | 上传失败，请重试 |
| 再次进入发布页且存在草稿 | 直接恢复同类型最近草稿，不展示确认状态 | 已恢复未发布内容 |
| 放弃发布 | 清除当前类型草稿并直接返回、刷新来源列表 | 不弹确认 |
| 互动历史无数据 | 按当前类型展示独立空态 | 暂无相关互动记录 |
| 点赞用户为空 | 复用通用互动空态 | 暂无点赞 |
| 评论用户为空 | 复用通用互动空态 | 暂无评论 |
| 已设置不看作者动态 | 更多操作显示“取消不看 TA 动态” | 已减少该用户动态推荐 |

## 5. 端内展示规则补充

| 规则 | 适用页面 | 处理 |
|------|----------|------|
| 作者头像 | 信息流、动态详情、话题详情、悦目、诚意贴列表、个人动态区和 YO 悄悄话弹窗 | 引用 `M05-RULE-author-avatar`；头像必须取用户已审核上传头像 URL，禁止用姓名、姓氏首字或昵称文字替代 |
| 信息流作者摘要 | 关注、同城、热门、话题内容卡片 | 展示出生年、城市、职业、活跃描述；缺失字段逐项隐藏，不拼接空分隔符 |
| 信息流评论预览 | 关注、同城、热门、话题内容卡片 | 最多展示最近 2 条公开评论和“查看全部 N 条评论”入口，N=0 时隐藏 |
| 热门话题入口 | 热门信息流页 | 展示话题名称、参与者头像（最多 3 个）、参与人数和浏览量；不展示最新帖子预览 |
| 话题列表 | 话题列表页 | 使用连续列表展示后台启用话题，不提供搜索框、“推荐话题/全部话题”分区或最新帖子预览 |
| 申请认识 | 作者卡片、详情和他人主页 | 未建立互动关系时展示，点击打开模块 08 `YO悄悄话-弹窗`；关系建立后隐藏 |
| 社区触达 | 作者卡片、详情和他人主页 | 头像/昵称始终进入他人主页；已建立互动关系时，显式消息动作直接进入 PRD-03 会话，不设置中转页 |
| 内容偏好 | 社区更多操作 | 只提供“不看 TA 动态/取消不看 TA 动态”作者级偏好，不提供单条内容屏蔽 |
| 更多操作不可用场景 | 社区更多操作 | 不适用动作隐藏，正反动作按最终态切换，请求中使用通用 loading；不提供独立置灰画板 |
| 更多操作结果 | 社区更多操作 | 复用蓝湖“千寻-成家-热门-发布失败”中央灰色反馈层，按实际结果替换文案 |
| 内容不可见反馈 | 动态详情页 | 返回来源列表并复用蓝湖“千寻-成家-热门-发布失败”中央灰色反馈层；按实际状态展示“内容已下架”“内容已删除”或“内容暂不可见” |
| 取消关注确认 | 关注粉丝列表页 | 复用蓝湖“千寻-成家-取消关注”：标题“温馨提示”、正文“确定取消关注吗？”、取消/确定双按钮 |
| 同城资料城市 | 同城信息流页 | 引用 `M05-RULE-city-feed-scope`；顶部资料城市只读，城市条件由服务端按登录用户获取，页面不申请 GPS 定位权限；空值用户由 PRD-01 提前拦截补录 |
| 举报对象分流 | 统一举报弹窗、他人主页、PRD-03 私信/悄悄话详情 | 用户资料/账号使用 `targetType=user`；聊天内容使用 `targetType=chat` 并按 `M05-RULE-report-target-context` 携带最小上下文 |
