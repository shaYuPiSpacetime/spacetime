## UI 仍需修改 / 补齐

1. 喜欢我的、最近看过我的、相互喜欢：补空态列表。
2. 喜欢我的：删除“资产殷实”“身高180”“有房有车”等筛选胶囊。
3. 心动页：删除“海量曝光”“10倍曝光”运营入口。
4. 相互喜欢：底部 TabBar 选中态应为“心动”；列表前台只保留“查看主页”。
5. 单条解锁：喜欢场景文案按“解锁Ta是谁 / 送出喜欢，即刻开聊 / 只看ta / 解锁全部”；价格取 PRD-04 配置，不在 UI 或 PRD-02 写死。
6. 匹配成功弹窗：按 `matchNo + userId` 为双方独立展示；需补实际展示、主动关闭/导航、加载失败等状态设计。

## UI 不需要补

1. 不需要前台关系失效卡片、失效态切换按钮或关系失效弹窗。
2. 不需要 PRD-02 独立后台管理页面蓝湖稿；后台能力可按 PRD 保留，开发前如需 UI 再补后台通用稿。
3. 不需要把后台规则参数做成前台 UI。
