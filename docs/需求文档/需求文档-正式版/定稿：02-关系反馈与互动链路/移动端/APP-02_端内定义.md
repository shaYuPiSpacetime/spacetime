## 1. 信息架构（页面树）

| 一级入口 / 场景 | 二级页面 / 弹窗 | 页面 ID | 一句话职责 | 优先级 |
|----------------|----------------|---------|------------|--------|
| 心动 Tab | 喜欢我的列表页 | `APP-02-PAGE-likes-me` | 展示喜欢过我的异性用户，承接新喜欢数量角标、摘要与分组，以及模糊展示、单条解锁、会员全量查看和回看主页 | P0 |
| 心动 Tab | 最近看过我的列表页 | `APP-02-PAGE-recent-viewers` | 展示最近 7 天访问过我婚恋主页的异性用户，承接模糊展示、单条解锁和会员全量查看 | P0 |
| 心动 Tab | 相互喜欢列表页 | `APP-02-PAGE-mutual-matches` | 默认展示当前有效匹配关系，并按蓝湖 UI 提供查看主页操作；聊天由主页/消息链路承接 | P0 |
| 异步反馈 | 匹配成功弹窗 | `APP-02-PAGE-match-success-modal` | 双方形成新匹配生命周期后，各展示一次匹配反馈，并承接稍后处理、查看主页和进入聊天 | P0 |
| 付费触点 | 单条解锁弹窗场景规格 | `APP-02-PAGE-single-unlock-modal` | 定义喜欢/访客单条解锁的标题、副标题、模糊头像和按钮组合；实际扣费与弹窗基础组件复用 PRD-04 | P0 |
| 付费触点 | 业务场景付费引导弹窗 | `APP-04-PAGE-paywall-modal` | 喜欢/访客单条解锁与解锁全部的统一付费承接 | P0 |
| 用户主页 | 婚恋用户主页 | 由 PRD-05/用户主页规格承接 | PRD-02 只定义进入主页是否生成访客记录及主页按钮状态 | P0 |

> `APP-02-PAGE-match-success-modal` 已纳入正式需求，当前缺蓝湖 UI，需补设计稿；2026-07-22 后端接口已实施，移动端页面仍待后续编码和视觉验收。心动页仍不展示“海量曝光”“10倍曝光”运营入口，也不提供前台失效态切换按钮。

## 2. 移动端登录态与核心准入

| 用户状态 | 可见页面/能力 | 不可用能力 | 不满足时处理 |
|----------|---------------|------------|--------------|
| 未登录 | 不可查看关系反馈个人数据 | 喜欢我的、最近看过我的、相互喜欢、喜欢动作、访客记录 | 点击入口后引导登录 |
| 已登录但未完成三重认证 | 可看到入口或强引导态 | 不可进入真实反馈列表，不可形成真实喜欢、访客、匹配、聊天 | 展示 `M02-TXT-core-access-block`，跳转 PRD-01 核心准入拦截/认证引导 |
| 三重认证通过且账号正常 | 可使用关系反馈全部基础能力 | 付费权益仍受 PRD-04 会员/千寻币规则限制 | 正常展示 |
| 账号冻结/停用/注销中 | 仅可查看必要提示 | 不可形成或继续关系反馈 | 按账号状态提示；关系反馈列表默认不展示异常对象 |

## 3. 移动端 UI 状态

| 场景 | 页面表现 | 默认文案/引用 |
|------|----------|---------------|
| 存在新喜欢 | 心动及喜欢我的入口显示数字角标；页面顶部显示新喜欢数量与最多 5 个头像摘要，列表按“新喜欢/更早”分组并显示“新”标签 | `M02-RULE-new-like-display`、`M02-TXT-new-likes-summary` |
| 新喜欢数为 0 | 入口不显示角标，页面不显示新喜欢摘要或“新喜欢/更早”分组标题，直接展示有效喜欢总数和常规列表 | `M02-RULE-new-like-display` |
| 新喜欢已读提交失败 | 保留入口角标和未读状态；当前页面可继续浏览，下次进入或刷新时重试确认 | `M02-RULE-new-like-read` |
| 喜欢我的无数据 | 空态 + 去完善资料/去看看推荐入口 | `M02-TXT-likes-empty` |
| 最近看过我的无数据 | 空态 + 去完善资料/提高曝光建议 | `M02-TXT-viewers-empty` |
| 相互喜欢无数据 | 空态 + 去推荐页看看 | `M02-TXT-mutual-empty` |
| 匹配成功待展示 | 新匹配弹窗；“稍后再说”、关闭、系统返回、去主页或去聊天均标记当前用户已读 | `M02-RULE-match-popup-user-state` |
| 匹配弹窗加载失败/异常退出 | 不标记已读，下次满足展示条件时重试 | `M02-RULE-match-popup-user-state` |
| 未完成三重认证 | 拦截页或弹层 | `M02-TXT-core-access-block` |
| 不可互动对象 | 默认列表隐藏，不画前台失效态或关系失效弹窗；后台保留真实原因 | `M02-RULE-relation-invalid` |
| 普通用户未解锁 | 模糊头像/弱识别标签，不展示强识别字段 | `M02-RULE-blur-display` |
| 单条解锁弹窗 | 标题“解锁Ta是谁”，喜欢场景副标题“送出喜欢，即刻开聊”，按钮为“只看ta”“解锁全部” | `M02-RULE-single-unlock-modal-content` |
| 会员生效 | 全量清晰展示喜欢/访客记录 | `M04-ENUM-vip-benefit-type=heart_list/visitor_list` |
| 会员到期 | 全量清晰权益回退普通模糊态 | `M02-RULE-vip-expiry-display` |
| 单条已解锁 | 对象与关系仍可展示时保持清晰；对象失效后前台移除 | `M02-RULE-unlock-visibility` |
| 网络失败 | toast + 保留上次数据 + 重试 | 移动端全局通用态 |

## 4. 页面跳转口径

| 来源 | 目标 | 跳转条件 | 备注 |
|------|------|----------|------|
| 喜欢我的清晰卡片 | 婚恋用户主页 | 记录 `displayStatus=clear` 且对象有效 | 进入主页按 `M02-RULE-visit-generate` 为对方生成或更新访客展示记录并累计 PV；一期无隐藏访问分支 |
| 最近看过我的清晰卡片 | 婚恋用户主页 | 记录 `displayStatus=clear` 且对象有效 | |
| 相互喜欢有效卡片 | 婚恋用户主页 | `matchStatus=matched` | 列表前台按蓝湖 UI 提供查看主页；主页主动作展示聊天 |
| 匹配成功弹窗“去主页” | 婚恋用户主页 | 弹窗展示成功且对象有效 | 先按 `matchNo + userId` 标记已读，再导航 |
| 匹配成功弹窗“去聊天” | PRD-03 私信会话页 | `canEnterConversation=true` | 先标记弹窗已读；进入后由 PRD-03 的 `canSend`、`protectStatus` 决定能否发送 |
| 单条模糊卡片 | APP-02 单条解锁场景弹窗 | 普通用户未单条解锁 | 第一步仅解释解锁对象，不扣币 |
| 单条解锁弹窗“只看ta” | PRD-04 千寻币确认弹窗 | 目标记录再次校验有效 | 第二步确认后才允许扣币；任一步取消均不扣币 |
| 解锁全部按钮 | PRD-04 付费引导弹窗 | 普通用户非会员 | 全量走时空邂逅会员 |
