## 4. 最终产品口径

1. 图片全屏预览保留为客户端通用能力，无需独立 UI 画板。
2. 动态提交后不展示成功、待复核或驳回业务提示；“我的动态”每条动态展示待复核或已驳回标识。
3. 重复举报只指同一 `reporterId + targetType + targetId` 已有 `pending/processing` 记录；不同对象、对象类型或举报人可独立举报，重复时复用通用 toast。
4. 点赞和评论用户空态复用同一通用结构，分别显示“暂无点赞”和“暂无评论”。
5. 千寻币消耗确认、余额不足和充值入口 UI 由模块 08 提供；PRD-05 只调用，资产规则仍引用 PRD-04。
6. `APP-05-hot-04` 按 UI 展示参与头像、参与人数和浏览量；内容术语统一为“诚意贴”。
7. `APP-05-topic-list-01` 不提供搜索框，不拆分推荐/全部分区，不展示最新帖子预览。
8. `APP-05-follow-relations-03` 使用关注/粉丝通用空态。
9. `APP-05-post-detail-01` 展示申请认识和互动人数，评论排序使用最新/最早。
10. `APP-05-report-01` 是“选择举报原因”弹窗，点击原因直接提交，不包含补充说明输入和独立提交按钮。
11. 本期不提供动态收藏，PRD、Demo、接口、统计和互动用户列表均不保留收藏能力。
12. `APP-05-post-interactors-03` 复用“千寻互动-互动-评论/点赞通用”UI。
13. 同城仅使用当前用户已审核资料城市，页面只读且不申请 GPS 定位权限。
