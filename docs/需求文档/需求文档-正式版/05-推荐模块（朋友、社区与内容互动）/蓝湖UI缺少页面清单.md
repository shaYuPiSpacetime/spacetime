## 4. 最终产品口径

1. 热门空态和话题列表无数据统一复用蓝湖“缺省页-切图”，文案为“暂无数据”。
2. 本期不提供 @Ta；发布页、草稿、提交载荷、配置和通知均不保留提及用户能力。
3. 话题详情只保留 `APP-05-topic-detail-01` 主画板：无内容时在列表区展示通用“暂无数据”；停用话题继续展示发布时快照，只在新发布的话题选择中不可选。
4. 未建立互动关系时展示“申请认识”，点击进入 `APP-05-greeting-01`；对方回复并建立互动关系后隐藏该入口，头像/昵称进入他人主页，消息动作直接进入 PRD-03 会话。
5. 婚恋用户主页与个人动态区他人主页为同一页面；他人主页展示已审核资料、认证、关系动作和公开动态，不另设重复页面。
6. `APP-05-hot-01` 完全以 UI 稿为准，不增加热门序号、热度分或页面更新时间字段。
7. `APP-05-more-actions-01` 按 UI 稿展示分享、关注/取消关注、不看 TA 动态/取消不看和举报；不增加单条内容屏蔽或复制内容链接。
8. `APP-05-more-actions-02` 按 UI 稿展示关注/取消关注、不看 TA 动态/取消不看和举报；申请认识是页面主操作，普通私信不经过更多菜单。
9. 图片全屏预览保留为客户端通用能力，无需独立 UI 画板。
10. 动态提交后不展示成功、待复核或驳回业务提示；“我的动态”每条动态展示待复核或已驳回标识。
11. 重复举报只指同一 `reporterId + targetType + targetId` 已有 `pending/processing` 记录；不同对象、对象类型或举报人可独立举报。
12. 点赞和评论用户空态复用同一通用结构，分别显示“暂无点赞”和“暂无评论”。
13. 千寻币消耗确认、余额不足和充值入口 UI 由模块 08 提供；PRD-05 只调用，资产规则仍引用 PRD-04。
14. `APP-05-hot-04` 按 UI 展示参与头像、参与人数和浏览量；内容术语统一为“诚意贴”。
15. `APP-05-topic-list-01` 不提供搜索框，不拆分推荐/全部分区，不展示最新帖子预览。
16. `APP-05-follow-relations-03` 使用关注/粉丝通用空态。
17. `APP-05-post-detail-01` 展示申请认识和互动人数，评论排序使用最新/最早。
18. `APP-05-report-01` 是“选择举报原因”弹窗，点击原因直接提交，不包含补充说明输入和独立提交按钮。
19. 本期不提供动态收藏，PRD、Demo、接口、统计和互动用户列表均不保留收藏能力。
20. `APP-05-post-interactors-03` 复用“千寻互动-互动-评论/点赞通用”UI。
21. 同城仅使用当前用户已审核资料城市，页面只读且不申请 GPS 定位权限。
