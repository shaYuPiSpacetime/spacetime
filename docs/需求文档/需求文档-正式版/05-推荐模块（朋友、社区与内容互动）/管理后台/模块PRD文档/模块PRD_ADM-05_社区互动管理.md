## 1. 模块目标

后台 PRD-05 负责社区内容与互动治理：参考后台菜单可称为“内容与动态管理”，一期实际承接动态和诚意贴内容审核、评论复核、举报处理、家园话题管理、审核规则/社区配置。模块目标是在一期上线时形成可运营、可审核、可追踪的治理闭环，支撑移动端社区内容安全上线。

**用户故事：** 作为运营、审核员、客服或风控人员，我想查询和处理社区内容、评论和举报，并维护话题、举报原因与发布规则，以便保证移动端社区互动安全、稳定上线。

**核心指标：** 待审核处理时长、举报闭环时长、误判恢复时长、配置变更成功率、敏感操作审计覆盖率。

## 3. 关键业务流程

### 3.1 内容与动态治理流程

```
入口：
  - 社区互动管理 -> 内容管理（参考菜单：内容与动态管理 -> 内容管理）
  - 社区互动管理 -> 动态管理（参考菜单：内容与动态管理 -> 动态管理）
正常路径：
  1. 审核员按关键词、用户 ID、内容类型、媒体类型、分发场景、状态、机审结果、时间筛选
  2. 打开内容详情抽屉，查看标题/正文、图片、作者、互动数据、机审结果、操作日志和历史记录
  3. 列表外层仅提供详情入口；通过、驳回、下架、恢复等处理动作只在详情抽屉内展示
  4. 对待人工复核内容执行通过或驳回
  5. 对已公开内容可执行下架或恢复
  6. 系统写审计日志并触发审核结果通知事件
异常：
  - 记录已被其他审核员处理：提示刷新
  - 图片加载失败：保留审核操作，标记图片不可预览
```

### 3.2 评论审核流程

```
入口：社区互动管理 -> 评论审核（参考菜单：内容与动态管理 -> 评论管理）
正常路径：
  1. 审核员按评论内容、用户 ID、评论状态、作者、时间筛选
  2. 列表外层仅提供详情入口
  3. 打开评论详情抽屉，查看评论上下文、所属内容、点赞数、举报次数、机审摘要、操作日志和处理历史
  4. 在详情抽屉内执行通过、驳回、屏蔽或恢复
  5. 系统更新评论状态、内容评论数和审计日志
```

### 3.3 举报处理流程

```
入口：社区互动管理 -> 举报处理（参考菜单：内容与动态管理 -> 举报管理）
正常路径：
  1. 审核员/风控按举报状态、来源、原因、对象类型筛选
  2. 查看举报对象、上下文、历史举报和被举报人摘要
  3. 选择举报成立或不成立
  4. 举报成立时选择处罚动作和说明
  5. 系统执行内容下架、评论屏蔽、警告、禁言或账号冻结联动
  6. 系统触发举报结果通知事件
异常：
  - 举报对象已处理：合并结果并提示
  - 处罚动作权限不足：按钮置灰
```

### 3.4 家园话题管理流程

```
入口：社区互动管理 -> 家园话题管理
正常路径：
  1. 运营按话题名称、状态、是否推荐筛选话题
  2. 新增或编辑话题名称、简介、封面、排序、状态和推荐标记
  3. 保存成功后写配置版本和审计日志
  4. 移动端家园话题入口、话题列表、发布页话题 chips 按启用话题展示
异常：
  - 话题已被内容引用时，停用后历史内容仍展示话题名，但发布页不再允许新增选择
  - 配置版本冲突时提示刷新
```

### 3.5 社区配置流程

```
入口：社区互动管理 -> 社区配置（参考菜单：内容与动态管理 -> 审核规则配置）
正常路径：
  1. 运营维护社区 Tab、举报原因、发布规则、审核规则和敏感词项
  2. 高风险开关保存时二次确认
  3. 保存成功后写配置版本和审计日志
  4. 移动端配置缓存失效并按新配置展示
异常：
  - 配置版本冲突时提示刷新
```

## 4. 核心数据模型

### 4.1 实体清单

| 实体 | 表名（建议） | 说明 | 所属模块 | 关键字段 |
|------|-------------|------|----------|----------|
| 社区内容 | `community_post` | 动态、诚意贴与悦目来源内容 | 05 | contentId, authorId, contentType, status |
| 评论 | `community_comment` | 评论和回复 | 05 | commentId, contentId, authorId, status |
| 举报 | `community_report` | 举报记录 | 05 | reportId, targetType, targetId, status |
| 审核记录 | `community_audit_record` | 内容和评论审核轨迹 | 05 | auditId, targetType, targetId, result |
| 社区配置 | `app_config` / `community_config` | Tab、规则、联系方式开关、抽检比例 | 05/系统配置 | configKey, configValue, version |
| 家园话题 | `community_topic` 或社区字典扩展表 | 话题名称、简介、封面、排序、状态、推荐标记、内容统计 | 05/系统字典 | topicId, topicName, coverUrl, sort, status |
| 举报原因 | `sys_dict_data` 或社区字典 | 举报原因 | 系统字典 | dictType, dictCode, dictLabel, status |
| 审计日志 | `sys_audit_log` | 敏感操作审计 | 系统 | operator, action, target, reason |

### 4.2 实体关系

```
社区内容 1──N 审核记录
评论 1──N 审核记录
举报 N──1 内容/评论/用户
话题 1──N 社区内容
配置版本 1──N 配置项
```

### 4.3 跨模块字段引用

| 本模块使用字段 | 来源模块 | 来源实体 | 若来源模块未就绪如何处理 |
|---------------|----------|----------|-------------------------|
| 用户昵称/手机号/账号状态 | PRD-01 | App 用户 | 显示用户编号和默认昵称，手机号按权限脱敏 |
| 认证状态 | PRD-01 | 认证记录 | 展示未知状态并允许后台排查 |
| 聊天来源举报 | PRD-03 | 聊天举报上下文 | 仅展示举报摘要和来源编号 |
| 通知发送状态 | PRD-03 | 通知中心 | 处理完成不阻塞，通知失败进入补偿 |
| 操作日志 | 系统管理 | 审计日志 | 审计服务异常时阻断高风险操作 |

## 9. 非功能性需求

### 9.1 权限

权限矩阵以 `../ADM-05_端内定义.md` 第 2 节为准；后端接口必须校验权限，不允许仅前端隐藏按钮。

### 9.2 安全与合规

| 字段 | 加密存储 | 脱敏规则 | 留存时长 | 注销后处理 | 是否可导出 |
|------|---------|----------|----------|-----------|-----------|
| 手机号 | 是/按用户体系 | 138****1234 | 按用户体系 | 按用户体系 | 按权限 |
| 举报补充说明 | 否 | 仅授权角色查看 | >= 1 年 | 匿名化举报人 | 按权限 |
| 审核驳回原因 | 否 | 后台可见，前台仅展示可理解文案 | >= 1 年 | 保留治理记录 | 是 |
| 图片内容 URL | 私有存储 | 授权预览 URL | 按内容治理策略 | 删除或匿名化 | 按权限 |
| 操作日志 | 否 | 操作人按后台账号展示 | >= 1 年 | 保留审计 | 是 |

### 9.3 性能

| 场景 | 要求 |
|------|------|
| 审核列表查询 | 默认 20 条/页，常规筛选 1 秒内返回 |
| 举报列表查询 | 默认 20 条/页，支持按状态和来源筛选 |
| 配置保存 | 保存后 5 分钟内移动端缓存失效 |
| 导出 | 异步生成，进入下载中心 |

### 9.4 并发与幂等

| 需幂等的操作 | 并发场景 | 幂等方案建议 |

| 内容管理/动态管理处理 | 多审核员同时处理 | 状态版本号 + 乐观锁 |
| 举报处理 | 重复提交处理结果 | reportId + version |
| 配置保存 | 多管理员同时编辑 | 配置版本号 + 冲突提示 |
| 导出 | 连续点击导出 | 同筛选条件短时复用任务 |

## 11. 上线 / 迁移 / 回滚

| 项 | 说明 |
|----|------|
| 存量数据如何处理 | 首次上线初始化家园话题、举报原因、社区 Tab 和默认规则 |
| 老版本客户端兼容 | 后台配置对新入口生效，老版本无入口时无影响 |

| 灰度策略 | 可先开放内容审核、举报处理，再开放发布入口 |
| 回滚策略 | 关闭移动端发布和互动入口，后台保留审核/举报只读 |
| 数据迁移脚本 | 创建内容、评论、举报、审核记录、家园话题相关表并初始化菜单权限 |
