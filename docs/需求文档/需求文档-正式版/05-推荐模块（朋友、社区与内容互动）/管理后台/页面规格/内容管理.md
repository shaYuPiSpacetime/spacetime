- **页面 ID**：`ADM-05-PAGE-content-manage`
- **所属模块 PRD**：`模块PRD_ADM-05_社区互动管理`
- **页面路由**：`/community/content`
- **入口来源**：社区互动管理 -> 内容管理；参考后台菜单为 内容与动态管理 -> 内容管理
- **对应设计稿**：待补充；设计画板按第 2.4 节输出
- **对应移动端 / 技术方案**：APP-05 内容发布与详情

## 1. 页面定位

- **目标用户**：审核员、运营、风控、超管
- **核心任务**：查询动态、诚意贴等社区内容并在详情抽屉中执行审核、下架、恢复
- **页面类型**：列表页 + 详情抽屉

## 2. 布局（给 UI）

### 2.1 整体布局

```
┌──────────────────────────────┐
│ 筛选区：关键词/用户ID/类型/媒体/状态/时间 │
├──────────────────────────────┤
│ 工具栏：查询/重置/导出          │
├──────────────────────────────┤
│ 内容管理表格                    │
└──────────────详情抽屉─────────┘
```

### 2.2 区块说明

| 区块 | 位置 | 内容 | 是否可折叠 | 是否记住展开状态 |
|------|------|------|------------|------------------|
| 筛选区 | 顶部 | 关键词、用户 ID、内容类型、媒体类型、审核状态、机审结果、提交时间 | 是 | 是 |
| 表格区 | 主体 | 内容 ID、内容类型、所属模块、标题/摘要、用户 ID/昵称、提交时间、机审/风险、状态/违规标签、详情入口 | 否 | 是 |
| 详情抽屉 | 右侧 | 正文、图片、作者、所属模块、互动数据、机审摘要、审核历史、操作日志时间线 | 否 | 否 |

### 2.3 弹层 / 抽屉 / 模态

| 弹层 | 触发方式 | 大小 | 内容 | 关闭方式 |
|------|----------|------|------|----------|
| 内容详情抽屉 | 点击详情 | 右侧 720px | 内容、图片、作者、机审、历史、审核处理表单 | 关闭按钮/ESC |
| 高风险确认 | 详情抽屉中选择下架/恢复/禁言等高风险处理结果 | 中央弹窗 | 影响说明、处理原因、通知选项 | 取消/确认 |

### 2.4 UI 画板拆分（必填）

| 区域 | 展现形式 | 编辑控件 | 新增/删除方式 | 保存方式 |
|------|----------|----------|----------------|----------|

## 7. 状态与异常

| 状态类型 | 触发场景 | 页面表现 | 用户可做的操作 | 引用 |
|----------|----------|----------|----------------|------|
| 加载态 | 首次加载/查询 | 表格 loading | 无 | — |
| 空态（无数据） | 无记录 | 表格空态 | 调整筛选 | — |
| 空态（搜索无结果） | 筛选无结果 | 表格空态 | 重置 | — |

| 业务态-待人工复核 | 待人工复核 | 列表仅详情；详情抽屉可通过/驳回 | 审核 | `M05-SM-content-audit` |

## 8. 查询与列表

- **默认排序**：提交时间倒序
- **可选排序**：提交时间、处理时间
- **分页**：默认 20 条，支持 20/50/100
- **分页方式**：传统分页
- **列表轮询/实时刷新**：不轮询
- **批量选择**：仅导出按筛选条件
- **列表为空时的引导**：调整筛选条件
