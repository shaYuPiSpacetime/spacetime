# 页面规格 - ADM-05-PAGE-moment-manage 动态管理

| 版本 | 日期 | 修改人 | 变更摘要 |
|------|------|--------|----------|
| 版本01 | 2026-07-07 | Codex | 按确认口径新增动态管理独立页面；列表外层仅保留详情入口，处理动作放入详情抽屉 |
| 版本02 | 2026-07-07 | Codex | 移除详情和列表的网络来源展示，操作日志按时间线展示 |
| 版本03 | 2026-07-09 | Codex | 按甲方帖子审核意见补充动态处理中的禁言周期 |

- **页面 ID**：`ADM-05-PAGE-moment-manage`
- **所属模块 PRD**：`模块PRD_ADM-05_社区互动管理`
- **页面路由**：`/community/moments`
- **入口来源**：社区互动管理 -> 动态管理；参考后台菜单为 内容与动态管理 -> 动态管理
- **对应设计稿**：待补充；设计画板按第 2.4 节输出
- **对应移动端 / 技术方案**：APP-05 成家关注/同城/热门信息流、动态详情

## 1. 页面定位

- **目标用户**：审核员、运营、风控、超管
- **核心任务**：查询普通动态流内容，查看媒体、互动、分发和风险状态，并在详情抽屉中执行处理
- **页面类型**：列表页 + 详情抽屉

## 2. 布局（给 UI）

### 2.1 整体布局

```
┌──────────────────────────────┐
│ 筛选区：关键词/用户ID/媒体/分发/状态/时间 │
├──────────────────────────────┤
│ 动态管理表格：动态、媒体、互动、分发状态   │
└──────────────详情抽屉─────────┘
```

### 2.2 区块说明

| 区块 | 位置 | 内容 | 是否可折叠 | 是否记住展开状态 |
|------|------|------|------------|------------------|
| 筛选区 | 顶部 | 关键词、用户 ID、媒体类型、分发场景、展示状态、是否被举报、发布时间 | 是 | 是 |
| 表格区 | 主体 | 动态 ID、分发场景、媒体类型、内容预览、用户 ID/昵称、发布时间、阅读/赞/评、展示状态、风险、详情入口 | 否 | 是 |
| 详情抽屉 | 右侧 | 动态正文、图片、互动数据、分发记录、审核历史、操作日志时间线和处理表单 | 否 | 否 |

### 2.3 弹层 / 抽屉 / 模态

| 弹层 | 触发方式 | 大小 | 内容 | 关闭方式 |
|------|----------|------|------|----------|
| 动态详情抽屉 | 点击详情 | 右侧 720px | 动态详情、媒体预览、互动数据、分发状态、处理表单 | 关闭按钮/ESC |
| 高风险确认 | 详情抽屉中选择下架/恢复/禁言等高风险处理结果 | 中央弹窗 | 影响说明、禁言周期、处理原因、通知选项 | 取消/确认 |

### 2.4 UI 画板拆分（必填）

| 画板 ID | 画板名称 | 设计内容 | 备注 |

### 2.5 编辑控件口径

| 区域 | 展现形式 | 编辑控件 | 新增/删除方式 | 保存方式 |

## 6. 数据联动规则

| 触发字段 | 触发事件 | 影响字段 | 联动行为 | 备注 |
|----------|----------|----------|----------|------|
| 分发场景 | 筛选 | 列表 | 仅展示命中场景的动态 | 对应关注/同城/热门/话题信息流 |
| 展示状态 | 打开详情抽屉 | 详情抽屉处理结果 | 按状态切换可用处理结果 | `M05-SM-content-audit` |
| 处理结果 | 确认处理 | 展示状态/分发状态 | 下架后移出前台分发，恢复后重新参与分发 | 写审计日志 |
| 处理结果 | 选择禁言用户 | 禁言周期 | 显示禁言周期并必填 | `M05-RULE-mute-period` |

## 7. 状态与异常

| 状态类型 | 触发场景 | 页面表现 | 用户可做的操作 | 引用 |
|----------|----------|----------|----------------|------|
| 加载态 | 首次加载/查询 | 表格 loading | 无 | — |
| 空态（无数据） | 无动态 | 表格空态 | 调整筛选 | — |
| 空态（搜索无结果） | 筛选无结果 | 表格空态 | 重置 | — |
| 错误态（网络） | 请求超时 | 错误提示 + 重试 | 重试 | `M05-ERR-*` |
| 无权限态 | 无菜单权限 | 菜单隐藏或 403 | 返回 | `ADM-05_端内定义.md` |
| 业务态-已公开 | 已公开 | 列表仅详情；详情抽屉可保持公开/下架 | 处理 | `M05-SM-content-audit` |
| 业务态-待人工复核 | 待人工复核 | 列表仅详情；详情抽屉可通过/驳回 | 审核 | `M05-SM-content-audit` |
| 业务态-已下架 | 已下架 | 列表仅详情；详情抽屉可恢复 | 恢复 | `M05-SM-content-audit` |
| 降级态 | 分发数据暂不可用 | 展示动态基础信息，分发列显示待同步 | 继续查看详情 | 信息流分发 |

## 8. 查询与列表

- **默认排序**：发布时间倒序
- **可选排序**：发布时间、阅读数、点赞数、评论数、举报数
- **分页**：默认 20 条，支持 20/50/100
- **分页方式**：传统分页
- **列表轮询/实时刷新**：不轮询
- **批量选择**：仅导出按筛选条件
- **列表为空时的引导**：调整筛选条件
