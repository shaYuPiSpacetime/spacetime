- **页面 ID**：`ADM-05-PAGE-comment-audit`
- **所属模块 PRD**：`模块PRD_ADM-05_社区互动管理`
- **页面路由**：`/community/comment-audit`
- **入口来源**：社区互动管理 -> 评论管理；参考后台菜单为 内容与动态管理 -> 评论管理
- **对应设计稿**：待补充；设计画板按第 2.4 节输出
- **对应移动端 / 技术方案**：APP-05 动态详情（含诚意贴视图）

## 1. 页面定位

- **目标用户**：审核员、运营、风控、超管
- **核心任务**：查询评论/回复并进入详情抽屉处理；仅覆盖 APP-05 动态、诚意贴详情内评论互动
- **页面类型**：列表页 + 详情抽屉

## 2. 布局（给 UI）

### 2.1 整体布局

```
┌──────────────────────────────┐
│ 筛选区：关键词/用户ID/状态/作者/时间 │
├──────────────────────────────┤
│ 评论管理表格                    │
└──────────────详情抽屉─────────┘
```

### 2.2 区块说明

| 区块 | 位置 | 内容 | 是否可折叠 | 是否记住展开状态 |
|------|------|------|------------|------------------|
| 筛选区 | 顶部 | 评论内容、评论编号、用户 ID、评论状态、作者、所属内容、时间 | 是 | 是 |
| 表格区 | 主体 | 评论 ID、归属帖子/动态、用户信息、评论内容、发布时间、点赞数、举报数、状态、操作 | 否 | 是 |
| 详情抽屉 | 右侧 | 评论上下文、所属内容、审核历史、操作日志时间线和处理表单 | 否 | 否 |

### 2.3 弹层 / 抽屉 / 模态

| 弹层 | 触发方式 | 大小 | 内容 | 关闭方式 |
|------|----------|------|------|----------|
| 评论详情抽屉 | 查看详情 | 右侧 640px | 评论、回复、所属内容、状态、操作日志和处理表单 | 关闭按钮/ESC |
| 高风险确认 | 详情抽屉中选择屏蔽、恢复、驳回或处罚处理结果 | 中央弹窗 | 影响说明、禁言周期、处理原因、通知选项 | 取消/确认 |

## 8. 查询与列表

- **默认排序**：评论时间倒序
- **可选排序**：评论时间、举报数
- **分页**：默认 20 条，支持 20/50/100
- **分页方式**：传统分页
- **列表轮询/实时刷新**：不轮询
- **批量选择**：仅导出按筛选条件
- **列表为空时的引导**：调整筛选条件
