# 页面规格 - ADM-05-PAGE-report-handle 举报管理

| 版本 | 日期 | 修改人 | 变更摘要 |
|------|------|--------|----------|
| 版本01 | 2026-07-06 | Codex | 创建页面规格 |
| 版本02 | 2026-07-07 | Codex | 结合参考后台举报管理补充回复状态字段和菜单入口口径 |

- **页面 ID**：`ADM-05-PAGE-report-handle`
- **所属模块 PRD**：`模块PRD_ADM-05_社区互动管理`
- **页面路由**：`/community/reports`
- **入口来源**：社区互动管理 -> 举报处理；参考后台菜单为 内容与动态管理 -> 举报管理
- **对应设计稿**：待补充；设计画板按第 2.4 节输出
- **对应移动端 / 技术方案**：APP-05 举报弹窗，PRD-03 聊天举报来源

## 1. 页面定位

- **目标用户**：审核员、风控、客服、超管
- **核心任务**：统一查询和处理举报，触发内容下架、评论屏蔽、警告、禁言、账号冻结联动
- **页面类型**：列表页 + 详情抽屉 + 处理弹窗

## 2. 布局（给 UI）

### 2.1 整体布局

```
┌──────────────────────────────┐
│ 筛选区：状态/来源/对象/原因/时间 │
├──────────────────────────────┤
│ 举报处理表格                    │
└────────────举报详情抽屉────────┘
```

### 2.2 区块说明

| 区块 | 位置 | 内容 | 是否可折叠 | 是否记住展开状态 |
|------|------|------|------------|------------------|
| 筛选区 | 顶部 | 状态、对象类型、原因、举报时间 | 是 | 是 |
| 表格区 | 主体 | 举报对象、举报人、被举报人、原因、状态、回复状态、操作 | 否 | 是 |
| 详情抽屉 | 右侧 | 举报详情、对象上下文、操作日志时间线、历史记录 | 否 | 否 |

### 2.3 弹层 / 抽屉 / 模态

| 弹层 | 触发方式 | 大小 | 内容 | 关闭方式 |
|------|----------|------|------|----------|
| 举报详情抽屉 | 查看/处理 | 右侧 760px | 举报对象、上下文、操作日志、历史处理 | 关闭按钮/ESC |
| 处理弹窗 | 点击处理 | 中央弹窗 | 成立/不成立、处罚动作、说明 | 取消/确认 |
| 处罚确认 | 选择高风险动作 | 中央弹窗 | 处罚影响确认 | 取消/确认 |

### 2.4 UI 画板拆分（必填）

| 画板 ID | 画板名称 | 设计内容 | 备注 |

## 7. 状态与异常

| 状态类型 | 触发场景 | 页面表现 | 用户可做的操作 | 引用 |
|----------|----------|----------|----------------|------|
| 加载态 | 首次加载/查询 | 表格 loading | 无 | — |
| 空态（无数据） | 无举报 | 表格空态 | 调整筛选 | — |
| 空态（搜索无结果） | 筛选无结果 | 表格空态 | 重置 | — |
| 错误态（网络） | 请求超时 | 错误提示 + 重试 | 重试 | `M05-ERR-*` |
| 无权限态 | 无菜单权限 | 菜单隐藏或 403 | 返回 | `ADM-05_端内定义.md` |
| 业务态-待处理 | 待处理 | 可处理 | 处理 | `M05-SM-report` |
| 业务态-举报成立 | 举报成立 | 展示处罚结果 | 查看 | `M05-SM-report` |
| 业务态-举报不成立 | 举报不成立 | 展示原因 | 查看 | `M05-SM-report` |
| 降级态 | 来源对象不可见 | 展示对象已变化 | 继续处理 | 来源模块 |

## 8. 查询与列表

- **默认排序**：举报时间倒序
- **可选排序**：举报时间、处理时间
- **分页**：默认 20 条，支持 20/50/100
- **分页方式**：传统分页
- **列表轮询/实时刷新**：不轮询
- **批量选择**：仅导出按筛选条件
- **列表为空时的引导**：调整筛选条件

## 9. 验收标准

| AC ID | 场景 | 类型 | 优先级 |
|-------|------|------|--------|
| `ADM-05-AC-report-list` | 查询举报列表 | 正常 | P0 |
| `ADM-05-AC-report-valid` | 举报成立并处罚 | 正常 | P0 |
| `ADM-05-AC-report-invalid` | 举报不成立 | 正常 | P0 |
| `ADM-05-AC-report-permission` | 权限不足时处罚动作置灰 | 异常 | P0 |

```
AC-ID: ADM-05-AC-report-valid
Given 当前管理员具备 `community:report:handle` 权限，举报状态为待处理
When  选择举报成立、处罚动作和处理说明后确认
Then  举报状态变为举报成立，系统执行对应处罚、记录审计日志并触发 `M05-NTF-report-result`
```
