- **页面 ID**：`ADM-05-PAGE-community-config`
- **所属模块 PRD**：`模块PRD_ADM-05_社区互动管理`
- **页面路由**：`/community/config`
- **入口来源**：社区互动管理 -> 社区配置；参考后台菜单为 内容与动态管理 -> 审核规则配置
- **对应设计稿**：待补充；设计画板按第 2.4 节输出
- **对应移动端 / 技术方案**：APP-05 全部社区页面

## 1. 页面定位

- **目标用户**：运营、风控、超管
- **核心任务**：维护社区 Tab、举报原因、发布规则、审核规则、联系方式开关、抽检比例、禁言周期和 IP 封禁策略；仅维护 APP-05 社区相关规则，家园话题由 `ADM-05-PAGE-topic-manage` 承接
- **页面类型**：配置页

## 2. 布局（给 UI）

### 2.1 整体布局

```
┌──────────────────────────────┐
│ Tab：入口配置 / 举报原因 / 审核规则 / 治理策略 │
├──────────────────────────────┤
│ 当前 Tab 配置表格或表单          │
├──────────────────────────────┤
│ 保存 / 重置 / 查看变更记录        │
└──────────────────────────────┘
```

### 2.2 区块说明

| 区块 | 位置 | 内容 | 是否可折叠 | 是否记住展开状态 |
|------|------|------|------------|------------------|
| Tab 导航 | 顶部 | 入口配置、举报原因、审核规则、治理策略 | 否 | 是 |
| 配置区 | 主体 | 表格/表单配置项，包含规则列表和敏感词项 | 否 | 是 |
| 操作区 | 底部 | 保存、重置、变更记录 | 否 | 否 |

### 2.3 弹层 / 抽屉 / 模态

| 弹层 | 触发方式 | 大小 | 内容 | 关闭方式 |
|------|----------|------|------|----------|
| 新增举报原因弹窗 | 点击新增原因 | 中央弹窗 | 原因名称、适用对象、排序、状态 | 取消/保存 |
| 保存确认 | 点击保存 | 中央弹窗 | 变更摘要与影响 | 取消/确认 |
| 变更记录抽屉 | 点击变更记录 | 右侧 640px | 历史版本和操作人 | 关闭 |

### 2.4 UI 画板拆分（必填）

| 画板 ID | 画板名称 | 设计内容 | 备注 |
|---------|----------|----------|------|
| `ADM-05-config-01` | 社区配置-入口配置 | Tab 文案、排序、启停 | |
| `ADM-05-config-02` | 社区配置-举报原因配置 | 原因表格和新增弹窗 | |
| `ADM-05-config-03` | 审核规则配置-规则列表 | 发布规则、机审开关、敏感词项和规则列表 | |
| `ADM-05-config-04` | 社区配置-治理策略 | 禁言周期、IP 封禁开关、封禁周期和写操作范围 | |
| `ADM-05-config-05` | 社区配置-保存确认 | 高风险确认 | |

### 2.5 编辑控件口径

| 区域 | 展现形式 | 编辑控件 | 新增/删除方式 | 保存方式 |
|------|----------|----------|----------------|----------|
| 入口配置 | 表格 | 输入框、开关、拖拽排序 | 行内启停 | 页面级保存 |
| 举报原因 | 表格 + 弹窗 | 输入框、下拉、开关、排序 | 弹窗新增/行内停用 | Tab 内保存 |
| 审核规则配置 | 表单 + 表格 | 开关、数字输入、下拉、规则启停 | 支持新增/编辑 PRD-05 社区规则项 | 页面级保存 |
| 治理策略 | 表单 | 多选、开关、数字输入、周期选择 | 不支持新增 | 页面级保存，高风险二次确认 |

## 6. 数据联动规则

| 触发字段 | 触发事件 | 影响字段 | 联动行为 | 备注 |
|----------|----------|----------|----------|------|
| 联系方式开关 | 开启 | 保存确认 | 展示高风险确认 | `M05-CFG-contact-allow` |
| IP 封禁开关 | 关闭或开启 | 保存确认 | 展示高风险确认并写审计日志 | `M05-CFG-ip-block-enabled` |
| 禁言周期选项 | 删除周期 | 历史处罚 | 历史记录保持原周期文案，新处罚不再可选该周期 | `M05-RULE-mute-period` |
| IP 封禁周期选项 | 删除周期 | 历史封禁 | 历史记录保持原周期文案，新封禁不再可选该周期 | `M05-RULE-ip-block` |
| 入口排序 | 拖拽排序 | 移动端 Tab | 保存后按新顺序展示 | `M05-CFG-community-tabs` |
| 审核规则状态 | 启停 | 内容/评论审核链路 | 启用后按规则触发人工审核、驳回或处罚建议；停用保留历史记录 | 仅 APP-05 社区规则 |
| 敏感词项 | 新增/删除 | 审核规则命中 | 只影响社区内容安全规则；不替代运营中心搜索屏蔽词 | 一期范围裁剪 |

## 8. 查询与列表

- **默认排序**：排序值升序
- **可选排序**：排序、最近修改时间
- **分页**：配置列表默认 20 条
- **分页方式**：传统分页
- **列表轮询/实时刷新**：不轮询
- **批量选择**：不支持
- **列表为空时的引导**：初始化默认配置

## 9. 验收标准

| AC ID | 场景 | 类型 | 优先级 |

| `ADM-05-AC-config-save` | 保存社区配置 | 正常 | P0 |
