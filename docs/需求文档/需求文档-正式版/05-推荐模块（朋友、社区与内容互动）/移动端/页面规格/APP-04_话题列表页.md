- **页面 ID**：`APP-05-PAGE-topic-list`
- **所属模块 PRD**：`模块PRD_APP-05_推荐模块（朋友、社区与内容互动）`

- **入口来源**：千寻 -> 成家 -> 话题
- **对应设计稿**：待补充；设计画板按第 2.4 节输出

## 1. 页面定位

- **目标用户**：已登录用户
- **核心任务**：浏览后台启用话题并进入话题详情
- **页面类型**：列表页

## 2. 布局（给 UI）

### 2.1 整体布局

```
┌────────────────────┐
│ 话题标题 + 搜索框    │
├────────────────────┤
│ 推荐话题 / 全部话题   │
├────────────────────┤
│ 话题卡片列表          │
└────────────────────┘
```

### 2.2 区块说明

| 区块 | 位置 | 内容 | 是否可折叠 | 是否记住展开状态 |
|------|------|------|------------|------------------|
| 搜索区 | 顶部 | 话题搜索框 | 否 | 否 |
| 推荐话题 | 顶部下方 | 后台配置推荐话题 | 否 | 否 |
| 全部话题 | 主体 | 话题卡片列表 | 否 | 是 |

### 2.3 弹层 / 抽屉 / 模态

本页无弹层；话题详情由 `APP-05-PAGE-topic-detail` 承接。

### 2.4 UI 画板拆分（必填）

| 画板 ID | 画板名称 | 设计内容 | 备注 |
|---------|----------|----------|------|
| `APP-05-topic-list-01` | 话题列表-主页面 | 搜索、推荐话题、全部话题 | |
| `APP-05-topic-list-02` | 话题列表-搜索无结果 | 空态和清空入口 | |
| `APP-05-topic-list-03` | 话题列表-加载失败 | 错误态和重试 | |

### 2.5 编辑控件口径

本页为展示页，无编辑控件。

## 3. 筛选与搜索

### 3.1 搜索

| 项 | 说明 |
|----|------|
| 搜索框位置 | 页面顶部 |
| 搜索字段 | 话题名称、话题简介 |
| 搜索方式 | 模糊匹配 |
| 搜索触发 | 输入防抖 300ms |
| 搜索历史 | 不保留 |
| 清空搜索 | 有清空按钮 |

### 3.2 筛选条件

| 筛选 ID | 筛选名 | 类型 | 选项来源 | 是否多选 | 默认值 | 是否可清除 |
|---------|--------|------|----------|----------|--------|------------|
| `APP-05-PAGE-topic-list-FILTER-keyword` | 关键词 | 输入框 | 用户输入 | 否 | 空 | 是 |

### 3.3 筛选交互

- 输入关键词后自动刷新推荐话题和全部话题两个分区；清空后恢复全部启用话题。
- 推荐话题与全部话题都只展示后台启用话题；搜索无结果时展示清空入口。

## 4. 字段表

### 4.1 列表字段

| 字段 ID | 显示名 | 类型 | 必填 | 取值范围 | 校验规则 | 默认值 | 可编辑 | 敏感级别 | 数据来源 |

### 4.2 详情/表单字段

本页不展示详情表单；详情字段见 `APP-05-PAGE-topic-detail`。

### 5.1 行级操作

| 操作 ID | 操作名 | 触发条件 | 前置权限 | 二次确认 | 成功态 | 失败态 | 影响（副作用） |
|---------|--------|----------|----------|----------|--------|--------|----------------|
| `APP-05-PAGE-topic-list-ACT-open-topic` | 查看话题 | 话题启用 | `GLB-ROLE-app-user` | 否 | 跳转话题详情页 | 话题已下线提示 | 增加话题浏览 |

### 5.2 批量操作

本页不支持批量操作。

### 5.3 页面级操作

| 操作 ID | 操作名 | 位置 | 触发条件 | 前置权限 | 二次确认 | 成功态 | 失败态 |
|---------|--------|------|----------|----------|----------|--------|--------|
| `APP-05-PAGE-topic-list-ACT-search` | 搜索话题 | 顶部 | 输入关键词 | `GLB-ROLE-app-user` | 否 | 列表刷新 | 网络错误 toast |

## 6. 数据联动规则

| 触发字段 | 触发事件 | 影响字段 | 联动行为 | 备注 |
|----------|----------|----------|----------|------|
| 关键词 | 输入 | 话题列表 | 自动筛选启用话题 | 防抖 300ms |

## 7. 状态与异常

| 状态类型 | 触发场景 | 页面表现 | 用户可做的操作 | 引用 |
|----------|----------|----------|----------------|------|
| 加载态 | 首次进入 | 骨架屏 | 无 | — |
| 空态（无数据） | 无启用话题 | 空态 | 返回 | `M05-CFG-topic-dict` |
| 空态（搜索无结果） | 搜索无匹配 | 空态 + 清空按钮 | 清空搜索 | — |
| 错误态（网络） | 请求超时 | toast + 重试 | 重试 | `M05-ERR-*` |
| 无权限态 | 未登录 | 登录引导 | 去登录 | `GLB-ROLE-app-user` |
| 业务态-启用 | 话题启用 | 正常展示 | 查看详情 | `M05-CFG-topic-dict` |
| 降级态 | 话题封面失败 | 默认封面 | 继续浏览 | — |

## 8. 查询与列表

- **默认排序**：推荐话题优先，其余按排序值和热度
- **可选排序**：无
- **分页**：默认 20 条
- **分页方式**：下拉刷新 + 上拉加载更多
- **列表轮询/实时刷新**：不轮询
- **批量选择**：不支持
- **列表为空时的引导**：返回社区热门页

## 9. 验收标准

| AC ID | 场景 | 类型 | 优先级 |
|-------|------|------|--------|
| `APP-05-AC-topic-list` | 展示启用话题 | 正常 | P0 |
| `APP-05-AC-topic-list-sections` | 展示推荐话题和全部话题分区 | 正常 | P0 |
| `APP-05-AC-topic-search` | 按关键词筛选话题 | 正常 | P0 |
| `APP-05-AC-topic-offline` | 话题下线后不可进入新增参与 | 异常 | P0 |

```
AC-ID: APP-05-AC-topic-search
Given 后台存在启用话题
When  用户输入关键词
Then  页面只展示名称或简介命中的启用话题，并可清空恢复列表
```
