# 页面规格 - APP-05-PAGE-community-city 成家同城信息流页

| 版本 | 日期 | 修改人 | 变更摘要 |
|------|------|--------|----------|
| 版本03 | 2026-07-20 | Codex | 同城范围收敛为已审核资料城市，只读展示城市并补齐资料缺失、无内容空态 |
| 版本02 | 2026-07-06 | Codex | 补充内容下架和评论数刷新联动 |
| 版本01 | 2026-07-06 | Codex | 创建页面规格 |

- **页面 ID**：`APP-05-PAGE-community-city`
- **所属模块 PRD**：`模块PRD_APP-05_推荐模块（朋友、社区与内容互动）`
- **页面路由**：`/pages/qianxun/community/city`
- **入口来源**：千寻 -> 成家 -> 同城
- **对应设计稿**：`APP-05-city-01`、`APP-05-city-03`
- **对应移动端 / 技术方案**：`MVP-PAGE-002`

## 1. 页面定位

- **目标用户**：已登录且 PRD-01 已审核资料中存在城市的用户
- **核心任务**：浏览与本人资料城市一致的公开社区动态
- **页面类型**：信息流列表页
- **本期边界**：资料城市只读；本页不提供跨城市浏览能力，不申请 GPS 定位权限

## 2. 布局（给 UI）

### 2.1 整体布局

```
┌────────────────────┐
│ 同城 · 资料城市只读  │
├────────────────────┤
│ 关注 同城 热门 话题  │
├────────────────────┤
│ 当前资料城市内容列表  │
└───────────发布按钮──┘
```

### 2.2 区块说明

| 区块 | 位置 | 内容 | 是否可折叠 | 是否记住展开状态 |
|------|------|------|------------|------------------|
| 城市标识 | 顶部 | 展示 PRD-01 已审核资料城市，只读 | 否 | 否 |
| 内容流 | 主体 | 资料城市一致的公开动态 | 否 | 是 |
| 发布按钮 | 右下角 | 进入发布动态页 | 否 | 否 |

### 2.3 弹层 / 抽屉 / 模态

本页不包含城市相关弹层。资料城市缺失时直接展示整页空态及“完善资料”按钮。

### 2.4 UI 画板拆分（必填）

| 画板 ID | 画板名称 | 设计内容 | 备注 |
|---------|----------|----------|------|
| `APP-05-city-01` | 成家同城信息流-主页面 | 资料城市只读标识、内容流 | 蓝湖现有同城首屏和长列表可承接 |
| `APP-05-city-03` | 成家同城信息流-空态 | 资料城市缺失、当前资料城市无内容两种变体 | 缺失时“完善资料”；无内容时“刷新/去热门” |

### 2.5 编辑控件口径

本页无城市编辑控件；用户需前往 PRD-01 资料编辑页维护城市。发布由 `APP-05-PAGE-post-publish` 承接。

## 3. 筛选与搜索

### 3.1 搜索

本页无搜索能力。

### 3.2 筛选条件

| 筛选 ID | 筛选名 | 类型 | 选项来源 | 是否多选 | 默认值 | 是否可清除 |
|---------|--------|------|----------|----------|--------|------------|
| `APP-05-PAGE-community-city-FILTER-city` | 资料城市 | 服务端固定条件 | PRD-01 已审核用户资料 | 否 | 当前用户资料城市 | 否 |

### 3.3 筛选交互

- 服务端根据登录用户身份读取已审核资料城市；客户端不得提交其他城市覆盖该条件。
- 用户在 PRD-01 更新城市并审核通过后，下次进入或刷新本页时按新资料城市重新查询。

## 6. 数据联动规则

| 触发字段 | 触发事件 | 影响字段 | 联动行为 | 备注 |
|----------|----------|----------|----------|------|
| 资料城市 | 页面进入/刷新 | 内容列表 | 服务端按当前用户已审核资料城市查询 | 客户端不可覆盖 |
| 资料城市 | PRD-01 审核通过 | 内容列表 | 下次进入或刷新后使用新值 | 不在本页实时编辑 |
| 点赞状态 | 点击点赞 | 点赞数 | 成功后 +1 或 -1 | 幂等返回最终态 |
| 内容状态 | 下架/删除 | 内容卡片 | 从列表移除或刷新后不再返回 | `M05-SM-content-audit` |
| 评论状态 | 评论被屏蔽/删除 | 评论数 | 下次列表刷新或详情返回时按服务端统计数更新 | 允许短暂缓存不一致 |

## 7. 状态与异常

| 状态类型 | 触发场景 | 页面表现 | 用户可做的操作 | 引用 |
|----------|----------|----------|----------------|------|
| 加载态 | 首次进入且资料城市存在 | 骨架屏 | 无 | — |
| 空态（资料缺失） | 已审核资料城市为空 | 不请求同城列表，展示资料补全说明 | 完善资料 | `M05-ERR-profile-city-required` |
| 空态（无数据） | 资料城市存在但当前无公开内容 | 保留资料城市标识并展示空态 | 刷新、去热门 | — |
| 错误态（网络） | 请求超时 | toast + 重试 | 重试 | `M05-ERR-*` |
| 无权限态 | 未登录 | 登录引导 | 去登录 | `GLB-ROLE-app-user` |
| 业务态-published | 内容公开 | 正常展示 | 查看、点赞、评论、举报 | `M05-SM-content-audit` |

## 8. 查询与列表

- **查询接口**：`GET /miniapp/community/feed?tab=city`
- **城市条件**：服务端从当前登录用户已审核资料获取，不接收客户端任意城市参数
- **默认排序**：资料城市内容按发布时间倒序
- **可选排序**：无
- **分页**：默认 20 条
- **分页方式**：下拉刷新 + 上拉加载更多
- **列表轮询/实时刷新**：不轮询
- **批量选择**：不支持
- **列表为空时的引导**：刷新或去热门

## 9. 验收标准

| AC ID | 场景 | 类型 | 优先级 |
|-------|------|------|--------|
| `APP-05-AC-city-default` | 仅展示与当前用户已审核资料城市一致的公开内容 | 正常 | P0 |
| `APP-05-AC-city-readonly` | 城市标识只读，客户端不能覆盖服务端查询城市 | 安全 | P0 |
| `APP-05-AC-city-profile-missing` | 资料城市缺失时不请求列表并引导完善资料 | 异常 | P0 |
| `APP-05-AC-city-empty` | 当前资料城市无内容时可刷新或去热门 | 空态 | P0 |

```
AC-ID: APP-05-AC-city-readonly
Given 用户已登录且已审核资料城市为杭州
When  用户进入同城页并请求信息流
Then  服务端仅返回杭州公开内容，页面只读展示“杭州”，客户端不能覆盖查询城市
```

```
AC-ID: APP-05-AC-city-profile-missing
Given 用户已登录但已审核资料城市为空
When  用户进入同城页
Then  页面不请求同城内容，展示说明与“完善资料”按钮，并跳转 PRD-01 资料编辑页
```

## 11. 蓝湖反向缺口补充

- 内容卡补充作者出生年、城市、职业、活跃描述和最近 2 条公开评论预览；有评论时提供“查看全部 N 条评论”。
- 未建立互动关系时展示“申请认识”并进入社区打招呼页；更多操作仅保留作者级“不看 TA 动态/取消不看”，不提供单条内容屏蔽。
- 内容卡内作者城市是作者展示字段；页面顶部资料城市是当前登录用户的信息流范围标识，两者语义不得混用。
