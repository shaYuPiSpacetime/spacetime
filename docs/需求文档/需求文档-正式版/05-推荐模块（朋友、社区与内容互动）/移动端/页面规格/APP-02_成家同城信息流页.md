| 版本 | 日期 | 修改人 | 变更摘要 |
|------|------|--------|----------|

- **页面 ID**：`APP-05-PAGE-community-city`
- **所属模块 PRD**：`模块PRD_APP-05_推荐模块（朋友、社区与内容互动）`
- **页面路由**：`/pages/qianxun/community/city`
- **入口来源**：千寻 -> 成家 -> 同城
- **对应设计稿**：待补充；设计画板按第 2.4 节输出

## 1. 页面定位

- **目标用户**：已登录用户
- **核心任务**：按城市浏览公开社区动态
- **页面类型**：信息流列表页

## 2. 布局（给 UI）

### 2.1 整体布局

```
┌────────────────────┐
│ 同城标题 + 城市选择  │
├────────────────────┤
│ 关注 同城 热门 话题  │
├────────────────────┤
│ 当前城市内容卡片列表  │
└───────────发布按钮──┘
```

### 2.2 区块说明

| 区块 | 位置 | 内容 | 是否可折叠 | 是否记住展开状态 |
|------|------|------|------------|------------------|
| 城市选择 | 顶部 | 当前城市、切换城市入口 | 否 | 是 |
| 内容流 | 主体 | 当前城市公开动态 | 否 | 是 |
| 发布按钮 | 右下角 | 进入发布动态页 | 否 | 否 |

### 2.3 弹层 / 抽屉 / 模态

| 弹层 | 触发方式 | 大小 | 内容 | 关闭方式 |
|------|----------|------|------|----------|
| 城市选择器 | 点击城市 | 底部弹窗 | 当前城市、热门城市、搜索城市 | 点击取消/遮罩 |

### 2.4 UI 画板拆分（必填）

| 画板 ID | 画板名称 | 设计内容 | 备注 |
|---------|----------|----------|------|
| `APP-05-city-01` | 成家同城信息流-主页面 | 城市选择、内容流 | |
| `APP-05-city-02` | 成家同城信息流-城市选择器 | 城市选择弹窗 | |
| `APP-05-city-03` | 成家同城信息流-空态 | 当前城市无内容 | |

### 2.5 编辑控件口径

本页仅支持城市选择；发布由 `APP-05-PAGE-post-publish` 承接。

## 3. 筛选与搜索

### 3.1 搜索

| 项 | 说明 |
|----|------|
| 搜索框位置 | 城市选择器顶部 |
| 搜索字段 | 城市名称 |
| 搜索方式 | 模糊匹配 |

| 筛选 ID | 筛选名 | 类型 | 选项来源 | 是否多选 | 默认值 | 是否可清除 |

## 5. 操作表

| 操作 ID | 操作名 | 触发条件 | 前置权限 | 二次确认 | 成功态 | 失败态 | 影响（副作用） |
|---------|--------|----------|----------|----------|--------|--------|----------------|
| `APP-05-PAGE-community-city-ACT-open-detail` | 查看详情 | 内容状态为 `published` | `GLB-ROLE-app-user` | 否 | 跳转动态详情页 | `M05-ERR-content-not-found` | 增加浏览行为 |

### 5.3 页面级操作

| 操作 ID | 操作名 | 位置 | 触发条件 | 前置权限 | 二次确认 | 成功态 | 失败态 |

## 6. 数据联动规则

| 触发字段 | 触发事件 | 影响字段 | 联动行为 | 备注 |
|----------|----------|----------|----------|------|
| 城市 | 选择城市 | 内容列表 | 自动刷新当前城市内容 | 记住最近选择 |
| 点赞状态 | 点击点赞 | 点赞数 | 成功后 +1 或 -1 | 幂等返回最终态 |
| 内容状态 | 下架/删除 | 内容卡片 | 从列表移除或刷新后不再返回 | `M05-SM-content-audit` |
| 评论状态 | 评论被屏蔽/删除 | 评论数 | 下次列表刷新或详情返回时按服务端统计数更新 | 允许短暂缓存不一致 |

## 7. 状态与异常

| 状态类型 | 触发场景 | 页面表现 | 用户可做的操作 | 引用 |
|----------|----------|----------|----------------|------|
| 加载态 | 首次进入 | 骨架屏 | 无 | — |
| 空态（无数据） | 当前城市无内容 | 空态 + 切换城市入口 | 切换城市 | — |
| 空态（搜索无结果） | 城市搜索无结果 | 城市选择器空态 | 清空搜索 | — |
| 错误态（网络） | 请求超时 | toast + 重试 | 重试 | `M05-ERR-*` |
| 无权限态 | 未登录 | 登录引导 | 去登录 | `GLB-ROLE-app-user` |
| 业务态-published | 内容公开 | 正常展示 | 查看、点赞、评论、举报 | `M05-SM-content-audit` |
| 降级态 | 城市来源缺失 | 默认城市 + 手动选择 | 选择城市 | 地区字典 |

## 8. 查询与列表

- **默认排序**：当前城市内容按发布时间倒序
- **可选排序**：无
- **分页**：默认 20 条
- **分页方式**：下拉刷新 + 上拉加载更多
- **列表轮询/实时刷新**：不轮询
- **批量选择**：不支持
- **列表为空时的引导**：切换城市或去热门
