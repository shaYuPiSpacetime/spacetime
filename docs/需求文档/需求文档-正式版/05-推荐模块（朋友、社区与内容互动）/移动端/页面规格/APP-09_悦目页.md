## 1. 页面定位

- **目标用户**：已登录用户
- **核心任务**：以图片优先方式浏览公开内容，并进入动态详情互动
- **页面类型**：瀑布流列表页

## 2. 布局（给 UI）

### 2.1 整体布局

```
┌────────────────────┐
│ 悦目标题             │
├────────────────────┤
│ 双列图片瀑布流        │
│ 图片 作者 点赞数      │
└────────────────────┘
```

### 2.2 区块说明

| 区块 | 位置 | 内容 | 是否可折叠 | 是否记住展开状态 |
|------|------|------|------------|------------------|
| 顶部标题 | 顶部 | 悦目标题和刷新 | 否 | 否 |
| 图片流 | 主体 | 双列图片卡片 | 否 | 是 |

图片流按双列等宽瀑布流展示，图片使用服务端返回的原始宽高比计算高度，禁止固定高度拉伸；点击图片进入全屏预览，点赞在卡片内完成即时反馈。

### 2.3 弹层 / 抽屉 / 模态

| 弹层 | 触发方式 | 大小 | 内容 | 关闭方式 |
|------|----------|------|------|----------|
| 图片预览 | 点击图片 | 全屏 | 图片预览、进入详情 | 点击关闭 |
| 更多操作弹窗 | 点击更多 | 底部弹窗 | 分享、关注/取消关注、不看 TA 动态/取消不看、举报 | 点击取消/遮罩 |

### 2.4 UI 画板拆分（必填）

| 画板 ID | 画板名称 | 设计内容 | 备注 |
|---------|----------|----------|------|
| `APP-05-yuemu-01` | 悦目-主页面 | 双列瀑布流 | |
| `APP-05-yuemu-03` | 悦目-空态 | 暂无悦目内容 | |

图片全屏预览复用客户端通用图片预览组件，不单独要求 UI 画板。

### 2.5 编辑控件口径

本页为展示页，无编辑控件。

## 7. 状态与异常

| 状态类型 | 触发场景 | 页面表现 | 用户可做的操作 | 引用 |
|----------|----------|----------|----------------|------|
| 加载态 | 首次进入 | 双列骨架屏 | 无 | — |
| 空态（无数据） | 无悦目内容 | 空态 | 刷新 | `M05-RULE-yuemu-source` |
| 空态（搜索无结果） | 本页无搜索 | 本节不适用 | — | — |
| 错误态（网络） | 请求超时 | toast + 重试 | 重试 | `M05-ERR-*` |
| 无权限态 | 未登录 | 登录引导 | 去登录 | `GLB-ROLE-app-user` |
| 业务态-published | 内容公开 | 正常展示 | 预览、详情、点赞 | `M05-SM-content-audit` |
| 降级态 | 图片加载失败 | 占位图 | 继续浏览 | — |

## 8. 查询与列表

- **默认排序**：发布时间倒序
- **可选排序**：无
- **分页**：默认 20 条
- **分页方式**：瀑布流加载更多
- **列表轮询/实时刷新**：不轮询
- **批量选择**：不支持
- **列表为空时的引导**：下拉刷新

## 9. 验收标准

| AC ID | 场景 | 类型 | 优先级 |
|-------|------|------|--------|
| `APP-05-AC-yuemu-list` | 图片内容双列展示 | 正常 | P0 |
| `APP-05-AC-yuemu-ratio` | 图片按原始宽高比展示 | 正常 | P0 |
| `APP-05-AC-yuemu-preview` | 点击图片打开预览 | 正常 | P0 |
| `APP-05-AC-yuemu-like-load` | 点赞与加载更多可反馈 | 正常 | P1 |
| `APP-05-AC-yuemu-detail` | 从图片进入动态详情 | 正常 | P0 |

```
AC-ID: APP-05-AC-yuemu-list
Given 用户已登录且存在符合 `M05-RULE-yuemu-source` 的公开图片内容
When  进入悦目页
Then  页面以双列瀑布流展示图片、作者和点赞数
```

```
AC-ID: APP-05-AC-yuemu-ratio
Given 服务端返回图片 `coverWidth` 和 `coverHeight`
When  前台渲染悦目双列瀑布流
Then  每张图片按 `coverWidth / coverHeight` 计算展示高度，不使用固定高度强制拉伸
```
