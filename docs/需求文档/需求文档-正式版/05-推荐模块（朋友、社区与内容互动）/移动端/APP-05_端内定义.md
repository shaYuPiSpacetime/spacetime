## 2. 登录态与核心准入

| 用户状态 | 可见页面/能力 | 可操作能力 | 不满足时处理 |
|----------|---------------|------------|--------------|
| 未登录 | 可进入入口骨架和登录引导 | 无 | 引导微信登录 |
| 已登录且账号正常 | 可浏览公开动态、话题、悦目、诚意贴；可提交举报 | 浏览、举报 | 涉及互动时按下一行判断 |
| 已登录且满足 `M05-RULE-interaction-gate` | 可参与发布、评论、回复、点赞、关注、@用户、社区打招呼和普通私信资格判断 | 全部本期互动 | 普通私信发送仍以 `M03-RULE-private-chat-open` 为准 |
| 账号冻结/停用/注销中 | 可按账号规则查看必要历史提示 | 无新增互动 | 展示账号状态提示 |

## 3. 移动端 UI 空态 / 错误态 / 降级态

| 场景 | 页面表现 | 默认文案 |
|------|----------|----------|
| 关注信息流无内容 | 空态 + 推荐去热门浏览 | 还没有关注动态 |
| 同城无内容 | 空态 + 城市选择入口 | 这个城市暂时没有新动态 |
| 热门无内容 | 空态 + 下拉刷新 | 暂无热门内容 |
| 话题无内容 | 话题头保留，列表空态 | 暂无相关内容 |
| 悦目无内容 | 图片流空态 | 暂无悦目内容 |
| 诚意贴无内容 | 列表空态 + 发布入口按权限展示 | 暂无诚意贴 |
| 未满足互动门槛 | 按钮置灰或点击弹出引导 | 完成认证后即可参与互动 |
| 内容安全服务异常 | 提交成功后进入复核提示 | 内容已提交复核，请等待结果 |
| 字典加载失败 | 话题/举报原因显示重试入口 | 数据加载失败，请重试 |
| 图片上传达到上限 | 发布页隐藏添加入口并保留删除 | 最多上传 9 张图片 |
| 悦目加载更多结束 | 加载更多按钮置灰 | 已加载全部 |
| 城市来源缺失 | 同城页展示默认城市和手动选择 | 请选择你想浏览的城市 |
| 悄悄话已有待回复 | 社区打招呼页展示等待态 | 你已发送悄悄话，等待对方回复 |
| 普通私信条件不足 | 社区发私信页展示原因和打招呼入口 | 相互喜欢后才能聊天 |
| 作者头像缺失或加载失败 | 展示平台默认头像图片，不展示姓名、姓氏首字或昵称文字头像 | 头像暂不可用 |
