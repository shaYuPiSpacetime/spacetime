# PRD-06 甲方前置准备清单

| 版本01 | 2026-07-08 | Codex | 创建 PRD-06 前置准备清单 |

## 1. 必须提供

| 编号 | 准备项 | 内容要求 | 影响范围 | 未提供时处理 |
|------|--------|----------|----------|--------------|
| M06-PREP-01 | 合规文档正式文本 | 用户协议、隐私政策、隐私摘要、单身承诺函、第三方信息共享清单、个人信息收集清单、平台信息管理规范 | 实名认证页、设置页、关于我们、公告与协议配置 | 使用占位 H5，标记上线前阻塞；单身承诺函需提供正式 H5 并确认初始版本 |
| M06-PREP-02 | 客服承接方式 | 微信客服链接、客服电话或客服 H5 地址、服务时间 | 帮助与客服页 | 未提供时入口置灰，并提示“客服暂不可用，请稍后再试” |
| M06-PREP-05 | 搜索屏蔽词首批词 | 违规词、屏蔽原因、启停 | 搜索结果、搜索屏蔽词后台 | 仅依赖内容状态过滤 |
| M06-PREP-06 | 安全提示内容 | 反诈指南、平台规范、安全提醒 H5 或原生内容 | 帮助客服、关于我们、安全提示配置 | 不展示安全提示卡片 |
| M06-PREP-07 | 注销规则运营口径 | 未到期会员、千寻币余额、邀请奖励未结算时的提示文案 | 隐私设置、注销申请后台 | 使用 PRD 默认“提示后继续申请”口径 |
| M06-PREP-08 | 移动端入口图标素材 | 我的页、设置页、帮助客服、认证中心、推荐给好友、签到等入口图标 | 我的页、设置页、入口配置后台 | Demo 使用占位图标 |
| M06-PREP-09 | 邀请规则 H5 | 与当前已发布 PRD-07 规则一致的正式 H5 URL，至少覆盖完成注册成功口径、永久关系、五类奖励事件、阶梯当次额外奖励和资格限制 | H5 内容配置、PRD-07 活动规则页 | 使用最近成功缓存；首次上线无缓存时阻塞邀请入口验收 |

## 2. 上线前风险

| 风险 ID | 风险 | 影响 | 处理 |
|---------|------|------|------|
| M06-RISK-01 | 合规文档未定稿 | 小程序审核和注销流程合规风险 | 上线门禁；未提供正式文本前不得通过上线验收 |
| M06-RISK-02 | 微信订阅消息模板未申请 | 外部提醒不可用 | 不影响站内通知，按 PRD-03 降级 |
| M06-RISK-03 | 搜索屏蔽词缺失 | 搜索违规词过滤不足 | 运营上线前补首批词，后续持续维护 |
| M06-RISK-04 | 安全中心设计稿缺失 | 不影响一期独立页，因为独立安全中心不做 | 安全提示入口和文案代码固定 |
| M06-RISK-05 | 邀请规则 H5 与 PRD-07 已发布规则不一致 | 用户看到的说明与实际发奖不一致 | 发布前由运营核对 PRD-07 规则版本；不一致时禁止通过上线验收 |

## 3. 自检结论

| 项 | 结论 |
|----|------|
| 是否存在普通未决标记 | 无；无法由 PRD 自行给出真实内容的项均进入本清单 |
| 是否阻塞 PRD 初稿 | 不阻塞 |
| 是否阻塞上线 | 合规文档、客服链接、搜索屏蔽词首批配置阻塞上线验收 |
