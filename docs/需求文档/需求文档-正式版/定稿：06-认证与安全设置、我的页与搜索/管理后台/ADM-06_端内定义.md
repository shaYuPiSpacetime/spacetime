## 1. 信息架构（菜单 / 页面树）

| 一级菜单 | 二级页面 / 区块 | 页面 ID | 一句话职责 | 页面性质 | 优先级 |
|----------|----------------|---------|------------|----------|--------|
| 用户准入 | App 用户管理-设置字段补充 | `ADM-06-PAGE-app-user-settings-fields` | 在 ADM-01 用户管理列表补充注销、搜索和设置摘要字段 | 原页面补充 | P0 |
| 用户准入 | App 用户详情-设置与安全区块 | `ADM-06-PAGE-app-user-settings-section` | 并入 ADM-01 现有用户详情页，查看设置、注销和搜索摘要；不新增菜单、路由或独立页面 | 原页面补充 | P0 |
| 用户安全设置 | 注销申请 | `ADM-06-PAGE-cancellation-list` | 查询注销申请、阻断原因、后悔期、撤销和最终注销状态 | 独立页面 | P0 |
| 运营中心 | 搜索屏蔽词 | `ADM-06-PAGE-search-block-words` | 维护搜索违规词和屏蔽原因 | 独立页面 | P0 |
| 移动端配置管理 | 公告与协议配置 | `ADM-06-PAGE-compliance-config` | 配置公告、帮助、协议、单身承诺函、隐私政策、清单和平台规范链接 | 独立页面 | P0 |

## 3. 敏感操作审计要求

| 操作 | 是否二次确认 | 是否记录审计日志 | 审计日志保留 |
|------|--------------|------------------|--------------|
| 修改搜索屏蔽词 | 是 | 是 | >= 1 年 |
| 修改注销后悔期或阻断规则 | 是 | 是 | >= 1 年 |
| 导出注销列表 | 是 | 是 | >= 1 年 |
| 下线合规文档或协议链接 | 是 | 是 | >= 1 年 |

## 4. UI 空态 / 错误态 / 降级态

| 场景 | 页面表现 | 默认文案 |
|------|----------|----------|
| 注销申请无数据 | 表格空态 | 暂无注销申请 |
| 搜索屏蔽词无数据 | 表格空态 + 新增入口 | 暂无屏蔽词 |
| 合规链接缺失 | 风险提示条 | 合规内容未配置 |
| 无权限 | 菜单隐藏或按钮置灰 | 无操作权限 |
| 配置版本冲突 | 弹窗提示刷新 | 配置已被他人修改，请刷新 |
| 字典加载失败 | code 展示 + 重试 | 字典加载失败，请重试 |

## 5. 原页面补充落点

| 补充规格 | 原页面 | 建议承接位置 | Demo 实现前要求 |
