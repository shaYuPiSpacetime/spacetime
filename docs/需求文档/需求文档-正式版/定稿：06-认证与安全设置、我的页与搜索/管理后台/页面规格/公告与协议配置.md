- **对应移动端 / 技术方案**：APP-06 合规内容页、`APP-07-PAGE-invite-rules`

## 1. 页面定位

- **目标用户**：运营、超级管理员；客服与风控只读。
- **核心任务**：维护预置 H5 内容的标题、URL、版本、状态和预览。`invite_rules` 的内容配置归 PRD-06，但邀请资格、奖励事件、金额和阶梯算法只引用 PRD-07，不在本页编辑。
- **页面类型**：列表型内容配置页。

## 4. 字段表

### 4.1 列表字段

| 字段 ID | 显示名 | 类型 | 必填 | 取值范围 | 校验规则 | 默认值 | 可编辑 | 敏感级别 | 数据来源 |
|---------|--------|------|------|----------|----------|--------|--------|----------|----------|
| `ADM-06-PAGE-compliance-config-FIELD-content-key` | 内容类型 | enum | 是 | `M06-ENUM-h5-content-key` | 系统预置且唯一 | 预置值 | 否 | 普通 | 系统初始化 |
| `ADM-06-PAGE-compliance-config-FIELD-title` | 标题 | string | 是 | 1-40 字 | 同内容键内非空；前后端校验 | 预置标题 | 运营/超管可编辑；不改变业务规则 | 普通 | 后台配置 |
| `ADM-06-PAGE-compliance-config-FIELD-source-module` | 来源模块 | enum | 是 | PRD-01/PRD-06/PRD-07 | 与内容键映射固定 | PRD-06 | 否 | 普通 | 系统初始化 |
| `ADM-06-PAGE-compliance-config-FIELD-version` | 版本 | string | 是 | `v{major}.{minor}` | URL 变化自动递增；`v1.9→v2.0` | v1.0 | 否 | 普通 | 系统计算 |
| `ADM-06-PAGE-compliance-config-FIELD-link-type` | 跳转类型 | enum | 是 | `h5` | 一期固定为 H5 | h5 | 否 | 普通 | 系统初始化 |
| `ADM-06-PAGE-compliance-config-FIELD-url` | H5 地址 | string | 是 | HTTPS URL，最长 500 字符 | 必须 HTTPS、可访问且域名在小程序业务域名白名单 | 无 | 运营/超管可编辑；保存触发版本递增 | 普通 | 后台配置 |
| `ADM-06-PAGE-compliance-config-FIELD-effective-time` | 生效时间 | datetime | 是 | `yyyy-MM-dd HH:mm:ss` | 保存成功后服务端生成 | 初始化时间 | 否 | 普通 | 系统生成 |
| `ADM-06-PAGE-compliance-config-FIELD-status` | 状态 | enum | 是 | 启用/停用 | 邀请入口启用时 `invite_rules` 不允许停用 | 启用 | 运营/超管可编辑；高风险操作需确认 | 普通 | 后台配置 |

## 5. 操作表

### 5.1 行级操作

| 操作 ID | 操作名 | 触发条件 | 前置权限 | 二次确认 | 成功态 | 失败态 | 影响（副作用） |
|---------|--------|----------|----------|----------|--------|--------|----------------|
| `ADM-06-PAGE-compliance-config-ACT-edit` | 编辑 | 任意预置项加载成功 | `ADM-06_端内定义` 的运营/超管编辑权限 | 保存停用状态时需要 | 打开/保存弹窗；URL 改变则版本递增并提示 | URL 非法或版本冲突时保留表单；引用 `M06-ERR-content-link-missing` | 触发 `M06-EVT-h5-content-published` 并刷新当前行 |
| `ADM-06-PAGE-compliance-config-ACT-preview` | 预览 | URL 有效 | `ADM-06_端内定义` 的查看权限 | 否 | 打开移动端宽度 H5 预览 | 加载失败显示目标 URL 与重试 | 只读，无数据变更 |
| `ADM-06-PAGE-compliance-config-ACT-disable` | 停用 | 当前状态启用 | 运营/超管 | 是，“停用后前台优先使用最近成功缓存” | 允许时变为停用并记录审计 | 邀请入口启用时拒绝停用 `invite_rules`，引用 `M06-ERR-business-content-disable-blocked` | 前台不再获取该版本；缓存不主动删除 |

## 6. 数据联动规则

| 触发字段 | 触发事件 | 影响字段 | 联动行为 | 备注 |
|----------|----------|----------|----------|------|
| 内容分组 Tab | 切换 | 表格行 | 仅展示对应分组；业务规则只展示 `invite_rules` | `M06-ENUM-h5-content-key` |
| H5 URL | 保存且发生变化 | 版本、生效时间 | 版本尾号递增并更新生效时间 | `M06-RULE-compliance-version` |
| 标题 | 保存且 URL 未变化 | 版本 | 版本保持不变 | 标题不改变内容版本 |
| `invite_rules` 状态 | 改为停用 | 保存结果 | PRD-07 邀请入口启用时阻止保存 | `M06-RULE-business-h5-content` |
| `invite_rules` URL | 保存成功 | PRD-07 活动规则页 | 下次进入读取新版本；已打开页面不强制刷新 | 移动端缓存最近成功版本 |

## 7. 状态与异常

| 状态类型 | 触发场景 | 页面表现 | 用户可做的操作 | 引用 |
|----------|----------|----------|----------------|------|
| 加载态 | 首次进入或切换 Tab | 表格骨架屏；Tab 可见不可重复点击 | 等待 | — |
| 空态（无数据） | 系统初始化异常 | 风险提示，不提供新增按钮 | 刷新/联系管理员 | `M06-CFG-compliance-links`、`M06-CFG-business-h5-links` |
| 空态（业务规则） | `invite_rules` 预置失败 | 显示“邀请规则配置缺失”的阻塞提示 | 刷新/联系管理员 | `M06-ERR-h5-cache-missing` |
| 错误态（网络） | 查询或保存超时 | Toast；保留上次列表或表单 | 重试 | — |
| 错误态（版本冲突） | 其他人已更新同一项 | 提示刷新，不覆盖服务端版本 | 刷新后重新编辑 | `ADM-06_端内定义` |
| 无权限态 | 无查看权限 | 菜单隐藏；直达路由展示无权限页 | 返回首页 | `ADM-06_端内定义` |
| 业务态-启用 | 状态为启用 | 绿色标签，可预览/编辑 | 预览、编辑 | `M06-RULE-business-h5-content` |
| 业务态-停用 | 状态为停用 | 灰色标签，展示前台影响提示 | 预览、编辑并重新启用 | `M06-RULE-business-h5-content` |
| 降级态 | H5 预览加载失败 | 预览区错误态并展示目标 URL | 重试/关闭 | `M06-ERR-content-link-missing` |

## 8. 查询与列表

- **默认排序**：按 `M06-ENUM-h5-content-key` 固定顺序。
- **可选排序**：不支持。
- **分页**：不分页，每个 Tab 一次返回全部预置项。
- **轮询**：不轮询，点击刷新主动获取。
- **批量选择**：不支持。

## 9. 验收标准

| AC ID | 场景 | 类型 | 优先级 |
|-------|------|------|--------|
| `ADM-06-AC-h5-tabs` | 三个 Tab 只展示对应预置项 | 正常 | P0 |
| `ADM-06-AC-invite-rules-save` | 保存邀请规则 H5 并升级版本 | 正常 | P0 |
| `ADM-06-AC-invite-rules-boundary` | 页面不提供奖励金额或阶梯编辑 | 正常 | P0 |
| `ADM-06-AC-invite-rules-disable-blocked` | 邀请入口启用时阻止停用 | 异常 | P0 |
| `ADM-06-AC-h5-preview` | 预览 H5 正常/失败状态 | 正常/异常 | P0 |

```text
AC-ID: ADM-06-AC-invite-rules-save
Given 运营具备编辑权限，invite_rules 当前版本为 v4.0，PRD-07 规则版本已核对
When  运营将 H5 URL 替换为合法 HTTPS 地址并保存
Then  系统保存 URL、将版本升级为 v4.1、更新生效时间、记录 M06-EVT-h5-content-published；PRD-07 的奖励金额和阶梯配置不发生变化
```

```text
AC-ID: ADM-06-AC-invite-rules-disable-blocked
Given PRD-07 邀请入口处于启用状态且 invite_rules 当前启用
When  运营尝试将 invite_rules 改为停用并确认
Then  系统拒绝保存并返回 M06-ERR-business-content-disable-blocked，原配置继续启用
```
