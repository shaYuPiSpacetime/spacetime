# 页面规格 - APP-06-PAGE-cancellation-modal 账号注销确认弹窗

| 版本 | 日期 | 修改人 | 变更摘要 |
|------|------|--------|----------|
| 版本01 | 2026-07-08 | Codex | 创建页面规格 |

- **页面 ID**：`APP-06-PAGE-cancellation-modal`
- **所属模块 PRD**：`模块PRD_APP-06_认证与安全设置、我的页与搜索`
- **页面路由**：`/pages/my/privacy` 内底部弹窗
- **入口来源**：隐私设置页 -> 注销账号
- **对应设计稿**：当前未绑定蓝湖画板；设计画板按第 2.4 节输出
- **对应移动端 / 技术方案**：`MVP-POP-024`

## 1. 页面定位

- **目标用户**：已登录 App 用户
- **核心任务**：阅读注销说明、查看阻断或风险提示、确认提交或撤销注销
- **页面类型**：底部弹窗

## 2. 布局（给 UI）

### 2.1 整体布局

```text
┌────────────────────┐
│ 注销说明标题         │
├────────────────────┤
│ 阻断/风险原因列表     │
├────────────────────┤
│ 勾选确认             │
├────────────────────┤
│ 取消 / 确认提交       │
└────────────────────┘
```

### 2.2 区块说明

| 区块 | 位置 | 内容 | 是否可折叠 | 是否记住展开状态 |
|------|------|------|------------|------------------|
| 说明区 | 顶部 | 注销影响、后悔期、数据处理说明 | 否 | 否 |
| 原因区 | 主体 | 阻断原因或可确认风险 | 否 | 否 |
| 勾选区 | 底部上方 | 我已阅读并确认 | 否 | 否 |
| 操作区 | 底部 | 取消、确认提交 | 否 | 否 |

### 2.3 弹层 / 抽屉 / 模态

本文件本身为弹窗；不再嵌套弹层。

### 2.4 UI 画板拆分（必填）

| `APP-06-cancel-03` | 注销确认-提交成功 | 后悔期说明 | P0 |

### 2.5 编辑控件口径

| 区域 | 展现形式 | 编辑控件 | 新增/删除方式 | 保存方式 |
|------|----------|----------|----------------|----------|
| 确认勾选 | 表单 | 复选框 | 不适用 | 点击确认提交 |

## 3. 筛选与搜索

本弹窗无筛选搜索。

## 4. 字段表

### 4.1 列表字段

本弹窗不展示列表。

#### 列表字段附加属性

本弹窗不适用。

### 4.2 详情/表单字段

| 字段 ID | 显示名 | 类型 | 必填 | 取值范围 | 校验规则 | 默认值 | 可编辑 | 敏感级别 | 数据来源 |
|---------|--------|------|------|----------|----------|--------|--------|----------|----------|
| `APP-06-PAGE-cancellation-modal-FIELD-block-reasons` | 阻断原因 | json[] | 否 | 封禁/退款/争议等 | 硬阻断时禁止提交 | 空 | 否 | 敏感（仅本人） | PRD-04/风控/账号 |
| `APP-06-PAGE-cancellation-modal-FIELD-risk-items` | 风险提示 | json[] | 否 | 会员/千寻币/奖励 | 可确认风险需展示 | 空 | 否 | 敏感（仅本人） | PRD-04/07 |
| `APP-06-PAGE-cancellation-modal-FIELD-confirm-checked` | 已阅读确认 | bool | 是 | true/false | 必须为 true 才能提交 | false | 当前用户可编辑 | 普通 | 用户勾选 |
| `APP-06-PAGE-cancellation-modal-FIELD-cooling-days` | 后悔期天数 | int | 是 | `M06-CFG-cancellation-cooling-days` | 大于 0 | 30 | 否 | 普通 | 后台配置 |
| `APP-06-PAGE-cancellation-modal-FIELD-recheck-token` | 重新校验凭证 | string | 否 | 后端校验返回 | 阻断解除后必须重新获取 | 无 | 否 | 敏感（仅系统） | 后端注销校验 |

## 5. 操作表

### 5.1 行级操作

本弹窗无行级操作。

### 5.2 批量操作

本弹窗不支持批量操作。

### 5.3 页面级操作

| 操作 ID | 操作名 | 位置 | 触发条件 | 前置权限 | 二次确认 | 成功态 | 失败态 |
|---------|--------|------|----------|----------|----------|--------|--------|
| `APP-06-PAGE-cancellation-modal-ACT-submit` | 确认注销 | 底部 | 无硬阻断且已勾选 | `GLB-ROLE-app-user` | 本弹窗即确认 | 创建注销申请并进入后悔期 | `M06-ERR-cancellation-blocked` |
| `APP-06-PAGE-cancellation-modal-ACT-cancel` | 取消 | 底部 | 弹窗打开 | `GLB-ROLE-app-user` | 否 | 关闭弹窗 | 无 |
| `APP-06-PAGE-cancellation-modal-ACT-service` | 联系客服 | 阻断态 | 命中硬阻断 | `GLB-ROLE-app-user` | 否 | 打开客服/反馈 | 客服链接缺失 |
| `APP-06-PAGE-cancellation-modal-ACT-recheck` | 重新校验 | 阻断态 | 用户重新进入弹窗或点击重试 | `GLB-ROLE-app-user` | 否 | 刷新阻断/风险结果 | 网络错误提示 |

## 6. 数据联动规则

| 触发字段 | 触发事件 | 影响字段 | 联动行为 | 备注 |
|----------|----------|----------|----------|------|
| 阻断原因 | 非空 | 确认按钮 | 禁用确认提交，展示客服入口 | `M06-RULE-account-cancellation-check` |
| 确认勾选 | 勾选 | 确认按钮 | 无硬阻断时启用 | 防误触 |
| 重新校验结果 | 阻断解除 | 阻断原因、确认按钮 | 清空硬阻断，展示可确认风险或标准说明，用户需重新勾选 | `M06-SM-account-cancellation` |

## 7. 状态与异常

| 状态类型 | 触发场景 | 页面表现 | 用户可做的操作 | 引用 |
|----------|----------|----------|----------------|------|
| 加载态 | 校验注销条件 | 弹窗 loading | 无 | — |
| 空态（无数据） | 无阻断无风险 | 展示标准说明 | 勾选确认 | `M06-RULE-account-cancellation-check` |
| 空态（搜索无结果） | 本弹窗不适用 | 本节不适用 | 无 | — |
| 错误态（网络） | 校验失败 | toast + 重试 | 重试 | `M06-ERR-cancellation-blocked` |
| 无权限态 | 未登录 | 登录引导 | 去登录 | `GLB-ROLE-app-user` |
| 业务态-硬阻断 | 命中阻断 | 原因列表 + 客服入口 | 联系客服 | `M06-ENUM-cancellation-status` |
| 降级态 | 资产服务不可用 | 显示“资产状态同步中”并禁止提交 | 稍后重试 | PRD-04 |

## 8. 查询与列表

本弹窗不展示列表。

## 9. 验收标准

| AC ID | 场景 | 类型 | 优先级 |
|-------|------|------|--------|
| `APP-06-AC-cancel-submit` | 正常提交注销 | 正常 | P0 |
| `APP-06-AC-cancel-blocked` | 命中硬阻断 | 异常 | P0 |
| `APP-06-AC-cancel-risk` | 未到期会员风险提示 | 正常 | P0 |
| `APP-06-AC-cancel-block-retry` | 硬阻断解除后重新校验 | 正常 | P0 |

```text
AC-ID: APP-06-AC-cancel-blocked
Given 当前账号存在未完成退款
When  用户打开注销确认弹窗
Then  弹窗展示未完成退款阻断原因，确认注销按钮不可点击，并展示联系客服入口
```

```text
AC-ID: APP-06-AC-cancel-submit
Given 当前账号未命中硬阻断，且用户已勾选阅读确认
When  用户点击确认注销
Then  系统创建注销申请，状态进入后悔期，并展示预计注销时间
```

```text
AC-ID: APP-06-AC-cancel-risk
Given 当前账号仅命中未到期会员或千寻币余额等可确认风险
When  用户阅读风险说明并勾选确认后提交
Then  系统允许创建注销申请，同时在后台申请记录中保留风险项摘要
```

```text
AC-ID: APP-06-AC-cancel-block-retry
Given 用户上次打开弹窗时命中未完成退款硬阻断
When  退款已完成且用户再次进入注销弹窗触发重新校验
Then  弹窗不沿用旧阻断结果，按最新校验展示标准说明或可确认风险，并要求用户重新勾选确认
```
