# 页面规格 - APP-06-PAGE-policy-content 协议与政策内容页

| 版本 | 日期 | 修改人 | 变更摘要 |
|------|------|--------|----------|
| 版本01 | 2026-07-08 | Codex | 创建页面规格，承接关于我们页的协议与政策内容展示 |

- **页面 ID**：`APP-06-PAGE-policy-content`
- **所属模块 PRD**：`模块PRD_APP-06_认证与安全设置、我的页与搜索`
- **页面路由**：`/pages/my/compliance/policy`
- **入口来源**：关于我们页 -> 用户协议 / 隐私政策 / 隐私摘要 / 平台信息管理规范
- **对应设计稿**：当前未绑定蓝湖画板；设计画板按第 2.4 节输出
- **对应移动端 / 技术方案**：`MVP-PAGE-069`、`MVP-PAGE-070`、`MVP-PAGE-071`、`MVP-PAGE-072`

## 1. 页面定位

- **目标用户**：访客、App 用户
- **核心任务**：查看用户协议、隐私政策、隐私摘要、平台信息管理规范等合规内容
- **页面类型**：合规内容页

## 2. 布局（给 UI）

### 2.1 整体布局

```text
┌────────────────────┐
│ 返回 / 内容标题       │
├────────────────────┤
│ 版本 / 生效时间        │
├────────────────────┤
│ H5 WebView / 原生正文  │
└────────────────────┘
```

### 2.2 区块说明

| 区块 | 位置 | 内容 | 是否可折叠 | 是否记住展开状态 |
|------|------|------|------------|------------------|
| 标题栏 | 顶部 | 返回、内容标题 | 否 | 否 |
| 元信息 | 标题下 | 版本号、生效时间、更新时间 | 否 | 否 |
| 正文区 | 主体 | H5 WebView 或原生富文本正文 | 否 | 否 |

### 2.3 弹层 / 抽屉 / 模态

本页无弹层。

### 2.4 UI 画板拆分（必填）

| 画板 ID | 画板名称 | 设计内容 | 备注 |
|---------|----------|----------|------|

| `APP-06-policy-02` | 协议政策-内容缺失 | 空态、返回、重试 | P0 |

### 2.5 编辑控件口径

本页无编辑控件；内容由 `M06-CFG-compliance-links` 配置。

## 3. 筛选与搜索

本页无筛选搜索。

## 7. 状态与异常

| 状态类型 | 触发场景 | 页面表现 | 用户可做的操作 | 引用 |
|----------|----------|----------|----------------|------|
| 加载态 | 内容加载 | loading | 无 | — |
| 空态（无数据） | 内容未配置 | 内容暂不可查看 + 返回 | 返回关于我们页 | `M06-ERR-content-link-missing` |
| 空态（搜索无结果） | 本页不适用 | 本节不适用 | 无 | — |
| 错误态（网络） | H5 或配置查询失败 | 错误页 + 重试 | 重试 | `M06-ERR-content-link-missing` |
| 无权限态 | 无 | 公开可访问 | 无 | — |
| 业务态-内容有效 | 内容已配置且启用 | 正常展示 | 阅读、返回 | `M06-RULE-compliance-content` |
| 降级态 | H5 不可用但有原生兜底 | 展示原生正文 | 阅读、返回 | `M06-ENUM-link-type` |

## 8. 查询与列表

本页不展示分页列表；根据页面入参 `contentType` 查询单条启用内容。

## 9. 验收标准

| AC ID | 场景 | 类型 | 优先级 |
|-------|------|------|--------|
| `APP-06-AC-policy-open` | 打开协议政策内容 | 正常 | P0 |
| `APP-06-AC-policy-missing` | 内容缺失不空白 | 异常 | P0 |
| `APP-06-AC-policy-native-fallback` | H5 不可用时原生兜底 | 降级 | P1 |

```text
AC-ID: APP-06-AC-policy-open
Given 后台已启用隐私政策内容
When  用户在关于我们页点击隐私政策
Then  页面打开 `APP-06-PAGE-policy-content`，展示标题、版本、生效时间和正文
```

```text
AC-ID: APP-06-AC-policy-missing
Given 后台未配置用户协议链接
When  用户点击用户协议
Then  页面展示内容暂不可查看，并允许返回关于我们页
```
