### 1.1 本期不建页面

| 不建页面 | 原因 | 本期处理方式 |
|----------|------|--------------|
| 独立 IM 会话运营工作台 | 超出首版报价和一期目标 | 隐藏，不建菜单 |
| 独立聊天质检中心 | 依赖内容风控和质检策略 | 后续增值服务 |
| 独立通知投放系统 | 一期只做业务节点通知和站内通知 | 文案与消息中心模板承接 |
| 后台完整通知偏好中心 | 一期目标明确不做 | 不建页面 |
| 完整黑名单管理页 | 一期只保留场景内拉黑和举报 | 用户详情/举报处理展示上下文 |

## 4. 后台 UI 状态

| 状态 ID | 适用页面 | 触发条件 | 页面表现 | 引用 |
|---------|----------|----------|----------|------|
| `ADM-03-STATE-no-permission` | 全部后台页面 | 角色无权限 | 菜单隐藏或按钮置灰；详情区显示无权限态 | `ADM-03_端内定义.md` 第 2 节 |
| `ADM-03-STATE-data-desensitized` | 用户详情、记录查询 | 角色仅可脱敏查看 | 昵称、手机号、消息摘要脱敏；内容详情按钮隐藏 | `ADM-03-PERM-*` |
| `ADM-03-STATE-message-service-down` | 消息记录查询 | 消息服务不可用 | 保留筛选条件，toast + 重试按钮 | `M03-ERR-message-send-failed` |
| `ADM-03-STATE-template-disabled` | 模板配置 | 模板停用 | 状态胶囊显示停用，前台不发送外部提醒但站内记录仍可查 | `M03-ERR-template-disabled` |
