## 1. 页面定位

- **目标用户**：通过邀请关系进入或收到邀请响应通知的用户
- **核心任务**：查看邀请关系响应结果和下一步可做事项
- **页面类型**：详情页

---

## 2. 布局（给 UI）

### 2.1 整体布局

```text
┌────────────────────────────┐
│ 返回  邀请响应              │
├────────────────────────────┤
│ 邀请人卡片 / 关系状态       │
├────────────────────────────┤
│ 奖励提示 / 活动说明         │
├────────────────────────────┤
│ 查看活动规则 / 推荐给好友   │
└────────────────────────────┘
```

### 2.2 区块说明

| 区块 | 位置 | 内容 | 是否可折叠 | 是否记住展开状态 |
|------|------|------|------------|------------------|
| 邀请人卡片 | 顶部 | 邀请人昵称、头像、邀请状态 | 否 | 否 |
| 响应结果 | 主体 | 绑定成功、已响应、奖励处理中等 | 否 | 否 |
| 操作区 | 底部 | 查看活动规则、推荐给好友 | 否 | 否 |

### 2.3 弹层 / 抽屉 / 模态

本页不直接弹层；活动规则跳转 PRD-07 页面。

## 6. 数据联动规则

| 触发字段 | 触发事件 | 影响字段 | 联动行为 | 备注 |
|----------|----------|----------|----------|------|
| 邀请状态 | 奖励到账 | 奖励提示 | 展示奖励到账说明 | PRD-07 |
| 邀请状态 | 失效 | 操作区 | 仅保留查看规则 | PRD-07 |
| 通知中心 | `jumpType=invite_response` 跳转进入 | 响应编号、来源通知编号 | 使用 `jumpValue` 或 `responseNo` 加载邀请响应详情，并将 `noticeNo` 作为来源通知编号 | `M03-ENUM-jump-type` |
| 通知详情 | `jumpType=invite_response` 跳转进入 | 已读状态、入口来源 | 邀请响应通知置已读，`entrySource=通知详情` | `M03-SM-notification-read` |

## 7. 状态与异常

| 状态类型 | 触发场景 | 页面表现 | 用户可做的操作 | 引用 |
|----------|----------|----------|----------------|------|
| 加载态 | 首次进入 | 骨架屏 | 等待 | 通用态 |
| 空态 | 无邀请响应 | 提示暂无邀请响应 | 查看活动规则 | PRD-07 |
| 错误态 | 网络失败 | toast + 重试 | 重试 | 通用态 |
| 无权限态 | 未登录 | 引导登录 | 登录 | `GLB-ROLE-visitor` |
| 业务态-success | 绑定/响应成功 | 展示邀请人和奖励提示 | 推荐给好友 | PRD-07 |
| 业务态-from-notification | 从通知中心或通知详情进入 | 先置已读，再展示邀请响应详情 | 查看规则/推荐给好友 | `M03-SM-notification-read` |
| 业务态-processing | 奖励处理中 | 展示处理中状态 | 查看规则 | PRD-07 |
| 业务态-invalid | 邀请关系失效 | 失效说明 | 返回 | PRD-07 |
| 降级态 | PRD-07 服务不可用 | 展示稍后重试 | 重试 | PRD-07 |

## 9. 验收标准

| AC ID | 场景 | 类型 | 优先级 |
|-------|------|------|--------|
| `APP-03-AC-invite-response-show` | 邀请响应展示 | 正常 | P0 |
| `APP-03-AC-invite-response-fallback` | PRD-07 不可用降级 | 异常 | P1 |

```text
AC-ID: APP-03-AC-invite-response-show
Given 用户收到一条 `bizType=invite_response` 的通知
When  从通知中心或通知详情点击进入邀请响应页
Then  系统携带 `noticeNo` 与 `jumpValue`/`responseNo` 加载邀请响应详情，将来源通知置为 `read`，并展示邀请人、邀请状态、奖励提示和后续操作入口
```
