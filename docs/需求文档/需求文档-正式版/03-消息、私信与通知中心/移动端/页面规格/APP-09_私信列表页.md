# 页面规格 - APP-03-PAGE-private-list 私信列表页

| 版本 | 日期 | 修改人 | 变更摘要 |
|------|------|--------|----------|
| 版本01 | 2026-07-13 | Codex | 按蓝湖“私信”补充独立列表页 |

- **页面路由**：`/pages/message/private-list`
- **入口来源**：消息首页顶部“私信”入口
- **出口**：点击会话进入 `APP-03-PAGE-private-chat`

## 1. 页面定位

展示已匹配用户的普通私信会话，不混入悄悄话、官方小助手或系统消息。

## 2. 页面结构

```text
返回            私信
会话头像  昵称  最新消息摘要  时间/未读
会话头像  昵称  最新消息摘要  时间/状态
```

顶部仅保留返回和标题，不展示筛选、搜索、全部已读或清理图标。

## 3. 字段表

| 字段 ID | 显示名 | 类型 | 必填 | 取值范围 | 校验规则 | 默认值 | 可编辑 | 敏感级别 | 数据来源 |
|---------|--------|------|------|----------|----------|--------|--------|----------|----------|
| `APP-03-PAGE-private-list-FIELD-conversation-no` | 会话编号 | string | 是 | 业务编号 | 当前用户必须是参与方 | 无 | 否 | 普通 | 私信会话 |
| `APP-03-PAGE-private-list-FIELD-avatar` | 对方头像 | image | 否 | 合法 URL | 使用已审核头像 | 默认头像 | 否 | 普通 | 用户资料 |
| `APP-03-PAGE-private-list-FIELD-nickname` | 对方昵称 | string | 是 | 1-20 字 | 使用已审核昵称 | 无 | 否 | 普通 | 用户资料 |
| `APP-03-PAGE-private-list-FIELD-preview` | 最新消息摘要 | string | 否 | 最多 30 字 | 超长省略 | 系统提示 | 否 | 敏感 | 消息记录 |
| `APP-03-PAGE-private-list-FIELD-unread-count` | 未读数 | int | 是 | 0-999 | 超过 99 显示 99+ | 0 | 否 | 普通 | 未读汇总 |
| `APP-03-PAGE-private-list-FIELD-last-time` | 最新时间 | datetime | 是 | datetime | 当天显示时分，其余显示日期 | 无 | 否 | 普通 | 私信会话 |

## 4. 操作表

| 操作 ID | 操作名 | 位置 | 触发条件 | 前置权限 | 二次确认 | 成功态 | 失败态 |
|---------|--------|------|----------|----------|----------|--------|--------|
| `APP-03-PAGE-private-list-ACT-open-chat` | 打开私信 | 会话行 | 双方已匹配且当前用户参与会话 | `GLB-ROLE-app-user` | 否 | 进入私信对话并置已读 | 网络失败保留列表；会话失效时进入只读态 |

## 5. 状态与验收

| 状态 | 页面表现 | 用户操作 |
|------|----------|----------|
| 加载 | 会话骨架屏 | 等待 |
| 空态 | 暂无私信，去推荐页看看 | 返回/去推荐 |
| 错误 | 加载失败提示 | 重试 |
| 未认证 | 展示三重认证引导，不加载会话 | 去认证 |
| 正常 | 按最新消息时间倒序展示 | 进入会话 |
| 失效会话 | 摘要弱化并标记不可发送 | 查看历史 |

```text
Given 用户完成三重认证且存在已匹配会话
When  从消息首页点击“私信”
Then  仅展示普通私信会话；点击会话进入私信对话页，不出现悄悄话、官方助手或系统消息
```
