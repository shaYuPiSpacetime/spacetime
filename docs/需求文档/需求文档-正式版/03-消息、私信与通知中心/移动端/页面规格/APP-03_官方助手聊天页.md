## 1. 页面定位

- **目标用户**：已登录用户
- **核心任务**：查看官方助手发送的平台提示、规则说明和客服引导
- **页面类型**：聊天式详情页

---

## 2. 布局（给 UI）

### 2.1 整体布局

```text
┌────────────────────────────┐
│ 返回  官方助手              │
├────────────────────────────┤
│ 官方消息气泡 / 引导卡片     │
├────────────────────────────┤
│ 不可回复提示或快捷入口      │
└────────────────────────────┘
```

### 2.2 区块说明

| 区块 | 位置 | 内容 | 是否可折叠 | 是否记住展开状态 |
|------|------|------|------------|------------------|
| 顶部导航 | 顶部 | 返回、官方助手名称 | 否 | 否 |
| 消息流 | 主体 | 官方消息、引导卡片、时间 | 否 | 否 |
| 底部提示 | 底部 | 官方助手暂不支持直接回复 | 否 | 否 |

### 2.3 弹层 / 抽屉 / 模态

本页不提供弹层；引导卡片点击跳转对应页面。

### 2.4 UI 画板拆分

| 画板 ID | 画板名称 | 设计内容 | 备注 |
|---------|----------|----------|------|
| `APP-03-assistant-01` | 官方助手聊天页-主页面 | 官方气泡、引导卡片、底部提示 | P0 |
| `APP-03-assistant-02` | 官方助手聊天页-空态 | 暂无官方助手消息 | P1 |
| `APP-03-assistant-03` | 官方助手聊天页-加载失败 | 加载失败和重试 | P1 |

### 2.5 编辑控件口径

本页首版不支持用户输入，不提供编辑控件。

---

## 3. 筛选与搜索

本页不提供搜索筛选；官方助手消息按时间分页加载。

## 4. 字段表

### 4.1 列表字段

| 字段 ID | 显示名 | 类型 | 必填 | 取值范围 | 校验规则 | 默认值 | 可编辑 | 敏感级别 | 数据来源 |
|---------|--------|------|------|----------|----------|--------|--------|----------|----------|
| `APP-03-PAGE-official-assistant-FIELD-message-no` | 消息编号 | string | 是 | 业务编号 | 唯一 | 无 | 不可编辑 | 普通 | 官方消息 |
| `APP-03-PAGE-official-assistant-FIELD-title` | 标题 | string | 否 | 0-30 字 | 超长省略 | 无 | 后台模板配置 | 普通 | 文案与消息中心 |
| `APP-03-PAGE-official-assistant-FIELD-content` | 内容 | string | 是 | 1-500 字 | 模板变量渲染后非空 | 无 | 后台模板配置 | 普通 | 官方消息模板 |
| `APP-03-PAGE-official-assistant-FIELD-card-type` | 卡片类型 | enum | 否 | 文本/跳转卡片/提示卡片 | 非法值降级为文本 | 文本 | 后台配置 | 普通 | 模板配置 |
| `APP-03-PAGE-official-assistant-FIELD-jump-type` | 跳转类型 | enum | 否 | `M03-ENUM-jump-type` | 有跳转按钮时必填 | 无 | 后台配置 | 普通 | 模板配置 |
| `APP-03-PAGE-official-assistant-FIELD-created-time` | 发送时间 | datetime | 是 | datetime | 展示到分钟 | 无 | 不可编辑 | 普通 | 官方消息记录 |
| `APP-03-PAGE-official-assistant-FIELD-read-status` | 已读状态 | enum | 是 | `M03-ENUM-read-status` | 进入页面置已读 | `unread` | 系统流转 | 普通 | 消息记录 |

#### 列表字段附加属性

| 字段 ID | 消息流位置 | 主次层级 | 点击行为 | 手势行为 | 溢出处理 |
|---------|------------|----------|----------|----------|----------|
| `APP-03-PAGE-official-assistant-FIELD-created-time` | 时间分隔条 | 辅助信息 | 不单独响应 | 上滑加载更早消息 | 时间分隔 |
| `APP-03-PAGE-official-assistant-FIELD-content` | 官方消息气泡或引导卡片 | 主要信息 | 有跳转卡片时点击执行 `APP-03-PAGE-official-assistant-ACT-open-card` | 长按菜单首版不提供 | 气泡换行 |
| `APP-03-PAGE-official-assistant-FIELD-jump-type` | 引导卡片按钮区 | 行为信息，不独立展示 | 由卡片或按钮承接跳转行为 | 长按菜单首版不提供 | 无跳转时隐藏按钮 |

## 6. 数据联动规则

| 触发字段 | 触发事件 | 影响字段 | 联动行为 | 备注 |
|----------|----------|----------|----------|------|
| 进入页面 | 加载成功 | 已读状态 | 官方助手未读置已读 | `M03-RULE-unread` |
| 模板停用 | 后台停用 | 消息展示 | 历史消息保留，后续不再生成 | `M03-ERR-template-disabled` |

## 7. 状态与异常

| 状态类型 | 触发场景 | 页面表现 | 用户可做的操作 | 引用 |
|----------|----------|----------|----------------|------|
| 加载态 | 首次进入 | 骨架屏 | 等待 | 通用态 |
| 空态 | 无官方助手消息 | 暂无官方消息 | 返回 | `M03-TERM-official-assistant` |
| 错误态 | 请求失败 | toast + 重试 | 重试 | 通用态 |
| 无权限态 | 未登录 | 引导登录 | 登录 | `GLB-ROLE-visitor` |
| 业务态-有引导卡片 | 存在跳转 | 展示按钮 | 点击跳转 | `M03-ENUM-jump-type` |
| 业务态-纯文本 | 无跳转 | 仅展示消息 | 查看 | `M03-ENUM-message-type=official` |
| 降级态 | 跳转目标不可用 | 卡片置灰或 toast | 返回 | `M03-ERR-notification-not-found` |

---

## 8. 查询与列表

- **默认排序**：发送时间正序
- **分页**：默认 20 条
- **分页方式**：上滑加载更早
- **列表轮询/实时刷新**：不需要
- **批量选择**：不支持
- **列表为空时引导**：返回消息列表
