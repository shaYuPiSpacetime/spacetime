# 页面规格 - APP-03-PAGE-notification-center 系统消息全文页

| 版本 | 日期 | 修改人 | 变更摘要 |
|------|------|--------|----------|
| 版本03 | 2026-07-13 | Codex | 对齐蓝湖改为系统消息全文消息流，移除筛选、全部已读和独立详情页 |

- **页面 ID**：`APP-03-PAGE-notification-center`
- **页面路由**：`/pages/message/system-message`
- **入口来源**：消息首页固定“系统消息”会话
- **对应设计稿**：蓝湖“系统消息”

## 1. 页面定位

- **目标用户**：已登录用户
- **核心任务**：直接阅读全文形式的社区热点、精选内容、社区活动和重要公告
- **页面类型**：只读全文消息流

## 2. 布局（给 UI）

```text
┌────────────────────────────┐
│ 返回       系统消息         │
├────────────────────────────┤
│ 时间                        │
│ 全文消息卡                  │
│ 立即参与 / 立即分享         │
│ 时间                        │
│ 全文消息卡                  │
├────────────────────────────┤
│ 联系客服       社区规则     │
└────────────────────────────┘
```

| 区块 | 位置 | 内容 | 是否可折叠 | 是否记住展开状态 |
|------|------|------|------------|------------------|
| 顶部栏 | 顶部 | 返回、系统消息 | 否 | 否 |
| 全文消息流 | 主体 | 时间、正文、可选行动按钮 | 否 | 否 |
| 固定底栏 | 底部 | 联系客服、社区规则 | 否 | 否 |

本页不提供搜索、类型筛选、全部已读、独立通知详情或表单编辑。

## 3. 字段表

| 字段 ID | 显示名 | 类型 | 必填 | 取值范围 | 校验规则 | 默认值 | 可编辑 | 敏感级别 | 数据来源 |
|---------|--------|------|------|----------|----------|--------|--------|----------|----------|
| `APP-03-PAGE-notification-center-FIELD-title` | 消息标题 | string | 否 | 0-50 字 | 超长换行 | 无 | 后台模板配置 | 普通 | 系统消息模板 |
| `APP-03-PAGE-notification-center-FIELD-content` | 全文正文 | string | 是 | 1-2000 字 | 富文本白名单 | 无 | 后台模板配置 | 普通 | 系统消息模板 |
| `APP-03-PAGE-notification-center-FIELD-created-time` | 发送时间 | datetime | 是 | datetime | 展示到分钟 | 无 | 不可编辑 | 普通 | 消息记录 |
| `APP-03-PAGE-notification-center-FIELD-action-text` | 行动文案 | string | 否 | 0-10 字 | 有跳转目标时展示 | 无 | 后台模板配置 | 普通 | 系统消息模板 |
| `APP-03-PAGE-notification-center-FIELD-action-target` | 跳转目标 | string | 否 | 白名单路由/H5 | 与行动文案同时存在 | 无 | 后台模板配置 | 普通 | 系统消息模板 |

## 4. 操作表

| 操作 ID | 操作名 | 位置 | 触发条件 | 前置权限 | 二次确认 | 成功态 | 失败态 |
|---------|--------|------|----------|----------|----------|--------|--------|
| `APP-03-PAGE-notification-center-ACT-open-target` | 立即参与/立即分享 | 消息卡底部 | 消息存在有效跳转目标 | `GLB-ROLE-app-user` | 否 | 打开对应社区内容 | 目标失效提示内容不可用 |
| `APP-03-PAGE-notification-center-ACT-service` | 联系客服 | 固定底栏 | 任意 | `GLB-ROLE-app-user` | 否 | 打开客服能力 | 能力不可用提示稍后重试 |
| `APP-03-PAGE-notification-center-ACT-community-rule` | 社区规则 | 固定底栏 | 任意 | `GLB-ROLE-app-user` | 否 | 打开社区规则全文 | 加载失败可重试 |

## 5. 状态与异常

| 状态类型 | 触发场景 | 页面表现 | 用户可做的操作 | 引用 |
|----------|----------|----------|----------------|------|
| 加载态 | 首次进入 | 全文卡片骨架 | 等待 | 通用态 |
| 空态 | 无系统消息 | 暂无系统消息 | 返回 | 通用态 |
| 错误态 | 加载失败 | 错误提示与重试 | 重试 | 通用态 |
| 无权限态 | 未登录 | 返回登录 | 登录 | `GLB-ROLE-app-user` |
| 业务态 | 存在消息 | 按时间倒序展示全文卡 | 阅读/跳转 | `M03-RULE-system-notification-scope` |
| 降级态 | 跳转目标失效 | 正文仍完整展示，按钮置灰 | 阅读/返回 | 通用态 |

## 6. 查询与验收

- 默认按发送时间倒序，每次加载 20 条。
- 进入页面后将当前系统消息会话置已读，不提供批量“全部已读”。

```text
AC-ID: APP-03-AC-system-message-fulltext
Given 用户从消息首页点击系统消息
When 页面加载成功
Then 直接展示全文消息流，不出现类型筛选、全部已读或独立通知详情页
```
