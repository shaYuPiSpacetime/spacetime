## 1.1 本需求旧版本隔离规则

本需求此前已存在旧代码、旧技术方案和旧测试用例，但用户已明确旧版本口径错误。本轮后续推进时：

| 类型 | 处理规则 |
|------|----------|
| 旧代码 | 不作为正确实现依据；实现阶段只用于定位需要替换、删除或重写的落点 |
| 旧技术方案 | 不参考、不继承、不局部续写；以本轮冻结 PRD 和本轮技术方案重新输出为准 |
| 旧测试用例 | 不复用、不补丁式维护；技术方案确认后重新生成测试用例 |
| 旧 SQL/权限脚本 | 不默认可信；只作为现状盘点对象，最终以本轮表设计和迁移脚本为准 |

不得因为旧版本中已有同名接口、页面、表或测试，就默认其符合当前需求。
