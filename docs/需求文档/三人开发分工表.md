## 1. 分工前提

1. 移动端前端代码由专人负责，不纳入本次 A/B/C 三人分工。
2. A/B/C 三位同学均负责各自模块的后端接口、管理后台页面和移动端接口支持。
3. 分工以领域边界清晰、减少交叉为原则。
4. 公共字典、权限点、通知类型、成家币流水类型需要提前统一。
