# 未认证与基本资料蓝湖闭环实施计划

> 日期：2026-08-04
> 设计基线：蓝湖 `未认证`、`认证-基本资料`、`认证-基本资料-家乡`

## 目标

- 将未认证主按钮圆角修正为蓝湖 13.5px 基线。
- 将基本资料原子字段组合为现居地、身高/体重、家乡三类业务行，并按设计稿分组。
- 字段弹层打开时只展示弹层“确定”，不叠加页面级“保存/下一步”。
- 新账号及历史空昵称账号由服务端生成稳定默认昵称，前端仍允许点击修改。

## 实施步骤

1. 先补小程序静态门禁和后端单测，覆盖圆角、组合行、卡片分组、弹层按钮互斥和默认昵称。
2. 增加基本资料展示领域模型，保证接口字段顺序变化不会影响 UI 分组。
3. 改造基本资料卡片及地区、身高体重选择器，继续使用运行时字典与地区接口。
4. 在登录及基础资料查询链路补齐默认昵称并持久化。
5. 运行目标测试、完整小程序构建、后端单测与微信开发者工具截图验收，记录差异和结果。
