# 用户准入资料认证小程序动态配置接入 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 按 `2026-07-07-用户准入与资料认证初始化-mobile-api-handoff.md` 接通小程序登录、首登五步、资料编辑、认证中心和审核型资料，并确保业务枚举、展示标签、流程文案和提示文案来自后端字典/运行时配置或业务接口响应。

**Architecture:** 后端扩展 `/miniapp/dict/profile-options` 和 `prd01.copy.rules` 的可运营配置覆盖面；小程序新增强类型 PRD01 API 层、运行时配置 Store 和纯领域适配器。页面只持有 `code`，展示 `label`；流程状态以 `init-status/init-step` 和各详情接口为准，不在页面自行拼业务规则。

**Tech Stack:** Java 21、Spring Boot 3.4、MyBatis-Plus、MySQL、React 18、TypeScript、Taro 4、Zustand、Node Test Runner、JUnit 5、MockMvc。

## Global Constraints

- 业务接口只传/只存 `code`，中文展示必须读取 `/miniapp/dict/profile-options` 或业务详情接口返回的 `*Label`。
- 所有准入、首登、认证、上传和开放文本提示优先读取 `/miniapp/config/prd01.copywriting`；`enabled=false` 时隐藏，不在页面写中文兜底文案。
- 后端返回的 `msg`、`rejectReason`、`blockedReason/blockReasons`、`educationSlaText` 和关于我 `questions[].title/placeholder` 直接作为动态文案使用。
- 首登仅以 `initFields`、`nextStep`、`firstLoginCompleted` 和 `/miniapp/profile/init-step` 返回值推进，不接 `/miniapp/profile/init-complete`。
- 地区按 `/miniapp/dict/locations` 逐级懒加载并提交行政区 code；不得提交“当前位置”等展示字符串。
- 上传限制读取 `uploadLimits`；未提供真实上传接口时禁止把本地临时路径当作公网 URL 提交。
- 不接入文档第 12 节旧兼容接口。
- 保留现有蓝湖页面结构和真实可见组件，不使用透明热区或截图冒充交互。
