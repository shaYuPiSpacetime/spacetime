# 学历锁定字段误拦截 Implementation Plan

> 执行：使用 executing-plans 在当前会话逐项落地；完成后按 requesting-code-review 做只读审查。

**Goal:** 已认证且历史快照缺字段的用户正常保存未修改的基本资料，同时阻止真正篡改认证字段。

**Tech Stack:** Taro/React/TypeScript；Java21/Spring Boot3.4/JUnit5/Mockito。

- 不改变两级地区或聊天行为；不批量改写历史认证材料。
