# 千寻同校信息流实施计划

**目标：** 在成家信息流的“同城”右侧增加“同校”，展示与当前用户学校相同的已发布动态，并发布小程序。

**方案：** 继续使用社区首页入口配置控制标签和顺序，新增 `same_school` → `SCHOOL` 场景。后端优先比较学校编码；任一方缺少编码时，以相同学校全称兼容历史资料。当前用户未填写学校时返回空页，不退化为同城或热门。沿用现有登录、作者屏蔽、内容发布状态和分页规则。

**影响范围：** `backend/` 社区信息流、生产配置迁移与部署；`miniapp/` 成家二级标签、空态和发布包。无新图片资源。

**成功标准：** 同校按钮位于同城和热门之间；点击后请求 `scene=SCHOOL`；有编码、历史名称、无学校三类情况筛选正确；其他场景不变；生产配置返回四个标签；小程序上传结果可核验。

**授权边界：** 用户已明确要求修改、Push 并发布小程序；生产后端和入口配置需先于小程序发布。
