# PRD-05 蓝湖最终口径对齐实施计划

> **执行要求：** 逐项按测试先行方式完成，先建立静态契约并确认失败，再更新 PRD、Demo 和最终缺失清单。

**目标：** 将 UI 已确认的 12 项结论落入正式 PRD 与静态 Demo，删除收藏功能，并把蓝湖缺失页面清单收敛为仅含当前最终结论的文档。

**验证方式：** 新增最终口径静态校验脚本，复用现有 Demo 校验；启动静态服务后用 Playwright 截图并检查页面交互。当前内置浏览器无可用实例，因此页面验收使用仓库现有 Playwright 能力。
