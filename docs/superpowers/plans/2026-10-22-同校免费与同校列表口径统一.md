# 同校免费与同校列表口径统一 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 让悄悄话同校免费资格与现有同校信息流使用完全相同的 `app_user` 学校投影匹配规则。

**Architecture:** 保留 `VerifiedSchoolPairService` 作为费用资格唯一入口，但将其数据源从有效学历认证和学校字典切换为调用方已经加载的 `AppUser` 学校投影。报价与创建继续复用同一服务，资格变化仍由服务端指纹和现有报价复验拦截。

**Tech Stack:** Java 21、Spring Boot 3.4、JUnit 5、Mockito、AssertJ。

## Global Constraints

- 仅在 `master` 修改、提交和推送。
- 不改同校信息流查询、不新增接口、不新增数据库迁移。
- 保留双方交友权限 `OPEN` 门槛及现有悄悄话安全校验链路。
- 使用 TDD，先看到新增用例失败，再修改生产代码。
