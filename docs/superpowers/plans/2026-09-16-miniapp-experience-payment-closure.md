# 小程序资料、互动、支付与推荐问题闭环计划

**目标：** 修复用户反馈的头像更换、评论举报、支付与客服、分享弹窗文本及推荐偏好滑块问题。

**方案：** 按资料、社区、商业、推荐四条独立链路定位真实失败点；每条链路先建立失败证据，再做最小修复。支付以服务端报价和微信渠道实际回执为准，不绕过支付平台限制。

**影响范围：** `miniapp/`，以及经排查确需修改的 `backend/` 支付或举报接口；不涉及生产数据修改。

**成功标准：** 对应回归用例通过，小程序构建通过；未支付订单可关闭提示并重新尝试支付；会员和千寻币调价后使用最新配置下单；客服入口能明确说明当前是否可进入会话。

**授权边界：** 本轮仅授权代码修复与验证；不提交、不 Push、不发布体验版或生产环境，不发起真实支付。
