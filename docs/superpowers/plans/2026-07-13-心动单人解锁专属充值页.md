# 心动单人解锁专属充值页 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 将心动单人解锁的“只看ta”入口改为独立千寻币充值页，并按蓝湖 `ffa585ea-0136-407a-9930-ae8c26da0128` 还原。

**Architecture:** 新页面放在 `pages/coins` 分包，独立承载场景视觉和路由；仅复用 `useCoins` 的余额、套餐和支付能力，不复用“我的-千寻币”页面组件。蓝湖展示兜底套餐使用负 ID，接口不可用时只展示、不创建订单。

**Tech Stack:** Taro 4、React、TypeScript、微信小程序、现有支付服务与 OSS 图标清单。

## Global Constraints

- 目标视口为蓝湖 750×1624，对应小程序 375×812。
- 页面按钮、套餐卡、协议勾选必须是可见真实组件并绑定事件。
- 通用 `/pages/coins/index` 保持不变。
- 心动场景路由固定为 `/pages/coins/unlock-recharge?sourceScene=likes_unlock_one`。
- 不自动提交 Git。
