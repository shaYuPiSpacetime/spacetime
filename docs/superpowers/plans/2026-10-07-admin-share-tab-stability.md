# 管理订单、社区入口与小程序展示修复计划

**目标：** 管理后台仅展示已支付订单；手机号名单用于时空站台工作人员；千寻互动无默认女性头像闪现；游客可浏览分享主页；推荐与其他底部 Tab 共用数字状态。

**方案：** 在服务端限定订单状态；保留旧配置键及已有号码，将名单改作时空站台发布权限，心灵搭子展示全员普通动态；复用审核通过的公开资料投影提供游客只读接口；推荐数字由共享状态维护，首页不重复绘制底部栏。

**影响范围：** `backend/`、`frontend/`、`miniapp/`；不改历史订单和用户资产。

**成功标准：** 订单查询无法返回未支付状态；配置姓名与实际用途一致；游客主页不触发登录拦截，互动时保存目标并进入登录；切换 Tab 或短暂请求失败不把已知推荐数字重置为 0。

**授权边界：** 用户已确认游客先看主页、名单改作时空站台工作人员用途；按项目规则同步、提交及 Push master、上传体验版、核对管理端与后端部署。

- [x] 订单列表及用户近期订单只查支付成功，管理端移除未支付筛选。
- [x] 社区入口配置使用时空站台文案及工作人员白名单；心灵搭子普通动态不按名单过滤。
- [x] 千寻互动优先使用当前用户头像，姓名与头像独立于互动列表加载。
