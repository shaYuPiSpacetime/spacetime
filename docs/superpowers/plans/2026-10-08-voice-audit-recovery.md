# 语音审核失败恢复

**目标：** 微信机审调用失败不伪装成持续审核；失败语音不公开，用户可重新录制提审，成功回调链路保持不变。
**范围：** `VoiceIntroServiceImpl`、微信内容安全适配器、统一审核条件失效接口、小程序语音提交反馈，以及相关定向回归。
**授权：** 用户已要求修复、提交、Push、发布；恢复本次明确定位的旧失败记录，保留审核历史，不批量修改其他账号、不直接通过审核。

- [x] 先复现凭证错误、Provider 异常/空响应后错误保留待审，以及旧无任务记录挡住重提。
- [x] 凭证失效仅刷新缓存并重试一次；语音失败转为已失效并允许重提，不把服务异常判为内容违规。
- [x] 超过五分钟的机审待审且无有效异步任务，在读取/提交时条件式恢复；已通过或真实异步待审不改动。
- [x] 统一审核失效使用状态比较更新并留 SYSTEM_EXPIRE 历史，避免覆盖并发通过。
- [ ] 小程序展示失败原因，保留录音草稿供重提；构建新体验版，提交 master、Push、核对服务部署。
- [ ] 恢复指定旧记录时核对原状态与错误任务，并写完整审核历史；不得发布未经审核的旧音频。

**验证：** 针对 VoiceIntroServiceImplTest、微信 Token 回归、统一审核与 DAO 状态比较的 Java 测试，以及小程序语音分支与产物门禁；不运行全仓测试。

**执行记录：** 初次定向回归验证失败语音和失效凭证缺少重试的红灯；实现后语音回归、微信凭证缓存隔离、内容安全映射与条件更新回归通过。小程序真实提交函数的失败/受理两分支通过，体验版构建及页面注册、开发登录隔离、包体门禁通过。统一审核测试类已有学历通过用例缺少用户 DAO 依赖导致空指针，本次不修改无关用例，只执行新增恢复用例。

**运维收尾：** Push 后核对同一提交的后端部署结果，再精准恢复本次旧失败记录并核对系统审核历史；不直接通过语音审核。体验版通过微信开发者工具 CLI 上传，不等同正式审核上架。
