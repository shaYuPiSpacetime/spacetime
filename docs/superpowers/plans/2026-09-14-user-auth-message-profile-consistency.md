# 用户认证、消息与资料一致性修复实施计划

**目标：** 完成已确认问题的代码修复、迁移、自动化测试和测试报告。

**技术路线：** 后端以审核记录为认证事实源，以 `app_user` 为审核通过后的查询投影；小程序将编辑态和公开预览态分离，所有流程状态只消费真实接口数据。

## 任务

1. 为学历字段锁定和审核投影编写失败测试，再实现服务端守卫与审核通过投影；因尚未上线，不做历史数据迁移。
2. 为驳回图片/文字的预览过滤编写失败测试，再拆分编辑态与预览态数据。
3. 为消息首页真实数据守卫编写失败测试，再移除非 mock 硬编码摘要。
4. 为 `CORE_BLOCKED` 分类编写失败测试，再修正首页准入分支。
5. 为短信 Provider 和 Redis 验证编写失败测试，再恢复真实发送链路。
6. 为 LiteChat 幂等退出、初始化超时恢复和错误传递编写失败测试，再修正连接生命周期。
7. 更新院校文案；验证在校生行业、职业、公司仍非必填，不新增“学生”行业项。
8. 先编写实名认证锁定性别和出生日期的失败测试，再实现字段禁用与服务端防绕过。
9. 运行相关后端 JUnit、小程序 Node 测试和构建检查，输出测试用例与测试报告。
