# 心动访客会员独立页 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 将“解锁全部访客”改为进入独立的「时空邂逅会员」蓝湖页面，并闭环相互喜欢入口和单人千寻币解锁跳转。

**Architecture:** 在 `pages/heart` 分包新增独立 `membership-unlock` 页面，只复用业务数据 hook、基础人物素材与支付能力，不复用 `pages/membership/index.tsx` 的会员中心布局。心动页头部图标改为 OSS 无损图标并在可见图标本体绑定跳转；单人解锁按钮携带 `likes_unlock_one` 场景进入千寻币充值页。

**Tech Stack:** React 18、TypeScript、Taro 4.1.9、微信小程序、项目内静态门禁脚本、OSS 原字节上传脚本。

## Global Constraints

- 设计基线：蓝湖 `image_id=c2cf99b4-3edd-4535-9ad9-ae9d39e594bc`，画布 750×1624。
- 关键首屏还原度必须不低于 97%，整体还原度必须不低于 95%。
- 新页面不得复用 `/pages/membership/index` 的 UI 结构，只允许共享业务 hook、类型和素材。
- 非底部静态图标必须使用 OSS 公网 URL；源文件保持至少 2x，无损原字节上传。
- 按钮、套餐卡、协议、底部支付条必须使用真实组件和真实事件，禁止整页截图与透明热区。
- 所有用户可见文案、注释和文档使用中文。
