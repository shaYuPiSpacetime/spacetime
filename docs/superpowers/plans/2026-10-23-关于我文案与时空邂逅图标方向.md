# 关于我文案与时空邂逅图标方向 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 将“关于我”的两个分类标题更新为“心愿”“小习惯”，并让底部“时空邂逅”默认态与选中态图标开口统一朝下。

**Architecture:** 只修改小程序展示配置，不改变分类键、题目键、接口或历史数据。底栏通过给“时空邂逅”配置 `rotate(180deg)` 并在两张常驻图标上共同应用，保留既有透明度切换防闪烁结构和原始 PNG 哈希。

**Tech Stack:** Taro、React 18、TypeScript、Node.js `node:test`/静态闭环断言。

## Global Constraints

- 只在 `master` 分支实施并同步 `origin/master`。
- “关于我”只改展示标题，不修改键名、字段、接口和存量数据。
- 两态图标均翻转，现有图片资源、尺寸、哈希和透明度切换机制保持不变。
- 仅提交本任务文件，不混入工作区已有删除、临时文件和构建缓存。
