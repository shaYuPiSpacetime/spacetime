# 知音双动态与运营权限实施计划

> **For Codex:** REQUIRED SUB-SKILL: Use test-driven-development to implement this plan task-by-task.

**目标：** 将“心灵搭子”和“时空站台”统一为同一套动态卡片 UI；心灵搭子只展示后台配置手机号对应账号的普通动态；时空站台仅允许后台启用的工作人员账号发布。

**架构：** 继续复用 `community_post` 与 `sincere_post` 两类社区内容，不新增业务表。心灵搭子通过私有 `app_config` 手机号列表解析作者 ID 后查询 `community_post`；时空站台发布时以小程序用户手机号匹配启用的 `sys_user` 工作人员。小程序只接收派生后的发布能力布尔值，不接收手机号配置。

**技术栈：** Java 21、Spring Boot 3.4、MyBatis-Plus、React 18、TypeScript、Taro、JUnit 5、Node.js 静态契约测试。
