# 关于我文案与时空邂逅图标方向设计

## 背景与目标

本次调整聚焦两个纯展示问题：个人资料“关于我”中的两个分类名称不符合当前产品口径，以及底部“时空邂逅”图标的开口方向需要改为向下。调整不改变既有业务字段、接口、数据或导航行为。

## 调整范围

### 关于我分类文案

- “我的故事”展示为“心愿”。
- “我的日常”展示为“小习惯”。
- 分类键、题目键、已保存回答和接口参数保持不变，不做数据迁移。
- 仅修改分类标题，不修改“补充更多关于我的故事”等其他独立文案。

### 底部时空邂逅图标

- “时空邂逅”的默认态和选中态图标都旋转 180 度，使开口统一朝下。
- 保留现有两张 PNG 图标、显示尺寸及资源哈希，不重新切图、不新增 OSS 资源。
- 保留默认态与选中态图片同时挂载、通过透明度切换的现有实现，避免切换时闪烁。
- 其他底部菜单图标不受影响。

## 实现位置

- `miniapp/src/domain/profileAboutVisibility.ts`：更新“关于我”分类标题。
- `miniapp/src/components/AppTabBar/index.tsx`：为“时空邂逅”配置图标变换，并同时应用于默认态和选中态。
- `miniapp/scripts/test-profile-edit-closure.cjs`：增加分类新文案及旧文案消失的回归断言。
- `miniapp/scripts/test-tabbar-lanhu-closure.mjs`：增加“时空邂逅”两态图标方向及无闪烁结构的回归断言。

## 验收标准

1. 个人资料“关于我”外层分类显示“心愿”和“小习惯”，原有回答仍在原分类中正常展示和编辑。
2. 底部“时空邂逅”默认态、选中态图标开口都朝下，选中切换不闪烁。
3. 其他分类、题目、底部菜单样式和点击行为没有变化。
4. 关于我闭环测试、底栏蓝湖闭环测试和小程序构建通过。

## 非目标

- 不修改“关于我”的数据模型、审核状态或编辑权限。
- 不迁移或重写用户历史回答。
- 不调整底部菜单布局、尺寸、路由和角标逻辑。
