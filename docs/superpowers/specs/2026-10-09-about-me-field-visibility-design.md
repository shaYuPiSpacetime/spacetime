# “关于我”字段按后台配置动态展示设计

## 目标

小程序“关于我”编辑页及资料编辑页摘要，按后台字段配置中的 `visible` 动态展示。后台关闭字段后，客户端不展示对应题目；重新开启后恢复展示，历史回答不删除。

## 方案选择

采用前端过滤方案（B）：后端 `/miniapp/profile/about-me` 保持返回完整问题列表，提交接口也不增加单字段限制。小程序加载 PRD-01 运行配置后，使用 `fieldSettings` 对题目进行展示过滤。

## 字段范围

| 字段 ID | 展示名称 | 分类 |
|---|---|---|
| `meetingPreference` | 见面偏好 | 我热爱的 |
| `preferredActivities` | 喜欢的见面活动 | 我热爱的 |
| `housingStatus` | 住房情况 | 我是谁 |
| `carStatus` | 购车情况 | 我是谁 |
| `childrenPlan` | 是否想要孩子 | 我的故事 |
| `hasChild` | 有无子女 | 我是谁 |
| `marriagePlan` | 结婚计划 | 我的故事 |
| `religion` | 宗教信仰 | 我是谁 |
| `smoking` | 吸烟情况 | 我的日常 |
| `drinking` | 饮酒情况 | 我的日常 |
| `pets` | 宠物态度 | 我的日常 |

## 客户端行为

1. 从现有 PRD-01 bootstrap/config 中读取 `fieldSettings`。
2. `visible=false` 的题目不出现在“全部”及所属分类列表中。
3. 没有可见题目的分类 Tab 不展示；“全部”仅在至少存在一个可见题目时展示。
4. 带 `topic` 参数进入已关闭题目时，回退到可见题目列表，不打开编辑框。
5. 资料编辑页的“关于我”摘要只展示可见题目；全部关闭时不展示该区块/入口。
6. 配置尚未加载或字段配置缺失时，沿用当前兼容行为，默认展示，避免旧配置导致全部题目意外消失。

## 非目标

- 不修改后端问题列表接口。
- 不限制已关闭字段的提交接口。
- 不删除历史回答或审核记录。
- 不调整题目文案、分类归属和审核流程。

## 测试

- 单元测试验证字段可见性过滤、缺失配置默认展示、空分类隐藏。
- 页面闭环测试验证“全部”和各分类只渲染可见题目。
- 小程序 TypeScript 类型检查及相关资料页回归门禁通过。
